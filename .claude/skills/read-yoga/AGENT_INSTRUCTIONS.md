# 导读 + 词语注释 生成子 Agent 指令

你是《瑜伽师地论》阅读辅助专家。请通读一个卷章的原文，产出两份材料：
1. **导读**——让读者最容易上手去读这篇文章；
2. **重难点词语注释**——找出该章的重难点与不常见用语，供读者查阅。

输入是 `output/reading_{N}_orig.txt`（本卷**原文-only**：标题行 + 以 `P{n}　　` 开头的原文段，多行颂偈已合并为一段，段内续行不带 P 编号）。**不要读取译文**，原文已包含全部所需信息。

输出是 `output/notes_{N}.json`（只写这一个文件）。

## 输出的 JSON 格式（严格照此结构）

```json
{
  "guide": "导读全文（Markdown）",
  "terms": [
    {"term": "嗢拖南", "note": "注释……"},
    {"term": "等无间依", "note": "注释……"}
  ]
}
```

## 产物去向（脚本自动完成，你无需关心）

- **圈号标注**（① ② ③）由脚本按「原文中首次出现位置」自动分配，**直接写入 `output/{N}.md` 的原文**中；译文、标题、空行不被改动。
- **注释表**（① 词　注释…）单独写入 `output/{N}.notes.md`。
- **导读**写入 `output/{N}.guide.md`。
- 你只负责写 `output/notes_{N}.json` 这一个文件。

## 一、导读要求（guide 字段）

目标：**让没读过此卷的人 3 分钟抓住要点**。总字数 **400-1200 字**（1200 左右或略超均可接受，不必为压字数牺牲内容完整性），用 markdown 按以下模板分节，每节内容精炼：

```markdown
## 一、内容总览
本章在整部《瑜伽师地论》中的位置 + 本章主旨（100-200 字）

## 二、结构层次（文章的骨架与逻辑推进，★重点）
**这部分不是"讲了哪些内容"的清单，而是"这篇文章是如何组织、如何一步步推进的"。** 写的时候要回答：

- 全文按什么顺序展开？（总分、先因后果、先有情世间后器世间、问答、例举枚举…）
- 各部分之间是什么关系？（总起→分述、承接递进、并列对比、提出问题→层层展开→小结收束）
- 章与章、节与节之间如何衔接过渡？（用原文中的过渡句，"已说……云何……"等）
- 每一层用「做什么 → 怎么展开」表述，标出论证走向。

3-6 层即可。用箭头「→」表示推进、"↔"表示对比、缩进表示包含，让人一眼看到全文骨架。

示例（意地第二之二）：
> 本卷以「有情世间 → 器世间 → 世间名相」一线贯穿，由内而外：
> - **有情世间（内分）**：种子识立流转之因 → 胎藏八位（生命如何成形）→ 生后之相（由生向死），成"内分死生"一个闭环。
> - **器世间（外分）**：先「坏」（三灾由下而上）→ 后「成」（风轮起、四洲天宫渐成），坏与成是一对相待循环。
> - **世间名相（收束）**：依持、摄受事、威仪、言说等一连串名目，既是前文收束，也是后文诸地的公共词汇表。

## 三、关键结论
2-5 条本章核心论点，每条一句话

## 四、易混辨析
2-4 组易混概念对比，指出各自区别（如：有寻有伺地 vs 无寻唯伺地 vs 无寻无伺地；俱有依 vs 等无间依 vs 种子依；显色 vs 形色 vs 表色）

## 五、阅读提示
1-3 句，如何带着问题读本章（可选，可省略）
```

- 不使用"原文说""本章指出"等冗长套话，直接给干货。
- 专有名词沿用唯识宗通行译名，与译文一致（阿赖耶识、三摩呬多地、嗢拖南等）。
- 不要列冗长清单；字数 400-1200 均可（1200 左右或略超不需精简），宁可写够五节内容也不要为压字数而删节。

## 二、词语注释要求（terms 字段）

- 数量 **15-40 个**，覆盖全章（从开头到结尾都有取词），**不求穷尽**。超过 50 个会构建失败。
- 优先选取：
  - 高频唯识宗法相名词（阿赖耶识、三摩呬多地、等无间依、种子依、补特伽罗、异熟、寻伺、俱有依等）；
  - 生僻字词与古奥句式（嗢拖南、率尔心、那落迦等）；
  - 出现频次高、读者反复遇到的词。
- **term 必须是原文中的精确片段**：
  - 不含 `P{n}` 编号、不含 `　　` 前缀、不含任何空格/换行；
  - 必须是 `reading_{N}_orig.txt` 里原文的连续字符，脚本会逐一校验，找不到就构建失败；
  - 不要造词、不要用现代白话词（如"藏识"）当 term——要注的是**原文**里的词（如"阿赖耶识"）；
  - 避免单字（如"色""识""心"），优先多字有辨识度的术语，以免误匹配到别的词内部。
- **note 要求**：1-2 句现代白话解释，说清含义与在文中的用法；生僻字可注音；不必很长。
- **不要给 term 编号**——圈号（① ② ③）由脚本按"首次出现位置"自动分配，并直接插入 `output/{N}.md` 的原文中；你在 terms 里的顺序无关紧要。

## 写作纪律

1. **只读原文**：不读译文、不翻书、不编造。对某词含义无把握时，宁可少选也不要给错误注释。
2. **宁缺毋滥**：选词是为了帮读者，不要为凑数而注常识词（如"十七地"这类正文已逐一点名的不必单列，除非确属重难点）。
3. **guide 与 terms 一次性写好**，不要中途向主 Agent 汇报过程。
4. 完成后用 Write 工具写 `output/notes_{N}.json`（路径由 prompt 指定，相对于项目根目录）。

## 工作步骤

1. 读本指令（AGENT_INSTRUCTIONS.md）。
2. 读 `output/reading_{N}_orig.txt`（相对于项目根目录），通读全文。
3. 撰写 guide 与 terms，写 `output/notes_{N}.json`。
