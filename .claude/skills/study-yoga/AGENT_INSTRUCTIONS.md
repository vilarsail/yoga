# study-yoga 交互学习网页 · 内容撰写规范

你的任务：为《瑜伽师地论》某一卷生成一个**单文件、零依赖的交互式教学网页**，输出到 `study/{N}-study.html`。读者是没有佛学基础、被文言吓退的成年人，目标是让他**不读原文也能弄懂这一卷在说什么**。

## 输入与输出

- 输入：`output/{N}.md`（校对版，文言原文 + 白话译文对照，含圈号标注 ① ②）。**全文通读后再动笔。**
- 骨架模板：`.claude/skills/study-yoga/template.html`——CSS、固定 JS（进度条 / initStepper / initSorter）、HTML 外壳**原样复制，一字不改**，只替换占位符与 `{{SECTIONS}}`、`{{CUSTOM_JS}}`。
- 输出：`study/{N}-study.html`，一个完整自包含 HTML 文件。

## 占位符填写

| 占位符 | 内容 |
|---|---|
| `{{PAGE_TITLE}}` | 《瑜伽师地论》卷N · 交互式学习模块 |
| `{{KICKER}}` | 卷首副题，如「瑜伽师地论 · 本地分中意地第二之三」 |
| `{{HERO_TITLE}}` | 卷第N · 交互式学习模块 |
| `{{HERO_SUB}}` | 用 1-2 句话概括这一卷的本质（例：「这一卷是一部佛教现象学分类总表……」） |
| `{{HERO_TAGLINE}}` | 「X 个主题 · Y 个学习步骤 · Z 组案例」（X=章节数，Z 为全页案例块总数，必须 ≥15） |
| `{{NAV_LINKS}}` | `<a href="#s1">① 主题名</a> …` 一行一个主题，按章节数生成 |
| `{{PATH_STEPS}}` | 5-6 个 step-item（见下） |
| `{{CHAPTER_NUM}}` | N（数字），用作 localStorage key |
| `{{SECTIONS}}` | 全部章节 HTML（见内容规范） |
| `{{FOOTER_NOTE}}` | 基于《瑜伽师地论》卷第N（output/{N}.md 重译校对版）制作 · 交互式学习模块<br>比喻仅作理解辅助，法义以原文为准 |
| `{{CUSTOM_JS}}` | 本章定制交互 JS（stepper 数据、simulator、sorter 数据等） |

### PATH_STEPS 格式（data-target 指向导航锚点）

```html
<div class="step-item" data-target="#s1"><label><input type="checkbox" data-step="1"><span class="no">1</span><span class="txt"><b>步骤标题</b><span>一句话说明这一步做什么、对应哪个章节</span></span></label></div>
```

- 5-6 步，由易到难；最后一步通常是「收官总纲/偈颂」。
- 每个 step 的 data-target 指向对应 section 的 id。

## 章节内容规范（{{SECTIONS}}）

### 总体结构

按该卷实际内容划分 **6-9 个主题章节**，每章：

```html
<section class="chapter" id="sK">
  <div class="sec-head"><span class="num">0K</span><h2>主题名</h2></div>
  <p class="sec-lead">引导段：这一部分在回答什么问题，为什么重要。</p>
  <div class="card">…</div>
  …
  <div class="divider"></div>
</section>
```

### 卡片内部的三件套（每张核心概念卡必须有）

1. **quote**（原文引用）：从 `output/{N}.md` 原文中**逐字摘取** 1-2 句关键文言（可含圈号），附 `<span class="src">—— 卷N原文</span>`。引文必须是原文精确子串。
2. **plain**（一句话总结）：绿色块，一句大白话说清结论。
3. **analogy**（比喻）：金色块，用现代生活事物作比喻。比喻必须映射准确——比喻只帮理解，不可扭曲法义；拿不准的义理不用比喻，直接用译文释义。

### 案例块（本 skill 的核心要求）

每章至少 **2 个 `.case` 案例块**，全页合计 **≥15 个**。案例 = 用具体、现代、日常的场景把抽象义理落地的短段：

```html
<div class="case"><b>场景名：</b>具体描述——某人在某时某地做某事，这正对应原文的某个道理（点明对应关系）。</div>
```

案例要求：
- **具体**：有时间、有人物/事物、有过程，不用「例如某某」式的空泛套话。
- **现代**：用读者身边事（通勤、做饭、刷手机、开会、健身、哄孩子），也可用论中自带的古代例子（如钻木取火），但现代例子不少于一半。
- **准确**：案例与义理的对应关系要点明，不牵强。
- 案例可放在 card 内、fn-card 的 back 里、analogy 之后，或独立成块。

### 交互组件（每章 ≥1 个，全页 ≥4 个，类型至少 3 种）

| 组件 | 适用内容 | 用法 |
|---|---|---|
| **fn-card 翻转卡** | 成组的概念/分类/关系 | grid 里放 4-8 张卡，正面 `cn`=术语、`sub`=一句话，背面=展开解释+`em` 比喻或案例 |
| **initStepper 流程推演** | 有先后顺序的过程 | 一个日常场景走完整条链，每步 `{t:'标题', d:'<b>术语（定义）：</b>解释'}`，最后一节点题收束；在 `{{CUSTOM_JS}}` 中调用 |
| **条件模拟器** | 「X 生起需要哪些条件」 | 3 个左右开关（cond-row + switch），拨动开关影响结果；`{{CUSTOM_JS}}` 中写 bespoke 处理函数（参考样式 id=condResult），结果分「全部满足/缺某条」多种文案 |
| **initSorter 归类练习** | 分类判断（善/恶/无记、染/净等） | `items:[{a:'场景', opts:['A','B','C'], ans:'B', exp:'原因'}]`，5 条左右，场景全部来自现代日常 |
| **timeline** | 阶段/分位/次序 | 3-5 个节点，t=名称，d=解释 |
| **yuan-grid 对比卡** | 并列的多类事物 | 3-5 张卡，y-tag=类别标签 |
| **dict 折叠字典** | 清单式枚举段落（可跳过内容） | summary 注明「可跳过」，body 保留全部分类条目 |
| **ety 词源卡** | 「故名为X」词源段 | zi=字，gc=文言引文，bhu=白话解读；无词源段的卷可省略 |
| **gatha 偈颂** | 卷末嗢拖南/总纲颂 | lines=颂文（含空格对齐），mean=逐句白话+点明结构作用 |
| **table.nine 对照表** | 术语↔通俗理解映射 | 表头三列：名相 / 出处成员 / 通俗理解 |

### 内容忠实性规则

- **所有法义以 `output/{N}.md` 为准**，义理解释可参考该卷白话译文；不得引入该卷没有的教义（不引用其他论典、不做宗派比较）。
- 文言引文必须是原文精确子串（含圈号亦可），每章 1-3 条，宁少勿错。
- 术语首次出现给出白话定义（「四大种：地水火风——即坚、湿、暖、动四种属性」式的定义句）。
- 圈号 ①② 在页面中直接显示无妨（表示「原文有注释，见 output/{N}.notes.md」），不必解释。
- 若该卷是长清单/枚举型内容，枚举主体放 dict 折叠区，正文章节只讲清单背后的**结构与逻辑**。

### 章节划分建议（按卷型套用）

- **论义型**（如意地卷）：总地图 → 核心概念 A → 核心概念 B → 心识/条件 → 时间因果 → 分类字典 → 词源彩蛋（如有）→ 收官偈颂。
- **清单型**：总地图 → 清单的结构逻辑（讲「怎么读清单」）→ 重点条目拆解 → 分类字典（全部条目）→ 收官。
- 每卷必有：开头的「全卷地图」章节（讲清这一卷在整个本地分中的位置、和前一卷的衔接）+ 结尾的「收官」章节（偈颂 + 结构回顾）。

### CUSTOM_JS 要求

- stepper 数据、sorter 数据、simulator 处理函数全部写在 `/* @@CUSTOM_JS@@ */` 位置。
- 模板里 `renderPath();` 必须保留在最后；定制初始化写在它之前。
- 定制 JS 中避免与模板保留名冲突：`loadProgress/saveProgress/renderPath/initStepper/initSorter`。

## 质量自检（写完后逐项过一遍）

1. 无 `{{` 残留占位符。
2. 无 quiz/测验区块（本 skill 不产出自测题）。
3. 导航每个锚点都有对应 `id="sK"`。
4. 案例块 ≥15，每章 ≥2。
5. 交互组件 ≥4 个、类型 ≥3 种，且都初始化（CUSTOM_JS 有调用）。
6. 每张核心概念卡有 quote + plain + analogy 三件套。
7. PATH_STEPS 5-6 个，data-target 正确。
8. 学习路径第一步骤描述「看懂大地图」，与开篇章节对应。
9. 用浏览器打开不报 JS 错误（自行检查括号配对、id 拼写）。
