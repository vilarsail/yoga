02

业的五种果实：兑现成绩的五个端口

「与果门」是业的第一扇门：业造下之后，从五个端口输出成果。同一桩业，可能同时或先后从多个端口发货——换身体、带习惯、改环境、今生到账、利益旁人。

五端口总览

与果门者。有五种应知。一与异熟果①。二与等流果②。三与增上果。四与现法果③。五与他增上果④。—— 卷九原文
异熟果
换一个全新生命体去承受
→
杀生等不善业反复串习，果报在另一个生命形态上成熟——「于那洛迦中受异熟果」（那洛迦即地狱）。「异」指异时、异类：果报不在造业的当下、也不以原样身体出现。比喻：角色在大号里犯规到极点，系统不是在原角色身上扣血，而是给你换了个地狱难度的小号从头挨打。
等流果
同款配方，流类相等
→
从地狱出来生到人间，仍带着同类的苦与习气：寿短、贫穷、被诽谤、亲友乖离、贪嗔痴增盛……果与因「同类相续」，所以叫等流。比喻：同款手机换了新机，你还是在同一个 App 上刷到凌晨——习惯的「配方」会流到下一台设备。
增上果
环境画质随业改变
→
造不善业，感得的外在环境「光泽鲜少」，果实朽败零落、空无果实；善业则相反。业不只改变你，还改变你周围世界的成色。比喻：鱼缸水质——鱼的生活方式决定水的浑浊；业决定你缸里的「水」。
现法果
今生就兑现的一笔
→
「有二因缘。善不善业与现法果。一由欲解⑥故。二由事故。」态度拉到极致，或对象足够重大，业就当世报——详见第 03 章。比喻：定期存款到期兑付是常态，但金额够大、手续够重，可以当天到账。
他增上果
大人物的业是公共设施
→
佛所住国邑「必无疾疫灾横等起」，转轮圣王、住慈定菩萨亦尔；菩萨以大悲心施饮食财谷，「彼诸众生得安乐住」——他的业力外溢成众生的环境红利。比喻：路灯不收电费也不分你我家，路过的人都照亮。
异熟果管「你去哪投胎」，等流果管「你带什么出厂设置」，增上果管「世界对你什么画质」，现法果管「哪笔今生就报」，他增上果管「谁沾你的光」。

等流果：从地狱回来，一身「同款配置」

谓若从彼出来生此间。人同分中寿量短促。资财匮乏。妻不贞良。多遭诽谤。亲友乖离。闻违意声。言不威肃。—— 卷九原文
这份清单是十不善业道的「镜像回执」：杀生者人寿短，偷盗者资财乏，邪淫者妻不贞，妄语者多被诽谤，离间者亲友散，粗恶语者闻违意声，绮语者言不威肃，贪嗔痴者贪嗔痴更猛利——造什么业，就流出同类的果。
茶水间的「热心人」：小李习惯在 A 同事面前说「B 背后说你坏话」，又在 B 面前换一套说辞。半年后部门聚餐没人叫她——她把别人的关系搅散的同时，自己的关系网先散了。这正对应清单中的「亲友乖离」一条：造离间语，流出的正是同类的疏离之果。

增上果：业连「地图画质」都改

所感外分光泽鲜少。果不充实果多朽败。果多变改。果多零落。果不甘美。—— 卷九原文
增上果落在「外分」——环境与器物层面：土地贫瘠、果实败坏、收成不稳。「当知善业与此相违」，善业感得的是光泽丰饶、果硕味甘的外界。
两片苹果园：同一个村子、同样品种，山北果园的苹果年年虫蛀落果、酸涩瘦小，山南果园却果大味甜。人们常只归因于技术和土质，论中指出环境本身也是业的产物——增上果的差别；善业者的世界，连果子都更「光泽鲜洁」。

他增上果与损益门

犹如如来所住国邑必无疾疫灾横等起。佛神力故。无量众生无疾无疫。无有灾横。得安乐住。—— 卷九原文
业的力量可以外溢：圣者的善业成为众生共同享用的环境。「与果门」之外还有第二扇门「损益门」——依十不善业道建立八损害门：「一损害众生。二损害财物。三损害妻妾。四虚伪友证损害。五损害助伴。六显说过失损害。七引发放逸损害。八引发怖畏损害。」与此相违，依十善业道建立八利益门。
山区食堂计划：某公益人十年间在山区推动营养午餐，三十七所学校的孩子身高体重曲线明显改善——「由此因缘。彼诸众生得安乐住」。他的善业成了别人的环境红利，这正是「与他增上果」：如同佛所住国邑必无疾疫灾横。
两种「好朋友」：阿强出事时，朋友甲替他向警方作假证掩盖，朋友乙天天给他发网赌平台链接「带你回本」。前者对应八损害门的「虚伪友证损害」，后者对应「引发放逸损害」——损益门提醒：损害不只来自刀棒，更来自作伪的信用与放逸的通道。
03

现法果：什么业今生就报

四种果大多「隔期兑付」，但有一种例外——现法果，今生就能看到回响。原文给出两个触发条件：欲解（态度的极端程度）与事（对象的重不重要）。

开关一：欲解——态度拉到极致

与现法果者。有二因缘。善不善业与现法果。一由欲解⑥故。二由事故。—— 卷九原文
一有顾欲解。二无顾欲解。三损恼欲解。四慈悲欲解。五憎害欲解。六净信欲解。七弃恩欲解。八知恩欲解。—— 卷九原文
有顾欲解
顾恋身、财、所有 · 不善
→
「由增上欲解。顾恋其身。顾恋财物。顾恋诸有。造不善业。」怕失去身体、钱财、拥有的一切，于是不顾底线。对应案例见下。
无顾欲解
不顾身、财、所有 · 善
→
与有顾恰好相反：「不顾其身。不顾财物。不顾诸有。造作善业」——不计个人得失地行善，强度同样拉满，善果今生兑现。
损恼欲解
对有情蓄意伤害 · 不善
→
「于他有情补特伽罗。以增上品损恼欲解。造不善业」——对具体的人存心损恼，且达到「增上品」的强度。
慈悲欲解
对有情极深慈悲 · 善
→
同是对有情，翻成「增上品慈悲欲解造作善业」——同一台机器，两个方向。
憎害欲解
憎恨三宝等尊重事 · 不善
→
「于佛法僧。及随一种尊重处事。以增上品憎害欲解。造不善业」——对大众公认的尊重之处蓄意憎害。
净信欲解
于三宝增上净信 · 善
→
同一对象翻成「增上品净信欲解。造作善业」——对象重、态度正，善果今生到账。
弃恩欲解
背恩、欺诳、酷暴 · 不善
→
「于父母所。及随一种恩造之处。以增上品背恩欲解。欺诳欲解。酷暴欲解。造不善业。」对有恩之处反手加害。
知恩欲解
知恩、报恩 · 善
→
「于父母等。以增上品知恩欲解。报恩欲解。所作善业。」——与弃恩成对，报恩的善业今生受现法果。
欲解是对某事的强力执持与取向。八种正好四对，两两相反：顾恋与放下、损恼与慈悲、憎害与净信、背恩与知恩——强度相同，方向相反，果报都「今生到账」。
签字之前：某项目主管明知检测数据造假，仍签了字——不是不知道后果，而是「顾恋其身。顾恋财物。顾恋诸有」：怕丢职位、怕还不上房贷、怕失去这一切。这种对身财所有的极端执持就是「有顾欲解」，它是不善业今生受报的第一类加速器。
一对兄弟：母亲住院期间，哥哥伪造母亲签名转走存款（「以增上品背恩欲解。欺诳欲解。酷暴欲解。造不善业」），弟弟辞掉外地工作回家陪护（「以增上品知恩欲解。报恩欲解。所作善业」）。同一对父母、同一间病房，两种欲解两种业——原文特意把弃恩与知恩排成一对。

开关二：事故——对象本身重

五无间业⑦者。一害母二害父。三害阿罗汉。四破僧。五于如来所恶心出血。—— 卷九原文
或于天庙衢路市肆。立杀羊法。流行不绝。—— 卷九原文
或于有苦贫穷困乏无依无怙。为作归依施无畏已。后返加害。—— 卷九原文
五无间业是直接通向无间地狱的五种极重业；「无间业同分」是性质相近的重业——在公共场所立杀生的规矩且让它流行不绝、对施过无畏的人反手加害、劫夺僧门、破坏灵庙等。善业同样「由事重故受现法果」：「谓如有一母无正信。劝进开化安置建立于具信中」「或于起慈定者供养承事」——把母亲劝入正信、供养出定者与圣者僧，都是善的重事。
「固定栏目」：某直播间把虐待流浪猫做成每晚八点的收费栏目，观众订阅、打赏、定期「更新」。对应无间业同分中的「立杀羊法。流行不绝」：把伤害做成公开的、制度化的、持续流行的惯例——其重不在一次的伤害量，而在立法定制、流行不绝。
借住的朋友：小周把落魄的老同学接进家中住（「为作归依施无畏已」），一年后为争一笔拆迁补偿，抢先举报对方「非法居住」，断了对方生计（「后返加害」）。先给依靠再背后加害，原文将其列为无间业同分——对施过无畏的人反手，属于重事。

条件模拟器：拨一拨，看今生报不报

原文的逻辑：增上欲解与重事，二者居其一，业就今生兑现；方向还可翻转。拨动下面的开关试试。

增上欲解态度拉满：极端的顾恋、损恼、憎害、背恩（或反方向的无顾、慈悲、净信、知恩）
事缘重大对象是重事：五无间及其同分、父母恩处、三宝等尊重事
善向翻转同样的强度与重事，转向善的一边：无顾、慈悲、净信、知恩
04

什么业最重：六个权重，三种 bug

同样是错，为什么有的业「猛利极重」？本卷给出六种加权重的方式（业增上）；又指出三种让业系统跑偏的故障（业颠倒）——做错了不可怕，可怕的是连「做错了」这个判定都被篡改。

业增上：给业加码的六种方式

业增上云何。谓猛利极重业。当知此业由六种相。一加行故。二串习⑨故。三自性故。四事故。五所治一类故。六所治损害故。—— 卷九原文
权重一

加行

发动前的蓄势。「由极猛利贪嗔痴缠。及极猛利无贪无嗔无痴加行。发起诸业」——冲动脱口与蓄谋已久，力道天差地别。

权重二

串习

「于长夜中。亲近修习若多修习不善善业」——重复本身就是重量，无论善习恶习。

权重三

自性

业的种类自带等级：语四支中绮语最轻、妄语最重；身三支中杀生最重；意三支中邪见最重；施不如戒，戒不如修，闻不如思。

权重四

事

对佛法僧及尊重事「为损为益名重事业」——对象重大，损益都加倍。

权重五

所治一类

「一向受行诸不善业。乃至寿尽无一时善」——从始至终一路作恶，恶业一路到底。

权重六

所治损害

「断所对治诸不善业。令诸善业离欲清净」——把对治掉的不善翻成善的力量，是最有力的一种善。

于绮语。粗恶语为大重罪。于粗恶语。离间语为大重罪。于离间语。妄语为大重罪。—— 卷九原文
于施性戒性无罪为胜。于戒性修性无罪为胜。于闻性思性无罪为胜。—— 卷九原文
脱口而出与深夜小作文：同样是对同事不满，小赵当场顶了一句就完事；小钱憋了两个月，写下两千字匿名小作文群发，字字诛心。原文说重业起于「极猛利贪嗔痴缠……加行」——加行（发动前的蓄势）越深，业越重。脱口而出的力道，远不如蓄谋已久的精心构造。
第一支烟与十年烟枪：戒烟门诊里，抽了三天的人几乎说戒就戒；抽了二十年的人复吸率居高不下。对应「串习故者。谓如有一于长夜中。亲近修习若多修习」——重复本身就是重量，「长夜」级的串习把行为烧进了底层。
两个司机：一个常年压线抢行、从不觉得有问题（「一向受行诸不善业。乃至寿尽无一时善」——所治一类，恶习一路到底）；另一个撞人后彻底悔改，从此礼让行人还劝亲友守规（「断所对治诸不善业。令诸善业离欲清净」——所治损害）。前者恶业增长，后者的善业获得「所治损害」的重磅加成。
职场语言升级链：从开会讲无聊段子（绮语），到当面讥讽同事口吃（粗恶语），再到分别向两人转述对方的坏话（离间语），最后编造对方收回扣的截图（妄语）——原文升级链在职场里每天重演：越接近「凭空捏造」，罪越重。

业颠倒：三种把系统搞乱的方式

业颠倒⑩云何。此有三种应知。一作用颠倒。二执受颠倒⑪。三喜乐颠倒。—— 卷九原文
于余众生思欲杀害。误害余者。当知此中虽有杀生。无杀生罪。然有杀生种类杀生相似同分罪生。—— 卷九原文
谓如有一不善业道现前行时如游戏法极为喜乐。—— 卷九原文
作用颠倒——执行时对象搞错：想杀甲误杀乙，或对非有情之物「加刀杖已谓我杀生」，虽无根本罪，但结「同分罪」；执受颠倒——见解层面把账本改掉：主张「无施无爱乃至广说。一切邪见」，无罪无福；喜乐颠倒——情绪层面倒挂：作恶不但不苦，反而「如游戏法极为喜乐」。下面用几道归类练习练一练。
05

业的分类总柜：一张不可怕的清单

本卷中段有一大段「业差别」，一口气列了十几组分类坐标。别急着背——先看懂它的结构逻辑：每一组都是一条「查询轴」，任何一桩业都能在每条轴上定位一次。枚举细节放进折叠区，可跳过。

怎么读这张总柜

作业者。谓若思业。若思已所起身业语业。—— 卷九原文
第一条轴就是「作与不作」：动了「思」（决意造作的动机）并由此发起身业语业，才算「作业」——业的主轴是动机，不是动作。其余各轴依次追问：力度（增长与否）、意图（故思与否）、果报排期（定受不定受、现生后受）、性质（善不善无记）、身份（律仪与否）、内容（施戒修）、去向（福非福不动、三界系）、修行位次（学无学、见断修断）与纯度（黑白、曲秽浊）。
十几组分类坐标总览可跳过的完整清单

作 / 不作：思业与思已起身语业为「作」；不思、不起为「不作」。

增长 / 不增长：除十种例外（见下），其余都是增长业。

故思 / 不故思：「故思业者。谓故思已若作业若增长业」；非故思所作为不故思业。

定受 / 不定受：「顺定受业者。谓故思已若作若增长业。顺不定受业者。谓故思已作而不增长业。」

已熟 / 未熟：已与果为异熟已熟业，未与果为异熟未熟业。

善 / 不善 / 无记：无贪无嗔无痴为因缘是善；贪嗔痴为因缘是不善；两者都不是，是无记。

律仪 / 不律仪 / 中间：别解脱、静虑等至、无漏三种律仪所摄；十二种不律仪类所摄；其余一切为「非律仪非不律仪所摄业」。

施性 / 戒性 / 修性：布施、持戒、禅修三类善业，各由因缘、等起、依处、自性四相界定。

福 / 非福 / 不动：「福业者。谓感善趣异熟。及顺五趣受善业。非福业者。谓感恶趣异熟。」不动业感色无色界异熟。

顺乐 / 苦 / 不苦不乐受：福业顺乐受，非福业顺苦受，阿赖耶识异熟业与第四静虑以上不动业顺舍受。

顺现法受 / 顺生受 / 顺后受：今生报、下一生报、第三生以后报。

过去 / 未来 / 现在：住习气位为过去，未生未灭为未来，已造已思未谢灭为现在。

欲系 / 色系 / 无色系：能感欲界、色界、无色界异熟的业。

学 / 无学 / 非学非无学：有学相续、无学相续中的善业，及其余相续中的三性业。

见所断 / 修所断 / 无断：受恶趣不善等业、受善趣三性业、世出世诸无漏业。

黑黑 / 白白 / 黑白黑白 / 非黑非白：四色业，见下表。

曲 / 秽 / 浊 / 清净 / 寂静：外道之业与圣教中犹豫、决定者的业，见下方词源卡。

十种「不增长」业：业力打折清单

一梦所作业。二无知所作业。三无故思所作业。四不利不数所作业。五狂乱所作业。六失念所作业。七非乐欲所作业。八自性无记业。九悔所损业。十对治所损业。—— 卷九原文
十种不增长业逐条展开查看

一 梦所作业：梦中造作，无真实的故思加行，力弱。

二 无知所作业：不知情而作——不知是业、不知后果。

三 无故思所作业：没有经过决意、无意中作。

四 不利不数所作业：不猛利、不反复——只此一次、力道轻微。

五 狂乱所作业：精神错乱状态下所作。

六 失念所作业：失去正念、迷乱中所作。

七 非乐欲所作业：被逼迫、非出于自己意愿。

八 自性无记业：行住坐卧、呼吸眨眼——自性非善非恶。

九 悔所损业：已作之后生起后悔，业的增上力被损减。

十 对治所损业：被后续的善法对治所损减。

顺定受业者。谓故思已若作若增长业。顺不定受业者。谓故思已作而不增长业。—— 卷九原文
两名酒驾者：甲每周精心挑夜路再饮、安排代驾缺口（故思＋作＋增长——顺定受业，果报已「锁定排期」）；乙一次侥幸后立即自省，从此滴酒不沾并主动做代驾志愿者（作而不增长——顺不定受业，尚可变动）。同是酒驾，业的「定与不定」取决于后续的重复与对治。
当天的道歉：小吴吵架时骂了好友很难听的话，半小时后当众真诚道歉、澄清事实，并写了一段自省。对应十不增长业中的「九悔所损业」——悔不是抹账，而是把业的利息停掉：已造不失，但增上力被损减。

三种「执照」与四色账本

谓或别解脱律仪㉖所摄业。或静虑等至果断律仪所摄业。或无漏律仪所摄业。—— 卷九原文
十二种不律仪类古代的十二种「职业性作恶执照」

「一屠羊。二贩鸡。三贩猪。四捕鸟。五罝兔。六盗贼七魁脍。八守狱九谗刺。十断狱十一缚象。十二咒龙。」——宰杀、捕猎、偷盗、屠夫、狱卒、谗言刺探、酷刑断狱、缚象、咒龙等十二类营生：以此为止的「职业身份」本身，就让相关之业持续归入不律仪所摄。

彼因缘者。谓以无贪无嗔无痴为因缘。彼等起者。谓无贪无嗔无痴俱行能舍所施物。能起身语业思。—— 卷九原文
施性业从四相界定：因缘（无贪嗔痴）、等起（与之俱行、能舍物起身语业的思）、依处（所施物与受者）、自性（思所起能舍的身语业）。戒性、修性「随其所应」同构——修性业的自性是三摩地本身。
名相出处成员通俗理解
黑黑异熟业非福业黑因黑果——染污的业感染污苦果（恶趣）
白白异熟业不动业白因白果——色无色界的善业感清净果
黑白黑白异熟业福业善恶夹杂——尚未断非福时的世间善业，果报苦乐相杂
非黑非白无异熟业出世间无漏业不染黑也不著白，是前三业的断对治，「能尽诸业」
曲
由邪解行义故名曲
心路拐进了邪见——像把尺子先放弯了，此后一切测量都歪。指外道的善不善业。
秽
由此为依。能障所起诸功德义故名秽
以邪见为依处，障碍功德生起——如污垢盖镜，善法起不来。
浊
能障通达真如义故。名浊应知
障碍见到真实——水浊则不见底；于圣教中犹豫不决者的业即浊业。
年终奖的三种花法：拿到年终奖后，老周给孩子母校捐了图书角（施性业），小郑报了戒酒营并坚持持守（戒性业），阿芳每天早晚各打坐二十分钟、坚持了一年（修性业）。原文分析施性业的四相——「彼因缘者。谓以无贪无嗔无痴为因缘」，戒性与修性「随其所应」同构：都是无贪嗔痴发起、各有依处与自性的善业。

业的七种代价：以杀生为例

「业过患」一章用杀生做样本，给出七种代价。这七条像七份文书：三份人身账单（自害、他害、俱害），三份罪状（现法罪、后法罪、现法后法罪），一份精神损害清单（身心忧苦）。

七种代价总览

谓杀生者。杀生为因。能为自害。能为他害。能为俱害。生现法罪。生后法罪。生现法后法罪。受彼所生身心忧苦。—— 卷九原文
能为自害
手段反噬自己
→
「谓为害生发起方便。由此因缘。便自被害。若被系缚。若遭退失。若被诃毁。然彼不能损害于他。」发起伤害的手段，先伤到自己。
买凶者被套牢：某老板雇中间人「教训」生意对手，定金一付即被录音要挟，被迫不断加钱，最后倾家荡产还被举报——自害的完整链条：被缚、退失、被诃毁。
能为他害
伤到对方而自己未损
→
「能损害他。由此因缘。不自被害乃至诃毁。」手段成功、对方受损，这一型里罪业在后法等待——「生后法罪。谓如能为他害」。
能为俱害
自他两败
→
「能损害他。由此因缘。复被他害。若被系缚乃至诃毁。」伤人又自伤。
冲突现场：甲挥拳伤了乙，乙的同伴一拥而上把甲打伤，甲随即被行政拘留、被公司辞退——「复被他害。若被系缚乃至诃毁」：现世的两败俱伤，对应「生现法后法罪」。
生现法罪
今世的罪
→
「云何生现法罪。谓如能为自害。」——今世法律、名誉、身心层面的直接损失。
生后法罪
后世的罪
→
「云何生后法罪。谓如能为他害。」——伤害成功而今生未见报的，罪在后世。
生现法后法罪
两世都占
→
「云何生现法后法罪。谓如能为俱害。」——自他两败型的业，现世后世都背罪。
受身心忧苦
连失败都躲不掉的账
→
「又不能办随欲杀事。彼由所欲不会因缘。便受所生身心忧苦。」
没整成的「报复」：小冯策划三个月想搞垮对手，对方毫无察觉，计划胎死腹中——此后半年失眠、暴瘦、注意力涣散。原文：所欲不成，忧苦照受，一事无成也逃不掉这一条。

附加条款：犯戒的十过患与「第五条」

又有十种过患。依犯尸罗。如经广说应知。—— 卷九原文
又有四种不善业道。及饮诸酒以为第五。依犯事善男学处。佛薄伽梵说多过患。—— 卷九原文
违犯尸罗有十种过患；四种不善业道之外，饮酒被单独列为第五条，同属在家善士的学处——佛说其中有多过患，详见《阐地迦经》。
酒桌上的「第五条」：年会上领导挨桌敬酒，「不喝就是不给面子」把饮酒做成了规矩。原文把饮酒列为四种不善业道之外的第五条，并对「事善男学处」广说过患——把饮酒制度化，正是过患清单反复警告的机制：不是一口酒有多重，而是它成了人人维护的惯例。

投生这件大事：生杂染的四张切片

业讲完，镜头转向果报的主体——「生」。原文立起总问题并给四张切片：差别（有多少种生法）、艰辛（生有多苦）、不定（轮回了多久）、流转（怎样一轮接一轮——即十二缘起，见下一章）。

切片一：差别——生法的抽样框

云何生杂染㉗。谓由四种相应知。一由差别故。二由艰辛故。三由不定故。四由流转故。—— 卷九原文
生差别者。当知复有五种。一界差别。二趣差别。三处所差别。四胜生差别㉘。五自身世间差别。—— 卷九原文
欲界中有三十六处生差别。色界中有十八处生差别。无色界中有四处生差别。如是总有五十八生。—— 卷九原文
五种差别是一张抽样框：按界（三界）、按趣（五趣四生）、按处所（合计五十八种生）、按胜生（出生的优劣等次）、按自身世间（十方无量世界的无量差别）。「胜生差别」在人中分三档：
下档

黑胜生生

「谓如有一生旃荼罗家」及造车、竹作等家，或「所余下贱贫穷乏少财物饮食等家」——人中薄福德者。

上档

白胜生生

「生刹帝利大富贵家」及婆罗门、长者等豪贵大富之家——人中胜福德者。

中档

非黑非白胜生生

「谓如有一非前二种生处中家者」——生在中等之家。欲界天、色界、无色界也各有三种胜生。

同一间产房：同一天同一间产房，三个婴儿分别出生在山区别墅的富豪家、棚户区低保家庭、普通工薪家庭。对应「胜生差别」的人中三档——但论中立场是不美化任何一档：三界五趣处处是苦，「出生彩票」只决定苦的口味，不改变苦的性质。

切片二：艰辛——佛算的第一笔账

汝等长时驰骋生死。身血流注过四大海。—— 卷九原文
如血洟泪。如是当知。所饮母乳其量亦尔。—— 卷九原文
量级的修辞：这不是说你真的流过四大海的水，而是像会计只报总额不列明细——轮回以「劫」计次，每次投生都伴随伤害、砍截、别离、哺乳，总量级大到只能拿大海当单位。血、泪、母乳三笔账，算的都是「次数无穷」。
母乳账：一位新手妈妈算过：每次喂奶约两百毫升，一天八次，喂到两岁——单这一个孩子就是一千多升。原文说长夜生死中「所饮母乳其量亦尔」——与流过的血、泪同量级。把一个孩子乘以无穷次投生，就是佛说的那笔账。

切片三：不定——佛算的第二笔账

假使取于大地所有一切草木根茎枝叶等。截为细筹。如四指量。—— 卷九原文
四指量筹速可穷尽。而我不说汝等长夜所经父母其量边际。—— 卷九原文
若一补特伽罗于一劫中所受身骨。假使有人。为其积集不烂坏者。其聚量高王舍城侧广博胁山。—— 卷九原文
把全大地的草木截成四指长的小签来数前世父母——「如是众生曾为我母。我亦长夜曾为彼母」——签子先用完，父母数不完；一个有情一劫的身骨能堆成广博胁山；大地上没有一处未曾经受无量生死。佛用三笔可想象的账，逼出「轮回无始」这个不可想象的结论。
族谱数字化：老杨给家族做谱系数字化，扫描、录入、走访，数到第九代时线索全断，他感叹「再往上就是一个名字了」。原文的筹算之喻正是同一体验的无限版：任何有限的工具（签子、记忆、档案）都会先耗尽，而轮回的世代数没有边际——「其量边际」根本无从谈起。

十二缘起：轮回的发动机（与它的熄火开关）

全卷的重头戏。「云何缘起？」原文用一首四句纲领领起，再以「前际—中际—后际」的三世框架建立缘起体：怎么从过去生到这一生，怎么从这一生到未来生，以及——如何在今生踩下刹车。

三相框架：三世两重因果

谓从前际中际生。从中际后际生。中际生已若趣流转。若趣清净究竟。—— 卷九原文
谓如有一不了前际无明所摄。无明为缘。于福非福及与不动身语意业。若作若增长。—— 卷九原文
由此随业识㉚。乃至命终流转不绝。能为后有相续识因。此识将生果时。由内外贪爱正现在前。以为助伴。—— 卷九原文
第一相：不了知（无明）为缘，造作种种业，业熏在识中（随业识）；命终时贪爱现前作助伴，识入母胎，「乃至羯罗蓝等位差别而转」——这一生的身心由此展开。识与名色互为依托，是整台机器的骨架。
识缘名色。名色缘识。犹如束芦㉟。乃至命终。相依而转。—— 卷九原文
两束芦苇：两捆芦苇互相斜靠才能立在田间，抽走任何一捆，另一捆立刻倒下。识与名色（心与身）正是这样互为支点——谁也不是谁的主人，没有一个独立的「我」坐在中间发号施令。
合伙创业：两位创始人合伙开公司：一位懂产品一位懂市场，谁也离不开谁，公司却既不是「产品那位」也不是「市场那位」的。识与名色的关系正是「犹如束芦……相依而转」——互相支撑、共同运转，而其中找不到单一的所有者。

流程推演：跟着「小林」走一遍十二支

从无明到老死，是这台发动机的一个完整冲程；最后一步是岔路口——熄火开关。

中际的两条线：流转与清净

谓中际已生补特伽罗。受二种先业果。谓受内异熟果。及境界所生受增上果。—— 卷九原文
由此爱故。或发欲求。或发有求。或执欲取。或执见戒及我语取。由此爱取和合资润。令前引因转名为有。—— 卷九原文
由此如理作意为缘。正见得生。—— 卷九原文
由此智见。无明及爱。永断无余。—— 卷九原文
无明灭故行灭。次第乃至。异熟生触灭故异熟生受灭。—— 卷九原文
如是于现法中。诸行不转。由不转故。于现法中。于有余依界。证得现法涅槃㊱。—— 卷九原文
同一份人生底账，两条线。流转线：对两份果报愚痴（于二果愚）→ 造新业 → 爱 → 取 → 有 → 生老死；清净线：如理作意 → 正见 → 智见断无明与爱 → 慧解脱、心解脱 → 有余依涅槃；此身寿尽后「无余永灭更不重熟」——「是名无余依涅槃界㊲究竟寂静处」。发动机还在转完最后的惯性，但供油已断。
同样被裁员：老张认定「完了，四十五岁没人要了」，越想越怕，一边疯狂投简历一边借钱撑面子，焦虑滚成失眠（爱→取→有，一圈圈加码）；老李如理作意，把「被裁」拆成行业、技能、时机三份因缘，重新规划学习与去向（「由此如理作意为缘。正见得生」）。同一场雪，一个雪崩，一个铺出新路——两条线的入口都在当下这一念的作意方式。
走了十年的通勤路：老郑在同一条线上通勤十年，闭着眼都能换乘——习惯刻进了识的底层，自动运行，不需要每次重新决定。原文说「由此随业识㉚。乃至命终流转不绝。能为后有相续识因」：串习成性的业就像这条通勤路，形成「档案袋」，在人不知不觉处决定下一程的方向。

缘起义：八层递进，层层拆掉「我」

谓离有情义㊴。是缘起义。于离有情。复无常义。是缘起义。于无常。复暂住义。是缘起义。—— 卷九原文
一 离有情
缘起中找不到一个恒常的「有情」主演——只有相续的过程，没有老板。
二 无常
这相续本身刹那生灭，从不静止。
三 暂住
虽无常，却并非顿起顿灭——有一期暂时的安住，才显出「一生」的轮廓。
四 依他
暂住的每一刻都依靠条件而立，不能自足自持。
五 离作用
既然只是依条件而起，就没有一个「能作者」在操控——无我而有运行。
六 因果相续不断
无作者，链条却不断：前支为缘，后支得起。
七 因果相似转
后一期与前一期相似相续——不是同一个「我」，也非全然无关。
八 自业所作
「于因果相似转。复自业所作义。是缘起义」——各人只吃自己业的饭，账不会记错人头。
为显因缘所摄染污清净义故。—— 卷九原文

收官：八门、无知地图与总纲颂

卷末三件事：缘起在哪八类事物中运转（门）；无明到底有哪几张面孔（差别——十九种无知、七愚、五愚）；以及一首四句颂，预告接下来几卷的路线图。

缘起门：八类运转现场

缘起门㊳云何。谓依八门缘起流转。—— 卷九原文
八门清单可跳过，每门一句话

一 内识生门：识依根境等缘而生——念头与认识都是缘起的。

二 外稼成熟门：种子、水土、阳光到谷熟——庄稼是看得见的缘起。

三 有情世间死生门：有情的死此生彼，即本章的主戏。

四 器世间成坏门：山河大地的成、住、坏，也有其缘起节奏。

五 食任持门：段食、触食等四食任持有情——吃饭也是缘起的支撑件。

六 自所作业增上势力受用随业所得爱非爱果门：自业自受——爱与非爱的果都按业的账本来。

七 威势门：大威德者的业力现前，如佛所住国邑无疾疫灾横。

八 清净门：依圣道断除杂染——缘起同样通向解脱这一端。

阳台上的番茄：上个月小敏在阳台种下小番茄：育苗、换盆、控水、追肥，六周后第一颗果实转红。种子不会「决定」结果，人也造不出没有阳光的果实——每一步都依赖上一环。这正是「外稼成熟门」：缘起不只是玄理，就在花盆里运转。

无明的面孔：从十九种收敛到一种

谓于过去诸行。起不如理分别。谓我于过去为曾有耶。为曾无耶。曾何体性。曾何种类。所有无知。—— 卷九原文
如是略说十九种无知㊵。—— 卷九原文
复有七种无知。一世愚。二事愚。三移转愚。四最胜愚。五真实愚。六染净愚。七增上慢愚。—— 卷九原文
当知义愚通摄一切。—— 卷九原文
无明的面孔有细目（对前际、后际、内外、业、异熟、佛、法、僧、苦集灭道、因等的十九种无知），再收拢为七愚、五愚——而「义愚」（对缘起义本身的愚痴）通摄一切。归根结底，所有无明是同一件事：没看懂「缘起」。此外还有六种无明差别（无知、无见、无有现观、黑闇、愚痴、无明闇），配闻思修三慧与其软中上品来对治。
凌晨两点的搜索框：小宋失眠到凌晨两点，在搜索框里敲下「人死后到底去哪里」「我真的存在吗」。这种对过去未来的茫然打转，正是「于前际无知」「于后际无知」的现代画像——问题本身不是病，执着于以「我」为坐标去问，才是论中所说的「不如理分别」；而它的总病根，是可以被「义愚」一词收编的。

总纲颂与全卷回顾

云何缘起。嗢拖南㉙曰。—— 卷九原文
体门义差别　　次第难释词
缘性分别缘　　摄诸经为后
