十七地：整部论的总目录

「瑜伽师地」= 瑜伽师（修行者）走过的十七个阶段/领域。整部百卷大论，就是沿着这十七站展开的。第一卷开头先用一首偈把目录背了一遍。

五识相应意　　有寻伺等三
三摩地俱非　　有心无心地
闻思修所立　　如是具三乘
有依及无依　　是名十七地
目录诗：五识身相应地、意地 → 有寻有伺等三地 → 三摩地俱非（三摩呬多/非三摩呬多）→ 有心无心地 → 闻思修三地 → 三乘（声闻独觉菩萨）→ 有余依、无余依。

课程表：可以把十七地想象成一所修行大学的专业目录——第 1-9 地是「基础课」（把心识这台机器拆开研究），第 10-12 地是「方法课」（听、想、练），第 13-15 地是「三个专业方向」，第 16-17 地是「毕业去向」。而卷一、卷二就是最基础的两门课：《五识》《意》。
为什么从五识开始讲？因为它离生活最近——你现在正「用眼睛看着这行字」，这个「看」就是五识地的研究对象。论从你最有把握的经验讲起，再一步步走向深的。
「云何瑜伽师地？所谓十七地。」——第一卷开门见山：全书 = 十七地的修行地图，本卷先讲第 1 地（五识）并开启第 2 地（意）。

五识身：五个感官「频道」

五识地定义五识只用一个统一公式，五个识全部套用——先记住公式，再看五个实例。

统一公式：依 X 了别 Y

「云何五识身相应地？就是五识身的自性、它所依止的、它所缘取的、它的助伴以及它的作用，这些总称为五识身相应地。」—— 卷一原文

每个识都从五个角度研究（这组框架叫「五事」，全书通用）：自性（它是什么）、所依（靠什么生起）、所缘（对象是什么）、助伴（带哪些心理员工）、作业（干什么活）。

「识」不是眼睛本身，而是依眼根生起的了别功能——眼睛是摄像头，眼识是「正在看」这件事。

细节：净色根与「无见有对」

净色：眼根不是肉眼可见的眼球，而是「四大种所造、眼识所依的清净色」——一种精微的感官组织。论中给一切五根的定位是「无见有对」：

无见有对：「无见」= 看不见（你看不见自己的视网膜视角背后的神经组织）；「有对」= 有质碍、占空间（它确实在那里、有物理定位）。
摄像头类比：眼球 = 镜头外壳；净色根 = 感光传感器（藏在里面，肉眼看不见，但真实占位）；眼识 = 「正在成像」这件事。论文对感官的解剖，精确到把「器官」与「功能」分开——这是它与现代常识最接近的地方。
身识不只是皮肤：原文列身识的所缘「触」：地水火风、轻、重、滑、涩、冷、饥、渴、饱、力、劣、缓、急、病、老、死、痒、闷、粘、疲、息、软、怯、勇——「饿了」「累了」「病了」都是身识了别的对象。你现在感受到的椅子硌腰，正是一次标准的身识活动。

三种所依：识靠什么生起

每个识生起，论文说它需要三层「依靠」。这一组概念是唯识学的地基，请务必拿下。

三层依靠（点击卡片翻转）

俱有依
同时俱在的器官
点击展开 →
眼识的俱有依是眼根——识生起的那一刻，根就在旁边同时运作。比喻：放映必须依赖放映机，机器和画面同时在场。
等无间依
前一念让位
点击展开 →
「意」指眼识无间过去的那念识——前一念灭、开出位置，后一念才能生。比喻：单行道上，前车不让位，后车进不来。
种子依
阿赖耶识
点击展开 →
一切种子异熟识——无始以来乐着戏论、熏习成的一切习气种子，都存放在这个「根本识」里。比喻：云端硬盘，存着从生命开始以来的全部「记录」。
一句话：识的生起 = 设备（根） + 让位（前念） + 存档（种子），三层缺一不可。
等无间依：电影 24 格/秒，前一格胶片必须移开，下一格才能到放映窗口——你看到「连续画面」其实是无数「前一念灭、后一念生」。论文说的「眼识无间过去识」就是这层让位关系：心也是一格一格放映的。
种子依：为什么你在语言课上听一遍就记得住法语发音，而室友怎么学都跑调？同样的课堂（俱有依相同）、同样的当下（等无间依相似），差别全在种子——过去熏习攒下的「存档」不同。论文说种子「无始时来乐着戏论，熏习为因」，每个人的阿赖耶识里存着一套独一无二的习气库。

五识的四个比喻（原文自带的）

「应当观察五识的所依，如同前往他方者所乘的车乘；所缘如同所要做的事情；助伴如同同行伴侣；作用如同自身功能。」—— 卷一原文
喻一

所依如车乘

出远门要靠车——识生起要靠根（+ 意 + 种子）。

喻二

所缘如所办的事

出门有目的地——识总对着一个对象。

喻三

助伴如同伴

路上有同行者——作意触受想思跟着一起上。

喻四

作用如自功能

你自己的本事——了别就是识的功能。

原文还给了第二套比喻：所依如家，所缘如受用之物，助伴如仆使，业如作用。两套比喻只是角度不同：出门喻与居家喻。

套用一遍：你下班开车去超市买菜——车 = 眼根等所依；「买晚饭食材」= 所缘（货架上的菜）；副驾的家人 = 助伴（作意触受想思）；「挑选比价」= 作业（了别）。一次寻常采购，五事俱全。

五识的所缘：每种识「看」什么

五识的对象各有各的世界：眼识缘色、耳识缘声、鼻识缘香、舌识缘味、身识缘触。其中眼识的「色」被拆得最细——显色、形色、表色。

显色 = 属性（颜色），形色 = 形状（轮廓），表色 = 动态（行为）。看任何东西，这三层同时到场。
红绿灯：路口那盏灯——「红颜色本身」是显色；「圆形轮廓」是形色；「由黄变红的切换过程」是表色。你一眼读出「该停了」，三层数据同时处理完毕。
为什么「表色」重要：论文把「行住坐卧」也归入眼识的所缘——也就是说，看一个人走路，你看到的不是一堆颜色像素，而是「行为」。古人早就意识到：视觉天然自带「动作识别」功能。

动手归类：显色 · 形色 · 表色

声音的三分法（原文的精细分类）

耳识所缘的「声」略分三种——按声源是「有情身体」（执受大种）还是「无情物体」（不执受大种）：

执受大种声

从身体发出

说话声、掌声、哭笑声——「唯内缘声」。

不执受大种声

从物体发出

雷声、风声、流水声——「唯外缘声」。

俱大种声

身体 + 物体

敲鼓、弹琴——「内外缘声」。

音乐会：同一晚你听到三种声——歌唱家的嗓音（执受大种声，从身体来）、空调的低鸣（不执受大种声，纯机械）、鼓槌击鼓（俱大种声，人手 + 鼓皮合作）。你的耳朵天然分得清这三类，论文只是把这个能力写成了清单。
原文对声、香、味、触各列长长的清单（螺贝声、江河声、根茎花果香、苦酢辛甘咸淡……），本页不详列——重点是方法：每个识的对象都可按属性清单化，这是修行时「观照当下」的备查表。
05

识的生起：三个条件 + 三心接力

这是五识地的核心机制：看（或听）不是自动发生的——需要条件，而且「看见」内部还有一套接力流程。

条件模拟器：眼识为什么此刻没有生起？

① 眼根不坏眼根没有损坏羸弱
② 色现在前对象实际呈现在眼前
③ 能生作意正起注意力正确转向它
「虽然眼根没有损坏，色境现前，能生起作意，但如果作意不能正起，所生的眼识必定不能生起。」—— 卷一原文
课堂走神：老师板书写满黑板（色现在前），你视力 5.2（眼根不坏），但心想着中午吃什么（作意未正起）——「眼识不生」，你对着整块黑板什么也没「看见」。直到老师喊你名字，作意一转，黑板上的字才突然「出现」。

三心接力：一次「看见」的内部流水线（点击推进）

闪光灯瞬间：拍照闪光灯一亮——第一刹那你「看见了」（率尔心，眼识纯领受），第二刹那你在想「刚才那是什么」（寻求心，意识接管），第三刹那你确定「是有人拍照」（决定心）。论文说这三心里只有第一刹那在眼识，后两步全是意识的活——「看见」从来是团队作业。
决定心之后才分染净（喜欢/讨厌），此后眼识才随善恶相续流转——而且它自己没有分别力，全被意识牵着走：「随意识转」。

五识作业的边界（六种业）

论文总结眼识（余识同理）的六种作用：只了别自己的对象、只了别自相（细节相）、只了别现在、只一刹那了别、随意识转随善恶转、能取爱非爱果。

为什么五识「记不住」：五识「唯了别现在、唯一刹那了别」——它只在当下闪一下，没有跨时间的记忆能力。你看电影时眼睛一直在看，但让你记住剧情、产生感动的全是意识；五识像每帧就报废的传感器，意识才是负责剪辑和存档的剪辑师。
06

意地：意识登场

五识讲完，卷一后半开启第 2 地「意地」。意地同样按五事展开，但对象换成那个真正做主的「意识」。

心 · 意 · 识：意自性的三个名字

「什么是意的自性？就是心、意、识。心，是指一切种子所随的依止性……异熟所摄的阿赖耶识。意，是指恒行意以及六识身无间灭意。识，是指现前了别所缘境界。」—— 卷一原文
心

仓库

一切种子所随依止的阿赖耶识——存储层，收藏全部习气种子。

意

让位机制

恒行意 + 六识无间灭意——前念灭位即是后念生门。

识

现前工作台

「现前了别所缘境界」——当下正在进行的了别活动。

电脑类比：心 = 硬盘（存着所有文件和系统习气）；意 = 内存总线的时钟节拍（前一拍结束才有后一拍）；识 = 屏幕上正在运行的窗口（此刻的了别）。同一颗心的三个角色：存储、节拍、显示。

意识凭什么比五识高级？——胜作业清单

五识只能「了别现在、一刹那、自相」；意识的能力清单长得多：分别所缘、审虑所缘、醉、狂、梦、觉、闷、醒、发起身业语业、离欲（或退）、断善根（或续）、死、生——全都是五识做不到的。

七种分别里的日常：「任运分别」——走夜路时你的脚自动避开坑洼，不假思索，心「随境势力任运而转」；「染污分别」——睡前复盘白天的争吵，越想越气（对过去顾恋、对现在执着），论文明确把这类归为染污。原来「内耗」在千年前就被列了分类编号。
梦、醉、闷、醒：论文逐一给出成因——醉由「过量饮」等四种；梦由疲倦、吃得沉重、串习睡眠、药物等引发；闷（晕厥）由风热乱、捶打、泻泄、极勤劳。这份一千多年前的「异常意识状态成因表」，与现代常识惊人地兼容。
发起身语业的流程：原文给出行动五步：智先行 → 欲生 → 功用起 → 随顺功用 → 身语业风转。对照你发一条重要消息：先想清楚（智）→ 想发（欲）→ 动手打字（功用）→ 措辞顺畅（随顺）→ 按下发送（业成）。任何身口行为背后都有这条隐形流水线。

53 心所总表（意识员工的第一次集体点名）

意地的「助伴」一段，一口气点出五十三种心所有法——这是全书心理学的花名册：

展开完整名单 同一所缘，非同一行相

五遍行：作意、触、受、想、思。五别境：欲、胜解、念、三摩地、慧。

善十一：信、惭、愧、无贪、无嗔、无痴、精进、轻安、不放逸、舍、不害。

根本烦恼六：贪、恚（嗔）、无明、慢、见、疑。随烦恼二十：忿、恨、覆、恼、嫉、悭、诳、谄、憍、害、无惭、无愧、惛沉、掉举、不信、懈怠、放逸、邪欲、邪胜解、忘念、散乱、不正知。

不定四：恶作（悔）、睡眠、寻、伺。

关系要点（原文）：同一所缘、非同一行相、一时俱有、一一而转、各自种子所生、更互相应——像同一间办公室的同事：盯着同一块白板（同一所缘），但各自负责不同任务（非同一行相）。

开会的会议室：你此刻读这段文字：意识盯着同一个屏幕（同一所缘），但「想」（认出这是心所表）、「受」（有点枯燥）、「念」（想起卷三也见过）、「精进」（决定读完）同时在岗、各干各的活（非同一行相）。心所不是排队出场，而是一间屋子里的协作团队。
07

死与生：卷一最震撼的部分

意地的「作业」清单里有一项五绝做不到的：死与生。论文用整整一组问答，把死亡过程、中阴、入胎讲到了今天仍在流传的程度。

死有三种（时死与非时死）

寿尽故死

寿量满尽

该活的年头活完了——「时死」，自然终。

福尽故死

资具缺乏

维持生活的资源耗尽而死。

不避不平等

九种非时死

食无度量、食所不宜、不消复食、生而不吐、熟而持之、不近医药、不知损益、非时非量行非梵行等——本可避免。

九因九缘的现代读法：「食无度量」= 暴饮暴食；「食所不宜」= 天天重油重辣；「不消复食」= 上一顿没消化又吃自助；「不近医药」= 小病拖成大病；「不知于己若损若益」= 熬夜刷手机明知伤身。论文把「不作死就不会死」写成了九条检查清单。

临终三态：善心死、不善心死、无记心死

状态过程体验
善心死自忆或他令忆平生善法，信等善法现行安乐而死，见不乱色相
不善心死自忆或他令忆串习恶法，贪嗔现行苦恼而死，极重苦受，见纷乱色相
无记心死自不能忆，无他令忆既非安乐亦非苦恼
决定临终心态的规则很朴素：多次串习、力量最强者先现行；若善恶势力平等，则「随初自忆或他令忆，唯此不舍」——第一念抓住什么，就沿着走。
从明趣暗，从暗趣明：论文用日出日落打比方——造恶者临终如日落后山峰影子层层覆盖（从明趣暗）；修善者如夜尽天明（从暗趣明）。这就是「临终关怀」的古老版本：让临终者安住在善的忆念里，是此时此刻能给出的最实在的帮助。
解肢节与冷触：论文描述死亡的身体过程：造恶者识从头顶开始舍、冷触从上向下蔓延；造善者从脚下开始舍、冷触从下向上——最终都收敛到肉心处，最后一点暖觉在心口消失。这与现代医学对死亡过程中核心体温最后消失于躯干中部的描述，方向上一致。

中有：死与生之间的「过渡态」

死生同时
「死与生是同时的，如同秤的两头，一头低下去另一头就翘起来」——没有空档。
中有现起
中有（又称健达缚/寻香、意行、趣生）必具诸根，眼如天眼，能见同类及将生之处。
七日一生死
未得生缘，极七日住；满七日未生则「死而复生」，辗转至多七七四十九日，此后决定得生缘。
形相随业
造恶业者中有如黑羊光色或阴暗夜；作善业者如白衣光色或晴朗夜。
健达缚「寻香」：中有的别名之一是「寻香行」——以香气为资养。民俗里「烧香能利益亡者」的观念，源头正在于此：论文说的中阴有情，寻找的就是气味资养。民俗与义理之间隔着一层，但你能看到那个古老的出处。
秤两头：「死生同时如秤两头，低昂时等」——想象一杆秤：这头（死有）落下的同一瞬间，那头（生有）翘起。论文强调死亡不是「断灭之后等一等再重来」，而是同一时刻的交接班。

入胎：三个条件 + 三个障碍 + 颠倒想

三处现前才能入胎：① 母亲身体调适且恰逢其时；② 父母和合、俱起爱染；③ 健达缚（中有）正现在前。

三种过患则挡住入胎：产处过患（产门形状、麻麦果等异物）、种子过患（父精母血朽烂不出）、宿业过患（父母与子女之间没有相应的感生之业）。

「条件 + 障碍」的双清单：入胎像一扇双重锁的门——三个条件是三把钥匙（都齐才开门），三个过患是三道锁（有一道就锁死）。论文的因果观从不含糊：任何一件事生起，正面条件与负面障碍都要清点。

和合依托：两滴浓厚精血和合，「犹如熟乳凝结之时」，阿赖耶识和合依托其中，名为羯罗蓝位。识最初依托之处即肉心，「识于此处最初托，即从此处最后舍」——与死亡时的冷触终点严丝合缝。

熟乳凝结：论文选的比喻是「熟乳凝结之时」——温热的牛奶放凉结成奶皮。受精与结胎的过程被浓缩在这个厨房可见的意象里：柔软、温热、正在凝固成形。

后序彩蛋：玄奘与翻译天团

卷一末尾附有一篇后序（中书令许敬宗奉诏撰写），记录了这部论的来历——它其实是一部「国家翻译工程」的竣工报告。

玄奘西行（后序原文的叙述）

「访道周游，共十七年；所经路途，横亘一百余国。异方之语言，借助一音而全部贯通；未译之经典，罄尽五财而全部抄写。」—— 后序原文
束发出家
「奚初束发，即事抽簪」——刚到束发之年就披剃出家，研求四谛，感叹真宗中的谬误旨趣。
裂裳裹足
「裂裳裹足，直趣迦维」——撕衣裹足，径直西行印度。
十七年 · 百余国
周游访道，语言全通，经典抄尽，半句半偈随白马俱返。
贞观十九年
携舍利 150 粒、佛像 7 躯、圣教要文 657 部回到长安，奉敕安置于弘福寺。
贞观二十一年启译
五月十五日开始译《瑜伽师地论》：梵本四万颂，每颂 32 字，共五分。
贞观二十二年绝笔
整整一年译成百卷。弥勒菩萨下睹史多天宫为无著菩萨所说。

翻译流水线：二十一人的分工

后序列出了译场的完整岗位表：笔受（记录译文，灵会、灵隽等）、证梵语（校对梵文，玄暮）、正字（勘正文字，玄应）、详证大义（审定义理，神泰、道深等）、各分卷的受旨证文（道智、行友、玄赜、玄忠、靖迈、辩机、处衡、明浚），最后许敬宗奉诏监阅。

现代对照：这配置就是今天的大型本地化项目——原典校对（证梵语）、文字编辑（正字）、多轮审稿（详证大义）、分册负责人（受旨证文）、项目经理兼出品人（监阅）。你手里这部一百卷的译本，是一支 21 人团队 + 皇家预算、耗时一年的成果；而开头那篇辞采华美的后序，就是工程的「竣工铭」。
为什么后序要写大唐气象：后序先用大段文字颂扬唐太宗「偃洪流而恢地络」「移浇反璞」，再引出玄奘——这是当时的官方文体惯例：先谢投资人，再讲项目。读懂这层结构，卷末那些「瑞露祯云」就不会读着突兀了。
这部你正在读的论，翻译动因是玄奘发现「真宗有谬旨、实相有讹文」——为了拿到未经转手的原文，他走了十七年。你现在读的每一卷，都是那趟旅行的直接产物。
