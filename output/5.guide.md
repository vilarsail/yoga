# 瑜伽师地论卷第五 导读

## 一、内容总览
本卷为有寻有伺等三地之二，续前卷界施设建立，先竟受用建立余义，次明生、自体、因缘果三相建立，转入相施设建立（寻伺七相）与如理作意建立开端，是三地由界向相、作意过渡的枢纽。

## 二、结构层次
按"竟受用 → 生 → 自体 → 因缘果 → 相 → 如理作意（起）"推进：
- **竟受用（P1-P19）**：四静虑四乐 → 苦乐六殊胜 → 圣财与非圣财所生乐十五差别 → 三受皆苦 → 饮食（四食）→ 淫欲（诸天递减：交会→抱→握手→笑→视）。
- **生建立（P20-P24）**：三种欲生+三种乐生，由三求（欲/有/梵行求）建立。
- **自体建立（P25-P26）**：四种得自体——自害/他害/俱害/俱不害。
- **因缘果建立（P27-P49）**：四门（相/依处/差别/建立）→ 十五依处 → 十因四缘五果 → 依处施设对应 → 因五相七相。
- **相施设建立（P50-P55）**：寻伺七相，寻以思为体、伺以慧为体。
- **如理作意建立（起，P56-P65）**：八相总标 → 施主/尸罗/修者四相、受施六种等。

## 三、关键结论
1. 圣财所生乐（七圣财：信戒惭愧闻舍慧）十五差别：无罪、遍满、一切时有、能持后世。
2. 三界身如毒热痈，乐受坏苦、苦受苦苦、不苦不乐受行苦；想受灭乐为乐中第一。
3. 段食唯欲界，触意思识三食通三界；那落迦有微细段食。
4. 欲界诸天淫欲递减：四王、三十三交会，时分抱，知足握手，乐化笑，他化视。
5. 十因依十五依处施设，四缘五果各有所依；寻以思为体，伺以慧为体。

## 四、易混辨析
- **圣财所生乐 vs 非圣财所生乐**：内缘无罪遍满/外缘有罪微小。
- **坏苦 vs 苦苦 vs 行苦**：乐受坏/苦受自性/不苦不乐受迁流。
- **三种欲生 vs 三种乐生**：欲界天分三/色界初二三静虑；由欲求/有求。

## 五、阅读提示
三地"中盘"，对照"受用竟→生自体因缘果立→相与如理作意启"读；因缘果最密集，建议列十因—四缘—五果对应表。
