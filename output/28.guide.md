# 瑜伽师地论卷第二十八 导读

## 一、内容总览
本卷为「声闻地第二瑜伽处之三」，广辨「学」「随顺学法」「瑜伽坏」「瑜伽」「作意」「瑜伽师」「瑜伽修」七门，并开启「菩提分修」详说四念住。三学建立次第、四瑜伽、四作意、三种瑜伽师、四念住为本卷主体，是声闻地由资粮转入正修的关键。

## 二、结构层次
全卷按「三学 → 随顺学法 → 瑜伽坏 → 瑜伽 → 作意 → 瑜伽师 → 瑜伽修 → 四念住」推进：
- **学（P1-P26）**：三胜学（增上戒/心/慧）→ 唯三建立（建立定义/智所依义/辨所作义）→ 次第因缘 → 增上义（所趣/最胜）→ 三学相引发 → 三根（未知欲知/已知/具知）→ 三解脱门（空/无愿/无相）。
- **随顺学法（P27-P40）**：十违逆学法 → 对治十想（不净/无常/无常苦/苦无我/厌逆食/一切世间不可乐/光明/离欲/灭/死）→ 四光明 → 复有十种随顺学法。
- **瑜伽坏（P41-P52）**：四种坏——毕竟（无种姓）、暂时（有种姓阙缘）、退失所得、邪行所作（诈为阿罗汉安立非法为法像似正法）。
- **瑜伽（P53-P60）**：四瑜伽——信、欲、精进、方便，十六种差别。
- **作意（P61-P78）**：四作意（力励/有间/无间/无功用运转）→ 复四作意（随顺/对治/顺清净/顺观察）→ 所缘四相（所缘/因缘/应远离/应修习）。
- **瑜伽师（P82-P88）**：初修业、已习行、已度作意三种。
- **瑜伽修（P89-P96）**：想修、菩提分修。
- **菩提分修与四念住（P97-P129）**：三十七菩提分总列 → 四念住别明——身相三十五、循身观三慧、念住三相、二十一受九受、二十心、二十法、治四颠倒、念住义（所缘/自性/相杂/闻思修所成）。
以「学 → 随顺 → 坏 → 体 → 作意 → 师 → 修 → 菩提分」为统一骨架。

## 三、关键结论
1. 三学唯三建立：建立定义（戒能建立心一境性）、智所依义（定能生如实智见）、辨所作义（慧能证烦恼断）；次第由戒生定生慧如实知见厌离染解脱涅槃。
2. 增上义二：所趣义（为趣后后而修前前）、最胜义（唯圣教独有不共外道）；有增上慧必具三学。
3. 十违逆学法对治十想，思惟诸法瑜伽作意过患复开十一种；复有十种随顺学法从宿因至离增上慢。
4. 四种瑜伽坏：毕竟、暂时、退失所得、邪行所作（诈现调善安立非法为法像似正法）。
5. 四瑜伽：信、欲、精进、方便，共十六种差别；由信生欲由欲精进由精进摄方便能得未得。
6. 四作意配九心住：力励配内住等住、有间缺配安住乃至最极寂静、无间缺配专注一趣、无功用配等持。
7. 四念住治四颠倒：身治不净计净、受治苦计乐、心治无常计常、法治无我计我。

## 四、易混辨析
- **毕竟瑜伽坏 vs 暂时瑜伽坏**：毕竟约无种姓毕竟失坏出世瑜伽、暂时约有种姓阙缘定当缘会现起。
- **力励 vs 有间缺 vs 无间缺 vs 无功用运转**：力励配初修未得作意、有间缺得了相已后为三摩地思所间杂、无间缺从了相至加行究竟、无功用配加行究竟果。
- **初修业 vs 已习行 vs 已度作意瑜伽师**：初修业约未得作意或初起了相、已习行约暖顶忍世第一法顺决择分、已度作意约已入正性离生得谛现观。
- **所缘念住 vs 自性念住 vs 相杂念住**：所缘谓于此住念、自性谓慧念摄持于定、相杂谓所余相应诸心心法。

## 五、阅读提示
