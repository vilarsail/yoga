# 瑜伽师地论卷第六十一 导读

## 一、内容总览
本卷为《瑜伽师地论·摄决择分》中「有寻有伺等三地」决择的第四部分，亦即此三地决择的收尾。先以佛为出爱王所说「王法」为入路，开示国王过失、功德、衰损门、方便门、王可爱法、能引王可爱法六大主题；次由王法转入有情苦相，广明八苦各五相；继而以「三士」为纲，依行、受欲、食、施、戒、律仪、止观等十数门反复分判补特伽罗差别；末后以诸欲过失、烦恼发业等杂决择收束全篇，并明示三地决择至此圆满。

## 二、结构层次
本卷以「王法 → 苦相 → 三士 → 杂决择」四段递进，由外王治世入内行修证：

- **缘起 → 王法六门**（P1—P56）：出爱王自述不为誉毁所动、独室筹量后请问于佛 → 佛先以「过失十种 vs 功德十种」为根本对 → 次出「衰损门五 vs 方便门五」为对治对 → 终出「王可爱法五 + 能引发王可爱法五」为果与因对。每对皆「先列名 → 次广释 → 后结失/德与现法后法义利」，六门末以「宜当远离/修习/希慕/受行」总劝修学。

- **苦相决择**（P57—P63）：由「生苦」五相起，老、病、死、怨憎会、爱别离、求不得、五取蕴一一各以五相展开；五取蕴苦总收生、依生、苦、坏、行五苦器，为八苦之根本。

- **三士差别**（P64—P102）：先依「行」立下中上三士（自利利他有无四句）→ 次以「行恶/乐恶」四句配三士 → 再由受欲、食、施物、施田、施心、戒福、禁戒处所、受戒心、别解脱律仪、苾刍律仪四支、三律仪、思惟方便、止观、寻伺三摩地、住修差别等门反复分判，皆以「初名下士、次名中士、后名上士」为固定格式层层枚举。

- **杂决择收束**（P103—P109）：十有情众乐十法、听法六烦恼、烦恼发业三种、非所爱法六种、欲受用五、欲过失八相、欲变坏六相、欲稠林五相似法，末以「我已略说有寻有伺等三地决择……更不复现」结显圆满。

## 三、关键结论
1. 王之得失在「性」与「行」而非资财——种姓过失只一，余九皆自性过失；功德亦然，故「虽有大府库大辅佐大军众而不可归仰」，反之一无所有而可归仰。
2. 王可爱法是果，能引可爱法是因；前四因引发现法利益，末一「勤修法行」引发后法利益，因果与二世义利对应严整。
3. 八苦各以五相分别，五取蕴苦总摄生、依生、苦、坏、行五苦器，是苦之根本；生苦中「粗重所随」贯通三界，为内在于有情的系缚性。
4. 三士之判随观察角度不同而异——同一补特伽罗于「行」「受欲」「施」「戒」「止观」等门中可属不同士类，关键在自利利他具缺与染净浅深。
5. 诸欲少味多苦，由「稠林」五相似法得名，当远离；听法亦有六烦恼过失，学者当先远离。

## 四、易混辨析
- **王过失十种 vs 王功德十种**：一一相对，如「种姓不高—种姓尊高」「立性暴恶—性不暴恶」「受邪佞言—受正直言」「所作不思—所作谛思」等；过失中初一为种姓过失，余九自性过失，功德配位亦然。
- **王衰损门 vs 王方便门**：五门一一相对（不善观察摄受 vs 善观察摄受、非时恩妙行 vs 能以时行恩妙行、放逸不思机务 vs 无放逸专思机务等）；衰损退现法后法义利，方便不退，前四约现法、末一约后法。
- **三士（依行判）vs 三士（行恶乐恶四句判）**：前者约自利利他有无立三；后者约「行恶/乐恶」四句中行恶亦乐恶为下士、行恶非乐恶或乐恶非行恶为中士、非行恶非乐恶为上士。判据不同，不可混为一谈。
- **别解脱律仪·静虑律仪·无漏律仪**：由浅入深配下中上三士；苾刍律仪复分四支（受具足支、受随法学处支、随护他心支、随护先所受学处支），具几支亦判三士。

## 五、阅读提示
本卷三士门反复枚举，易读而难记，建议抓住「自利—利他、染—净、浅—深」主线，记一例（如施心三品或受欲三人）即可贯通其余；王法部分将过失与功德两表对照读，最能见其对称结构。
