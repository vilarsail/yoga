# 瑜伽师地论卷第七十九 导读

## 一、内容总览

本卷为《瑜伽师地论·摄决择分》中菩萨地决择的第八部分，承「功德品决择」之后，进一步决择菩萨所依世界、所住阶位、地地行相、果德不共，及菩萨邪行与正行的对治关系，末以一连串譬喻显菩萨功德。全卷以「境—行—果」为隐线，由菩萨所处境位入手，归于正行与功德譬喻，是菩萨地修学纲要的集中展示。

## 二、结构层次

本卷以问答与「后后引发」两条线索交织推进，可分五层：

- **世界与住位（总起）**：以「五无量世界有无差别」问答引入 → 立「清净世界」（纯菩萨僧、第三地以上方生）→ 密意释疑（化懈怠故说皆往生）→ 转入菩萨阶位，立「四住」（极欢喜、增上戒、增上心、增上慧）能成「四事」（不退菩提心、善品增长、转静虑还生欲界、通达安立速证妙智），成「位—行—果」第一环。
- **心行与障治（内省）**：以四问答明菩萨苦乐作意住（众生损恼为苦、无分别为住）→ 立「四上品障」与「四净除障法」对治 → 复明「四微细难断随烦恼」（法爱、二乘作意、味着等至、众魔事业），由粗障到细障递进。
- **地地行相与修证差别（展开）**：以「已入初地……当言何相」为框架，逐地问答枚举初地至如来地相 → 收束于「造修、得、等流、成满」四问 → 别立「正性离生」差别：声闻由法界差别相入，菩萨由差别、自相二相通达，多住自相故不速趣涅槃 → 配「三世三轮清净」，由遍计所执自性显三世平等。
- **果德不共（升进）**：明「十八不共佛法」——以阿罗汉十八种误失（误失、暴音、忘念、不定等）反显如来永无 → 归摄为无忘失法、大悲、一切种妙智三类 → 略示「随好」为生净信而显、不立相。
- **邪行正行与譬喻（收束）**：以「应当了知」长串列举领起 → 立「邪行八相」后后引发（退智资粮→忘念→坏白法→恶意现行→难调伏→行非道→亲近不贤良→不如其义），一一明其因缘 → 正行即八相反过来 → 正行胜利有四（资粮、障净、白法、利他）→ 立「法行、平等行、善行、法住」四行相 → 终以「能生净信譬喻」（大地、大水、大火、大风、朗月、日轮、师子、龙象、红莲、大树、众流、诸天、大王、大云、轮王、末尼宝、杂林诸天）一连串「非如……然菩萨……」对比，显菩萨功德超世譬喻所不及。

## 三、关键结论

1. 清净世界无三恶道、无三界、纯菩萨僧，唯已入第三地菩萨由愿自在力受生；经说菩萨皆当往生是密意，为化懈怠者勤修善法。
2. 菩萨依四住成四事：初住终不退菩提心，二住善品运运增长，三住以大愿力转静虑还生欲界而不染，四住通达一切法安立、不待余住速证如来妙智。
3. 十地行相次第增明：初地超过异生得极欢喜，三地得强盛奢摩他、尔焰光明，四地起毗钵舍那烧烦恼智焰，八地无功用行，十地得如来同大洒亦名如来，如来地永离二障。
4. 声闻与菩萨虽等通达法界入正性离生，然声闻唯由差别相、缘差别作意速趣涅槃；菩萨由二相通达，多住自相作意，故为无上菩提正方便。
5. 十八不共佛法对治阿罗汉十八种误失，分属无忘失法及拔除习气、大悲、一切种妙智所摄。
6. 菩萨邪行八相后后引发、环环相因；正行即是对治，胜利有四，归于法行等四行相。

## 四、易混辨析

- **四住 vs 十地**：四住（极欢喜、增上戒、增上心、增上慧）是菩萨地中戒定慧与初地欢喜的纲领；十地是逐地别明行相。四住约「能成四事」立，十地约「地地何相」立，互摄而非等同。
- **差别相 vs 自相（法界）**：差别相指常住相、寂静相（约离系、无生、无尽）；自相指遍计所执自性不成实的法无我性，即相名分别真如正智所摄一切法。声闻由差别相入，菩萨由二相通达且多住自相。
- **邪行八相 vs 正行八相**：邪行以后后引发成八相（退智资粮→忘念→坏白法→……→不如其义）；正行是「与上相违离别过失，宣说对治」，即一一反过来。
- **法行 vs 平等行 vs 善行 vs 法住**：法行约「凡所修行不越正法」（五行相）；平等行约「遍于一切利众生事平等修行」（八行相）；善行约「内成熟佛法、外成熟有情」（七行相）；法住约「非但追求读诵宣说寻思为究竟，于内心胜奢摩他发勤方便」（十二行相）。

## 五、阅读提示

读本卷可带着两条线索：一是「由位到行到果」的阶次推进，留意四住、十地、正行如何收束于果德；二是「邪行—正行」的对治结构，留意八相后后引发的因果链如何一一反转。
