- **全篇总括**：本卷是全论开篇，先给出一部百卷大论的完整目录（十七地），然后解剖人的五种感官认识——眼耳鼻舌身识怎么生起、看什么、靠什么；接着开启「意识」的世界，讲到意识最震撼的功能：人是怎么死的、又是怎么投入下一生的；卷末附一篇后序，记录玄奘法师西行取经与朝廷组织翻译这部论的全过程。全卷从「认识怎么发生」一路讲到「生命怎么流转」，是后续一切义理的地基。
  - **十七地：整部论的总目录**
    - **开篇一首偈颂**：把全书目录背了一遍：修行者（瑜伽师）要走的十七个阶段，叫「十七地」
      - **前九地讲认识的各个层面**：五识身相应地 → 意地 → 有寻有伺等三地（语言思维的粗细三档）→ 三摩呬多地与非三摩呬多地（禅定与否）→ 有心地与无心地（心在不在状态）
      - **中间三地讲怎么学习**：闻所成地（听来的）、思所成地（想通的）、修所成地（修证的）
      - **后五地**：讲修行者的种类与最终归宿：声闻地、独觉地、菩萨地，再到有余依地与无余依地（还有残余身体 / 完全解脱）
    - **本卷正文只覆盖前两地的开头**：五识身相应地全篇 + 意地的前半
  - **五识身：五个感官「频道」，一个公式套五次**
    - **五识地**：定义眼耳鼻舌身五种感官认识，只用一个统一公式，五个识全部套用：自性（是什么）→ 所依（靠什么生起）→ 所缘（对象是什么）→ 助伴（有哪些搭档）→ 作业（功能是什么）
    - **自性：依根了别境**——眼识依眼根、了别颜色；耳依耳根了别声音；鼻、舌、身同理。「依根了别」就是识的定义
    - **所依：识生起要靠三层依靠**（唯识学的地基概念，以眼识为例，余识相同）
      - **俱有依**：眼根（净色根）——与识同时运作的感官器官
      - **等无间依**：意——前一刹那刚消失的识，给下一刹那的识「让位」，像接力棒
      - **种子依**：阿赖耶识（储存一切行为种子的根本识）——每个识都从自己过去熏下的「种子」里生出来
    - **所缘：每个频道各看各的世界**
      - **眼识缘色**：色分三种 → 显色（颜色本身：青黄赤白、光影明暗）、形色（形状：长短方圆）、表色（动作：取舍屈伸、行住坐卧）——显色是颜色，形色是轮廓，表色是动态
      - **耳识缘声**：先按来源分（体内器官发 vs 体外物质发 vs 两者共同发），再按感受分（好听、难听、无所谓）
      - **鼻缘香**：（好香、恶香、平等香）、舌缘味（苦酸辛甘咸淡）、身缘触（地水火风、轻重滑涩、冷饥渴饱等）——触特别值得注意：饥饿、口渴、疲劳都是「触」
      - **关键点**：这些对象同时也是意识的所缘——感官收到的东西，意识都能再加工
    - **助伴：识不是独自工作**——每个识生起时都有一组「心所有法」（心理活动，如作意、触、受、想、思）同时运作，它们看同一个对象但角度不同，各自从各自的种子生起
    - **作业：五种感官认识的职能边界**——只了别自己的对象、只了别现在、只了别一刹那；但它会跟着意识转、跟着善恶转、能发起行为并招来苦乐结果
    - **看（听）不是自动发生的：三个条件**——眼根完好 + 对象现前 + 作意（注意力）正确生起，三者齐备眼识才生，缺一不可；听、嗅、尝、触同理
    - **「看见」内部是一场三心接力**——率尔心（眼识的第一瞬间反应）→ 寻求心（意识开始追问「刚才看到的是什么」）→ 决定心（意识下判断）；决定之后才有善恶染净之分，此后眼识意识相续运作
    - **一组帮助记忆的比喻**：所依如出门乘的车 / 家，所缘如要办的事 / 所受用的东西，助伴如同伴 / 仆人，业如自身的能力 / 作用
  - **意地（上半）：意识登场，同样五门，但能量级完全不同**
    - **承接**：五识讲完了，「已说五识身相应地，云何意地」——意地仍按同样五门展开，只是对象换成了真正做主的意识
    - **自性：心、意、识三个字各管一段**——心＝阿赖耶识（一切种子的仓库和依止体）；意＝恒审思量的末那意 + 给六识让位的无间灭意；识＝当下对外境的了别
    - **所依与所缘**——所依仍是等无间依（意）与种子依（阿赖耶识）；所缘最广：一切法，其中意识独有的对象包括受想行蕴、无为法、无见无对色（如观念中的色法）和一切种子
    - **助伴：一张完整的心理活动清单**——广列五十一心所，从遍行的作意触受想思，到善心所（信惭愧、无贪嗔痴）、烦恼心所（贪嗔慢疑）、随烦恼（忿恨嫉悭）、不定心所（睡眠、寻伺），同一所缘、各自起用
    - **意识的「特有功能」清单，逐问展开**（五识做不到、只有意识能做的，即「胜作业」）
      - **分别所缘：想事情的七种方式**——有相（根据已知概念的）、无相（婴儿式的本能反应）、任运（跟着境界跑）、寻求（探索）、伺察（深究）、染污（贪恋过去、期待未来、执着现在）、不染污（出离、无怒、无害）
      - **审虑所缘：判断要有标准**——如理（不添油加醋：破除常乐我净四种颠倒；也不无中生有的否定）、不如理（颠倒和邪见）、非如理非不如理（无记的观察）
      - **一部精神状态百科：醉、狂、梦、觉、闷、醒**——每项都给出成因清单：醉由饮酒习惯与过量；狂由宿业、四大错乱、惊吓、外伤、鬼魅；梦由体弱、疲倦、吃撑、习惯睡眠、外力引发等
      - **行为怎么发动**——一条发动的链条：智慧先行 → 意欲生起 → 加功用行 → 身语业风推动，然后才有身体动作和言语
      - **修行动态：离欲 ↔ 离欲退，断善根 ↔ 续善根**——离欲需要根器成熟、得善知识教导、排除障碍、正确修法；退失因根软、贪恋旧相、烦恼恶友；断善根因利根者造上品恶业、邪见圆满、毫无畏惧（注意：断的是现行的善根，不是连种子都拔掉）；续善根则因见亲友修福、听闻正法、由犹豫转坚定
    - **死：命终的完整过程**（意识作业中最详尽的一问）
      - **先分类**：死有三种 → 寿尽而死（按时死）、福尽而死（供养维持生活的资具断了）、非时死（九种不良生活因缘：饮食无度、吃不合适的、不消化又吃、不吐不泻、不去就医、不知损益、纵欲无度等）
      - **临终什么心态**：决定怎么死 → 善心死者自忆或被人提醒善法，安乐而死、看到不乱色相 ↔ 不恶心死者贪嗔现前，苦恼而死、看到混乱色相；无记心死者两边都想不起来，不苦不乐
      - **临终前的「预兆影像」**——生前作恶的，像梦中见到种种怪异色相（从明趣暗）；受完恶果又修善的相反（从暗趣明）；上品恶业者临终流汗毛竖、大小便失禁、翻睛吐沫
      - **临终的深层动力**：「我爱」现行——直到昏迷位之前，长久习惯的自我贪爱一直运作，恋着自己的身体将消失，正是这份爱推动下一世（但预流、一来果的圣者能以智慧制伏它，不还果则不再现行）
      - **身体的冷却顺序**：跟着业走 → 造恶者识从头顶向下舍、冷触从上往下；造善者从脚底向上舍；最后都止于心口——识最初托在肉心，最后也从这里离开
    - **生：怎么投入下一生**（与「死」对问，讲中有与入胎）
      - **中有（死亡与再生之间的过渡身）如何生起**——两个力量推动：无始戏论熏下的种子 + 善恶业熏下的种子；死与生同时完成，像天平两头一低一昂
      - **中有的形象随业决定**——造恶业者的中有像暗夜黑光，造善业者像晴夜白光；中有具足诸根，眼如天眼、无障碍，能看到自己同类中阴和将要投生之处；方向也随业：往恶趣低头下行、往天上仰面上行
      - **中有的期限：七天一个周期**——没找到投生因缘就死一次再活一次，最多七个七天，之后必定投生；因缘改变也可转去别的种类
      - **中有的一串别名**——中有（在死有与生有之间）、健达缚（寻香而行，靠香气滋养）、意行（以意为导向）、趣生（正对向下一生）
      - **入胎的完整条件**——三处现前：母亲身体调适值排卵期、父母和合起爱染、中阴正现前；还要避开三种障碍：产处过患（产道疾病畸形）、种子过患（精血不健康）、宿业过患（父母子女之间没有感生的业）
      - **入胎时的「颠倒想」**——中阴见到父母交合，误以为是自己在行事：要投生为女的贪恋父亲、要投生为男的贪恋母亲，渐渐只见男女根门，一被障碍，中有灭、生有起
      - **投生家的贫富，决定死时入胎时所见**——薄福者听到纷乱之声、妄见走进丛林芦苇；厚福者听到寂静美妙之声、妄见登上宫殿
      - **结生：新生命第一刻**——父母精血各一滴和合成一段（像熟乳凝结），阿赖耶识就在此处依托进入，微细的根与大种开始和合生长，此即「羯罗蓝位」（受精卵阶段）；之后身根先立，眼耳等诸根依次生成——识最初托在肉心，最后也从这里舍离
  - **后序：一部「国家翻译工程」的竣工报告**（中书令许敬宗奉诏撰写，附于卷末）
    - **先颂皇帝功德**：休兵偃武、弘无为之道，礼乐典章俱兴，广开译场迎接佛法
    - **再记玄奘法师行谊**——少年出家、深悟空假两宗，为寻真教发弘誓愿，裂裳裹足直赴印度：越葱岭、周游十七年、途经百余国，贞观十九年携佛舍利一百五十粒、佛像七躯、经论六百五十七部回到长安
    - **译经始末**——奉敕安置弘福寺，召集二十一位学通内外的名僧共同翻译：贞观二十一年五月十五日开译本论，梵本四万颂、每颂三十二字、全书分五分、宗旨在阐明十七地义；贞观二十二年五月十五日绝笔，总成一百卷
    - **译场分工名单**：笔受、证梵语、正字、详证大义、受旨证文各司其职，由灵会、玄暮、玄应、神泰、道智、行友、玄赜、玄忠、靖迈、辩机、处衡、明浚等诸沙门分掌各分
    - **最后交代论之来源**：佛灭度后，弥勒菩萨从睹史多天宫下降到中印度阿瑜他国，为无著菩萨所说——这部论因此被尊为「法门极地」
