# 瑜伽师地论卷第十六 词语注释

① 思所成地　闻、思、修三慧之思慧所成就地，即本地分第十一地；以自性清净、思择所知、思择诸法三相为相。

② 自性清净　思慧之自性，由九相（独处空闲审谛思惟等）显其清净，是后二相所依之能观体。

③ 思择所知　思慧所观之境，于有法了知有相、于无法了知无相，即「所观察义」。

④ 黑说大说　又称恶说善说、劣说胜说，指世间种种言说议论；思惟者须善了知其相以辨别是非。

⑤ 自相有法　五种有法之一，谓法自体相，分胜义相、相状相、现在相三种。

⑥ 共相有法　五种有法之一，谓诸法共通之相，分种类、成所作、一切行、一切有漏、一切法五种。

⑦ 假相有法　五种有法之一，谓依名言施设之假立相，由六种言论所起，如瓶、宅、军等。

⑧ 因相有法　五种有法之一，谓能生果之因，分可爱、不可爱、长养、流转、还灭五因。

⑨ 果相有法　五种有法之一，谓从五因所生、所得、所成、所办、所转之果。

⑩ 一切有漏共相　共相之一，谓有漏行皆苦性相，即苦谛之义。

⑪ 一切法共相　共相之一，谓一切法空无我性相，即空、无我之义。

⑫ 属主相应言论　假相有法六言论之一，谓言论必配属于主（如「色之生」）方能解其相，显此法是假。

⑬ 远离此彼言论　六言论之一，谓非以此显此、亦非以彼显彼之言论，一向于假相处转，如「宅之门」。

⑭ 众共施设言论　六言论之一，依六种相状（事、所识、净妙等、饶益等、言说、邪行等）假立自性。

⑮ 众法聚集言论　六言论之一，于众多法和合建立自性，如内五蕴立「我」、外色等立「瓶宅」。

⑯ 非常言论　六言论之一，由破坏、不破坏、加行、转变四相显物非常，如瓶破已瓶言舍、瓦言生。

⑰ 还灭因　五因之一，谓能寂静道、般涅槃、趣菩提及彼资粮方便，能生能办还灭之果。

⑱ 毕竟无　五种无之一，谓石女儿等毕竟无类，从本以来决定非有。

⑲ 圆成实相有性　五种有性之一，即胜义相，真如法性圆满成就真实有。

⑳ 依他起相有性　五种有性之一，即缘生相，依众缘而起之有为法相。

㉑ 遍计所执相有性　五种有性之一，即假施设相，凡夫妄计所执之我法相。

㉒ 补特伽罗　梵语 Pudgala 音译，意译「数取趣」，指轮回中数数取趣受生之有情个体，佛教假名安立无实自性。

㉓ 素呾缆　梵语 sūtra 音译，旧译修多罗，意译契经，佛所说经教，为十二分教之首，属三藏之一。

㉔ 伽他　梵语 gāthā，颂、偈颂；以韵文形式宣说法义。

㉕ 胜义伽他　三类伽他之一，依补特伽罗无我胜义宣说，遮遣增益损减二边，显唯有因法。

㉖ 意趣义伽他　三类伽他之一，依如来意趣宣说，本卷为大梵天王请问三学之颂。

㉗ 染污意　第七识，末那识，恒与我痴等诸烦恼俱生俱灭；若解脱诸惑，非先亦非后。

㉘ 增益边执　二边执之一，于无计有，如执有实我；胜义伽他为遮此边说「诸法无用」。

㉙ 损减边执　二边执之一，于有计无，如拨无因果；胜义伽他为遮此边说「用转非无」。

㉚ 行苦　三苦之一，谓一切有为行刹那生灭迁流之苦，为粗重所随逐、阿赖耶识所摄，是苦谛之主体、三苦之本。

㉛ 阿赖耶识　梵语 Ālayavijñāna 音译，意译「藏识」，唯识宗所立第八识，含藏一切法种子，为诸法生起之根本所依。

㉜ 有余依　即有余依涅槃，阿罗汉断尽烦恼而残余先业所感有漏依身尚存之状态，烦恼已尽而苦依未灭。

㉝ 无余依　即无余依涅槃，阿罗汉身坏命终，一切有漏依身与识永灭之究竟寂灭状态。

㉞ 杜多功德　梵语 dhūta（头陀）功德，意为抖擞、弃除烦恼；指粪扫衣、常乞食、树下坐等少欲知足之行，为趣向寂静之助缘。

㉟ 增上戒学　三学之首，以净戒为增上、防护身语令不散乱，包括律仪、圆满、清净等差别，为定慧之所依止。

㊱ 增上心学　三学之二即定学，谓依戒修习禅定令心专注一境，为发慧之方便、增上慧学之所依。

㊲ 增上慧学　三学之三，依增上心所发以慧为性，于四圣谛如实智见能证究竟诸烦恼断，为三学之极。

㊳ 别解脱律仪　梵语 Prātimokṣa（别解脱），谓七众弟子各别受持、别别防护身语之戒律仪，受持一条即于一条别别解脱。

㊴ 三摩地障　禅定之障碍，即诸粗重；断除三摩地障是增上心学成满之因。

㊵ 旃茶罗　梵语 caṇḍāla，古印度贱民阶层，屠者等；律制苾刍不应往其家，防讥毁故。
