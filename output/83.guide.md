# 瑜伽师地论卷第八十三 导读

## 一、内容总览
本卷为《瑜伽师地论》「摄异门分」之上半。摄异门分是对前文（尤本地分十七地）所列法相以「异门」——同义、近义之别名——重新归纳诠释的部分，与前一卷「摄释分」相承接。全卷以「白品与黑品异门等宣说」为总纲，实际广释以白品为主：先释师之异名与德号，次释慧之种种品类，次广说施、戒、道三学，复明远尘离垢、如病等观行、如来十号、无常想修及涅槃无量异名，是研究法相名训与同义词类的重要篇章。

## 二、结构层次
全卷由总嗢拖南「白品与黑品异门等宣说」开展，按「师 → 法 → 行 → 果 → 德」一线推进，内分四大块：

- **师与所学法（P6–P45）**：先释大师、绍师、袭师三种师位（立教、传教、随教），次明师之奖导三德、伴友四名、义利等所求；再以「第一、尊、胜、上、无上」五号三释（自他义、三界善、二障净）显师德；次释慧之数十种异名（加行、正体、后得三慧所摄），收束于善说法律四圆满与佛世尊法五相。其中慧名一段最繁，按「能得生长清净成办圆满无退 → 捷速利出决择甚深 → 大广无等慧宝 → 慧眼明光曜灯炬照 → 慧根力财剑杖辔垣墙阶陛堂殿」层层铺排。
- **施戒道三学广说（P45–P80）**：施分六种；戒立尸罗、律仪等一串异名；道品按念住、正断、神足、根力、觉支、道支、无量为序，详释修念住之对治、简择之层次（简择 → 最极简择 → 极简择法，对应解了 → 等解了 → 近解了，寻求道 → 决定道）、寻思思惟分别之所依（圣教/现量/比量）及远离护戒诸名。
- **远尘离垢与四谛观行（P81–P120）**：先释智、见、觉、知、明等慧名异门及宣说、施设、安立等言教次第；次明初善中善后善、纯一圆满等法之妙相；次释猛利欲、炽然、独、远离等加行相；正释「远尘离垢法眼生」即见道断我慢及见所断烦恼；广明如病等无常苦空无我观、我生已尽等四果记别、并天世间等所化境、依取执着随眠之杂染缘起。
- **如来十号与无为涅槃异名（P121–P154）**：先以嗢拖南标如来、无常想等；次正释如来十号（如来、应、明行圆满、善逝、世间解、无上丈夫调御士、天人师、佛陀、薄伽梵），分共德、不共德；次明无常想修习方便与譬喻（台阁梁栋象迹、流注日出、轮王城王）；次列道障道失（疑、邪寻思、忿恼、有怖畏刺、失道恶道）；末以无动、甘露、安隐、清凉、不死没、无炽然、涅槃等无量异名显无为果，并以无余断七句（永弃舍、永变吐、永尽、永离欲、永灭、永寂静、永灭没）配三世与见修二道收束全卷。

## 三、关键结论
1. 大师立为「第一、尊、胜、上、无上」，由自义、他义、俱义及三界善、出世间善、二障清净等多重义理建立，显如来功德超胜三乘一切世间。
2. 「慧」名虽多，总摄为加行慧、正体慧、后得慧三类，与闻思修三慧相配；末以慧剑、慧杖、慧辔、慧垣墙等譬喻显慧之断障防过功能。
3. 远尘离垢即见道位，尘指我慢及见所断一切烦恼，垢指彼品所有粗重；断已证法眼、得法、知法，越渡自他所证之疑。
4. 我生已尽、梵行已立、所作已办、不受后有四句通记四果，分别记别初二果、不还果、阿罗汉果之解了行相。
5. 涅槃有无量异名（无动、甘露、安隐、清凉、趣吉祥、不死没等），皆显一切依寂灭、一切苦永尽之理；末以无余断七句配三世解脱与见修二道，总显断烦恼事。

## 四、易混辨析
- **大师 / 绍师 / 袭师**：大师是立圣教者（如来），绍师是传圣教者（第一弟子如舍利子），袭师是随圣教者（轨范师、亲教师等），由立、传、随递降。
- **能奖 / 胜奖 / 至奖 vs 能导 / 胜导 / 至导**：奖侧重驱摈不应作、庆慰应作、开示前二事；导侧重遣疑惑、遣恶作忧悔、遣烦恼及随烦恼，奖主行仪奖掖，导主心疑开导。
- **简择 / 最极简择 / 极简择法 vs 解了 / 等解了 / 近解了**：前者取苦谛总别与契经法，后者由发悟、寻求、决定次第；对应寻求道与决定道。
- **寻思 / 思惟 / 分别**：同依无倒法义，然所依不同——寻思以圣教为依，思惟以现量为依，分别以比量为依。
- **尘 / 垢**：尘指已生未究竟智、能障现观之我慢及见所断一切烦恼；垢指彼品及见断品所有粗重。

## 五、阅读提示
带着「异门」思路读：同一法在不同语境下何以用不同名？名异义同之处，正是论主令读者从多面入观之方便。可特别注意慧名一段（P29–P40）与涅槃异名一段（P142–P149），看论主如何以譬喻与义理双显一法。
