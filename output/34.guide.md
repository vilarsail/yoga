# 瑜伽师地论卷第三十四 导读

## 一、内容总览
本卷为「声闻地第四瑜伽处之二」，明出世道修习——依四圣谛境起七作意，由十行观察苦谛悟入四行（无常苦空无我），次第趣入集灭道谛，经暖顶忍世第一法顺决择分，证谛现观得预流一来不还果，复修金刚喻三摩地永断修道所断烦恼证阿罗汉果，究竟声闻行位果论。十行入四谛与四沙门果现观是本卷核心，为声闻地出世道的圆满总结。

## 二、结构层次
全卷按「四谛十六行 → 十行入苦谛 → 集灭道 → 暖顶忍世第一法 → 谛现观 → 修道四果 → 金刚喻定阿罗汉」推进：
- **了相作意四谛十六行（P1-P35）**：苦谛四行（无常苦空无我）由十行观察——变异/灭坏/别离/法性/合会五行无常、结缚/不可爱/不安隐三行苦、无所得行空、不自在行无我；集谛四行（因集起缘）了知爱为取因招集生起缘；灭谛四行（灭静妙离）；道谛四行（道如行出）。
- **胜解作意（P37-P38）**：超过闻思间杂一向发起修行胜解，于苦集二谛得无边际智，发无常苦空无我无边际胜解。
- **断我慢入谛现观（P38-P44）**：粗品我慢随入作意间无间转（我于生死流转、我能观苦等），以慧通达制伏外所知境，以心缘心专精无替，悟入四谛；能缘所缘平等平等智生，下忍名暖、中忍名顶、上忍名谛顺忍；最后一念无分别心起内作意名世第一法，无间出世心。
- **谛现观与三果（P45-P49）**：无分别决定智现见智生，永断见道所断粗重；先已离欲界贪得不还、倍离欲界贪得一来、未离欲界贪得预流；得四智（唯法/非断/非常/缘生如幻）。
- **修道（P50-P55）**：修自性（定地作意令心相续会彼体性）、八修业（得习净遣知断证远）、十一修品类（奢摩他/毗钵舍那/世间/出世/下中上/加行/无间/解脱/胜进道）；摄乐作意、观察作意数数观察已断未断。
- **金刚喻定阿罗汉果（P55-P62）**：最后学位喻如金刚三摩地生，永断修道所断一切烦恼，发尽智无生智，成阿罗汉诸漏已尽所作已办；住有余依般涅槃界，余取无故入无余依般涅槃界。
以「十六行了相 → 胜解 → 断慢现观 → 三果 → 修道 → 金刚喻定」为统一骨架。

## 三、关键结论
1. 苦谛四行由十行观察：五行（变异灭坏别离法性合会）是无常行、三行（结缚不可爱不安隐）是苦行、无所得是空行、不自在是无我行。
2. 集谛四行：爱为取因名因、招集令生名集、令苦起名起、摄受当来种子名缘；又依爱随眠及三种缠（后有爱喜贪俱行爱彼彼喜爱）。
3. 灭谛四行：无余息灭名灭、一切寂静名静、第一最胜无上名妙、常住永出离名离；道谛四行：能通寻求名道、能实寻求名如、四门随转名行、一向趣涅槃名出。
4. 暖顶忍世第一法：下忍能缘所缘平等智生名暖、中忍名顶、上忍名谛顺忍；最后一念无分别心起内作意名世第一法，无间出世心生。
5. 谛现观永断见道所断，得四智（唯法非断非常缘生如幻），不堕恶趣不更受第八有生。
6. 三果配位：先已离欲界贪得不还、倍离得一来、未离得预流。
7. 金刚喻三摩地最上最胜最坚固能坏一切烦恼非上烦恼所能蔽伏，永害粗重种子发尽智无生智成阿罗汉。

## 四、易混辨析
- **了相作意 vs 胜解作意**：了相约四谛十六行犹为闻思间杂、胜解超过闻思一向发起修行胜解唯缘谛境一向在定。
- **暖 vs 顶 vs 谛顺忍**：约能缘所缘平等平等智生分下中上忍，暖为下忍顶为中忍谛顺忍为上忍，顺决择分四位如钻火。
- **世第一法 vs 谛现观**：世第一法是世间诸行最后界畔边际、最后一念无分别心起内作意；谛现观无间出世心生无分别决定智现见智生。
- **见道 vs 修道**：见道率尔智生永断见所断、修道数数修习断修所断，配预流至阿罗汉向。
- **尽智 vs 无生智**：尽智于烦恼究竟尽中起、无生智由因尽故当来苦果毕竟不生起，阿罗汉具二智。
- **有余依般涅槃 vs 无余依般涅槃**：有余约住最后有身先业烦恼所引诸蕴犹在、无余约诸蕴自然灭余取无不相续。

## 五、阅读提示
本卷是声闻地出世道圆满总结，可带「十行入四谛十六行 → 暖顶忍世第一法 → 谛现观三果 → 修道八业十一品类 → 金刚喻定阿罗汉」五线索读；十行配四行表、四沙门果对治表最宜对照把握。
