# 瑜伽师地论卷第二十九 导读

## 一、内容总览
本卷为「声闻地第二瑜伽处之四」，续广辨菩提分修之余（四正断→四神足→五根五力→七觉支→八圣道），次明修果、补特伽罗异门、建立因缘、魔及魔事、发趣空无有果。三十七菩提分渐次修习与四沙门果建立因缘为本卷主体，是声闻地行位果论总结。

## 二、结构层次
全卷按「四正断 → 四神足 → 五根力 → 七觉支 → 八圣道 → 修果 → 异门 → 建立因缘 → 魔事 → 无果」推进：
- **四正断（P1-P21）**：未生已生恶不善法令不生令断、未生已生善法令生令住 → 略义（黑白品舍取增上意乐加行圆满）→ 四名（律仪断/断断/修断/防护断）。
- **四神足（P22-P31）**：欲勤心观四三摩地，各由增上力所得 → 八断行（欲/策励/信/安/念/正知/思/舍）→ 神足名义（能得能证殊胜出世法）。
- **五根五力（P32-P43）**：信精进念定慧根力 → 信等即四证净/四正断/四念住/四静虑/四圣谛 → 渐修发起顺决择分四种善根（暖/顶/顺谛忍/世第一法），如钻火喻。
- **七觉支（P42-P43）**：择法精进喜（观品）、安定舍（止品）、念（遍行），见道位修。
- **八圣道（P44-P53）**：正见/正思惟/正语/正业/正命/正精进/正念/正定，慧蕴戒蕴定蕴所摄，修道位修。
- **修果（P54-P64）**：四沙门果——预流（断三结）、一来（薄贪嗔痴）、不还（断五下分结）、阿罗汉（永断一切烦恼）。
- **补特伽罗异门（P72-P85）**：沙门四种、婆罗门三种、梵行三种、苾刍五种、精勤三种、出家二种。
- **建立补特伽罗因缘（P86-P89）**：八补特伽罗由四差别建立——根/瑜伽/加行/时差别。
- **四魔及魔事（P90-P104）**：蕴魔/烦恼魔/死魔/天魔 → 魔事（退舍善法欲、取相入欲、疑惑三宝四谛、可怖畏相、利养悭吝等）。
- **发趣空无有果（P105）**：三因缘——诸根未积集、教授不随顺、等持力微劣。
以「菩提分余 → 修果 → 异门 → 因缘 → 魔事 → 无果」为统一骨架。

## 三、关键结论
1. 四正断略义：黑白品舍取中增上意乐圆满（生欲）及加行圆满（策励精进策心持心）；又名律仪断/断断/修断/防护断。
2. 四神足八断行：欲、策励、信、安、念、正知、思、舍，为害随眠瑜伽圆满三摩地。
3. 五根即四证净中净信、四正断中精进、四念住中正念、四静虑中正定、四圣谛中正智；五力难伏摧伏魔军。
4. 顺决择分四善根如钻火喻：暖（无漏火前相）、顶（如热气上冲）、顺谛忍（如烟发）、世第一法（如无焰火），世第一法无间生出世无漏圣法。
5. 七觉支三品：择法精进喜观品、安定舍止品、念遍行；初有学见圣谛迹。
6. 八圣道三蕴：正见正思惟正精进慧蕴、正语正业正命戒蕴、正念正定定蕴；见道后修道方立正语业命。
7. 四沙门果对治四烦恼：预流断感恶趣三结、一来断再生相续、不还断还生此界、阿罗汉断一切感生有烦恼。

## 四、易混辨析
- **策励 vs 发勤精进**：策励约缘不现见境及下中品缠、行过去未来境；发勤精进约缘现见境及上品缠、行现在境。
- **律仪断 vs 断断 vs 修断 vs 防护断**：律仪断约已生恶令断、断断约未生恶不生、修断约未生善令生、防护断约已生善令住不忘。
- **见道 vs 修道**：见道率尔智生暂时智起即永断见所断、七觉支摄；修道长时相续断修所断、八圣道摄。
- **顺决择分四善根次第**：暖→顶→顺谛忍→世第一法，如钻火之暖→热气→烟→无焰火→猛焰。

## 五、阅读提示
本卷是声闻地行位果论总结，可带「四正断→四神足→五根力→七觉支→八圣道 → 四沙门果对治 → 六异门 → 四魔魔事 → 三无果」五线索读；顺决择分四善根钻火喻与四沙门果对治表最宜对照把握。
