- **全篇总括**：本卷是《菩萨地》「持随法瑜伽处」连收四品，回答闯菩萨道前的四个问题：怎样才算真菩萨（立五张身份证）？日常具体修什么（给在家出家的四法处方）？靠什么心撑住修行（七相怜愍与十五种意乐）？修到哪一级了（十二住进度条）？全卷最后落在两站细描——胜解行住的新手画像与极欢喜住的第一关风光。
  - **菩萨相品：怎样才算真菩萨？**
    - **本品开篇即问**：「云何真实诸菩萨相」，答案是一首偈与一套公式：五相成就才算入菩萨数，且每相都用同一个「五转」框架解剖——先立总纲，再逐项填内容。
      - **五张身份证**：哀愍（对众生苦难感同身受并施救）、爱语（说真正利益人的话）、勇猛（刚决坚固无所怯劣）、舒手惠施（广大而无染污的布施）、能解甚深义理密意（通达深法密意）
      - **五转公式**：自性（本质是什么）、依处（对哪些对象运转）、果利（修了得什么）、次第（先后顺序）、相摄（归入六度——布施、持戒、忍辱、精进、静虑、般若——中的哪一度）
    - **自性**：五相各自的本质定义
      - **哀愍分两层**：心里有利益与安乐意乐（在意乐），行动上随力随能以身语饶益（在正行）
      - **爱语是三种话**：慰喻语（安抚）、庆悦语（祝贺）、胜益语（增益），引前摄事品
      - **勇猛**：即刚决坚固、有大势力，惠施即广大施与无染施；能解甚深义的标准是四无碍解（对法、义、词、辩说通达无碍）加上正确引发它的加行智慧
    - **依处**：五相各有一张「运转对象」清单，每张清单结尾都重复「除此无有若过若增」，表示范围封闭完整
      - **哀愍的五类对象从苦到不苦排开**：地狱等纯苦有情 → 乐在恶行的有情（如屠宰从业者）→ 耽欲放逸的有情 → 依妄见出家修邪苦行的有情 → 被烦恼种子缠缚的贤善修行人与有学圣者
      - **另四相各引前文或遍布三藏**：爱语依五种正语、勇猛沿用菩提分品「坚力持性」五依处、惠施即数数等五种施；能解甚深义的五依处是契经中空性与缘起的甚深、戒律中持犯与还净的善巧、论藏（摩怛理迦）的无倒法相、佛意趣难解之处、一切法的法义与释词差别
    - **果利**：五相各自的回报清单
      - **哀愍**：先断怨害嫌恨 → 做利他事心无怯劣不厌倦 → 现世得无罪的安乐住，如佛说修慈者现生不受毒药刀杖
      - **爱语**：现世断妄语、离间、粗恶、绮语四种语过，能摄受自他安隐而转，来世言必信用；勇猛现世离懈怠、受净戒而不犯不退，来世做菩萨事业禀性坚固、未成不退
      - **惠施与甚深义解的果利**：归入威力品所说的施威力与般若威力
    - **次第与相摄**：五相不是并列散件，而是一条有先后顺序的操作链，再各自归位到六度
      - **顺序**：先修哀愍摄受有情 → 次修爱语把人从不善处安立到善处 → 次修勇猛在烦恼邪行中堪忍、不弃舍任何人 → 次修惠施以财、以法令有情成熟 → 最后修解甚深义理
      - **相摄**：哀愍归静虑度，爱语归戒度与慧度，勇猛归精进度、忍度与慧度，惠施即施度本身，甚深义解归静虑度与慧度
  - **分品：在家出家的四法速成包**
    - **上一品立了「验货标准」**：本品接着回答日常功课：在家、出家两类菩萨修哪几法能快速成佛？答案是四法——善修事业、方便善巧、饶益于他、无倒回向
    - **善修事业**：六度共用四把尺子
      - **公式**：每一度都要「决定修作（遇缘必做）、委悉修作（彻底周遍）、恒常修作（无间不断）、无罪修作（远离杂染）」，六度全部照此套用
      - **以施度为样板**：乞者现前，有恩无恩有德有失都要给（决定）；连身命都能舍何况外物（委悉）；随时随得随施无厌倦（恒常）；远离施品所列的杂染施（无罪）
    - **方便善巧**：十种工具合起来能作五事
      - **前四种沿接引流程排列**：对憎背圣教者除其恚恼 → 对处中者令其趣入 → 对已趣入者令其成熟 → 对已成熟者令其解脱
      - **后六种是知识装备**：通世间异论、能观察持犯、明正愿，以及于声闻乘、独觉乘、大乘各有善巧
      - **五事**：安立所化有情于自义利、摧伏一切异论、不犯所犯犯已速悔、证当来所爱事圆满、随有情种性根机说相称法
    - **饶益于他与无倒回向**
      - **饶益于他**：依四摄事（布施、爱语、利行、同事）：或予利益、或予安乐、或利益安乐兼予
      - **无倒回向**：由前三法三门积集的善根，以淳净信心唯一回求无上菩提，绝不拿去换世间果报异熟
      - **原文断言**：三世一切在家出家菩萨证得菩提，全由这四法而来，「除此无有若过若增」
    - **出家与在家**：同一张处方，不同的起点
      - **两类解脱**：出家者于父母亲属的摄受过患、营农商贾事王等艰辛杂务忧苦，皆得解脱，在家菩萨则不然
      - **三项修行优势**：能行一向清净的「钩锁梵行」（相续不断的净行）、菩提分法速证通慧、安住决定清净律仪故凡所发言众咸信奉
  - **增上意乐品：靠什么心撑住修行？**
    - **前品讲「做什么」**：本品讲「动力系统」：先立对众生的七相怜愍（所以菩萨名为善意乐、极善意乐），再给增上意乐下定义并展开十五种型号，最后总归十事。定义是：以净信为先、择法为先，对诸佛法生起印可决定的胜解（坚定认许）——这样的意愿就名增上意乐
    - **七相怜愍**：对众生心意的七条合格标准
      - **无畏**：（不因害怕讨好而起）、如理（决不以非法非律劝授）、无倦（饶益事业不厌倦）、无求（不待请求主动做）、无染（不祈恩报、不求生果异熟，亦名无缘怜愍）
      - **广大**：（遭一切不饶益事而不弃舍，宁自受苦不以恶加人）与平等（普于一切有情，无分限）
    - **十五意乐**：动力的完整型号表
      - **前十种按所缘对象分**：最上（于三宝）、遮止（于净戒）、波罗蜜多（于六度）、真实义（于二无我与真如）、威力（于神通）、利益（愿以善法授与众生）、安乐（愿以饶益授与众生）、解脱（无爱染心、不系当来异熟）、坚固（于菩提心不变易）、无虚妄（于方便有无颠倒智）
      - **后五种按修行阶段分档**：不清净＝胜解行位的意乐（即应调伏，须思择对治）；清净＝从净胜意乐地到决定行地；善清净＝到究竟地；清净以上是俱生意乐（本性成就、不假造作）
      - **十五意乐能作十事**：从最上意乐于三宝修最胜供养、遮止意乐命难亦不犯戒、真实义意乐以无染心流转生死而不舍涅槃，到无虚妄意乐不满足于下劣证悟、俱生意乐速证菩提并为天人作义利
      - **结尾断言**：三世诸菩萨证菩提全由此十五意乐，「除此无有若过若增」
  - **住品：菩萨修行的十二级进度条**
    - **标准、操作、动力齐备后**：本品回答「修到哪一级」：一切菩萨住与菩萨行收进十二住，另有如来为第十三「无上住」；本卷细描前两站
    - **十二住名单**：定义串成一条升级链
      - **种性住**：（本性仁贤、任持一切佛法种子、不现起粗重烦恼）→ 胜解行住（从初发心到未得清净意乐之间的一切菩萨行）→ 极欢喜住（即「净胜意乐住」，净胜意乐即清净坚固的胜解意愿）
      - **增上戒住**：（以净胜意乐为缘得性戒）→ 增上心住（得世间静虑等持等至）→ 三种增上慧住：觉分相应（依三十七菩提分法简择诸谛）、诸谛相应（于四谛如实觉）、缘起流转止息相应（观无智故众苦流转、有智故众苦止息）
      - **两个无相住**：有加行有功用（勤修真如无分别慧）→ 无加行无功用（任运自然运转）；再上是无碍解住（善辨诸法异门、义趣、释词、差别而为说法）与最上成满菩萨住（菩萨道究竟、得大法灌顶，或一生所系——再受一生即成佛，从此无间证菩提）
    - **发趣→得→净**：每一站怎么升上去
      - **种性住**：对其余诸住只是摄受其因（只有种子）；胜解行住对一切后住算「发趣」（已上路未到达）；此后每住修清净，下一住就从「先已发趣」变为「今复名得、为令清净而修正行」，展转至最上成满；如来住则是「顿得顿净」
      - **修行质量同步升级**：胜解行住所作狭小、有缺、不定、有退 → 极欢喜住至三种增上慧住所作广大、无缺、决定、无退 → 两个无相住以后所作无量、终无退转；对「无相修」的进度也是胜解行住发趣 → 极喜至增上慧住获得 → 初无相住圆证 → 第二无相住清净 → 无碍解住清净、最上成满领受其果
    - **胜解行住**：一份极诚实的新手画像
      - **总特征是「思择力胜」**：一切加行都要靠反复分别思择才做得出，不能任运成办；成就狭小的闻思智、属「苦迟通行」（钝根慢速的进道）；对佛法僧、真实义、因果、神通威力都「随他信」而行——靠信佛菩萨，还不能自内了知真实
      - **五种怖畏未超越**：不活畏、恶名畏、死畏、恶趣畏、处众怯畏；三处有忘失念（好恶境界中失念、受生忘前生、久作久说有所忘失）
      - **行为起伏**：或发心又退舍、或舍所受净戒、或利他中途生厌倦、或闻深法生惊怖；说法如暗中射箭「或中不中」
      - **收尾用忍位分层**：下忍时以上毛病最重（上品），中忍转轻，上忍时其性微薄、渐次无余永断，从此无间入极喜住——染污诸法皆无所有、白净诸法显现，才正式得名净胜意乐；此前纵有软中上品胜解，都被随烦恼染污，不名净胜意乐
    - **极欢喜住**：第一关为什么叫「极欢」
      - **入住先发起具六相的「善决定」大愿**：内证修性、超过一切白净愿、无等不共果、超世间境界而救有情苦、不共声闻独觉、一刹那生起即得无量白法果；此愿无变无尽、直趣菩提边际——它也叫「发心」；发心四相即何相（于菩萨行正超出）、所缘（缘菩提资粮与利他事的圆满）、状相（随顺无师自然妙智与广大愿心）、胜利（超凡夫地、生如来家成佛真子）
      - **「欢」的来源**：断五怖畏——不活畏由无我智（我想尚不转，况我爱资生爱）、恶名畏由于他无所希求、死畏由离我见、恶趣畏由自知当来决定值佛、处众怯畏由自见世间无与等者；并远离闻深法惊怖、高慢憍傲、他害起嗔、世财贪喜
      - **以十种大愿开路**：供佛、受持正法、劝转法轮、随佛行菩萨行、成熟有情、往诣佛土、净修自土、不离诸佛菩萨、利他不空过、证菩提作佛事；并自誓如众生界相续无尽，此愿生生相续乃至菩提边际
      - **十种净修住法**：令此住速得清净，环环相接：净信 → 观缘起纯大苦蕴起大悲 → 誓令解脱起大慈 → 无顾恋惠施身财 → 无倦求世出世法 → 善知诸论 → 善解世间 → 修惭愧 → 坚力持性 → 供养如来；修此十法还能开晓其余九住
      - **现见诸佛有二因缘**：（由粗净信、由正愿力）；见佛后供养、闻法、四摄成熟有情、回向菩提——三种清净因缘令善根倍复明净，如工匠炼金愈炼愈净，经历无量俱胝那庾多百千大劫
      - **受生与威力**：在在生处多作赡部洲轮王，威被有情调伏悭吝；若弃财位净信出家，一刹那证百三摩地——净天眼见百如来、动百世界、化百类身、住百劫、入百法门化百身；此后愿力所引神变无量难数
    - **卷末收束**：两个词源定全卷
      - **略说极欢喜住八门**：善决定、四相发心、引发正愿、净修住法、开晓余住、修治善根、受生、威力；广说即《十地经》极喜地
      - **「地」取「能摄持菩萨义」**：「住」取「能为受用居处义」——《十地经》的十地与这里的十住，是同一进度的两个名字
