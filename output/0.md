# 前言

佛家与道家的典籍卷帙浩繁，文辞讲究，义理深奥。然而对于初学者而言，其语言往往过于艰涩，不易入门。更遗憾的是，像《华严经》《瑜伽师地论》等许多重要经典，至今仍缺乏完整的现代汉语译本。笔者在学习过程中发现，市面上或网络上能获取的资料，大多仅收录原文及少量注疏，这无疑为初学者深入理解带来了不小的障碍。

经典本身是最珍贵的学习资源，若因文字隔阂而却步，实为可惜。随着信息时代的推进，人工智能技术迅速发展，笔者作为一名计算机工程师，遂萌生借助AI之力尝试对这些典籍进行翻译与整理的念头。于是决定将翻译内容陆续整理成书或博客，既是对个人学习的记录，也希望能为后来的学习者略尽绵薄，让更多人能够更便捷地亲近经典、深入经藏。

本书为笔者对《瑜伽师地论》的重译版本，在初版基础上做了较多的改进。笔者刚开始翻译该书时，AI尚处起步阶段，智能水平有限，机器幻觉严重，而业界对agent、skill、harness等工程的实践也相对匮乏，导致初版越到后期，章节内容存在的问题越多。

随着AI技术与业界工程能力的持续进步，本次重译着重解决了上述问题，进行了大量的优化和校对，并增补了注释与导读，以方便读者理解。主要更新如下：

** 以下为v2.x版本更新内容：**

1. 对所有原文及译文，使用大语言模型进行了三轮翻译、检查与校对，最大可能地保证了原文与译文的准确性；

2. 基于语义理解，对原文进行了智能化拆分。原文中存在许多长达数千字的段落，给对照阅读造成了较大负担，本次借助大语言模型对其进行了合理的段落重划；

3. 每章增设导读，对文本内容进行总括并梳理逻辑架构，帮助读者在阅读前大致做到心中有数，尽可能减轻阅读压力；   

4. 新增专业术语对照表，并对难点、重点及特殊术语补充了详细译注，方便读者随时查阅。

** 以下为v3.0版本更新内容：**

1. 针对初版译文中大量「翻译正确但表达仍近文言」的段落，新增译文明晰化处理：在不改变原意的前提下，将残留的文言句式、紧缩复句与省略主语统一改写为顺畅的现代白话，使全文语言风格一致、普通读者无需对照原文即可一遍读懂；

2. 对佛典中可按字面解义的义理复合术语（如「无见有对」「任运」「现法」等）进行了全卷统一整改，或直接意译、或首次出现时括注白话释义，消除了因术语未译而造成的阅读障碍；

3. 建立了「改写→校验→修正」的自动化质量闭环，每段改写均经独立校验 Agent 对照原文与原译文逐句审核，确保改写不引入错译或漏译，不通过则修正或回退；

4. 对初版中的近似未翻译段落（仅做标点替换、个别词替换）与漏译段落进行了系统性检测与补译，进一步完善了全文的翻译覆盖度；

5. 为每卷配了一张可交互的思维导图网页（共 100 张）：以层级树形式呈现全卷的义理脉络，每个节点附简明白话概述，单击节点即可折叠/展开分支，支持拖拽平移、滚轮与捏合缩放、一键复位。读者既可先纵览全卷结构，也可逐层展开深入细节，作为阅读正文前的「地图」使用；

6. 为每卷配了一份交互式学习网页（共 100 份）：按「由易到难」的学习路径重新组织本卷的核心义理，通过点击翻转卡片、条件模拟器、流程分步推进、动手归类练习等多种交互形式，把抽象义理拆解为可动手体验的学习环节，适合初学自测与复习巩固。全部学习网页与思维导图配有统一目录页（study/index.html），可通过仓库根目录的 serve-study.sh 一键启动本地服务浏览；

7. 重难点词语注释全面扩充：从旧版每卷 20–40 条的术语注释扩充至每卷 111–254 条，新增注释重点覆盖**非术语的难解文言词**——古今异义（如「胜利」谓殊胜利益、「现法」谓今生、「数数」读 shuò 谓屡次）、生僻字词（一律注音）、通假字、关键虚词与论辩句式（如「汝何所欲」「不应道理」）、律制名物与音译词，并对旧版漏收的法相术语逐一补注；文言原文中偶见的形近讹字（如「元明」当作「无明」）亦如实收录并加以辨析；
