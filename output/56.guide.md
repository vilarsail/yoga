# 瑜伽师地论卷第五十六 导读

## 一、内容总览
本卷为《瑜伽师地论》第五十六卷，"摄决择分中五识身相应地意地之六"，紧接前卷决择意地所余法相。先以问答广立诸蕴分位所摄心不相应行法，次以多门分别诸蕴自相共相并破"唯心实有"之执；继而决择界、处、缘起三善巧，最后广辨无明体性与能生五杂染，是三科与缘起决择的汇归处。

## 二、结构层次（★）
全文按"蕴→界→处→缘起"四善巧次第展开，由自相到共相、由现行到种子：
- **蕴善巧（P1-P42）**：
  - 心不相应行分位（P1-P15）：从"得"起，依次建立无想定、灭尽定、无想天、命根、众同分、四相（生老住无常）、名句文身、异生性、流转、定异、势速、次第、时、方、数、和合、不和合等，每法皆"依何分位+复几种"二问二答，是"总分→别列"格式。
  - 诸蕴多门分别（P16-P33）：有色有见有对乃至三界系、三性、学无学、见修所断近二十门横切，再答"积聚义""色名义""名名义""摄""相应"五义，回归蕴之所以为蕴。
  - 破执显正（P34-P42）：破"名中唯心实有非诸心所"，以五性不成、分位有过、因缘无别、违圣教四义证成心心所更互相应，附嗢拖南颂。
- **界善巧（P43-P77）**：定义眼界等 → 实假（十七或十二） → 四句（眼与眼界） → 同分彼同分 → 能取所取 → 执受 → 界义（因义等六） → 建立义（六种分别） → 三界系 → 根二分 → 根识因果（灯焰喻） → 生何界何根定转，门类最广。
- **处善巧（P78-P83）**：处之定义 → 处与触处差别 → 四句 → 处义（生长门等六） → 八胜处十遍处等摄十二处，与界善巧相呼应。
- **缘起善巧（P84-P122）**：
  - 缘生法总相（P84-P86）：无主宰、因名缘起果名缘生；十二支中二假余实。
  - 五相建立缘起（P87-P93）：引因依处 → 生因依处 → 引因 → 生因 → 生起，层层推进。
  - 无明体性（P94-P103）：破"无明即明无""无明即邪智"，成立别有心所与心相应。
  - 行三与十二支分类（P104-P111）：身语意三行，二业三烦恼七事，引业生业、因果所摄。
  - 无明生五杂染（P112-P122）：疑、爱、非处信、见、增上慢，收束全章。

## 三、关键结论
1. 诸蕴分位差别虽多，皆依有情身心相似相续分位假立，不离识所变相。
2. 心与心所决定相应，"唯心实有"之执于教于理皆不成立。
3. 十八界广说无非显因缘义与根境受用义；六根次第有六种因缘，意遍行故最后说。
4. 眼与眼识如灯与光，俱时而有因果性成，破"因果必异时"之执。
5. 无明别有心所体性，非仅明无、非即邪智，能生五杂染为生死本。

## 四、易混辨析
- **无想定 vs 灭尽定 vs 无想天**：三者皆"灭分位"。无想定在异生、依出离想、第四静虑受果；灭尽定在圣者（学无学）、依止息想、已建立阿赖耶识者一切处现前；无想天生彼天中、无覆无记、唯异生。
- **同分 vs 彼同分**：有识眼界名同分，所余眼界名彼同分；唯内根界立，外色等不立。
- **处 vs 触处**：处是"已得不舍且非无间断灭法"；触处必是处，处非必触处（如眼等不与触合）。
- **引业 vs 生业**：行支引当来总报种子名引业，有支由爱取润种生当来异熟名生业。
- **众苦引因 vs 众苦生因**：引因是"无明缘行乃至触缘受"熏识等种，生因是"受缘爱乃至有"润种令生。
