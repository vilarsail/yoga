# 瑜伽师地论卷第六十四 导读

## 一、内容总览
本章为《瑜伽师地论·摄决择分》对「闻所成慧地」的决择，承接前文「无心地决择」。所谓闻所成慧，即由听闻正法所成就的智慧。全章围绕闻慧学人应决了的法相与轨则展开：先明归依之相与三宝差别，次辨内明处为五明之最胜，由六理门统摄一切圣教，由四圣谛建立安立真实，由三自性显非安立真实，终归于造论庄严经、七种通达与十相多闻，为闻慧学人建立完整的法相坐标。

## 二、结构层次
全章以「闻慧所学」一线贯穿，由归依入门，层层展开至造论通达，可分四大推进：

- **归依与三宝（入门根基）**：由五处观察所归 → 四缘立能归依 → 四正行明归依之行 → 四功德明归依之果 → 由六相辨佛法僧三宝差别，构成「所归—能归—归依行—归依果—所归相」一个完整闭环。

- **所学内容与所归胜劣（五明比较）**：先列欲求、有求、梵行求三类所求 → 由五法辨沙门婆罗门胜劣 → 由四清净显内明处为五明中最胜，建立「所学—能学人—所学优劣」递进。

- **六理门与四谛证得（核心义理）**：六理门中前三（真义、证得、教导）为所决了，后三（远离二边、不可思议、意趣）为能决了 → 真义理门展开为六种真实，前四如菩萨地，安立即四圣谛、非安立即诸法真如 → 由四证得明能证之机（业果、声闻、独觉、大乘）→ 由三处所摄明教导之教 → 由不可记事明教之界限。此段是全文枢纽，由「理」到「谛」到「证」到「教」递进。

- **远离二边与法相差别（深入决择）**：增益边（我常净乐四颠倒）↔ 损减边（谤圣谛无）→ 由三自性显中道 → 由安立非安立谛明相缚粗重缚解脱差别 → 依四谛立十三补特伽罗，由造作等十三法分别其相 → 杂法决择（粗重相、五长养、奢摩他毗钵舍那、三漏等）→ 造论庄严经、七种通达、十相多闻收束。

## 三、关键结论
1. 归依三宝须具四缘（知功德、知差别、自誓愿、不说有余大师），修四正行（亲近善士、听闻正法、如理作意、法随法行），方名真实归依。
2. 三宝差别由相、业、信解、修行、随念、生福六相分别：佛自然觉悟，法是觉悟之果，僧随他教正修行。
3. 真义略分六种：世间所成、道理所成、烦恼障净智所行、所知障净智所行、安立、非安立；安立即四圣谛，非安立即诸法真如。
4. 行安立谛犹有相缚，须行非安立谛方能于相缚粗重缚二俱解脱；但为令资粮方便道清净，仍须显示安立谛。
5. 造论须先归礼二师、具六因、自安四德；所造论显发经义，名为「庄严经」。

## 四、易混辨析
- **安立真实 vs 非安立真实**：安立真实即四圣谛，依三种世俗（世间、道理、证得）安立，有所缘相；非安立真实即诸法真如圆成实自性，圣智所行不可安立，离名言相。
- **增益边 vs 损减边**：增益边于依他起、圆成实上执有遍计所执自性，即我常净乐四种颠倒；损减边于依他起、圆成实有法中谤其自相言无所有，并诽谤三量与染净。一执有，一执无。
- **相缚 vs 粗重缚**：相缚是行有相心时为境相所系缚；粗重缚是无所堪能不调柔相，顺杂染违清净。行安立谛有相故相缚不脱，相缚不脱故粗重缚亦不脱。
- **世间世俗 vs 道理世俗 vs 证得世俗**：世间世俗安立宅舍瓶盆我有情等假名；道理世俗安立蕴界处等法相；证得世俗安立预流果等圣果所依。由浅入深，皆属安立谛摄。

## 五、阅读提示
带着两个问题读本章：（1）六理门中「前三为所决了、后三为能决了」的关系如何贯通全章？（2）安立谛与非安立谛在解脱上的差别何在？抓住这两条线索，全章纲目自现。
