# 瑜伽师地论卷第二 导读

## 一、内容总览

本卷是本地分「意地」的第三品（意地第二之二），承接卷一。前半主讲作为意地根本的种子识与胎藏中生命流转的机理，后半转入器世间的成坏与构成，最后以名目繁多的世俗法相作结，是理解瑜伽行派世界观（有情世间 + 器世间）的枢纽一卷。

## 二、结构层次（逻辑骨架）

本卷以「有情世间 → 器世间 → 世间名相」一线贯穿，由内而外：

- **有情世间（内分）**：种子识立流转之因（种子与随眠）→ 胎藏八位（羯罗蓝至形位，生命如何一步步成形）→ 生后之相（触 → 受 → 家室 → 造业 → 受用，由生向死），成「内分死生」一个闭环。
- **器世间（外分）**：先「坏」——三灾（火 → 水 → 风）由下而上坏至三禅，各历二十中劫；后「成」——由风轮、金性地轮起，苏迷卢山、四洲、诸天宫殿渐次建立，有情复入、世界复成。坏与成是一对相待的循环。
- **世间名相（收束）**：依持、摄受事、身资具、威仪、活命、苦、慢、憍、言说等一连串名目，既是前文收束，也是后文诸地展开的公共词汇表。

## 三、关键结论

1. 一切有情自体中皆含摄三界一切种子，染净业因不同而感果差别。
2. 烦恼品所摄种子名粗重亦名随眠，余品唯名粗重；种子即界、种姓、萨迦耶等诸名。
3. 胎藏经八位而具足，从羯罗蓝至形位，凡三十八七日出生。
4. 器世间为三种大灾所坏，四禅以上无灾，成坏各经二十中劫，共八十中劫为一大劫。
5. 三千大千世界即一佛土，世界成坏由有情业力所感。

## 四、易混辨析

1. 粗重 vs 随眠：烦恼品种子二者皆名，异熟及无记品唯名粗重，善法种子二名俱非。
2. 火灾、水灾、风灾：分别坏至初禅、二禅、三禅，第四静虑无灾。
3. 内分 vs 外分：内分由寿量尽而坏，外分粗色恒住、由感坏劫业力而坏。
4. 卵生、胎生、湿生、化生：以出离母体方式与所依差别分类。

## 五、阅读提示

可先抓住「种子识」「胎藏八位」「三灾」「四洲」四条线索，其余名相（六十二有情之类等）属罗列，了解即可，不必强记。
