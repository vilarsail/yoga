# 瑜伽师地论卷第八十一 导读

## 一、内容总览

《瑜伽师地论》卷八十一为「摄释分之上」，承前「摄决择分」而来，专释契经自身之体性、解释经典之方法、说法师所应具之德相、及对听法众之差别施设——即「经是什么」「经如何解释」「经由谁说、对谁说、怎么说」。本章主旨可归为「以文义为体，以五相释经，配机说法」，是研习一切佛经的公共方法论。

## 二、结构层次

本章以总嗢拖南「体释文义法，起义难次师，说众听赞佛，略广学胜利」统领全卷，按「体 → 释 → 文 → 义 → 法等起 → 释难 → 次第 → 师 → 说众」一线推进，先立经体，再分述能释五事，最后落到能说之人（师）与所化之众（说众）：

- **总标纲要（P1-P3）**：以「已说摄决择，云何摄释」承上启下 → 出总嗢拖南统摄全卷脉络。
- **立经体（P4）**：契经之体略为「文」与「义」二种——文是所依，义是能依，总名一切所知境界 → 立体以立其本。
- **明释与文（P5-P28）**：先明释略有五（法、等起、义、释难、次第），再广明文有六种：
  - 名身（十二种）、句身（六种）、字身（四十九字）层层枚举
  - 语（八支：先首美妙等）配三德（趣向、自体、加行）
  - 行相（蕴界处缘起等相应语言）
  - 机请（二十七种补特伽罗）
  → 自「文之结构」推到「机之差别」。
- **明义十种（P29-P63）**：地、相、作意等、依处、过患、胜利、所治、能治、略、广。
  - 相义中特详五相——自相共相乃至所诠能诠执着不执着相
  - 依处义中广开事依处（根本事六、得方便事十二、悲愍他事五）
  → 由「义」广开诸法。
- **中间嗢拖南收束十义（P64-P65）**：以颂「诸地相作意，依处德非德，所对治能治，广略义应知」收束前十义 → 总结前文。
- **五相释经（P66-P107）**：建立文义体已，诸说法者应依五相解释一切佛经——略说法要、宣说等起、宣说其义、释难、辩次第：
  - **法**（P68-P76）：十二分教（契经乃至论议）
  - **等起**（P77）：依事、时、补特伽罗三种依处起说
  - **义**（P78-P83）：总义四相、别义四相（含训释言词五方便、义门差别五相）
  - **释难**（P84-P87）：五难、四记（一向记、分别记、反问记、置记）
  - **次第**（P88-P91）：圆满、解释、能成三种次第
  - **师**（P92-P99）：说法师十法（善于法义乃至具足忍力）
  - **说众**（P100-P107）：五众（在家、出家、净信、邪恶、处中）配八种言
  → 自「经之所说」递进至「能说之人」与「所对之众」。

## 三、关键结论

1. 一切契经之体唯「文」与「义」——文为所依，义为能依，离文则义无所显，离义则文无所成。
2. 解释佛经须依五相：略说法要、等起、义、释难、辩次第——五相具足方能解了佛经。
3. 经典之「义」虽广为十种，要不出境行果——地相作意是境，依处过患胜利是行，所治能治是行中之相违。
4. 说法师须具十德，自利（成就法随法行）与利他（能广宣说、善方便说）并重；仅多闻而不修行，不名圆满法师。
5. 处众说法须观机——于五众各依其所应（在家赞善毁恶、出家三学、净信等广陈威德），契理契机方为善说。

## 四、易混辨析

- **契经 vs 应颂 vs 记别 vs 讽颂**：契经是长行直说贯穿义；应颂是长行后再以伽他重宣（亦摽不了义经）；记别是广分别略所摽之义，并记命过弟子生处；讽颂是唯以偈说（二句至六句），不长行。
- **自说 vs 缘起**：自说为「无请而说」，为令上品所化安住胜理；缘起为「有请而说」，依问依事而说（如依黑鹿子）。
- **圆满次第 vs 解释次第 vs 能成次第**：圆满次第是先略举体（如三受总举）；解释次第是次第分别其相（如净饭王宫颜容等）；能成次第是以彼成此（以前句成立后句，或反是）。
- **一向记 vs 分别记 vs 反问记 vs 置记**：一向记于如理问无倒建立法性相；分别记于如理或不如理问开示差别；反问记为令戏论者自见过；置记以无体性、甚深等四因缘默置不答（如如来灭后有无）。
- **根本事 vs 得方便事 vs 悲愍他事**：根本事是所趣之果（善趣乃至涅槃六种）；得方便事是趣果之行（欲行乃至他义行十二种）；悲愍他事是利他之用（令离欲乃至庆喜五种）。

## 五、阅读提示

读本章可带着两个问题：佛经的「文」与「义」如何配当？说法者面对不同根机听众如何施设不同言教？以此二条线索串起全卷，便能见其条理。
