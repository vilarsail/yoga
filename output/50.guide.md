# 瑜伽师地论卷第五十 导读

## 一、内容总览
本卷是《瑜伽师地论》本地分的末卷，以四部分收束整部本地分：其一，建立品第五之二（续）——以嗢拖南总摄如来十力七相（自性、分别、不共、平等、作业、次第、差别），次第广说四无所畏、三念住、三不护、大悲、无忘失法、永害习气、一切种妙智，合为如来百四十种不共佛法，并比较究竟地菩萨与如来的身心差别，列举如来十种作业，归结菩萨地之义与福聚；其二，发正等菩提心品——揭示菩萨地由种性、发心乃至证菩提的次第；其三、其四，有余依地与无余依地——立有余、无余二涅槃地的三相安立。本地分至此圆满。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
本卷以「如来功德圆满 → 菩萨学道次第 → 二涅槃地收束」三层递进，将整部本地分由菩萨行归结到佛果与涅槃：

- **如来功德（建立品第五之二续）**：
  - 嗢拖南总摄十力七相 → 逐一别说七相：自性（五根为体，慧胜故说慧）→ 分别（时分、品类、相续三种）→ 不共（唯佛不共声闻独觉）→ 平等（诸佛皆具）→ 作业（一一力降伏外道、教授有情）→ 次第（顿得而次第现前，三门异说：初门约所化根机，二门约大悲观机，三门约缘生法界）→ 差别（十力两两相望，有差别亦无差别）。
  - 次别说四无所畏、三念住、三不护、大悲、无忘失法、永害习气、一切种妙智，合为百四十种不共佛法。
  - 以八组譬喻（隔縠/无隔、画未净治/已净治、微闇/离闇、远/近、轻医眼/极净眼、处胎/出胎、梦中心行/觉时心行、昧灯/明灯）比较究竟地菩萨与如来身心妙智的极大差别。
  - 列如来十种作业，一一配属前说功德 → 摄归菩萨地名为「建立」，并以受持福聚等于菩萨藏经典收束。
- **菩萨地义次第（发正等菩提心品）**：以「种性 → 发菩提心 → 自他利行 → 无杂染方便 → 无厌倦方便 → 善根增长方便 → 证无上菩提」为主线，层层展转引发；其中又分信解正法、广为他说、断他疑惑、福智资粮圆满、三解脱门、正行圆满、正行功德殊胜与称赞功德殊胜，最后归到「不生喜足、升进究竟、得无上」。
- **有余依地（十六地）**：地施设安立（除五地一分及无余依地）→ 寂静施设安立（苦、烦恼、不损恼有情、舍四种寂静）→ 依施设安立（施设、摄受、住持、流转、障碍、苦恼、适悦、后边八种依），并简别阿罗汉与诸依相应不相应。
- **无余依地（十七地）**：地施设安立 → 寂灭施设安立（寂静寂灭、无损恼寂灭二种）→ 寂灭异门施设安立（常、恒、舍宅、洲渚、甘露、涅槃等无量异名），终归于清净真如一向无垢。

## 三、关键结论
1. 如来十力以五根为自性，慧根胜故说慧为自性；十力顿得而次第现前，立三门次第以应不同根机与视角。
2. 如来百四十种不共佛法唯佛证得极圆满，菩萨分得而不圆满，故说「不共」；其中大悲、无忘失法、永害习气、一切种妙智为声闻独觉一切不得。
3. 究竟地菩萨与如来身心妙智差别极大——菩萨如隔轻縠睹色、画未净治、处胎身、梦中心行；如来如无隔睹色、画已净治、出胎身、觉时心行。
4. 菩萨地以种性为始、无上菩提为果，由正行功德与称赞功德展转引发，最终升进究竟、得无上，亦名菩萨藏摩怛理迦、摄大乘。
5. 有余依地立三相、四种寂静、八种依，犹有后边依；无余依地永断一切依，转依所显真无漏界，清净真如一向无垢。

## 四、易混辨析
1. **处非处智力 vs 自业智力**：前者了知善不善业能感爱非爱果之理（重在因果通则）；后者了知能造业者即彼能受果者而非所余（重在自业别招）。
2. **一切种智 vs 妙智 vs 一切种妙智**：一切种智照无义聚及非有义非无义聚（恶与无记），妙智照有义聚法（善）；二合为一，名一切种妙智。
3. **有余依地 vs 无余依地**：有余依犹有最后身依（后边依），具苦等四种寂静，与一种依一向相应；无余依永绝一切依，与一切依不相应，真无漏界。
4. **究竟地菩萨 vs 如来妙智**：菩萨如隔縠睹色、画未净治、微闇中见、远睹、轻医眼、处胎身、梦中心行、昧灯体；如来反之，无隔、已净治、离闇、近睹、极净眼、出胎身、觉时心行、明灯体——身心皆有广大差别。

## 五、阅读提示
读本卷可带着这一问题：为何在广说菩萨行之后，要归结到如来百四十种不共佛法与有余、无余二涅槃地？此即「圆满显示一切菩萨学道及学道果」的最终指向——菩萨地之「建立」正为显此佛果与涅槃。
