# 瑜伽师地论卷第十九 导读

## 一、内容总览
本卷为《瑜伽师地论》卷十九，思所成地第十一之四。以二十余则偈颂配长行释义，辨在家出家修善法、远杂染。由「思」抉择法义，从善语、正信、多闻、调伏、出离诸欲入路，汇归三学增上、涅槃解脱，末以贤善颂与嗢拖南总束。

## 二、结构层次
全卷以「偈颂→长行→略辨」循环，一颂一义：
- **善语正行（P1-9）**：善语三相 → 信惭戒施法趣天。
- **多闻解脱（P10-17）**：多闻四果 → 阿罗汉如空 → 三解脱差别。
- **见佛心识（P18-28）**：破色相 → 见法身 → 增上王 → 心城四杂染。
- **摄寻思舍寿（P29-36）**：如龟藏支 → 等不等辨色名身与舍寿。
- **欲过患四轭（P37-54）**：四不自在 → 外道无沙门 → 离爱 → 四轭不往生。
- **三学调伏（P55-67）**：惠施四正行 → 诸恶莫作 → 调伏心 → 止观。
- **真实苾刍（P68-76）**：五支成就永断 → 心远行独行明三世。
- **世间杂染（P77-91）**：无明覆 → 念慧名色 → 诸欲出离。
- **贤善收束（P92-97）**：贤善颂 → 嗢拖南总摄。

## 三、关键结论
1. 善语三相贯世出世间：爱语庆悦、谛语护尸罗、法语令出不善安善。
2. 多闻为修行之始，闻法知义、法随法行，渐次证涅槃。
3. 阿罗汉如虚空幢，世法不染，已显了无更须作。
4. 见如来以胜义法身见，非以色声相测量。
5. 心意识为流转根本，染则凡夫，调伏名婆罗门。
6. 诸欲过患当远，出离如断多罗树顶不复生。

## 四、易混辨析
- **慧解脱 vs 俱解脱**：前者慧尽漏未得灭尽定；后者定慧俱满得定自在。
- **有学 vs 无学**：有学见迹未极果，须断余惑；无学已显了无更须作。
- **事欲 vs 烦恼欲**：事欲指田财色外境；烦恼欲为随逐爱味染心。
- **伏 vs 断对治**：伏对治仅伏不永断；断对治无漏慧永断根本。

## 五、阅读提示
先读偈颂立框架，再读长行看释义，末看「略辨所说义」收束一颂之要，体会偈与长行互释。
