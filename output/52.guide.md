# 瑜伽师地论卷第五十二 导读

## 一、内容总览

本卷为《瑜伽师地论》卷第五十二，属「摄决择分」中「五识身相应地意地」第二部分。承接前卷对八识与心心所的决择，本卷系统梳理与心识相关的一系列法相：先明四缘与十因，继而以问答决择「意识缘无」之理、三世密意之诤、有为四相之假实，随后逐一诠释得、命根、众同分、异生性、和合、名句文身、流转、定异、相应、势速、次第、时、数等法相，最后归于种子的体性与「转依」对治阿赖耶识之究竟义。全卷以法相为纲、以问答为纬，是唯识宗「决择法相」的典范段落。

## 二、结构层次

本卷以「缘 → 识 → 相 → 法 → 果」为暗线，由能生之缘推至所证之转依：

- **四缘十因（总起）**：先定义等无间缘、所缘缘、增上缘三缘 → 点出因缘为生因、余三为方便因 → 依此四缘建立十因，为下文一切法相讨论铺设因果框架。
- **缘无之识（五重论证）**：以「过去未来诸行非有，何故说为缘生意」之问发起 → 先以「法处假说」一答，再以五种言论道理（无我、饮食等假名、邪见、无常、未来生灭）层层证成意识能缘无性为境 → 收束于「证有缘无意识」。
- **三世密意（三问并列）**：过去业、过去未来行、三世界三组问答并列 → 共同以「种子相续」一义贯通：已与果名过去、未与果名未来、正相续名现在 → 附遮破外道二执（不平等因、无因）。
- **有为四相（破立并举）**：先以「生不即诸行亦非诸行因」破生相实有 → 立「生老住无常假施设有」 → 解释佛说三相（生、灭、住异）而非四相之由 → 分述生差别（十一种）、老差别（六种）、住差别（五种）、无常差别（六种），四组并列枚举。
- **心不相应行法（连锁展开）**：得（三种成就）→ 命根（多种寿量）→ 众同分（界趣生类等）→ 异生性（见所断种子未永害）→ 和合（六种和合）→ 名句文身（依五明建立），诸法相次第相引。
- **流转等法相（系列列举）**：流转 → 定异 → 相应（四种道理）→ 势速 → 次第 → 时 → 数，七法相各以「定义 + 差别」格式统一展开。
- **种子与转依（收束升华）**：先明种子非析诸行别有、即诸行种性安布 → 分九种、三种 → 以「真如所缘缘种子」答出世间法所从生 → 以「有障无障」释种性差别 → 终以「转依对治阿赖耶识，名无漏界」收束全卷。

## 三、关键结论

1. 四缘中唯因缘望所生法为生因，等无间、所缘、增上三缘但为方便因；依此四缘建立十因。
2. 意识不仅缘实有境，亦能缘过去、未来及无性之法为境，由五种言论道理证成。
3. 佛说「有过去业」「有过去未来诸行」是依种子相续之密意，非谓三世实有。
4. 生、老、住、无常非离色等蕴别有实体，乃于诸行中假施设有；佛说有为三相，由三世所显。
5. 诸法各有自种子为生因；出世间法从真如所缘缘种子生，非习气积集种子所生；转依对治阿赖耶识，名无漏界、离诸戏论。

## 四、易混辨析

- **四相 vs 三相**：经部等许生、老、住、灭（无常）四有为相；本论主依三世义说三相——未来本无而生说「生」，过去落谢说「灭」，现在住与变异合说「住异」，故佛但说三相。
- **种子成就 vs 自在成就 vs 现行成就**：种子成就指染污法、无记法及生得善之种子未被损伏永害；自在成就指加行所生善法及一分无记法，由修习势力自在而得；现行成就指诸法自相正现前转。
- **名身 vs 句身 vs 文身**：名身依诸法自性自相施设，诠自性；句身依法差别施设功德过失等，诠差别；文身是名句所依之字身，但了音韵。极略是文，中是名，广是句。
- **般涅槃法种性 vs 不般涅槃法种性**：差别在于通达真如所缘缘中有无「毕竟障种子」——有者名不般涅槃法种性，无者名般涅槃法种性；般涅槃法中又依所知障、烦恼障之有无，分立声闻、独觉、如来三种种性。

## 五、阅读提示

读本卷可紧扣一条线索：佛经中既说「过去未来非有」，又说「有过去业」「有过去未来诸行」，看似矛盾如何会通？论主以「种子相续」与「密意」贯通之——这是理解全卷法相决择的一把钥匙。
