# 瑜伽师地论卷第七 导读

## 一、内容总览
本卷为《瑜伽师地论》卷七，「本地分中有寻有伺等三地之四」，承接卷六破十六异论之余，续破后十一种：宿作因论、自在等作者论、害为正法论、边无边论、不死矫乱论、无因见论、断见论、空见论、妄计最胜论、妄计清净论、妄计吉祥论。每种按「立论—因缘—破斥—结非」展开，以二难推理令外道进退失据，终总收「十六异论于一切种皆不应理」。

## 二、结构层次
十一种异论并列铺陈，每种内部论证模式高度统一：
- 统一范式：立论 → 因缘（答由教及理）→ 破斥（二难诘问）→ 结非（非如理说）
- 推进序列：宿作因论 → 自在等作者论 → 害为正法论 → 边无边论 → 不死矫乱论 → 无因见论 → 断见论 → 空见论 → 妄计最胜论 → 妄计清净论 → 妄计吉祥论
- 破中显正：宿作因论后立「如实因相」明苦有唯宿作、杂因、纯现法三类；害为正法论后明「非法之相」；空见论后立三性显体相非无
- 收束：以二种门观察，总破十六异论归于「一切种皆不应理」

## 三、关键结论
1. 诸法因缘生，非宿作独招、非自在天造、非无因生。
2. 苦有多因：唯宿作、杂因、纯现法功用三类差别。
3. 邪见皆由「教」（师承妄传）与「理」（寻思不如实）二门而起。
4. 破邪即显正：空见论后立三性，明诸法体相实有非无。
5. 十六异论由二门观察，于一切种皆不应理。

## 四、易混辨析
- 宿作因论 vs 无因见论：前者执一切苦皆宿业所招，后者执我及世间无因生；一计有因，一计无因。
- 断见论 vs 空见论：断见局于死后断灭，空见遍拨施与、祠祀、业果乃至一切法相。
- 妄计清净论 vs 妄计吉祥论：前者计欲、定、沐、戒为涅槃清净，后者计供日月星宿为吉祥成事。
- 害为正法论 vs 妄计最胜论：前者计杀生祀天生天，后者计婆罗门从梵口生最胜。

## 五、阅读提示
带着「立论—因缘—破斥—结非」四段式读每种异论，重点看破斥部分的二难推理如何令对方两不可；并留意破邪中夹带的正面教义（如实因相、非法之相、三性），那是论主破邪显正的真正落脚处。
