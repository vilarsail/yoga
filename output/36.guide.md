# 瑜伽师地论卷第三十六 导读

## 一、内容总览
本卷属〈本地分·菩萨地〉，承接上卷〈自他利品〉之余，续明因摄果摄、现法后法、毕竟不毕竟等自他利差别，随即开启〈真实义品〉，系统建立「四种真实义」与「离言自性」的中道义理，是唯识宗真实义理论的核心文本。前半为菩萨利他行的因果框架，后半转入认识论与真理观的深层辨析，由事入理，最终归宗于菩萨依四如实智证大般涅槃的修证果相。

## 二、结构层次
全文以「事→理→行→果」一线贯穿，前品收束、后品展开：

**前品（自他利品第三之二）— 菩萨利他行的因果框架**
- **三因三果总起**（P1）→ 异熟/福/智三类因果并列展开。
- **异熟因果**（P2-P10）→ 八异熟果（果相）→ 八异熟因（因相）→ 三缘增长（心清净/加行清净/田清净）→ 八果之用（每果各显利他功能）→ 二力具足方名炽盛利他。
- **福智因果**（P11-P15）→ 福智分类（六波罗蜜多分属）→ 福智分别（精进静虑通二分）→ 福因智因三种 → 福果智果 → 福智相依、福最胜智无上（收束）。
- **三类自他利收束**（P16-P21）→ 现法/后法/现法后法 → 毕竟/不毕竟（三因缘：自性、退不退、受用果有尽无尽）→ 总结十种自他利。

**后品（真实义品第四）— 真实义的中道建构**
- **真实义品类**（P22）→ 二种（如所有性/尽所有性）开为四种。
- **四种真实义逐层展开**（P23-P29）→ 世间极成（世俗共许）→ 道理极成（智者依现比至教量）→ 烦恼障净智所行（四圣谛、声闻独觉现观）→ 所知障净智所行（法无我、离言自性、菩萨诸佛），由浅入深、由凡入圣。
- **真实义相＝无二所显**（P30-P31）→ 有（假说自性）↔ 非有（无假说所依）→ 二俱远离＝无二＝中道。
- **空胜解与大方便**（P32-P35）→ 反显（厌生死/怖涅槃/愿涅槃皆堕一边）→ 正明（如实了知生死、不厌不怖、不深愿乐＝大方便）→ 依止最胜空性胜解。
- **法无我智的胜利**（P36-P37）→ 平等心、不贡高、不秘吝、菩提分增长。
- **依极真智修正加行**（P38-P40）→ 舍身财、律仪、忍辱、勤修明处、禅定、慈悲报恩。
- **离言自性的论证**（P41-P43）→ 假说无自性（一法多假说则多自性，不成）→ 离言有事（未立假说前应起色觉而实不起）。
- **二种失坏与善取空**（P43-P49）→ 增益执（实无起有）↔ 损减执（实有起无）→ 恶取空过患 → 善取空正义（不增不减、不取不舍）。
- **至教量印证**（P50-P57）→ 转有经颂 → 义品颂 → 散他迦多衍那经，三经共显离言自性。
- **起言说之由**（P58）→ 为令他闻知离言自性，故于离言而起言说。
- **八分别生三事**（P59-P63）→ 八分别（自性/差别/总执/我/我所/爱/非爱/俱相违）→ 三事（戏论所依缘/见我慢/贪嗔痴）→ 展转更互为因。
- **四寻思→四如实智**（P64-P67）→ 名/事/自性假立/差别假立四寻思 → 引四如实智 → 通达假立不二之义。
- **修证果相**（P68-P72）→ 愚夫阙智故流转 → 菩萨依智灭戏论 → 证大般涅槃 → 五自在 → 五胜利 → 五业 → 摄菩萨所作。
- **总结胜劣**（P73）→ 四真实义：初二下劣、第三处中、第四最胜。

## 三、关键结论
1. 菩萨自他利以异熟、福、智三因三果为框架：八异熟为利他所依，福智相依而福最胜、智无上，缺一不能证菩提。
2. 真实义有四重，从世间共许到诸佛所证离言法性，层层深入；前二属世俗，第三出世，第四唯菩萨诸佛所行。
3. 诸法离言自性：非有（无假说自性）非无（有离言唯事），离增益损减二边即中道。
4. 菩萨以空胜解为大方便，不厌生死、不怖涅槃、不速愿涅槃，方能成熟佛法与有情；反之则无方便。
5. 由四寻思引四如实智，灭八分别及所依缘事，证大乘大般涅槃，获五自在与五种胜利。

## 四、易混辨析
- **四种真实义**：世间极成（凡夫共许）vs 道理极成（智者依量比度）vs 烦恼障净智所行（声闻独觉证四谛）vs 所知障净智所行（菩萨诸佛证法无我离言自性）。前二有漏，第三通二乘，第四唯大乘。
- **增益执 vs 损减执**：前者于实无事起有执（执假说有自性），后者于实有唯事起无执（拨离言自性为无）。二皆失坏法毗奈耶。
- **善取空 vs 恶取空**：善取空者知「彼无所有」亦知「余实是有」，不增不减；恶取空者说一切都无所有，拨圆成实，堕恶趣。
- **毕竟 vs 不毕竟自利利他**：毕竟指究竟涅槃与八支圣道（无退、受用果无尽）；不毕竟指欲界财宝、异生世间清净（有退、有尽）。

## 五、阅读提示
带着「菩萨如何不舍生死又不染生死」的问题读真实义品，重点关注空胜解与大方便的关系；并留意「离言自性」如何通过假说无性、离言有事、二执失坏、善取空四层论证层层展开。
