# 瑜伽师地论卷第三十二 导读

## 一、内容总览
本卷为「声闻地第三瑜伽处之三」，明初修业者始修业时依五种相（厌离/欣乐/过患/光明/了别事）安立修作意，详述不净观、慈愍观、缘起观、界差别观、阿那波那念五观的初修方便与趣入四念住，最后明有作意的清净相状（顶上似重而起非损恼相、身心轻安生起次第）。是声闻地由加行入正修、证得少分作意的完整教授。

## 二、结构层次
全卷按「五相安立 → 五观趣入念住 → 有作意相状」推进：
- **五相安立（P1-P10）**：①厌离相（闻见自他衰损生死重苦深心厌患）②欣乐相（观察尸罗清净生无悔欢悦喜悦）③过患相（色等十相、欲等八寻思、贪等五随烦恼令心苦恼散动染污）④光明相（灯明大火日月轮明，依六想住无相无分别寂静）⑤了别事相（乱不乱相审谛了知）。
- **正加行与趣入念住（P11-P28）**：不净观从一青瘀至无量青瘀，胜解作意趣入真实作意（前际所弃尸骸无量过此），如画师数作数除；依不净观趣入四念住——内身三十六物、外身青瘀骨锁、内外身死已冢间；受心法三分配奢摩他品/无散乱品/毗钵舍那品；以平满油钵喻奢摩他心。
- **慈愍观（P29-P32）**：亲怨中三品平等利益安乐，胜解作意趣入真实作意（先际亲怨互转起平等心），坏缘念住。
- **缘起观（P33-P34）**：由闻思慧取有情颠倒相，纯大苦蕴真实作意，自他三世诸蕴缘性缘生循观。
- **界差别观（P35-P38）**：先取外坚湿暖动空相，复于内起胜解；分析至极微；胜解作意趣入真实作意（无始生死所经地水火风空识无量过此）。
- **阿那波那念（P41-P42）**：先于舍舍窗门打铁师吹筒等取入出相，渐至一切毛孔风皆随入。
- **有作意相状（P43-P45）**：初修业者证得色界定地所摄少分微妙正作意，相状谓顶上似重而起非损恼相，心粗重灭心轻安生，风大偏增身轻安遍满，初踊跃后舒缓，心于所缘寂静行转。
以「五相 → 五观趣入念住 → 证得相状」为统一骨架。

## 三、关键结论
1. 初修业者应取五相：厌离、欣乐、过患、光明、了别事，依此安立修作意。
2. 过患相三类：色等十相、欲等八寻思、贪等五随烦恼，令心作用遽务思慕躁扰恒不寂静。
3. 依六想住心一境性：无相想、无作用想、无分别想、无所思慕无躁扰想、寂静想、寂灭乐想。
4. 胜解作意趣入真实作意：不净观从前际来所弃尸骸无量无边过胜解所作；慈愍观先际亲怨互转起平等心；界差别观无始所经地水火风空识无量过此。
5. 四念住配四观：不净观趣入身念住、慈愍观趣入坏缘念住、缘起观趣入四念住、界差别观趣入身念住。
6. 有作意相状：顶上似重而起非损恼相，心粗重灭心轻安生，风大偏增身轻安遍满状如充溢，初令心踊跃后舒缓，心于所缘寂静行转。

## 四、易混辨析
- **厌离相 vs 过患相**：厌离相约闻见自他衰损生死重苦深心厌患，过患相约色等十相欲等八寻思贪等五随烦恼令心散动染污。
- **胜解作意 vs 真实作意**：胜解约数数起相除遣、画师喻、有限量境；真实约趣入实际前际无始生死所弃尸骸等无量过此。
- **内身 vs 外身 vs 内外身循观**：内身约自内三十六物、外身约他青瘀骨锁、内外身约自他死已冢间。
- **欢悦 vs 喜悦 vs 悦意**：先名欢悦（尸罗净生无悔欢悦）、今名喜悦（除障喜悦处所）、总名悦意。
- **心轻安 vs 身轻安**：心粗重灭能对治心调柔性心轻安性生起，随顺起身轻安风大偏增遍满身中。

## 五、阅读提示
本卷是初修业者证得少分作意的完整教授，可带「五相安立 → 五观趣入念住 → 有作意顶上重相」三线索读；胜解作意趣入真实作意的画师喻与有作意相状最宜对照把握。
