# 瑜伽师地论卷第四十二 导读

## 一、内容总览
本卷为《瑜伽师地论》菩萨地初持瑜伽处的三品合卷：收束戒品第十之余（难行戒至清净戒及戒度归宗），连续开启忍品第十一、精进品第十二。三品按菩萨六度次第推进，且共用同一套「九相」分类框架——自性、一切、难行、一切门、善士、一切种、遂求、此世他世乐、清净，并由「嗢拖南」偈颂总标。本卷是菩萨三度（戒、忍、精进）的纲领总集，结构高度对称，可作一处通读。

## 二、结构层次
本卷以「戒 → 忍 → 精进」三度一线贯穿，三品共用九相模板，如同同一套架构在三种度上分别打样：

- **戒品（收束）**：先补足前卷未尽的七种戒相（难行、一切门、善士、一切种、遂求、此世他世乐、清净）→ 总归为三聚净戒（律仪、摄善法、饶益有情）↔ 三聚对应「安住其心、成熟自佛法、成熟有情」三所作事 → 以三世诸菩萨同修同证作结。
- **忍品（展开）**：嗢拖南总标九相 → 自性忍（无染心悲愍）→ 一切忍分在家出家二品，各开三忍（耐他怨害、安受众苦、法思胜解）→ 耐怨害忍内修五想（宿亲、唯法、无常、苦、摄受），安受苦忍内列八处苦 → 难行至清净七相递进 → 末云「忍为依止，能证菩提」收束。
- **精进品（同构）**：同样嗢拖南标九相 → 自性精进（心勇悍）→ 一切精进分在家出家二品，各开三精进（擐甲、摄善法、饶益有情）→ 擐甲精进立「千大劫处那洛迦」誓愿 → 难行至清净七相铺陈，清净精进详列十相（相称、串习、无缓等）→ 收归「圆满精进波罗蜜多，疾证菩提」。

三品皆以「九相 → 圆满波罗蜜多 → 证无上菩提」为统一收束，结构之美一目了然。

## 三、关键结论
1. 戒波罗蜜多虽开为九相，总摄为三聚净戒——律仪戒安住其心、摄善法戒成熟自佛法、饶益有情戒成熟有情，是菩萨一切所应作事。
2. 耐他怨害忍的核心是「自业过」思惟与五想（宿生亲善、随顺唯法、无常、苦、摄受），把怨害转化为菩提道用。
3. 擐甲精进以「为一有情千大劫处那洛迦」的誓愿为底色，菩萨精进之大，全由悲心与般若所摄。
4. 三品皆以「九相 → 圆满波罗蜜多 → 证无上菩提」为统一收束，强调此三度是菩萨证菩提的共通因缘。

## 四、易混辨析
- **三种忍**：耐他怨害忍（面对他人伤害）、安受众苦忍（忍受修行及世间八种处所之苦）、法思胜解忍（于八种境界以胜慧安立胜解）。前者对境是人，中者对境是事，后者对境是法。
- **擐甲精进 vs 摄善法精进 vs 饶益有情精进**：擐甲是发心前的誓愿铠甲，摄善法是六度加行的落实，饶益有情是十一种利他事业的实践。
- **难行戒三 vs 难行忍三**：戒以「弃财、护命、恒念」为难；忍以「对羸劣、对臣隶、对卑贱增上不饶益」为难——前者强调自持，后者强调对下不报。
- **遂求戒 vs 遂求忍**：遂求戒从「己所不欲勿施于人」立八支不恼他，遂求忍从「于求索者恶逼能忍」立八支堪耐——同是「遂求」之名，戒重不害，忍重堪耐。

## 五、阅读提示
读此卷可带着一个统一问题：菩萨的戒、忍、精进与二乘有何不同？留意每品「自性」的定义——都点出「为有情、为菩提」的大乘心要；并留意嗢拖南偈颂在忍、精进二品中的总纲作用。
