- **全篇总括**：本卷是本地分的收官卷：先用七个问题总盘点佛的十力，再清点四无畏、三念住、三不护等，合交一百四十种不共佛法，用八组比喻照出究竟地菩萨与佛的差距，以十件佛事给能力派上用场；随后借发心品回顾菩萨地从种性到无上的次第总纲；最后讲阿罗汉证果后的两种寂静状态——有余依地与无余依地，宣告「本地分竟」。
  - **十力总辨：用七个问题给佛的十种智力做总盘点**
    - **上一卷已逐一别释十力**，本卷开头改换俯视视角「今当总辨」；卷首一首偈颂给出全节目录：自性、分别、不共、平等、作业、次第、差别——七个关键词就是下文七节的标题，先给地图再进景区
    - **四个基本问法**：构成、范围、归属、异同
      - **自性**：十力由什么构成——总以五根（信、进、念、定、慧五种心理能力）为体，但其中慧（观察判断力）最胜，所以径说「慧为自性」，经文只立「处非处智力」之名而不另立信力等——十力是一套能力系统，最锋利的那项被推出来当代表
      - **分别**：能覆盖多大所知——三种分别撑起「无量」：时分（过去、未来、现在三世一切所知）、品类（每一事物的自相共相与一切行相）、相续（十方有情各各差别的生命之流）——时间×事物细度×众生数量，三个维度一乘
      - **不共**：唯佛有此十力，声闻（亲闻教法的弟子）与独觉（无师自悟者）都没有
      - **平等**：一切佛悉皆平等具足、无有差别；但论日常最常启用哪一力（多所安住），诸佛之间各有侧重——标准平等，侧重有差别
    - **作业**：从「十力是什么」转向「十力各自干什么活」——每项工作都有正反两面，既「如实了知」，又能降伏对应的错误论调
      - **处非处智力**：因中如实知因、果中如实知果，降伏无因论、恶因论种种诤论——「善行没回报」「祸事怪天」这类说法当场拆穿
      - **自业智力**：谁造业谁受果，降伏「施福移转」（布施的福报可转手让渡）之类诤论
      - **静虑解脱等持等至智力**：依深定示现三种神变（三种教化演示），无颠倒地教授所化有情，并降伏种种相违怨害的诤论
      - **说法前先摸底三件事**：根胜劣智力知软、中、上根差别而如应说法；种种胜解智力知净与不净的胜解（内心认可的取向），令净者渐增、不净者渐舍；种种界智力知劣、中、妙界（习气品类），如其根、其意乐、其随眠（潜伏的烦恼习性），从合适的门径把人安立进修行
      - **界智力条下**：详写一整套给初发心菩萨的「除遣假想」教授：先从自己的名字入手，认出名字只是「客想」（临时贴上的标签），于名想施设处都无所得
        - **再分析眼**：除眼名、眼想等假施设外唯有实事；若眼真是离开名言的实在物，应不待「眼」这个名字、不由听闻分别就自然生起眼的认识——实则无有，故名言是客，法亦唯客
        - **推广到耳鼻舌身乃至一切法想**：普于一切想中唯起客想，数数除遣一切戏论之想，以无分别、无相之心唯取于义，多修习住，即得无倒心一境性
        - **随后嘱咐守护作意**：于不净、慈愍、缘起、界差别、阿那波那念（数息）、初静虑乃至非想非非想处等一切作意勿当舍离——此教授是过去、未来、现在诸佛共同施设的，声闻勤修也速得胜通慧，如实通达便能获得诸法现观
      - **遍趣行智力**：了知能出离行与不出离行，令人舍离后者、授与前者——分得清哪条路真能出离
      - **宿住随念与死生智力**：数数随念过去世的本事本生（往昔的事迹故事），令有情生厌离、生净信，并降伏执常论者（认为有永恒不变的我）；对弟子命终受生之处能正记莂（授记预言），降伏执断论者（人死如灯灭）
      - **漏尽智力**：于自解脱无惑无疑，降伏未证谓证的增上慢者
    - **次第**：成佛之初十力顿然俱得（全套设备一次装好），启用却有先后——本卷给出三门启动顺序，起点都是处非处智力
      - **第一门依求法者的目标分层**：处非处先起，建立无倒因果的总纲 → 自业接住求人天可爱果者（教离不善业、行善业）→ 静虑智力接住求世间离欲者 → 其余七力接住求出世的
        - **出世段内部再排队**：根胜劣（看根）→ 胜解（看志向）→ 界（看随眠）→ 遍趣行（引入门径）→ 宿住、死生（摄心净修后为说中道，远离以萨迦耶见（执有真实自我的见解）为根本的常断两边偏执）→ 漏尽（对虽未断烦恼但暂不现行而自起增上慢者，令舍慢）
      - **第二门依在家、出家分观察**：处非处依妙法住智（如实照见缘生因果的智慧）观察缘生法 → 自业观在家分的业与果 → 静虑智力观出家分，查遍世间确认无人能说出苦的正道，由大悲以佛眼观照 → 根胜劣知钝中利根而说法 → 余力次第如前
      - **第三门依缘生法界观察**：处非处观察缘生法界 → 自业观察有情自造何业、还受何果 → 静虑智力示现三种神变教授 → 余力令趣入正道，再令解脱众苦
    - **差别**：次第讲完再看十力之间怎么划界——十力两两相望「亦有差别亦无差别」，边界不在知道什么，而在从哪个角度知道，原文用「若正了知……当知此由……」的判据句逐对划定
      - **处非处 vs 自业**：「善业感乐果」是规则层面（处非处），「这果正是造业者本人受、别人代不了」是责任层面（自业）
      - **自业 vs 静虑**：能修定者能入定归自业；依定现神变教人、照取与信等俱生的心归静虑智力
      - **根 vs 胜解**：照取以诸根为先的意乐归根胜劣；分别意乐本身的种种差别归胜解——顺带给出意乐六种：不出离（信解大自在天等各别天神）、出离（信解三乘）、远清净（善根下品中品成熟）、近清净（上品成熟）、现法得涅槃（信解声闻乘涅槃）、当来世得涅槃（信解大乘涅槃）
      - **胜解 vs 界**：照取胜解所起的相似种子归胜解；分别种子的无量品类归界——顺带给出种子（潜藏的心理倾向与可能性）四种：本性住（先天本有）、先习起（后天熏成）、可修治（有般涅槃法（具足能证涅槃之性）者）、不可修治（无般涅槃法者）
      - **界 vs 遍趣行**：知如界种类的行迹趣入归界；分别行迹品类——能令离染、毕竟清净、不毕竟清净——归遍趣行
      - **遍趣行 vs 宿住**：知前际随念一切趣的因缘归遍趣行；详知前际死生相状（随顺八言说句、六种略行）归宿住随念
      - **宿住 vs 死生 vs 漏尽**：前际死生归宿住、后际种种死生归死生智力；自事义未究竟者后际受生相续归死生，已究竟者现法证涅槃归漏尽
  - **不共佛法：佛的独家装备与「谁更接近佛」**
    - **承接十力**，连续清点其余功德（经文各有出处，本卷逐一给出定义），从四无畏一路列到一切种妙智，合计百四十种不共佛法
    - **四无畏**：在大众中就四处公开自称叹——一切法现等正觉（所知障永解脱，不共声闻）、漏尽（烦恼障永解脱，共声闻）、说出离道、说诸障法应当远离；前二叹自利行满、后二叹利他行满
      - **无畏的底气**：他人就四处兴谤难，如来于其中不见有任何如实因相，故坦然无畏、心无怯劣；顺带说明同一句法结集时按听众分记——声闻藏除去「菩萨」字样，菩萨藏只诵「菩萨」之言
    - **三念住**：佛长夜唯愿有情于善说法毗奈耶（正法与戒律）如实随住；听众分三众——一向正行、一向邪行、半正半邪，所愿遂或不遂皆不生杂染，心态不随听众顺逆起落
    - **三不护**：一切鄙恶所作的覆藏永断——阿罗汉尚有忘念时的无记（非善非恶）小过，佛连这个也没有，教诫弟子无所防虑
    - **大悲**：一切种相如前供养亲近无量品所说，无量无上
    - **无忘失法**：事、处、方式、时间四要素样样正随念——作事从不丢项
    - **永害习气**：阿罗汉虽断烦恼，动转、瞻视、言论、安住中仍有「似有烦恼」的旧习痕迹；佛连痕迹也没有
    - **一切种妙智**：一切法分三聚——能引有义聚、能引无义聚、非有义非无义聚；对全部三聚都无颠倒知名一切种智，对其中能引有义聚法尤其通达名妙智，二者合称一切种妙智
    - **最后刹那**：住最后有的菩萨坐菩提座，无师修三十七菩提分法，得一刹那无障碍智三摩地，即金刚喻定（学道的最后一个定，坚不可摧如金刚）
      - **从此无间**，第二刹那顿得其余不共佛法（十力为首、一切种妙智为末），获得无垢智的转依（生命依托从染污彻底转为清净）——此转依最上，其余乃至最上成满位的菩萨转依皆有上
    - **八面镜子**：一组问答回答「安住到究竟地的菩萨与佛差在哪」，八组比喻说同一件事——菩萨什么都看得见，只隔最后一层膜
      - 隔轻纱看色 ↔ 无障隔；画彩未净修治 ↔ 已净修治；微暗中见色 ↔ 离一切闇；远睹 ↔ 近睹；轻病眼 ↔ 极净眼；处胎身 ↔ 出胎身；阿罗汉梦中心行 ↔ 觉时心行；昧灯 ↔ 明灯
      - **结论**：究竟地菩萨与佛的妙智、身心「有大差别」——差别不在有没有，而在还隔不隔最后一层
  - **十件佛事：给一百四十种不共佛法派上用场**
    - **承接**：装备清点完毕，接问佛成道后拿它们做什么——遍于十方佛土施作一切佛事，略有十种，每件佛事原文都补一句「如是作事，××所能成办」，十个功能各配一个承办模块
    - **十件与模块一一对应**：自现大丈夫身令有情发净信 ← 诸相随好（佛身的相好庄严）；普为一切有情起一切种教授加行 ← 四一切种清净；作一切利有情事、断一切疑惑 ← 十力；降伏一切他论、成立一切自论 ← 四无畏；弟子安住或不正安住而心无杂染 ← 三念住；如自所言即如是作 ← 三不护；昼夜以佛眼遍观世间 ← 大悲；一切作事皆无退舍 ← 无忘失法；所行仪轨如实随转、无越作用 ← 永害习气；于三聚法简择舍离、宣说开示 ← 一切种妙智
    - **佛事之广**：若广分别不可数尽——乃至俱胝那庾多（天文数字）百千大劫说不能尽
    - **为什么叫「建立」**：诸菩萨依此住此，能正修学菩萨学、亦有所证、能成办一切有情一切义利，故说名为建立
    - **为什么叫「不共」**：判据是利他——一切如来是利他事之所显现，声闻独觉不如是
      - 其中大悲、无忘失法、永害习气、一切种妙智四样，声闻独觉一切皆不得；其余各项或分似得而一切种皆不圆满；「独一有义」是不共义
  - **菩萨地收官：总名、受持功德与次第总纲**
    - 学道（怎么修）与学道果（修成什么）至此全部讲完，名菩萨地；另有四个别名——菩萨藏摩怛理迦（对菩萨藏的纲目式论释）、摄大乘、开示坏不坏路、无障智净根本（无障碍智慧清净的根基）
    - **受持功德**：于菩萨地起坚信解、乐闻受持乃至书持供养，所得福聚等同听闻一切微妙经典——因为它显示菩萨藏中略标广释诸门摄
      - **一个警告**：若像似正法（貌似正法的相似教说）兴盛，能引实义的正法当速灭没
    - **发心品**：给出菩萨地的官方次第总纲，回答「几十卷内容按什么顺序组织」：安住种性 → 发心 → 自他利行 → 无杂染方便 → 无厌倦方便 → 善根增长方便 → 证无上菩提——环环相扣，断一环后面就断
      - **展开为一条修行流水线**：先于甚深广大正法立信解 → 访求正法 → 广为他说 → 自能成办 → 福德智慧增长 → 不舍生死（生死无杂染行、于自乐无著行、于无量生死大苦无厌倦行）→ 访求异论得无畏 → 善知世间 → 断他疑惑 → 二资粮圆满 → 修谛行相菩提分法并回向大乘、不求声闻独觉涅槃 → 得陀罗尼（总持不忘的能力）与无碍辩才 → 修三解脱门（空、无相、无愿）永断障 → 断自他颠倒增上慢 → 一切种相正行圆满
    - **两种殊胜收束其果**：正行功德殊胜——用利他事以为自事（声闻独觉不如是），于有情起平等心、常施恩惠不望其报、常起不虚加行；可称赞功德殊胜——于诸佛所获授记、安住不退转地、得坚固无忘失法，善法恒常无间、运运增长如明分月（上弦月逐夜增辉），得名「真实菩萨」不名「相似」
      - **称赞殊胜再展开**：了知一切有情的调伏方便故一切安立得善巧 → 教授得善巧 → 获得无量所缘三摩地王 → 宣说正法皆有胜果 → 于大乘究竟出离、能摄大乘，并在大乘出离的各个位次中得到诸佛菩萨共许的名号
      - **终点**：得诸菩萨相，在家出家二分成办，故作意思受诸有生（主动受生）而恒值诸佛、蒙无倒教授，于后后殊胜分位觉慧升进、不生喜足，直至究竟极边际，故名得无上
  - **有余依地：烦恼已断、残余之身还在**
    - **菩萨地讲完**，翻开倒数第二块地，回答阿罗汉证果后生命状态的第一种答案：火已熄、锅还温着——苦与烦恼不再生，但最后一身还在运转
    - **三种安立**：地施设、寂静施设、依施设——从地域、寂静、依托三个角度给这块地划界
      - **地施设安立**：除去无心地、修所成地、声闻地、独觉地、菩萨地五地的一分，再除去无余依地全地，所余诸地名有余依地
      - **寂静施设安立**：由四种寂静立名，此地因此「最极寂静、最极清凉」
        - **苦寂静**：当来后有众苦永断——如多罗树（棕榈类乔木）断截根顶不复现前，断的是根
        - **烦恼寂静**：贪嗔痴一切烦恼永断，得毕竟不生法
        - **不损恼有情寂静**：不造诸恶、修习诸善
        - **舍寂静**：六恒住（六根对六境恒常安住的持守）——眼见色、耳闻声乃至意了法已，不喜不忧、安住上舍正念正知
      - **依施设安立**：列举生命赖以运转的八种依托
        - **施设依**：五取蕴——依它假立「我」、名字、种姓、寿量等种种想；摄受依：七摄受事——自己、父母、妻子、奴婢僮仆、朋友眷属，人被种种关系所摄受；住持依：四种食（段食、触食、意思食、识食四种滋养），已生有情由之住立支持
        - **流转依**：四识住与十二缘起——一期接一期生死流转的依托；障碍依：诸天魔于修善法处作障碍；苦恼依：一切欲界令有情领受忧苦；适悦依：静虑等至之乐；后边依：阿罗汉相续诸蕴所持的最后之身
      - **阿罗汉与依的账目**：与后边依一向相应（仍持最后一身），与流转依、障碍依一向全不相应（不再流转、无人能碍），与六摄受事不共相应，与所余诸依非相应非不相应
  - **无余依地：一切依托彻底寂灭，本地分竟**
    - **第二种答案**：连残余之身与一切依托也彻底寂灭——本地分最后一地，由三种安立划界（地施设、寂灭施设、寂灭异门施设）
      - **地施设安立**：有余依地所除去的那五地一分，即此无余依地所摄
      - **寂灭施设安立**：由两种寂灭立名
        - **寂静寂灭**：在有余依四寂静之上更立四种最胜寂静——数教寂静、一切依寂静、依依苦寂静、依依苦生疑虑寂静——连「依」、依所生之苦与疑虑一并寂灭；所引偈颂说：不生下劣怯弱之心、能忍受一路勤苦，所趣入的解脱「譬如灯尽灭」——燃料已尽，火不再燃
        - **无损恼寂灭**：与一切依不相应，违背一切烦恼诸苦的流转生起，是转依所显真无漏界——佛经说「比丘永寂灭」，才是真正的安乐住
      - **无为的保证**：正因实有无生、无起、无作、无为，说「有生有为的轮回可以永出离」才不是空头支票
      - **四句赞叹**：功德难了知故名甚深、极宽博故名广大、无穷尽故名无量、数不能数（有非有不可说、即色离色不可说）故名无数——由清净真如所显，一向无垢
      - **寂灭异门安立**：同一个寂灭有无量异名——常、恒、久住、无变、舍宅、洲渚、救护、归依、安隐、吉祥、无垢、甘露、涅槃、永绝一切戏论……每个名字突出一德，异名各显一德，同指一个寂灭
    - **「本地分竟」**：十七地至此全部讲完，全论前半部（本地分）就此画上句号
