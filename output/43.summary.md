- **全篇总括**：本卷是菩萨修行手册的续篇，写法是「一张模板填三遍」：用九个名相（自性、一切、难行、一切门、善士、一切种、遂求、此世他世乐、清净）先后解剖禅定与智慧两度，再以同一模板展开爱语、利行、同事三种凝聚众生的手段；末尾总收全篇，说明这些善法如何现行、何以最胜、何时清净，并逐一列出九相修行各自感得的佛果。
  - **九相模板：三章共用的组织公式**
    - **每品开头**：都以一首偈颂报出九个名相——自性、一切、难行、一切门、善士、一切种、遂求、此世他世乐、清净，静虑、慧、摄事三章全部照此填空
    - **九相各有分工**：自性是定义；一切、一切门、善士、一切种是不同角度的分类清单；难行专挑最难做到的情形；遂求针对众生的具体困境；此世他世乐强调现世来世两利；清净是纯度认证
  - **静虑品：禅定的定义、类型与济世功能**
    - **先答「定是什么」**：自性静虑是菩萨以闻思菩萨藏（大乘经典）为先，成就善净的、通世间与出世间的「心一境性」（心专注一境的状态），贯通奢摩他（止）、毗钵舍那（观）与止观双运三条路——这就是菩萨静虑波罗蜜多（度：由此渡到彼岸的修行）的自性
    - **再答「定有哪几类、干什么用」**：一切静虑先分世间、出世间两类，两类各自又开三种用途
      - **现法乐住静虑**：远离一切分别，身心轻安、最极寂静，离憍举、离爱味、泯一切相——当下的安住受用
      - **能引等持功德静虑**：能引发声闻独觉连名字都不知道的殊胜等持（定），以及解脱、胜处、遍处、无碍解、无诤、愿智等与声闻共的功德
      - **饶益有情静虑**：依定力为众生作助伴、除苦、如理说法、报恩、救护、解愁、施财、统御大众等十一种事业
    - **难行静虑三种**，最难的是「考上了却主动不去」：已能安住最胜定乐，却为怜悯有情、成熟利他事业，自愿弃定受生欲界；另二种是引发超越声闻独觉境界的等持、依定速证无上菩提
    - **三个分类清单**：一切门静虑四种——有寻有伺、喜俱行、乐俱行、舍俱行，即定心的四个层次；善士静虑五种——无爱味定，加上与慈、悲、喜、舍（四无量心）相应俱行的定；一切种静虑六种＋七种共十三种——止品、观品、名缘、义缘、止相缘、举相缘、舍相缘等细分
    - **遂求静虑八种与此世他世乐静虑九种**：定不是安静屋，是济世工具
      - **遂求八种**：息咒术灾患、除诸界互违之病、感降甘雨解饥馑、拔济水陆怖畏、施饮食、施财位、谏诲放逸者、成办应作之事
      - **二世乐九种**：以神通、记说、教诫三种变现调伏有情，向造恶者示现恶趣作警诫，施辩才、施正念，造立无颠倒的论典、赞颂与论议（摩怛理迦）使正法久住，制作书算等资生工具，放光照触息恶趣之苦
    - **清净静虑十种是纯度认证**：从世间离爱味、出世无染污，经加行净、根本净、胜进净、入住出自在、舍已复能还入、神通变现自在，到离一切见趣、烦恼障与所知障（障碍证知诸法的微细障）俱净——静虑无量无边，依此圆满静虑波罗蜜多，速证无上菩提
  - **慧品：智慧的范围、类型与纯度**
    - **与静虑同一模板再填一遍**：定之后讲慧，因为慧是真正证悟的工具——自性慧是「能悟入一切所知、简择诸法」的智，普遍运转于五明（五门学科：内明＝佛法义理，因明＝逻辑论辩，医方明＝医药，声明＝语言文典，工业明＝工艺技术）
    - **一切慧**：分世间、出世间两类，展开为三种
      - **随觉通达慧**：对离言说的法无我性（诸法无实自性、超越语言的真理），在将悟、正悟、悟后三个阶段慧皆寂静明了、无分别离戏论，远离增益、损减两边，顺入中道
      - **决定善巧慧**：于五明处及三聚（能引义利、能引非义利、非义利非非义利三类法聚）如实了知，能速满无上妙智资粮
      - **有情义利慧**：饶益有情的十一种，与前文饶益有情静虑相同
    - **难行慧三种**：甚深法无我智 → 了知调伏众生方便的智 → 于一切所知境界无障碍的智（文中称为最难）
    - **分类清单**：一切门慧四种——闻所成、思所成、思择力所摄、修习力所摄的定中无量慧；善士慧五种——闻法集成、内正作意俱行、自他利方便俱行、于法安立善决定、舍烦恼，另有微细、周备、俱生、具教、具证五种异门；一切种慧六种＋七种共十三种——苦集灭道四谛智加尽智、无生智；法智、类智、世俗智、神通智、相智、十力前行智、四道理中正道理智
    - **遂求慧八种与此世他世乐慧九种**：会懂，更要会说、会办事
      - **遂求八种**：前四种是四无碍解——于法、于义、于释词、于辩才皆无滞碍；后四种是论辩与生活实务——摧伏他论、成立自论、正训家属家产、善解世间政务
      - **二世乐九种**：于内明善安住、于其余四明善明净而不执住，依此对愚痴、放逸、怯弱、勤修正行四类所化众生，依次示现、教导、赞励、庆慰
    - **清净慧十种＝五个问题各二种**：真实义（尽所有性与如所有性）、流转义（正因果）、执受义（颠倒与不颠倒）、方便义（应作与不应作）、究竟义（杂染与清净），皆如实了知——极善决定的无量妙慧能证大菩提果
  - **六度会通：散在各经的六个度收拢为一**
    - **衔接性插叙**：六种波罗蜜多在佛经（素怛缆）中处处散说，本论将它们摄集一处略说——经中或标举或解释的施乃至慧，都可在此对应了解
    - **佛过去为菩萨时**，本生中一切难行苦行都与施等六度相应依止：或唯依一度，或杂依二、三、四、五乃至全部六度
    - **六度是大白法海、涌施大宝泉池**：一切有情一切种类圆满之因；所集福智资粮，除无上菩提外再无他果足以相称
  - **摄事品：爱语、利行、同事——靠什么把众生聚到善法上**
    - 摄事（四种摄事，即凝聚众生的手段：布施、爱语、利行、同事）同样套用九相模板；布施前已详说，本卷依次讲爱语、利行、同事
    - **爱语：怎么对人说话**
      - **自性**：常乐于说悦可意语（令人欢喜）、谛语（真实）、法语（如法）、引摄义语（引入义利）
      - **一切爱语三种**：再归为两类
        - **慰喻语**：先含笑问安、随世间礼仪慰问；庆悦语：见人眷属财谷昌盛或信戒闻舍慧增长而不自知，代为道贺；胜益语：宣说圆满法教真实饶益
        - 慰喻与庆悦属「随世仪轨语」，胜益属「顺正法教语」
      - **难行爱语三种**：对能杀害自己的怨家恶友说、对上品愚痴钝根者誓受疲劳反复说、对谄诈欺诳的师长福田无嫌恨心说
      - **一切门爱语四种**：向欲断诸盖（烦恼的遮盖）趣善者说入门应作之法，向心已调善者说四圣谛增进法，向放逸者劝离放逸，向疑惑者说法论义决择
      - **善士爱语五种与一切种爱语十三种**：善士指所说之法有因缘、有出离、有所依、有勇决、有神变（三神变所摄，所说终不落空）；一切种为开听、遮制、法门、法相、训释言词、法句差别六种，加慰喻、庆悦、恣少希欲、安慰惊怖、如理宣说、举呵令离不善、请有力者饶益七种
      - **遂求、二世乐、清净三种**：遂求爱语依四净语（离妄语、离间语、粗恶语、绮语）起八圣语——见言见、闻言闻、觉言觉、知言知，不见不闻不觉不知亦如实而说；二世乐九种以正法断人于亲属难、财位难等的愁忧，赞美净戒、正见、轨则、正命的圆满；清净爱语二十种，以二十相宣说正法，如前力种性品所广说
    - **利行：推人实际行动**
      - **自性**：由爱语示现正理，引导有情依所学如法而行（法随法行），安住悲心、无爱染心而劝导调伏；利行的九相广说同于爱语，此处只讲差别
      - **一切利行**：按对象分二种——令未成熟者成熟、令已成熟者得解脱；按利益时段分三门
        - **现法利**：劝导以法与业德招集、守护、增长财位，得现世安乐与广大名称
        - **后法利**：劝导弃舍财位、清净出家乞食自活，必得来世安乐而不必得现世乐
        - **现法后法利**：劝导在家出家渐次修行趣向离欲，现世得身心轻安，来世或生净天或般涅槃
      - **难行与一切门利行**：难行三种是对无善根者、对耽着广大财位极放逸者、对执着本有道果邪见邪行的外道行利行，三种人都最难劝导；一切门四种是对不信者建立信、对犯戒者建立戒、对恶慧者建立慧、对悭吝者建立舍
      - **善士利行五种与一切种利行十三种**：善士是于真实义、应时宜、能引胜妙义利，以柔软心、慈心劝导；一切种为摄受、调伏、除恚恼令入圣教、令三乘成熟、令得解脱等六种，加安处于善资粮、远离、心一境性、清净诸障、修习作意，并按声闻独觉种性或如来种姓分别安处其乘等七种
      - **遂求与二世乐利行**：遂求八种是见有情被无惭、无愧、惛沈、睡眠、掉举、恶作、嫉、悭八种缠（缠缚身心的烦恼）所缠，一一方便开解令离；二世乐九种是劝行十善——依净身业劝离杀生、偷盗、邪淫、饮酒，依净语业劝离妄语、离间、粗恶、绮语，依净意业劝离贪欲、嗔恚、邪见
      - **清净利行十种**＝依外五种＋依内五种
        - **外五**：无罪、不转（不把非解脱处当作真解脱）、渐次（劣慧说浅法、中慧说中法、广慧说深法，因材施教）、遍行（于四姓乃至天人随类劝导）、如应（随其下中上根机以相应方便劝导）
        - **内五**：起广大悲意乐而行；虽受大苦劬劳心无倦而深生欢喜；虽处最胜财位而自谦如奴仆孝子；心无爱染无虚伪，真实哀怜；生毕竟不退转的慈愍心
    - **同事：以身作则**
      - **定义与原理**：劝别人学的善根，自己或等量或增上地现场受学，故称同事——所化有情见菩萨亲自在修，对所学善根便坚固决定不退转，因为无人能诘难「你自己都不学」
      - **同事四句辨析**（是同事与否 × 是否显示）
        - **是而不显**：与诸菩萨功德威力平等，却隐自善不显己功
        - **不是而显**：见下劣信解者对甚深法生怖畏，为方便化导，故意示现与其同法，乃至故思受生旃荼罗（贱民）、狗类之中
        - **是而亦显**：见所化者善根犹可摇动，为令坚住，现与同事或等或增
        - **不是亦不显**：菩萨自行放逸、弃舍他事
  - **收官总论：善法的现行、最胜、清净与感果**
    - **分工总结**：六波罗蜜多能自成熟一切佛法，四种摄事能成熟他一切有情——两句话概括菩萨一切善法作业
    - **现行、最胜、清净各有条件**
      - 三因缘（身、语、意）应知现行；二因缘（广大、无杂染）应知最胜，故亦名无上、名不共；三因缘（炽然、无动转、善清净）应知清净
      - **广大的内涵是三个「无别」**：有情无别（普为一切法界有情，非专为己）、事无别（于一切种施等善根精勤受学）、时无别（恒常无间，昼夜现法后法常行无替）
      - **无杂染四相**：怀欢喜心修善，无苦无忧无悔；不损恼他、不著见趣、不杂恶行；殷重遍体，唯见功德真实寂静，不从他缘非余引夺；不悕求异熟果报（转轮王、帝释、魔、梵），不求返报，不依利养恭敬名誉乃至养活身命
      - **清净三级**：入清净意乐地者，善根不由思择而炽然现前、无有退转（如明分月唯增无减）；住到究竟地或系属一生最后有者，善法名善清净，此外更无菩萨地所摄的更胜净法
    - **九相感果表**（各相多修习、善清净、具圆满，各感一果）
      - **一切** → 无上菩提金刚坚固身、正法久住果
      - **难行** → 如来无等希奇法果；一切门 → 最胜有情天人所供养果；善士 → 于一切有情类中最尊胜果
      - **一切种** → 三十二大丈夫相、八十随好庄严身果
      - **遂求** → 坐菩提座、魔怨不能恼触不倾动果；此世他世乐 → 最胜静虑解脱等持等至乐果
      - **清净** → 四一切种清净果（所依净、所缘净、心净、智净），并感三不护、十力、四无所畏、三念住等一切不共佛法极清净果
      - **结语**：这些善法亦感生死流转中顺菩萨行的无量无边可爱无罪胜果
