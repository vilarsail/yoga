# 瑜伽师地论卷第五十三 导读

## 一、内容总览

本卷为《瑜伽师地论》卷第五十三，属「摄决择分」中「五识身相应地意地」之第三。在决择分中，本卷承前对意地的深入决择，从「业」的安立出发，系统决择了表业、律仪与不律仪、等至（无想定、灭尽定）、无为法（虚空、非择灭）、心不相应行，以及五蕴善巧中色、受、想、行四蕴的自性与差别。全卷以「业 → 律仪 → 定 → 无为 → 蕴善巧」为脉络，由有漏业用渐入定慧无为，终收于蕴处自相，是理解唯识宗业论与蕴善巧建立的关键章节。

## 二、结构层次

本卷以「业」为入口，层层推进至定、无为、蕴善巧，呈总起 → 分述对比 → 转入定慧 → 收束善巧之势：

- **表业安立（总起）**：身语意三表业（染污/善/无记） → 论证一切表业皆假有（诸行刹那灭，无实作用，唯变异相） → 由表业引出不律仪与律仪两类业用。

- **不律仪 ↔ 律仪（分述对比）**：
  - 不律仪：不律仪者成就相 → 邪恶愿思与五随烦恼（不信、懈怠、忘念、散乱、恶慧）俱行 → 恶尸罗恶戒者，非福运运增长。
  - 律仪：受律仪差别（自然受 vs 从他受；惭愧为支，惭强于愧） → 百行所摄（十十行） → 八种律仪（能起、摄受、防护、还引、下中上、清净[静虑/无漏]） → 总立为三（受、持、清净）。
  - 三种律仪建立因：依所化三类建苾刍（离恶行+离欲行）、近事（离恶行）、近住（俱不能究竟） → 各支差别（苾刍四支、近事三支、近住五支） → 摄属（苾刍尼等摄苾刍、近事女摄近事） → 制立差别（母邑渐受、勤策离金银、歌舞处开合、扇搋迦半择迦不许出家）。

- **受戒与舍戒因缘（律仪之边际）**：不应授戒因缘（苾刍六因：意乐/依止/男形/白法损害、系属于他、为护他；近事二因；近住一因；半择迦三种） → 舍戒因缘（苾刍五因、近事、近住；正法隐没时先受不舍）。

- **等至与无为（转入定慧决择）**：无想定（出离想作意，假有，三品修） → 无想（生得心心所灭） → 灭尽定（止息想作意，唯灭转识不灭阿赖耶识，圣者能入；无想定非学非无学，稽留诳幻处） → 虚空（唯诸色非有所显，假有） → 非择灭（余法生故余不生，假有，非一向决定；学见迹所得则决定） → 心不相应行（假想安立）。

- **五蕴善巧（以嗢柁南收束）**：嗢柁南「自性义差别次第摄依止」 → 诸蕴自性（色十一/二种、受六/二种、想六、行六、识六，十八自性） → 色蕴差别六相（事/相/识执不执/识空不空/想所行/边际） → 受蕴差别五相（事/相/生/观察/出离） → 想蕴差别五相（事/相/颠倒/无颠倒/分别） → 行蕴差别五相（境界/分位/杂染/清净/造作）。

全卷由「业」立「律仪」，由律仪引入「定」与「无为」，终收于「蕴善巧」，从有漏业用归于蕴处无我自相，是一完整的决择单元，过渡句如「复次云何表业」「复次云何无想定」「如是已说六种善巧」串起各段。

## 三、关键结论

1. 一切表业皆是假有——以诸行刹那灭故，无实从此至彼之作用，唯有身语意之相变异生。
2. 律仪胜劣不在自受他受，而在能持之心等不等；自然受与他受福德无别，关键在惭愧俱行与等心护持。
3. 八种律仪可摄为受、持、清净三类；清净中静虑律仪仅损伏犯戒种子，无漏律仪（圣所爱戒）方能永害，阿罗汉位但由能治胜故胜。
4. 灭尽定唯灭转识、不灭阿赖耶识，是有学不还身证与无学俱分解脱所能入；无想定无慧现行、非学非无学，故稽留诳幻处。
5. 五蕴皆以「无我性义」为建立义——色等诸蕴唯有种种名性诸行，积聚为相，为显无我而立。

## 四、易混辨析

- **无想定 vs 灭尽定**：无想定已离遍净贪（第三静虑）、未离上贪，以「出离想」作意为先，凡夫外道所入，无慧现行，非学非无学，稽留诳幻处；灭尽定已离无所有处贪，以「止息想」作意为先，唯灭转识不灭阿赖耶识，圣者（不还身证、俱分解脱）所入，能证胜善法。
- **择灭 vs 非择灭**：非择灭不由智慧简择断烦恼得，而是「余法生缘现前，余法生故余不得生」——因生缘阙而不生，唯假有，非一向决定（余时遇缘可生）；学见迹于卵湿二生、北拘卢洲、无想天等所得非择灭则一向决定。
- **想倒 vs 心倒 vs 见倒**：想倒是于境邪取其相（无常计常等）；心倒是由此等了相于境贪着；见倒是于颠倒事坚执忍可、开示建立。在家者多发心倒，一分出家者多发见倒。
- **执受色 vs 非执受色 / 同分色 vs 彼同分色**：执受色是识所依执、安危事同、和合生长（如根身），非执受色反是；同分色是识不空、与识等义转，彼同分色是识空、似自相续而转。

## 五、阅读提示

读本章可带着两个问题：(1) 佛为何对三类所化建立三种律仪？分支开合的内在逻辑（离恶行/离欲行、在家/出家轻重）是什么？(2) 五蕴善巧中「自性—差别」的展开方式，如何服务于「为显无我性义建立诸蕴」这一根本意趣？带着业用与蕴相两条线对照阅读，更易把握全卷骨架。
