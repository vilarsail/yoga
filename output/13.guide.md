# 瑜伽师地论卷第十三 导读

## 一、内容总览
本卷收束三摩呬多地第六，展开非三摩呬多地第七、有心无心二地第八第九、闻所成地第十之一，呈「由定入慧」递进：先结归禅定善巧与得失，再以否定式定义划出非定地，继以五门判心/无心，最后以五明处（特重内明）开显法相名相，为思修二地奠基。

## 二、结构层次
全文按四地次第，由「定」到「慧」层层推进：
- 三摩呬多地第六之三：身心远离 → 三种修相 → 等持/等至善巧 → 定相 → 四倒与无倒 → 四捡行（顺退/住/胜进/决择）→ 四净胜 → 五相治寻思 → 陶炼生金喻 → 四正法
- 非三摩呬多地第七：十二相反显非定地 → 自性不定→阙轻安→极散乱→太略聚→未圆满→杂染污→不自在→不清净→起→退
- 有心无心二地第八第九：五门判心有无 → 地施设→心乱不乱→生不生→分位→第一义；唯无余依涅槃为真实无心地
- 闻所成地第十之一：五明处总摄 → 内明四相（事施设、想差别、摄圣教义、所应知处）→ 三颂嗢拖南 → 所应知处相（「二法」安立）

## 三、关键结论
1. 禅定善巧不在能入定，而在善知定相、入住出自在、辨倒与无倒。
2. 非定地十二相皆定的反面或未圆满。
3. 有心无心判别依五门而异，第一义中唯无余依涅槃（阿赖耶识永灭）为真实无心地。
4. 闻所成地以五明处为范围，内明四相统摄佛法名相。
5. 圣教无乖诤在「义句文平等润洽、互相随顺」，异于外道。

## 四、易混辨析
- 等持善巧 vs 等至善巧：等持重空等三三摩地及名句文身；等至重十遍处、无想、灭尽等至出入。
- 进时倒 vs 退时倒：进时倒喜乐未得谓退；退时倒由出世作意令喜乐不现行，谓退定生利益。
- 顺退/住/胜进/决择：顺退欲俱行想数现前；顺住令定坚住；顺胜进趣上地；顺决择趣出世现观。
- 有心无心五门：地施设唯无想定/灭尽定为无心；心乱不乱以颠倒乱心为无心；分位除六位余有心；第一义唯无余依涅槃为无心。

## 五、阅读提示
带两个问题读：① 禅定「善巧」与「倒/无倒」如何辨别？② 内明处如何统摄无量法相？
