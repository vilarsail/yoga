- **全篇总括**：本卷进入声闻地的「出离地」（讲修行人如何脱离欲界乃至整个三界），开卷先立一张三件事的路线图：世间道离欲、出世间道离欲、以及两条道共同需要的资粮。世间道靠逐级禅定爬到三界最高处，出世间道靠四圣谛的智慧彻底超出三界；随后转入资粮清单，本卷只精讲第一项「戒律仪」——从持戒的六个构件，讲到十种亏损、戒的六个别名、身语意三业的观察法，最后列出持戒的十种回报。
  - **出离地开篇：这张地图只有三件事**
    - **上一地「趣入地」讲完**，本卷接着发问：什么叫出离地——即修行人脱离下地乃至三界所必经的阶段
    - **开卷偈**（嗢拖南，提纲式偈颂）给出全部内容：世间道离欲 → 出世间道离欲 → 两条道的资粮，三者合起来名为出离地
  - **世间道离欲：一级一级往上换**
    - **方法是一个统一公式**：把下层境界观为「粗相」（过患深重），把上层境界观为「静相」（寂静微妙）；长久安住这种观想，就能离欲下地、证入上地
    - **推进路线**：先观欲界粗、初静虑（初禅）的离生喜乐静而离欲证入；再照此逐级上推，从初静虑一路推到无所有处，乃至证入非想非非想处（三界最高点）
    - **天花板**：原文说「除此更无若过若增」——这条路顶点就是非想非非想处，出不了三界，与出世道形成分野
  - **出世间道离欲：一次换掉整个系统**
    - **前提不同**：要亲近善士（真正的善知识），在圣法中已得聪慧、调顺
    - **核心是四圣谛**：对苦、集、灭、道各各如实了知，成就有学智见（圣者位的智慧）
    - **之后渐修圣道**，对三界中见道、修道所应断的一切法，自己离系（解除烦恼系缚）而得解脱 → 结果是「超过三界」
  - **二道资粮：出发前先备粮**
    - **问题**：无论走世间道还是出世道，都需要共同的准备工作——共十四项：自圆满、他圆满、善法欲、戒律仪、根律仪（守护感官门户）、于食知量（饮食有节）、常勤修习觉寤瑜伽（初夜后夜不空过）、正知而住（行住坐卧保持觉知）、善友性（亲近良友）、闻正法、思正法、无障碍（没有违逆的障碍因缘）、修惠舍（慷慨布施）、沙门庄严（具足沙门应有的仪表德相）
    - **前三项**（自圆满、他圆满、善法欲）在前面讲修行劣缘时已辨明，本卷不再重复
    - **从戒律仪开始逐项展开**，本卷也只讲到戒律仪为止
  - **戒律仪总起：偈颂先预告全章骨架**
    - **定义式开头**：「安住具戒，广说乃至受学学处」——一整段戒法由此展开为六个构件
    - **提纲偈预告**：辨三种略义相、十种亏损（相违即是圆满）、六个异门别名、十种殊胜功德；随后还讲身语意三业的观察清净法
  - **戒的六个构件：从守住戒到学全戒**
    - **安住具戒**：对所受的学处（戒条），身业、语业都不亏犯，无缺无穿（没有破损漏洞）
    - **善能守护别解脱律仪**：别解脱律仪（比丘等七众各自逐条受持的戒）因持戒人身份不同分成多种，本卷以比丘律仪为代表来讲
    - **轨则圆满**：一个公式套三个场域——威仪路（行住坐卧的姿态）、所作事（穿衣、如厕、用水、乞食、洗钵、敷卧具等日常杂务）、善品加行（读诵正法、侍奉尊长病人、随众作法、静坐思惟等善行）
      - **三个场域统一标准**：所应作的就如法而作，使世间不讥毁、贤良善士与持律者不呵责——即随顺世间与毗奈耶（戒律），不越过二者
    - **所行圆满**：一张「不去」名单——唱令家（演艺传讯之家）、淫女家、酤酒家、国王家、旃荼罗羯耻那家（贱姓之家）五处，是如来制立的非所行处；远离之外，其余无罪的处所还要知时而行
    - **于微小罪见大怖畏**：微小罪指可还净的轻罪（犯了稍下功夫就能忏悔干净）；为何要看成大怖畏——怕因此失去得所未得的证悟堪能、堕向恶趣、被大师天众呵责、恶名远近流布；标准是即使命难（性命受威胁）也不故意犯，万一失念而犯，速速如法发露还净
    - **受学学处**：受具足戒时从戒师处先听闻部分学处，再从亲教师、轨范师处听闻别解脱经全部二百五十余条，一一自誓当学；半月诵戒继续听学；未善巧的就去请问，得到善巧后随教诲无增无减地受持——由先发誓言驱动，把「守戒」落成「学戒」
  - **三种略义相：把六个构件收成三相**
    - **这是佛显示戒蕴**（戒这一聚法）的归纳：无失坏相、自性相、自性功德相
    - **安住具戒** → 无失坏相（戒体没有失坏）
    - **善守护别解脱律仪** → 自性相（戒的自体本身）
    - **轨则、所行圆满** → 观他增上（以他人所见为检验）的自性功德相：他人见了，未信者生信、已信者增长，成为生净信之处，心无厌恶、口不讥毁
    - **于微小罪见大怖畏＋受学学处** → 观自增上（对自己未来负责）的自性功德相：能保住生善趣的果报、保住证悟的堪能
  - **三种戒性：戒在修行版图中的位置**
    - **受持戒性**（对应安住具戒）：只是把戒领受在手
    - **出离戒性**（对应善守护别解脱律仪）：别解脱律仪就是增上戒学，而增上心学、增上慧学（定学与慧学）都依它为前行所依——一切苦尽的究竟出离，以戒为第一站
    - **修习戒性**（对应轨则所行圆满、微小罪见怖畏、受学学处）：把戒修到「善修习极善修习」的纯熟程度
  - **十种亏损：戒为什么会失灵**
    - **总公式**：十种因缘使戒亏损，与它们相反的十种就是戒圆满清净；其中「不能出离」「所受失坏」两种，佛另说为「尸罗艰难」（尸罗即戒），其余只称亏损
    - **动机不纯**：最初恶受——被王法、盗贼、债主、怖畏、活不下去所逼迫才出家，不是为调伏寂静涅槃；发起邪愿——持戒梵行为求生天，或为求利养恭敬
    - **心态失衡**：太极沉下（无羞耻、对学处拖沓迟缓）↔ 太极浮散（在该悔处执恶不悔、不该悔处乱悔，对他人起轻蔑恼害）；放逸懈怠——犯了不还净、事先不发猛利的「决不再犯」之愿、贪恋睡眠不勤修问
    - **行为偏差**：轨则亏损（威仪、所作、善品加行不顺世间与毗奈耶）；净命亏损（邪命自活）——大欲不知足、矫诈造作骗取供养、伪现寂静相显己有德、对施主强逼苦索、贬低他人的布施以图更多，凡非法求衣服饮食医药都叫邪命
    - **见地有误**：堕在二边——放纵享乐的极乐行边 ↔ 折磨自己的自苦行边（卧刺灰、蹲坐、事火、下水、一足而立随日转等苦行）；不能出离——外道由邪见执取戒禁，以为持它就得清净解脱，戒虽防护得再清净也叫不出离
    - **最重一种**：所受失坏——毫无羞耻、毁犯净戒、内怀腐败而外现贞实，如「螺音狗行」（说话像圣者、行为如恶狗），实非沙门自称沙门
  - **戒的六个别名：一个东西，六面镜子**
    - **佛在不同经处给戒起了六个名字**，各显一义
    - **根本**：戒能建立、任持一切世间与出世间的无罪第一快乐功德，如大地长养药草丛林——善住根本，心便寂静
    - **庄严具**：世俗耳环指环只有年少盛壮时戴才好看，戒的庄严却一切人、一切时戴上皆妙
    - **涂香**：如酷暑天涂栴檀龙脑消除郁蒸，戒能除遣恶戒引起的身心热恼
    - **薰香**：如香气顺风逆风都能飘送，具戒者的美誉声名传遍四方、愈传愈远
    - **妙行**：戒是清净善行，能趣向妙药、妙天趣、妙安隐
    - **律仪**：戒的本性是防护、息除、远离——所以又叫律仪
  - **三种观清净：身语意业的自查流程**
    - **观察对象是身、语、意三业**，公式相同：将要造及正在造时，观察此业是自损损他、能生众苦招苦果的不善性，还是不损自他、能生诸乐的善性
    - **预判取舍**：不善 → 收敛不作、不给它方便；善 → 放手去作
    - **事后复查**：已造的业再观察，不善就在同梵行者（同修道友）前如实发露、如法悔除；善则心生欢喜，昼夜安住、多多随学
    - **普遍有效**：过去、未来、现在的一切沙门婆罗门，都由这样观察三业而得清净——佛曾为此为罗怙罗（佛陀之子）说偈：于身语意业应数数正观察
    - **名相收束**：审正思择叫「观察」，该敛的敛、该悔的悔、该喜的喜叫「清净」
  - **十种功德胜利：持戒的回报清单**
    - **第一条是一条完整因果链**：戒净 → 无悔 → 欢 → 喜 → 身轻安 → 受胜乐 → 心定 → 如实知见 → 起厌 → 离染 → 解脱 → 自知能证无余依涅槃（不留残余身心的究竟涅槃）
    - **第二条是临终的无悔**：自知曾善作身语意行，凡作福作善所应往的善趣必定能往，称为贤善死、贤善过往
    - **中间七条是现世安稳**：美誉远闻；睡时醒时都安稳、远离身心热恼；诸天保护；遇凶暴者不怖畏；怨敌仇家即使得了空隙也会转而保护或保持中立；魍魉药叉等非人无法加害；利养资具不招自至、得国王长者恭敬
    - **第十条是所愿皆遂**：想生大族姓家或欲界诸天、想入四禅八定现法乐住、想证究竟涅槃，都由戒净而达成
  - **卷末收束：一张成绩单**
    - **本卷已把戒蕴讲完五方面**：亏损、圆满、异门（别名）、观察与清净、功德胜利——这是资粮所摄戒律仪的最极圆满开示
    - **结语劝勉**：凡自爱乐沙门性的善男子，应对此勤加修学
