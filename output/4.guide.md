# 瑜伽师地论卷第四 导读

## 一、内容总览
本卷为有寻有伺等三地之一，开启三地施设建立。先总标三地五门，次明界施设建立八相，实际展开数、处、量、寿、受用五相，重点在处所与受用（苦乐）广说，是三地诸卷的义理基础。

## 二、结构层次
按"总标五门 → 界建立八相 → 数 → 处 → 量 → 寿 → 受用"推进：
- **总标（P1-P6）**：嗢拖南列五门，再出界建立八相（数处量寿受用生自体因缘果）。
- **数建立（P7-P8）**：三地划分——欲界及初静虑除静虑中间为有寻有伺地，静虑中间为无寻唯伺地，二静虑以上为无寻无伺地；判地以"离寻伺欲"为准。
- **处所建立（P9-P12）**：欲界三十六处（八热+八寒+饿鬼+非天+傍生+四洲+六欲天等）→ 色界十八处（四静虑诸天+无想+五净宫）→ 无色界四处或无处。
- **量与寿（P13-P19）**：各趣身量寿量，以踰缮那/岁/中劫计。
- **受用建立（P20-P51）**：苦乐为本卷主体，按那落迦（八热+近边四园+八寒+独一）→ 傍生 → 饿鬼 → 人（八匮乏）→ 天（三苦+转轮王七宝+诸天富乐）展开。

## 三、关键结论
1. 三地判属以"离寻伺欲"为根本，非以现行；无漏定所摄初静虑亦名有寻有伺地。
2. 欲界三十六处、色界十八处、无色界四处或无处。
3. 八大那落迦：等活/黑绳/众合/号叫/大号叫/烧热/极烧热/无间，苦具次第加重。
4. 四天王寿五百岁为等活一日一夜，无间寿一中劫。
5. 诸天受死堕、陵蔑、斫截三苦；转轮王具七宝。

## 四、易混辨析
- **有寻有伺地 vs 无寻唯伺地 vs 无寻无伺地**：以离寻伺欲判，静虑中间属无寻唯伺，二静虑以上属无寻无伺。
- **八大那落迦 vs 八寒那落迦 vs 近边 vs 独一**：热地狱苦具/寒触卷缩/大那落迦门外四园/身业散处。
- **摩罗天宫 vs 他化自在天**：即他化自在天摄，处所高胜别立。

## 五、阅读提示
对照"八热—八寒—近边—独一"与"四洲—六欲天—色界诸天"两轴读；抓每地狱"得名+苦相+寿量"三要素。
