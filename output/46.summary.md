- **全篇总括**：本卷两品连排。前半（菩提分品之三）详解四条佛法总纲——诸行无常、诸行是苦、诸法无我、涅槃寂静：先双层观察「无常」，再放大到一刹那的生住老灭四相，论证四相并非额外实体，末以王子、病医两喻点破凡圣对涅槃理解的差距。后半（菩萨功德品）是功德总目：四首总颂带出几十组清单——希奇、平等、加行、真伪功德、授记、施设建立、五无量、大乘七性，止于十种菩萨与真假之辨。
  - **上半场·菩提分品之三：四法嗢拖南——把四条总纲讲透**
    - **四法嗢拖南：开卷先立四条总纲**
      - **诸佛菩萨为令有情清净而说四条总纲**：一切诸行皆无常、一切诸行皆是苦、一切诸法皆无我、涅槃寂静
      - **名为「嗢拖南」**（提纲挈领的总颂）有三个理由：所说正是与法相应之义；古来心已寂静的圣者（牟尼）展转宣说；此行迹既能趣向大生，也能趣出第一有（最高的生存处）
    - **观无常：两层观察，把「常」从概念到事实都拆掉**
      - **概念层**：一切行的「言说自性」（用语言安立出来的自性）在一切时都无所有——「常」根本不可得，故名无常
      - **事实层**：离言说的事体（离言自性，超越语言概念的真实自体），因不了知真实、以无知为因，而呈现生灭——所以说离言自性有生有灭
      - **三世对照**：过去行已生已灭（因与自性皆不可得）；现在行已生未灭（自性可得而无因，果已与故）；未来行未生未灭（有因而无自性，犹未生故）
    - **刹那四相：把一刹那放大，看见生住老灭**
      - **每一刹那的诸行都具备三种有为相**，刹那之后复有第四相：前刹那灭坏、后刹那无间生起是「生」；生已暂未坏是「住」；与前面已灭诸行判然有别是「老」；生起之后随即灭坏是「灭」
      - **关键一转**：已生刹那诸行的自性，当下就是生住老的自性——不见「生」等四相另有自性；生刹那之后即此诸行灭坏，也没有别的实体
      - **四相总摄诸行，归结为两分所显**：「有分所显」与「无分所显」；世尊依有分立第一种相、依无分立第二种相，住与异同属有分所显
      - **落点**：一切时唯有诸行可得，除此之外更无生住老灭——诸行是恒有实物的自体，四相只是它的呈现
    - **归谬论证：假如生住老灭是四样额外的东西**
      - **若离诸行别有一个「生」**，这个「生」自己也应有生——于是出现「行生」与「生生」两种生：说二者是一，「别有生」便是废话；说二者是异，诸行又不应由行生生——都不成立；住、老、灭同理
      - **若「灭」别有实体，灭也应有生有灭**：灭生起时一切诸行应同时皆灭（如同入灭尽定，心心所一下全灭）；灭自身灭时诸行又应还生——同样说不通
      - **结论**：把恒时实有的诸行观成假有、却想由此修厌离求解脱，不合理；反过来如实了知诸行无常才是正观
    - **苦、无我、涅槃寂静：后三条总纲各给一句要义**
      - **无常之行相续流转，正是三种苦的所依**：行苦（迁流不息之苦）、坏苦（乐坏之苦）、苦苦（苦上加苦）
      - **二无我**：补特伽罗无我——并非诸法本身是真实的「人」，也非离法之外别有真实的「人」；法无我——一切言说自性的法都无所有
      - **涅槃**：先因永断、后果不生，体性寂静——一切众苦毕竟止息、一切烦恼究竟灭尽；不过未得清净增上意乐的菩萨与未见圣谛的声闻，虽也宣说「涅槃寂静」，却未如实解了——但他们仍有如理作意
    - **王子喻与病医喻：两个故事教人「如实」二字**
      - **王子喻**：幼童长在深宫，玩假造的鹿牛马象车而当成真车；长大后被父王领出宫见真车，才自知先前于「相似影像」起真实胜解，追起羞愧，转依后来的如实胜解
      - **对应**：宫室喻生死；幼童喻未得清净增上意乐的菩萨与未见谛声闻；父喻诸佛及已登地菩萨；假车喻方便宣说的涅槃相，真车喻佛菩萨自现证的真实涅槃
      - **转折在资粮成熟**：此时才于真实涅槃生现证智——此前不过是「随顺音声觉慧」，凭语言对涅槃功德长夜胜解
      - **病医喻**：病人服药病愈，旧病才去新病又起，良医劝舍前药改服新药，病人却执着前药不肯弃——喻凡夫菩萨声闻被烦恼病所执持，闻佛教授教诫不能悟入
      - **反面对照**：净信的菩萨声闻于佛所说无惑——佛的教说如一切支分圆满的庄严车，无上法乘又如善御者，随所行地、随所应到，快速前进、毫不耽搁
  - **下半场·菩萨功德品：菩萨的岗位说明书——四首总颂带出几十组清单**
    - **全品先自问「菩萨有哪些功德」**，以一首总颂列出希奇与不希奇、平等心、饶益、报恩、欣赞、不虚加行诸目；此后另起三首总颂，共成四组，逐题作答
    - **第一组（希奇·平等·饶益·报恩·欣赞·不虚加行）：菩萨凭什么与众不同**
      - **五种甚希奇法（不与一切余有情共）**：无缘而自然亲爱有情；为饶益有情常处生死、忍无量苦；对多烦恼难调伏者善解调伏方便；对极难解的真实义能随悟入；具不可思议大威神力
      - **五种「不希奇法」反成甚希奇**：共同心法是把利他当作自己的乐：以利他之苦为己乐而恒受行；明知生死过失涅槃功德，仍誓受生死；明知默然之乐，仍恒勤说法；虽积六度善根，布施以清净意乐而不求异熟果报；以利他事为自利事
      - **五种平等心**：初发心即为利一切有情；哀愍俱行；视一切有情如独子；知一有情的法性即一切有情的法性，以法平等之心；如于一有情行利益，即于一切有情行利益，以利俱之心
      - **五种饶益与五种报恩**：对众生说授正命、引导随顺义利的事业、为无依怙贫苦者作依怙、说授善趣之道与三乘；对有恩者则令学己德他德、作其依怙、劝供诸佛、令其受持正法
      - **五种欣赞**：于值佛承事、常闻六度菩萨藏法、成熟有情有势力、速证菩提、证觉后弟子无诤这五处常当欣赞
      - **五种不虚饶益加行**：关键在两条——先真实欲求利益安乐有情，再如实了知而无颠倒觉（欲乐真诚加知见无误，加行才不落空），其相如前供养亲近无量品所说
    - **第二组（加行·进退·真伪·调伏）：修行路上的台阶、开关与照妖镜**
      - **五种加行普摄一切无倒加行**（加行：为达成目标所做的实际功夫）：随护加行——护聪睿、正念、正智、自心、他心五处，令已得之法不退失；无罪加行——于诸善法无倒炽然、无量无间回向菩提
      - **后三种加行正好对应阶位**：思择力加行在胜解行地（登地前的凡夫位）；清净增上意乐加行在净胜意乐地与行正行地（见谛登地后的修行位）；堕决定加行在决定地、决定行地、到究竟地
      - **顺退分五法 ↔ 顺胜分五法，一一相翻**：不敬正法与说法师、放逸懈怠、亲近执着烦恼、亲近执着恶行、起增上慢（未得谓得的高慢）——反其道而行即是胜进
      - **五种相似功德实是过失 ↔ 五种真实功德**，五对镜子：对犯戒者作不饶益 ↔ 起胜悲心；诈现威仪 ↔ 本性成就威仪；靠世间文词咒术外道论跻身智者 ↔ 于佛所说教证跻身智者；行有罪之施 ↔ 行无罪之施；宣扬像似正法（貌似正法）使之广流 ↔ 开示正法、遮灭像似正法
      - **十处调伏**：远离恶行、远离诸欲、专精无犯犯已能出、密护根门、正知而住、离愦闹、离恶寻思、离障、离烦恼缠、离烦恼品粗重——由行为表层到习气深处的十个下手处
    - **第三组（受记·堕决定·定作·常作·最胜）：佛的保证书与修行里程碑**
      - **六种授记（佛预先印证菩萨当得菩提）**：就位次分——安住种性未发心位、已发心位、现在前位、不现前位；就方式分——有定时限、无定时限
      - **三种堕于决定（进入不可退转的轨道）**：安住种性堕决定（住种性位，遇胜缘必能证觉）、发菩提心堕决定（起决定心后直至证觉不退）、不虚修行堕决定（已得自在，利他之行终无空过）；佛只依第三种授「堕决定记」
      - **五处定所应作与五处常所应作**：发菩提心、深生哀愍、炽然精进、修习明处（各类知识学科）、无有厌倦——此五处不做终不能成佛；日常则常不放逸、常作依怙、常供如来、常遍知有失无失、一切作意以大菩提心为导首
      - **十种最胜，各于其类中第一**：菩萨种性（诸种性中）、最初发心（诸正愿中）、精进与般若（诸波罗蜜多中）、爱语摄事（诸摄事中）、如来世尊（诸有情中）、悲愍（诸无量中）、第四静虑（诸静虑中）、空三摩地（三等持中）、灭尽等至（诸等至中）、清净方便善巧（诸方便善巧中）
    - **第四组（施设建立·寻思遍知·五无量·说法果·大乘·菩萨位）：佛法的总账本**
      - **四种施设建立**（安立名相、建立体系；唯佛与菩萨能正建立，其余天人沙门婆罗门至多闻而转述）：法施设——佛所说十二分教次第结集、安置、制立；谛施设——从一谛到十谛层层开列；理施设——四道理（如前已详）；乘施设——三乘各以七行相建立
        - **谛的目录学**：一谛唯是「不虚妄义」，二谛分世俗、胜义，四谛即苦集灭道，直至十谛把苦细分为逼切、财位匮乏、界不平和、所爱变坏、粗重五类，再列业、烦恼、闻思、正见、正见果——广说无量
        - **三乘各七行相**：以「慧」为主体，配所依、所缘、伴类、作业、资粮、得果；声闻独觉之慧是对四圣谛的无颠倒慧，大乘之慧是缘离言真如、无分别平等性的出离慧
      - **四寻思与四如实遍知**：为得如实遍知，于一切法起名、事、自性假立、差别假立四种寻思，四种寻思各引出如实遍知（详见真实义品）
      - **五种无量**（对五类对象作无量分类的善巧）：有情界（六十四类）、世界（十方名号差别，如此界名索诃）、法界（善染净诸法差别）、所调伏界（从一到十种分法，略说五十五品）、调伏方便界
        - **两界之别与立项次第**：一切有情不论有种性总名有情界，唯住种性、在彼彼位者才名所调伏界；五量次第即饶益有情的流程——先看有情，再看所处世界，再看染净之法，再筛出堪能解脱者，最后配上方便
      - **说法五大果胜利**：闻法者或远尘离垢生法眼（如实见法的智慧）、或得尽诸漏、或发菩提愿心、或证最胜法忍（于深法忍可不动）、或受持弘传令正法久住
      - **大乘的两个总括**：七大性说明「大」在哪——法大、发心大、胜解大、增上意乐大、资粮大、时大（经三无数大劫）、圆证大，前六为因、圆证为果；八种法则呈递进——菩萨藏教 → 真实义教 → 威力之教 → 如理听闻 → 趣胜意乐 → 入修行 → 修果成满 → 究竟出离
      - **十种菩萨是一条进度条**：住种性 → 已趣入 → 未净意乐/已净意乐 → 未成熟/已成熟 → 未堕决定/已堕决定 → 一生所系（只剩此生，来生即证）/住最后有（正住此生即证）；换挡规则一一衔接，十位之中更能正修学者，其上更无
      - **收尾三笔**：菩萨随德有无量假立名号（菩提萨埵、商主、法师、大福、自在等）；自称是菩萨而能正修行者才是真实菩萨，自称而不正修行的只是相似菩萨
