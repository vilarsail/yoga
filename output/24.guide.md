# 瑜伽师地论卷第二十四 导读

## 一、内容总览
本卷为「初瑜伽处出离地第三之三」，续广辨二道资粮，专明「初夜后夜常勤修习觉寤瑜伽」与「正知而住」二资粮。觉寤瑜伽约昼日初夜后夜经行宴坐从顺障法净修其心、夜中分右胁而卧住光明想正念正知思惟起想巧便而卧；正知而住约往还睹瞻屈伸、持衣钵、食饮啖尝、行住坐卧觉寤语默解劳睡时一切正知。是声闻地行住坐卧二六时中不离正知的细行规范。

## 二、结构层次
全卷按「觉寤瑜伽 → 正知而住」二大段推进：
- **觉寤瑜伽（P1-P37）**：标初夜后夜觉寤瑜伽 → 经行宴坐从顺障法净心（五盖及顺障法）→ 经行时治惛沉睡眠（光明想、念佛等、读诵、冷水洗面等）→ 宴坐时治贪欲（不净观）、嗔恚（慈俱心）、掉举恶作（心内住一趣）、疑（如理思惟三世唯法唯事唯因唯果）→ 由法/自/世三种增上净修其心 → 右胁而卧如师子王 → 住光明想、正念、正知、思惟起想巧便而卧 → 夜后分速疾觉寤 → 略义四种正所作事（不舍善品/以时而卧/无染心睡眠/以时觉寤）。
- **正知而住（P38-P87）**：广辨十种正知——往还、睹瞻、屈伸、持僧伽胝及衣钵、食饮啖尝、行住坐卧、觉寤、语默、解劳睡 → 往施主家行时次第（远离非所行处/不与暴乱恶象等俱行/月喻惭愧/知量受施）→ 住时次第（不应观伎乐妙色/应观衰老死尸等/端严而坐/次第受食/如法经行/结跏宴坐/夜中分寝息）→ 略义（行时五业/住时五业/行住时四业）。
以「广辨 → 略义」为统一骨架，二资粮同构。

## 三、关键结论
1. 觉寤瑜伽：于昼日及初夜后夜经行宴坐从顺障法净修其心，夜中分右胁而卧住光明想正念正知思惟起想巧便而卧，夜后分速疾觉寤。
2. 五盖：贪欲、嗔恚、惛沉睡眠、掉举恶作、疑；顺障法谓净妙相嗔恚相黑闇相等。
3. 经行时专治惛沉睡眠盖，宴坐时治贪欲嗔恚掉举恶作疑四盖，各以不净观、慈俱心、心一趣、如理思惟对治。
4. 右胁而卧如师子王，身无掉乱念无忘失睡不极重不见恶梦；卧时四巧便：住光明想、正念、正知、思惟起想。
5. 正知而住十种：往还、睹瞻、屈伸、持衣钵、食饮啖尝、行住坐卧、觉寤、语默、解劳睡时一切正知。
6. 略义：行时五业（身/眼/支节/衣钵/饮食）、住时五业（身/语/意/昼/夜）、行住时四业（正念不放逸摄、如量如理正知而作）。

## 四、易混辨析
- **经行 vs 宴坐**：经行于广长处若往若来，专治惛沉睡眠盖；宴坐结跏趺坐端身正愿安住背念，治贪欲等四盖。
- **法增上 vs 自增上 vs 世增上**：法增上约如理作意俱行妙慧正知，自增上约自观盖羞耻弃舍，世增上约畏大师诸天同梵行呵责。
- **睹 vs 瞻**：睹谓先无觉慧欲乐眼见众色，瞻谓觉慧功用欲乐为先眼见诸王僚佐等及房舍庄严等。
- **行时五业 vs 住时五业**：行时约往还睹瞻屈伸持衣钵食饮啖尝，分身/眼/支节/衣钵/饮食五业；住时约行住坐卧语默觉寤解劳睡，分身/语/意/昼/夜五业。
- **师子王卧 vs 鬼卧天卧受欲者卧**：师子王右胁而卧勇悍坚猛；余卧懒堕懈怠下劣精进薄弱。

## 五、阅读提示
本卷是声闻地「二六时中细行」规范，可带「五盖对治 → 四巧便卧 → 十种正知 → 行住业」四线索读；经行治惛沉、宴坐治四盖的对应表，与正知而住十种行相最宜对照把握。
