# 瑜伽师地论卷第五十五 导读

## 一、内容总览
本卷为《瑜伽师地论·摄决择分》中「五识身相应地意地」第五，紧接卷五十四决择色蕴之后，转入「名所摄四无色蕴」（受想行识）的决择，并依善、染、无记三性展开心心所相、本随烦恼、四圣谛十六行观与谛现观，末以婆罗门三处谛实之喻收束，对照佛法「谛实」义。

## 二、结构层次
本卷以「总起心心所 → 三性决择 → 圣谛现观 → 喻说收束」一线推进：

- **总起：四无色蕴与心心所相（P1-P20）**
  - 一心相（世俗相续）→ 分别/无分别心同缘现在境 → 染心三因（自性/相应/随眠，自性非染）→ 染恼心法三种（业/受/烦恼）→ 遍行五（作意触受想思）与不遍行五（欲胜解念定慧）→ 各别业用 → 不遍行五所缘四境（所爱决定串习观察）→ 心心法和合而不可分 → 差别名（有所缘/相应/有行/有所依）→ 嗢拖南颂「依处、自性、相应、世俗等、软等事差别、德失能所治」总立下文三性决择六门。

- **善法决择（P21-P32）**
  - 依处六（决定/止息/作业/世净/出世净/摄受众生）→ 自性十一善根（信惭愧无贪无嗔无痴精进轻安不放逸舍不害）→ 相应义 → 世俗有三（不放逸舍不害）实物有余 → 软中上品 → 生起依八事 → 差别 → 功德无量 → 对治十五种（厌患乃至离系）。

- **染法决择（P33-P55）**
  - 先**本烦恼**：六依处 → 六自性（贪嗔无明慢见疑）→ 相应义 → 见世俗有余实物有 → 软中上品（断位反立）→ 各别生事（贪十、嗔十、无明七、慢六、见二、疑六）→ 差别十五种 → 非能对治 → 是彼所治十五种；
  - 后**随烦恼**：九依处 → 二十余自性（忿恨覆恼等）→ 展转相应 → 假实分别 → 软中上品随本烦恼。

- **无记决择（P56-P68）**
  - 异熟生、威仪路、工巧处、变化四自性 → 假有皆世俗 → 软中上品（依界/威仪/串习/定深浅）→ 依十二事 → 差别（异熟五、威仪四、工巧十二、变化八）→ 一向无记与通善染。

- **四圣谛与谛现观（P69-P97）**
  - 五蕴与四谛相摄（灭谛不摄）→ 十六行观（苦四对治四颠倒、集四依四爱、灭四道四）→ 苦三分类（苦苦/坏苦/行苦配八苦）→ 四种苦配十六行 → 空/无愿/无相三三昧配十六行 → 圣谛次第（喻重病病因病愈良药）→ 谛义 → 胜义谛摄 → 谛现观六种（思/信/戒/现观智谛现观/现观边智谛现观/究竟现观），明世间道不能永害随眠。

- **喻说收束（P98-P111）**
  - 三种姓婆罗门三处（养命/修福/安立果）↔ 三过失（语言/憍慢/胜解） ↔ 第一义婆罗门三处（不害一切生/一切行无常/一切法无我）离三过失；唯有如来是真觉者。

## 三、关键结论
1. 心性本净：染污由相应与随眠，非自性染；若自性染应如贪等毕竟不净。
2. 三性法皆依「依处→自性→相应→世俗有/实物有→软中上品」五门决择；世俗有者皆是本善或本烦恼分位假立（如不放逸是精进无贪等分，见是慧分）。
3. 烦恼生处皆依无明与不如理作意；对治十五种从厌患到离系，世间道不能永害随眠，唯出世道能究竟。
4. 四圣谛为胜义谛摄，由共相一味苦建立；十六行观配三解脱门（空、无愿、无相）与道谛清净因。
5. 谛现观六种由浅入深，见道三心缘非安立谛，断见断；后得智缘安立谛，令所断不复起；究竟现观永断修所断，生尽智无生智。

## 四、易混辨析
- **本烦恼 vs 随烦恼**：本烦恼六（贪嗔无明慢见疑）是根本；随烦恼二十余种（忿恨覆恼等）是本烦恼分位差别，多分假有（忿等是嗔分，悭憍掉举是贪分，覆诳等是痴分）。
- **世俗有 vs 实物有**：世俗有指由他法分位假立无别自体（如不放逸、舍、不害、见、忿等）；实物有指有别心所性自体（如无惭无愧、不信懈怠、本烦恼五）。
- **苦苦 vs 坏苦 vs 行苦**：苦苦由不可爱行相（生老病死等正苦受位）；坏苦由变坏增上所起忧恼（可爱境坏时）；行苦由不安隐行相（众缘生无常苦相所摄诸行，圣者现观为苦之主体）。
- **安立谛 vs 非安立谛**：安立谛是依自相差别施设之苦集灭道名义；非安立谛是离言一味苦共相真如，为见道根本无分别智所缘，唯缘非安立谛。
- **现观智谛现观 vs 现观边智谛现观**：前者是根本无分别智，断见道所断随眠；后者是后得智，是有分别，思惟所缘令所断不复起，能进趣世出世断道。

## 五、阅读提示
读时可带着两个问题切入：(1) 何以「心性本净」而又说有染心？关键是「相应故随眠故，非自性故」。(2) 善/染/无记三性如何统一在「依处—自性—相应—假实—软中上品」五门框架中展开？把握此五门与嗢拖南六义，全卷脉络自现。
