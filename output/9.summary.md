- **全篇总括**：本卷继续解剖「业」，并把话题推进到「生」：先用五种果报出口（业门）、六种加码条件（业增上）、三种错乱形态（业颠倒）、一张分类总表（业差别）和七笔代价账（业过患）把业讲完；后半进入生杂染，用佛的两笔账显示轮回之久与广，最后端出十二缘起的完整图纸——今生如何承接前世、注定来世，又如何从无明与爱处拆起，经有余依涅槃走到无余依涅槃。
  - **业门：业的果报从哪些出口兑现**
    - 承接前卷十业道的说明，接着问业的「出口」：分两扇门——与果门（业给出什么果）与损益门（业对众生与世界是损是益）
    - **与果门：五种兑现方式**，一套公式各配一类果报
      - **与异熟果**（来世换一个生命整体去受的果）：杀生等不善业亲近修习、多修习，来世堕地狱受报；其余不善业道同理
      - **与等流果**（与因同类相续的果）：从地狱出来生回人间，还带着同款余殃——寿短、贫穷、妻不贞良、多遭诽谤、亲友乖离、闻违意声、言语无威、贪嗔痴更猛
      - **与增上果**（依托的外部环境之果）：业力连环境都改——外物光泽鲜少、果实朽败零落不甘美乃至空无果实；善业则一切与此相反
        - **与现法果**（今生就报的果）：要拨动两个开关——欲解（把某种心态推到极点的强烈倾向）或事（对象本身重大）
          - **欲解八种、四正四邪两两相对**：顾恋身财 ↔ 不顾身财、损恼 ↔ 慈悲、憎害三宝 ↔ 净信三宝、背恩欺诳 ↔ 知恩报恩——任一端做到「增上」程度，今生即报
          - **由「事」重的恶业是五无间业**：（害母、害父、害阿罗汉、破僧、恶心出佛身血）及同类行为——于母或罗汉尼行秽染行、打最后有菩萨、立杀羊法流行不绝、欺诳极受倚重的亲友、加害曾受自己庇护的贫苦者、劫夺僧门破坏灵庙；善业则是劝母亲安住信戒舍慧（父亦然）、供养起慈定者乃至预流果阿罗汉与佛及学无学僧——在同样的尊重事上反行损害，善即翻成恶业现报
      - **与他增上果**（他人的福德让众生沾光）：佛所住国邑必无疾疫灾横；转轮圣王、住慈定菩萨，以及以大悲施饮食财谷、令贫苦众生得安乐的菩萨，都是这种「他增上」的现法受业
    - **损益门：八损八益**
      - **依十不善业道立八扇损害门**：（损众生、损财物、损妻妾、虚伪友证、损助伴、显说过失、引发放逸、引发怖畏）；依十善业道立相反的八扇利益门
  - **业增上：什么业最重**
    - **讲完出口接着讲重量**：猛利极重之业由六种相构成，善业恶业通用
      - **加行**：以极猛利的贪嗔痴（善业则是无贪无嗔无痴）发起
      - **串习**：长夜中一次又一次反复修习
      - **自性**：业道之间有轻重阶梯——绮语之上粗恶语更重、离间语又重、妄语最重；欲邪行之上不与取更重、杀生又重；嗔恚之上邪见更重；施戒修之间戒胜于施、修胜于戒、思胜于闻
      - **事**：对象是佛法僧等尊重处，为损为益都成重业
      - **所治一类与所治损害**：一向作恶、至寿终无一时善是一端，断尽不善、善业离欲清净是另一端
  - **业颠倒：三种把业算错账的方式**
    - **接着看业的异常形态**：业道现前而心行错乱，价值判定整个变形，共三种
      - **作用颠倒**：想杀甲误杀乙，或对无情物加刀杖自以为杀了生——都不成完整杀业，但生「杀生同类分」之罪；其余业道照此类推
      - **执受颠倒**：持邪见者认定无施无爱、无能杀所杀、无罪无福，更极端者认为杀害所憎的梵行者、天、婆罗门反而唯福无罪——见地一错，业的账本整个错乱
      - **喜乐颠倒**：造不善业时如玩游戏般欢喜尽兴——心态本身就把业加重
  - **业差别：一张完整的分类总表**
    - 本节不提新命题，而是把业按十几个并列的分类轴成组列出，像一份总账科目表
    - **发动维度：做没做、想没想**
      - 作业（思已发动身业语业）↔ 不作业；故思业（存心构思后所做）↔ 不故思业；顺定受（故思且增长，决定受报）↔ 顺不定受（故思作而不增长，受报不定）
      - **增长与否**：十种业不算增长——梦中所作、无知所作、无故思、不利不数、狂乱、失念、非乐欲、自性无记、悔所损、对治所损；除这十种，其余都是增长业
    - **性质与戒律归属**
      - 善业以无贪无嗔无痴为因缘，不善业以贪嗔痴为因缘，无记业两者都不是
      - **律仪所摄业有三种来源**：别解脱律仪（受戒所得的防非止恶）、静虑等至中果断恶的律仪、无漏律仪；不律仪所摄业是十二种以恶为业的行当（屠羊、贩鸡贩猪、捕鸟、罝兔、盗贼、魁脍、守狱、谗刺、断狱、缚象、咒龙）；两者之外是「非律仪非不律仪」业
    - **施戒修：三种福业的四件套**
      - 都用「因缘、等起（引发行为的动机思）、依处、自性」定义——施以所施物与受者为依处、思所起的舍物身语业为自性，戒的自性是律仪身语业，修的自性就是三摩地（定）、依处是十方无苦无乐等有情界
    - **感果维度**
      - 福业感善趣、非福业感恶趣、不动业感色无色界；顺乐受业是福业及初二三禅不动业，顺苦受业是非福业，顺不苦不乐受业是能感一切处阿赖耶识（贯穿三界、执受身命的根本异熟识）异熟之业及四禅以上不动业
      - **受报时间**：顺现法受（今生）、顺生受（下一生）、顺后受（更后）；过去业住习气位（或已与果或未与果），未来业未生未灭，现在业已造已思未谢灭
      - **界地与圣位**：欲系/色系/无色系业；学、无学、非学非无学业；见所断业（招感恶趣的不善业）、修所断业（招感善趣诸业）、无断业（世出世无漏业）
    - **价值判定**
      - **四色账本**：黑黑异熟业（非福业）、白白异熟业（不动业）、黑白夹杂异熟业（未断非福时的福业）、非黑非白无异熟业（出世无漏业，是前三业的断对治、能尽诸业）
      - **曲、秽、浊与清净、寂静**：外道之业因邪解名曲，依曲障功德名秽，障通达真如名浊；佛弟子中正决定、不犹预者的善业名清净，圣者的学无学业名寂静
  - **业过患：以杀生为例算七笔代价**
    - **分类讲完接着算害处**：以杀生为因，略说七种过患
      - **自害/他害/俱害**：造业的方便可能只反害自己（被系缚、退失、诃毁）而伤不到对方，可能只害他人，可能两边俱损；并与现法罪/后法罪/现后法罪一一对应
      - **身心忧苦**：即便杀事没办成、该成的过失没成，所欲不成的因缘本身也生忧苦
    - **附加条款**：犯戒另有十种过患；四种不善业道加饮酒为第五，犯在家人学处，佛说多过患（广说如阐地迦经）
  - **生杂染：换到「投生」这个大题**
    - **业与果讲尽，转到果报那一端问**：「生」有什么毛病？四种观察角度——差别、艰辛、不定、流转
    - **生差别：给「生」做的抽样**
      - 界差别（三界）、趣差别（五趣四生）是粗框架；处所差别是细目录——欲界三十六处、色界十八处、无色界四处，共五十八种生
      - **胜生差别讲生处高下**：人间三种——生旃荼罗等下贱家为「黑」、生刹帝利婆罗门大富贵家为「白」、处中为「非黑非白」；欲界天、色界、无色界又各分三种
      - **自身世间差别**：十方无量世界还有无量有情生差别——框架本身是开放的
    - **生艰辛：佛算的第一笔账——轮回成本**
      - **长夜驰骋生死**，生为象马牛羊鸡鹿等被斫截支分，身血流注超过四大海；人间的遭遇亦然
      - 长夜丧失父母亲属的泪水、生生世世饮下的母乳，其量都与那血相等
    - **生不定：佛算的第二笔账——轮回规模**
      - **把大地草木截成四指小签**，数生生世世的父母——互为父母、互相偿还——小签先数尽，父母却数不到边际
      - 大地上找不出一寸未曾经历生死之处；一个众生一劫所受身骨若堆起来，高如王舍城侧的广博胁山
    - **生流转**：生的来龙去脉——引出全卷重头戏十二缘起
  - **生流转：十二缘起——轮回与熄火的完整图纸**
    - **先以总纲颂立目录**：体、门、义、差别、次第、难、释词、缘性、分别缘、摄诸经；本卷讲到体、门、义、差别与分别缘开头。缘起体以三相建立：从前际中际生（前世→今生）、从中际后际生（今生→来世）、中际生已或趣流转或趣清净（今生是分岔口）——下面三条线对应三相
    - **流转线一：从前际到中际——今生是怎么来的**
      - **流程**：不了前际的无明（对因缘事实的根本无知）为缘 → 造福、非福、不动业（作且增长）→ 随业识（携带业种、随业受生的识）流转至命终 → 将生果时内外贪爱现前作助伴 → 舍命投生
      - **在母腹中**：以因识为缘，相续果识前后次第生起，经羯罗蓝等胚胎位次；果识与名色（名是精神部分、色是身体）俱转，乃至衰老——感生受业至此已与异熟果
      - **识与名色互相撑住**：色是俱有依根、名是等无间灭依根（前念识灭去、为后识让位之处）；由识执受诸根，诸根才得以相续流转——「识缘名色、名色缘识，犹如束芦」（两捆芦苇相倚而立）
      - **按出生方式补充分支**：以上以胎生为例；卵湿生略去母胎一段；欲色界的化生诸根圆满顿然而生；无色界以名及色种子为依；又福业生欲界人天、非福业生恶趣、不动业生色无色界
    - **流转线二：从中际到后际——今生怎么注定来生**
      - **已生者先受两种前业之果**：内异熟果（果报身）与境界所生受（外境引发的受）；对二果愚昧无知，便再造新业——此识名随业识，是能摄受后生果识的因识
      - **由新作业**，识携名色、六处、触、受的种子层层相随，总名「后有引因」——能引出下一期的识乃至受
      - **再由境界受果愚生爱**：爱发为欲求、有求，执为欲取、见戒取、我语取；爱取和合资润，引因转名为「有」——命终后识等次第生、受为最后，生与老死随之
      - **归结**：现法中以无明触所生受为缘生爱，爱缘取、取缘有、有缘生、生缘老病死苦——中际里「无明缘行」与「受缘爱」两段链条接力，后际诸行由此而生
    - **清净线：中际的分岔——怎么让发动机熄火**
      - **与流转线并行的另一条路**：先集资粮、从他闻音，对二果的因、灭、趣灭如理作意 → 正见生 → 次第得学无学清净智见 → 无明与爱永断无余
      - **断的连锁**：无明断则无明触所生受断 → 现证慧解脱；与受相应心中的贪爱离系永灭 → 心解脱
      - **反向拆除**：无明灭故更不复起、得无生法——「无明灭故行灭」，次第乃至异熟生触灭故受灭、爱灭，取等诸行永灭
      - **两站结果**：先于有余依界证现法涅槃（唯余清净识缘名色，恒受离系受，身随先业寿量相续住）；寿尽舍身，识与诸受任运灭尽不复相续——无余依涅槃界，究竟寂静处，梵行已立
    - **缘起门与缘起义：原理的现场与内核**
      - **缘起门**：内识生、外稼成熟、有情世间死生、器世间成坏、食任持、自业增上受爱非爱果、威势、清净——缘起原理不止管轮回，识的生起、庄稼成熟、世界成坏都是它的现场
      - **缘起义**：八层递进拆掉「我」——离有情（没有实体的作者）→ 无常 → 暂住 → 依他（依缘而立）→ 离作用（没有主宰的施为）→ 因果相续不断 → 因果相似转 → 自业所作
      - **建立缘起为显何义**？为显「因缘所摄的染污与清净」——同一套机制，既是轮回的原因，也是解脱的通道
    - **缘起差别与分别缘：无明的地图与诸支的实体**
      - **缘起差别先开列十九种无知**：对前际/后际/前后际的分别（我过去有没有？未来有没有？从哪来往哪去？）、于内执我、于外执我所、于他分怨亲、于业执有作者、于异熟执有受者、于佛法僧、于苦集灭道、于因（计无因或自在天等不平等因）、于从因所生诸行，最后是增上慢者（未证谓证）对六触处如实通达的无知
      - **十九种收敛为七无知**：（世愚、事愚、移转愚、最胜愚、真实愚、染净愚、增上慢愚），再收敛为五愚（义愚通摄一切、见愚、放逸愚、真实义愚、增上慢愚），最后是无明的六种差别名（无知、无见、无有现观、黑闇、愚痴、无明闇）——前三种按闻思修三慧分别所治，后三种按所治的软中上品分
      - **分别缘给每一支下定义**。三行支：身行是身业、语行是语业、意行是意业——欲界名福非福业，上二界名不动业；识支：眼识等六识是被福非福不动行熏发的种子识及其所生果识——欲界具六、色界唯四、无色界唯一
      - **名色支**：受是领纳、想是了像、行是心所造作意业、识是了别，四蕴通三界；色即四大种（地水火风）与所造色（十色处及法处所摄色）——欲界具十、色界有八；各有种子名色与果名色两种
      - **六处支**：眼处是眼识所依的净色（净色根），各处有已见、现见、当见等三时业用；前五处在欲色二界，意处通三界
      - **触支与受支**：触是三和（根境识会合）所生，能取境界净妙等义——欲界具六、色界四、无色界一；乐受是顺乐境所生的适悦受、苦受相反、不苦不乐受两者皆非——欲界三受俱全，色界二受，第四静虑以上直至非想非非想处唯有不苦不乐受
