# 瑜伽师地论卷第三 导读

## 一、内容总览
本卷为意地第二之三，承前两卷展开意地。以"五事由三处所摄"为纲，将一切法归入色聚、心心所品、无为三类，先广明色聚，再述心心所品，末以善巧、诸佛语言九事收束，为由意地过渡到有寻有伺等三地的桥梁。

## 二、结构层次
按"总标三处 → 色聚 → 心心所品 → 法相枚举 → 名相收束"五段推进：
- **总标（P1）**：五事由色聚、心心所品、无为三处所摄。
- **色聚（P2-P11）**：大种望所造色五作用 → 极微假立与方分 → 不相离二种 → 十四种事 → 三种流转（长养/等流/异熟生）。
- **心心所品（P12-P25）**：五十三心所五类配列 → 识生三因 → 作意四因 → 五识随意识转与率尔堕心 → 遍行别境体业用 → 三世四相四缘。
- **法相枚举（P26-P47）**：三性广辨 → 六根五境法界八十七法各1-11种建立。
- **名相收束（P48-P56）**：释根境得名 → 嗢拖南重颂 → 善巧摄 → 诸佛语言九事。
前半讲理，后半列相。

## 三、关键结论
1. 一切法由色聚、心心所品、无为三处所摄；大种望所造色有生依建立任持长养五作用。
2. 极微非实有，乃觉慧分析极量边际假立，极微即是分。
3. 遍行五（作意触受想思）遍一切处地时；别境五（欲胜解念三摩地慧）非一切时。
4. 识生须根不坏、境界现前、能生作意正起；五识随意识转。
5. 四缘：因缘种子、等无间缘无间引后、所缘缘所缘境、增上缘所依助伴。

## 四、易混辨析
- **同处不相离 vs 和杂不相离**：前者同处共存，后者杂处而住。
- **长养 vs 等流 vs 异熟生**：增广/相似相续/异熟因生。
- **因缘 vs 等无间缘 vs 所缘缘 vs 增上缘**：种子/引后/所缘境/所依助伴。

## 五、阅读提示
带"色法构成、心法生起、法相分类"三线索读；枚举段抓分类原则即可。
