# 瑜伽师地论卷第七十五 导读

## 一、内容总览
本卷为《瑜伽师地论·摄决择分》中「菩萨地之四」，承前诸卷继续决择菩萨行。前半论菩萨三聚戒之细相、六波罗蜜多之功德与清净、四念住与相粗重缚、想缚对治，并破恶取空；后半广引《解深密经》明胜义谛五相。全卷由「戒度事相」之「行布」层层升进至「胜义理观」之「谛相」，事理交贯，是菩萨地从行门趣理门之枢纽。

## 二、结构层次
全文按「戒 → 度 → 观 → 谛」四阶推进：
- **菩萨毗奈耶三聚（P1-P25）**：先标三聚（律仪、摄善法、利益有情）→ 摄善法戒中辨「六心」罪福（前三心一向有罪、病随行心一向无罪、余二通罪福）→ 利益有情戒中辨「六处」（自他 × 财法盛衰）当为不应为 → 舍戒四缘与出家菩萨施三衣外长物、叶纸之细行 → 收束「三种戒蕴皆得圆满」。
- **六波罗蜜多功德与清净（P26-P44）**：先总标施等「五德」（无著、无恋、无罪、无分别、回向）方名到彼岸 → 别明施有「十随烦恼」对治「十清净」→ 戒十清净（意乐清净 + 加行五种）→ 忍二清净（思择力、修习力）→ 精进十清净 → 静虑十清净 → 慧五清净。由施至慧逐度列清净数，呈递进式枚举。
- **念住与缚（P45-P59）**：菩萨于身住循身观（即于相身观真如身）→ 七觉支修道次第（念住→正断→神足→根力→觉支→道支→菩提）→ 十四种相粗重缚 → 六种想缚与十一种后后想缚，菩萨依空修念住令心解脱 → 破恶取空（驳「世俗有、胜义无」之自相矛盾）。
- **大乘起因缘与胜义谛（P60-P129）**：先标大乘经起说五相、十二处十种无颠倒道（六自相、四共相）、八殊胜 → 次总举胜义谛五相 → 详引《解深密经》四段长行+偈颂：无二相（幻师喻）→ 超过寻思相（法涌菩萨事，蜜味等喻）→ 超过一异性相（善清净慧菩萨事，螺贝色性等喻）→ 遍一切一味相（善现事，虚空喻）。每段皆「问答 → 譬喻 → 颂结」三重收束。

## 三、关键结论
- 菩萨三聚戒以律仪戒为根本持，律仪毁即毁一切菩萨律仪；摄善法戒中「前三心（轻蔑、懈怠、覆蔽）一向有罪，病随行心一向无罪」，勤劳倦、障随行二心通罪福，须观义利有无而判。
- 六度皆须具五德（无著、无恋、无罪、无分别、回向）方名到彼岸，各度复有别清净数；施度由内外十随烦恼对治得十清净，忍度前九思择力、第十修习力。
- 相缚与粗重缚并称二缚，见谛者于二缚皆得解脱；菩萨依空修念住，先破六种想缚，再破十一种后后想缚，方得一切想缚解脱。
- 恶取空者执「胜义一切皆无」自相矛盾：世俗若从因有则非有，若唯名言则无事而有，二俱不应理；颠倒事有则胜义非全无，无则世俗无性亦不应理。
- 胜义谛五相——离名言、无二、超寻思、超一异、遍一切一味——层层递进；以幻师喻显无二，蜜味等喻显超寻思，螺贝色性喻显非一非异，虚空喻显遍一味。

## 四、易混辨析
- **财衰/财盛 vs 法衰/法盛**：财指衣食等外物，法指所学、闻思修证；菩萨作自法衰令他财盛不应为，作自财衰令他财盛则视是否引法衰而定，引法衰者不应为。
- **思择力清净 vs 修习力清净**：忍度十清净中前九属思择力（数数思择对治不忍因缘），第十属修习力（现观实证对治，究竟清净）。
- **相缚 vs 粗重缚**：相缚约境相执实，粗重缚约烦恼种子之粗重；二者并称二缚，见谛者于二缚皆得脱，方能证涅槃菩提。
- **六种想缚 vs 十一种后后想缚**：六种约「内/外/内外/愿他解脱/循观能观/循观所观」立；十一种约「杂染清净第一义、造作无造作、常/流转/无变异、苦性、自相、染净一切法、我无染净、无自性」层层展转立，后者更深细。

## 五、阅读提示
读本卷可抓住「戒→度→观→谛」主线：前段菩萨戒判罪福之微细，可对照菩萨戒本；中段六度清净数与《菩萨地》戒品相参；后段胜义谛五相对应《解深密经·胜义谛相品》，长行与偈颂互文，宜合观譬喻与法说。
