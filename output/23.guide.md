# 瑜伽师地论卷第二十三 导读

## 一、内容总览
本卷为「初瑜伽处出离地第三之二」，续广辨二道资粮，专明「根律仪」与「于食知量」二资粮。根律仪约能防护、所防护、从防护、如何防护、正防护五门分别，明六根对六境不取相不取随好以断杂染；于食知量以正思择观察段食三过患，远离倡荡憍逸饰好端严，为身安住为摄梵行而食。是声闻地对治根境与饮食二大欲漏的根本行法。

## 二、结构层次
全卷按「根律仪 → 于食知量」二大段推进：
- **根律仪（P1-P22）**：广辨密护根门、防守正念、常委正念、念防护意、行平等位 → 不取相不取随好二相 → 略义五门（能防护/所防护/从防护/如何防护/正防护）→ 复略义三门（防护方便/所防护事/正防护）→ 思择力所摄与修习力所摄二种根律仪差别（一伏缠不拔随眠、一缠随眠俱断）。
- **于食知量（P23-P68）**：正思择食 → 段食三过患（受用种类/变异种类/追求种类，追求复开积集/防护/坏亲爱/无厌足/不自在/恶行六过患）→ 少胜利 → 如子肉想食 → 月喻往施主家 → 四种食（段/触/思/识，今义唯段食）→ 不为倡荡不为憍逸饰好端严 → 为身安住为暂支持（有艰难/无艰难存养）→ 为除饥渴为摄梵行为断故受为令新受不生为存养力乐无罪安隐 → 略义（所食/如是食）→ 摄受对治/离欲乐行边/离自苦行边/摄受梵行四义 → 平等食与不平等食五种差别。
以「广辨 → 略义」为统一骨架，二资粮同构。

## 三、关键结论
1. 根律仪略义五门：能防护谓防守正念及常委正念、所防护谓六根、从防护谓可爱不可爱色等、如何防护谓不取相不取随好修律仪、正防护谓由正念防护于意行平等位。
2. 取相谓眼识取所行相，取随好谓分别意识执取境相起贪嗔痴；远离此二名不取相不取随好。
3. 思择力所摄根律仪唯伏缠不拔随眠、属资粮道；修习力所摄根律仪缠与随眠俱断、属离欲地。
4. 段食三过患：受用种类（食时变秽相）、变异种类（消变生血肉便秽及诸病）、追求种类（积集/防护/坏亲爱/无厌足/不自在/恶行六种）。
5. 平等食五种：非极少非极多非不宜非不消非染污；不平等食即反是。
6. 食所为止：都无所食、不平等食；食所为：为身安住为暂支持、为除饥渴为摄梵行为断故受为新受不生为存养力乐无罪安隐。

## 四、易混辨析
- **取相 vs 取随好**：取相约眼识取所行境相，取随好约分别意识执取起贪嗔痴；又余类取相约色在可见处眼见众色，取随好约先闻名句文身后随所闻分别。
- **思择力所摄 vs 修习力所摄**：前者于境界深见过患而不能除遣过患、唯伏缠；后者亦能除遣过患、缠与随眠俱永拔，分属资粮道与离欲地。
- **善舍 vs 无记舍**：平等位有二——善舍与无记舍，由念防护意行此二舍中。
- **受用种类过患 vs 变异种类过患 vs 追求种类过患**：受用约食时变秽相、变异约消变生身病、追求约求食时六种所作过患。
- **有艰难存养 vs 无艰难存养**：前者增饥羸困苦重病、令身沉重心迟钝、有罪有染；后者无饥羸、身堪能心速定、无罪无染。

## 五、阅读提示
本卷是声闻地「根境与饮食对治」，可带「能所防护 → 取相随好 → 二力差别」与「三过患 → 六所为 → 平等不平等食」两组线索读；思择力与修习力差别是判道位的关键，最宜对照把握。
