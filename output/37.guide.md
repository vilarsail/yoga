# 瑜伽师地论卷第三十七 导读

## 一、内容总览
卷第三十七属《本地分·菩萨地·初持瑜伽处》，含两品：**威力品第五**与**成熟品第六**。威力品系统阐释佛菩萨三类（圣/法/俱生）或五品类（神通/法/俱生/共/不共）威力，详述六神通、六度法威力、如来本生俱生威力及与二乘共不共之相；成熟品则讲菩萨如何以二十七种方便成熟自他，配六地菩萨、四种姓有情，建立下中上三品成熟差别。两品前后相承：先明菩萨利他之"能"（威力），后明利他之"所作"（成熟有情）。

## 二、结构层次
全文以「威力 → 成熟」二品一线贯穿，每品再以"总—分—结"层层展开：

**威力品**
- 总起 → 以"云何诸佛菩萨威力"双开三种（圣/法/俱生）与五种品类（神通/法/俱生/共/不共）→ 二者是开合关系，并非另立。
- 神通威力（重头）→ 六神通并列：神境智通（最详，能变十八变 + 能化身/境/语三事）↔ 随念宿住 → 天耳 → 见死生 → 知心差别 → 漏尽，逐通皆"自相 + 作业"。
- 法威力 → 六度各开四相（断所对治 / 资粮成熟 / 饶益自他 / 与当来果），整齐对应、收束于般若。
- 俱生威力 → 三类：本生堪忍 + 见便饶益 + 贤圣行住，归于如来无量希有。
- 共不共 → 三相分别（微细 / 品类 / 界）↔ 声闻但以二千世界、独觉但以三千世界为神通境之局限。
- 收束 → 三种神变（神境 / 记说 / 教诫）摄入三种神通，将前文归摄。

**成熟品**
- 总标六种 → "云何成熟，略有六种"。
- 自性 → 所成熟 → 差别 → 方便 → 能成熟 → 已成熟相，由体到用、由所化到能化、由差别到相貌，层层推进。
- 二十七方便从"界增长"到"俱成熟"，是全文最长枚举，可归为财法摄受、神通引摄、说法、加行等类。
- 收束 → 三品（下/中/上）× 三乘，配三无数劫，开为下下至上上九品差别。

## 三、关键结论
- 佛菩萨威力可摄为三种或五种品类；神通威力复开为六神通，神境智通又分能变十八变与能化三种（身/境/语）。
- 六神通中**漏尽智通最为殊胜**：菩萨虽如实了知漏尽方便而不作证，于有漏事不染而住。
- 法威力即六度，每度皆具四相（断所对治 / 资粮成熟 / 饶益自他 / 与当来果），显示大乘自他两利。
- 威力与声闻独觉有共不共，由"微细、品类、界"三相显不共：佛菩萨以一切世界、一切有情界为境，声闻但以二千、独觉但以三千为境。
- 成熟品以二十七种方便成熟四种姓补特伽罗，配六地菩萨；菩萨依三无数劫圆满下中上三品成熟，九品差别展转无量。

## 四、易混辨析
- **三种威力 vs 五种品类**：三种约体性分（圣/法/俱生），五种约作用分（神通/法/俱生/共/不共）；"法威力""俱生威力"二名两处并见，开合不同，不可混为一谈。
- **能变神境智通 vs 能化神境智通**：能变是转有自性物令成余物（十八变：振动、炽然等）；能化是无事而有（化身为境为语），"变"改旧物，"化"从无造。
- **共威力 vs 不共威力**：粗相与二乘共；不共由微细（无量利益事皆知皆作）、品类（三威力皆成就）、界（以一切世界为境）三相显发。
- **成熟自性 vs 成熟差别 vs 成熟方便**：自性是体（善法种子数习所得堪任性，喻如痈熟/器熟/果熟），差别是相（诸根/善根/智慧/下中上六种），方便是用（二十七法）。

## 五、阅读提示
- 先记"三开五 / 六神通 / 六度四相"的整齐框架，再填具体内容，便不会迷失于枚举。
- 神境智通篇幅最长，分"能变十八变"与"能化三事"两块记，十八变可按身/境/他/物分组。
- 二十七方便不必逐条强记，留意其归类（摄受、说法、加行、神通引摄等）与下中上三品的对应即可。
