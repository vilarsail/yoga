- **全篇总括**：本卷借《解深密经》三场问答层层深入：广慧菩萨问心识底细——六识之下还有一个收藏一切种子的根本识；德本菩萨问现象怎么拆——一切法分标签、条件现象、真实三面；胜义生菩萨问佛说「一切法皆无自性」的密意——佛用三种无自性性作解，再以三时判教把这套说法定位为最了义的「胜义了义之教」。
  - **心意识相：前台六识背后还有什么（广慧菩萨之问）**
    - **提问**：怎样才算真正通达心识秘密（「于心意识秘密善巧」）的菩萨？佛分两步回答：先讲心识的实际结构，再给「善巧」的验收标准
    - **一切种子心识：生命最底层的第一个住户**
      - **六道众生**：无论卵生、胎生、湿生、化生，身分生起时最先成熟的是「一切种子心识」（含藏一切种子、与生命一同发育的根本识）
      - 它「展转和合、增长广大」（与身分互相配合长大），靠两种执受（执持摄受）撑住生命：一是有色诸根及所依执受（摄持身体根身），二是相名分别言说戏论习气执受（摄持概念言说的习气种子）；有色界两种齐全，无色界两种都不具足
    - **三个名字：同一个识的三份职责**
      - **名阿陀那识**（随逐执持的持身识）：它一直跟随身体、执持不弃
      - **名阿赖耶识**（摄受藏隐、与身同安危的藏识）：它藏于身中、同安共危
      - **名为心**（积集滋长的识）：色声香味触等的种子在这里积集滋长
    - **六识怎么生起：一条统一公式**
      - **阿陀那识是六识生起的依止与建立**：底层识不打地基，前台的六个感官识转不起来
      - **公式**：根与境为缘生识，同时有一个「有分别意识」（能起分别的意识）与之俱起、同境同行——眼与色为缘生眼识即如此；一识活动时一个意识同行，二三四五识齐动时仍只有一个意识与它们同所行转（耳鼻舌身识全部照此套用）——多个频道，一块屏幕
    - **暴流与明镜：底层恒流，前台起灭**
      - **暴流喻**：一个生缘现前只起一浪，多缘现前多浪齐转，而水流自类恒流不断——六识随缘起灭，底层识川流不息
      - **明镜喻**：一影生缘一影起，多影生缘多影起，但镜面并不转变为影像——底层识不变质、不损耗
    - **善巧的标准：从「知道」到「不见」**
      - 只凭法住智（依教理认识诸法安立相的智慧）理解心意识，如来尚不据此施设（认定）他为「一切秘密善巧菩萨」
      - **验收标准是「如实不见」**：不见阿陀那识、阿赖耶识，不见积集（心），不见眼色眼识乃至意法意识——不再把心识及其对象实化为有，才是胜义善巧菩萨；偈点破风险：此识甚深细、种子如暴流，「恐彼分别执为我」——怕凡夫把它错当成「我」
  - **三种法相：一切现象该怎么拆（德本菩萨之问）**
    - 讲完心识结构，接着拆一切现象。德本菩萨问：怎样才算「于诸法相善巧」的菩萨？佛总答：诸法相略有三种——遍计所执相、依他起相、圆成实相，再用两个比喻讲透三者关系
    - **三相定义：标签、条件、真实**
      - **遍计所执相**（遍遍计较、执以为实的假相）：一切法上由「名」假安立的自性与差别——为随起言说而贴上去的标签世界
      - **依他起相**（依条件而起的现象）：一切法缘生自性——「此有故彼有，此生故彼生」，从无明缘行一直推到招集纯大苦蕴
      - **圆成实相**（圆满成就的真实）：一切法平等真如（平等不变的本性）；菩萨以勇猛精进为因，如理作意、无倒思惟方能通达，再渐渐修集，直到无上菩提才证得圆满
    - **病眼喻：一只眼睛讲清三相**
      - **眼中眩翳（白翳眼病）的过患本身** = 遍计所执相——病把假相当真实
      - **病眼所见毛发、蜂蝇、青黄赤白等乱相** = 依他起相——确实是病中依缘现起的现象
      - **净眼人除病后无乱的本性所见** = 圆成实相——去除歪曲后的如实
    - **颇胝迦喻：一颗水晶讲清三相关系**
      - **清净颇胝迦宝（透明水晶）本身** = 依他起相
      - 与青染色合则似帝青大青宝、与赤合似琥珀、与绿合似末罗羯多宝、与黄合似金——染色 = 依他起上的言说习气，有情邪执「这就是真宝」而被惑乱（染色与邪执 = 遍计所执的习气与执著）
      - **那些宝色**：「于常常时、于恒恒时」无有真实、无自性性——这个无自性性即圆成实相
    - **三相各有一把观察钥匙**：以「相名相应」（名与相挂钩）为缘 → 了知遍计所执相；以「依他起上执遍计所执」为缘 → 了知依他起相；以「依他起上不执遍计所执」为缘 → 了知圆成实相——执与无执分别照见染净两端
    - **知三相的因果链与结偈**
      - **了知三相的收益是一条因果链**：了知无相之法 → 断灭一切杂染相法 → 证得一切清净相法；齐此施设「于诸法相善巧菩萨」
      - **偈重申**：不了知无相法，杂染不能断；不断杂染，便坏失微妙清净法的证得；不观察诸行过失、放逸懈怠，最为可愍
  - **三种无自性性：佛说「一切法皆无自性」到底指什么（胜义生菩萨之问）**
    - **再由胜义生菩萨发问**：佛曾以无量门细说蕴、处、缘起、食、谛、界与念住乃至八圣道的自相和修习，如今又说「一切诸法皆无自性、无生无灭、本来寂静、自性涅槃」——两套说法如何相容？佛答：我是依三种无自性性（「无自性」的三个方面）说的
    - **三种无自性性：把「无自性」拆成三件事**
      - **相无自性性 = 遍计所执相**：只是假名安立为相，不由自相安立——「相」上无自性，如空华（病眼所见的虚幻花朵）
      - **生无自性性 = 依他起相**：依他缘力故有，非自然有——「生」上无自性，如幻像
      - **胜义无自性性有两分**：一分指依他起——缘生法由生无自性性故也名胜义无自性性（它不是清净所缘的胜义境界），也如幻像；一分指圆成实相——法无我性（诸法无我的本性）名为胜义，由无自性性所显故名胜义无自性性，如虚空（众色无性所显、遍一切处）
      - **结论**：佛依这三种无自性性，密意说「一切诸法皆无自性」
    - **推理链**：依相无自性性说，自相都无 → 无生 → 无灭 → 本来寂静 → 自性涅槃（其中无一分实体可令其般涅槃）；又依法无我性所显的胜义无自性性说，法性安住无为故无生无灭，一切杂染不相应故本来寂静、自性涅槃
    - **为什么立三种无自性性：病根是「增益」**
      - 不是因为众生分别观三种自性本身，而是因为众生在依他起与圆成实上增益（凭空添加）了遍计所执自性
      - **执著的连锁**：增益 → 随起言说 → 言说熏习于心（或言说随觉、言说随眠） → 于依他起与圆成实上执著遍计所执 → 感生来世的依他起 → 被烦恼、业、生三种杂染所染 → 在六道中长时流转、受诸苦恼
  - **对机说法：这句法药怎么分层宣讲、听众会怎么反应**
    - 密意说清之后，佛接着交代这句法要的用法：根机未熟者先学浅的，已熟者再学深的；并对「唯有一乘」与听众的种种意解差别作了交代——同一句法药落到人身上，结果大不相同
    - **分层教法：先教厌离，再教无相**
      - **对五事未备者**（未种善根、未净障、未熟相续、未多胜解、未集资粮）：先依生无自性性讲缘生诸行无常、不安稳、会变坏 → 生怖畏厌患 → 止恶修善，从而种善根、净障、熟相续、集资粮
      - 但此时尚未了知相无自性性与二种胜义无自性性，未正厌、未离欲、未解脱 → 佛再说法要：于生无自性性中正信解相无自性性与胜义无自性性
      - **深入效果**：于依他起上不执遍计所执，以「言说不熏习、不随觉、离随眠」之智灭依他起相 → 永断当来世因 → 正厌、正离欲、正解脱，遍脱烦恼、业、生三种杂染
    - **一乘密意：一条道，多种根性**
      - **声闻、独觉、菩萨三乘**：皆由此道、此行迹证得无上安隐涅槃——「皆共此一妙清净道」，故密意说「唯有一乘」；但钝根、中根、利根的差别依然存在
      - **一向趣寂声闻**：本唯下劣种性，一向慈悲薄弱、怖畏众苦，弃背利生与起行——佛再施设勇猛加行化导，也终不能坐道场成佛
      - **回向菩提声闻**：异门（换个名目）说为菩萨——已解脱烦恼障（烦恼的束缚），蒙佛觉悟时于所知障（障碍遍知一切的无明）亦可解脱
    - **同一句经文，几种听众**
      - **五事俱全者**：闻已如实解了 → 深生信解 → 速疾证最极究竟
      - **资粮未上品而性质直者**：虽不能如实解了，却生清净信、自轻而住（「我等智见犹如牛迹」）；恭敬书写流布、供养受诵——虽未能以修相发起加行，仍增长福慧，后来相续能成熟
      - **性非质直、安住自见取（固执己见）者**：随言执着「决定皆无自性」 → 拨一切相皆是无相 → 诽拨三相（若依他与圆成实被拨为无，遍计所执也无处安立） → 于非义中起义想 → 退失智慧与善法；随其见者同退失
      - **闻而生怖者**：斥「此非佛语，是魔所说」而诽谤毁骂 → 获大衰损、触大业障
      - **五事皆无又住自见取者**：起非法想非义想、毁谤摧伏经典、视信解者为怨家 → 业障于百千俱胝那庾多劫无有出期
      - **佛总断**：于一切相起无相见、以非义为义，是起广大业障的方便——陷坠无量众生；偈重申：不知此密意则失坏正道不能往，并点出趣寂者唯度一身、大悲者不舍众生、无漏界中解脱等无差别
  - **领解与判教：这套说法凭什么最了义**
    - 胜义生菩萨领解佛意后，把「无自性」这套说法与佛的全部旧教法对齐，并给出它的定位：为什么它是第三次、也是最了义的一次说法
    - **胜义生领解：以色蕴为例复述三相**
      - 在分别所行、遍计所执所依的行相中，假名安立「色蕴」的自性差别、生灭与永断遍知 → 是遍计所执相，依此施设相无自性性；即此行相本身 → 是依他起相，依此施设生无自性性及一分胜义无自性性
      - 由遍计所执不成实故，即此无自性性是法无我真如（诸法无我的真实本性）的清净所缘 → 是圆成实相，依此施设一分胜义无自性性
      - **推广**：余蕴、十二处、十二有支、四食、六界十八界、四谛、念住至八圣道，一一皆照此套用——佛的旧教法全部可作三自性读法
    - **四个比喻：了义教像什么**（胜义生连设四喻，佛印可「如是如是，更无有异」）
      - **毗湿缚药**（一味通用的药引）：遍于一切散药仙药方中皆应安处——无自性了义言教遍于一切不了义经皆应安处
      - **彩画地**：一切彩画同一味，复能显发画业——了义教于一切不了义经皆同一味，能显发其中未了之义
      - **熟酥**：投入珍馐饼果更生胜味——置于不了义经能生胜欢喜
      - **虚空**：遍一切处同一味、不障一切事业——不障声闻、独觉、大乘所修事业
    - **三时判教：佛说法的三个阶段**
      - **第一时**：在婆罗痆斯的施鹿林，唯为发趣声闻乘者以四谛相转法轮——甚奇希有，但有上、有容（其上更有胜法、其中容有未竟之义），未了义，是诸诤论安足处所（争论可以立足之处）
      - **第二时**：唯为发趣大乘者，以隐密相说一切法无自性、无生灭、本寂、自性涅槃——更甚奇，但仍是有上有容、未了义、诤论安足处
      - **第三时（今）**：普为发趣一切乘者，以显了相依无自性性转法轮——第一甚奇、无上无容、真了义、非诤论安足处
    - **受持功德与经名**
      - **受持此了义教的福**：如爪上土比大地土、牛迹中水比四大海水——不了义经的功德比此了义教，百分不及一乃至邬波尼杀昙分（微乎其微的计量单位）不及一
      - **佛命名此教为「胜义了义之教」**；说此教时大会得果：六百千众生发菩提心，三百千声闻得法眼净（初见真理的清净慧眼），一百五十千声闻漏尽解脱，七十五千菩萨得无生法忍（证悟诸法无生的智慧境界）
