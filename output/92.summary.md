- **全篇总括**：本卷是摄事分对契经的第四段择摄，两首纲领偈把全卷切成两半。前半回答修行人的实际课题：上品贪从哪来、老师怎么说法教授、不守根为何住苦、伏惑后如何不退、什么人不配受供养，再给出明与解脱的修道次第、无我正见的三件正事、得定住正法的五种殊胜，以二种法见和希求人天的过患收尾。后半追问来世从哪里来：有爱造出第二自体、烦恼拉人远离涅槃、业的顺逆传递、空的七种分别，最后以阿罗汉的恒住与师徒德相双圆满作结。
  - **前半卷目录：第一首偈列出的主题**
    - **开卷偈先背出前半脉络**：上品贪、教授、苦住、观察引发、不应供养、明与解脱、无我论、定法，法见与苦殿后——以下各节依次展开
    - **上品贪：人为什么贪得格外猛利**
      - **先找成因**：三个条件凑齐，对境便起上品贪——身体康强不羸弱、相貌端严不丑陋、长期串习贪而非舍贪
      - **再给对治**：密护根门（管住感官入口，远离纵欲一边）、于食知量并减省睡眠（远离苦行一边）、最胜正念正知（行中道出离行）——三法连上品贪者都能调伏到勤修梵行、心得寂静，何况中下品薄贪的人
      - **最胜正念正知分两级**：基础级是善住四念住（在身受心法上安住观照）——行动时对境若不取相取随好，如实了知「受」的生住灭；若取相取随好，了知「想」的生住灭；静住时了知寻思（杂念）的生住灭，由此一切时按正轨守护其心
      - **高级级属已得深定的人**：得灭尽定（受想都止息的定）、无想定、无寻伺定者，出定入定时如实了知其中的受、想、寻伺
      - **分水岭在「唯取法」**：只把受想寻伺当纯现象看，不生「我能领受」这类我、我所（执为我的）虚妄分别——凡夫作「我能领受」之想，连正念正知都没有；基础级适用从得定的不放逸凡夫到一来果（还须再来受生一次的圣果），唯取法级属不还果（不再回来）或阿罗汉（诸漏永尽者）
    - **教授：佛年老为何请人代讲**
      - **讲完个人用功，转到教学安排**：佛自称年衰力疲、劝声闻请别人说法，用意有二——让恃年轻而憍傲放逸者自生怖畏厌离；让后世年老无力的比丘远离疑悔（年轻力壮的说法者则应无所恐惧）
      - **大集会说法分两种**：决择说（设问征核、以正理灭除疑惑）与直言说（听众默然，法师直讲）
      - **随顺教授教诫有四相**，正好层层引出四种正见清净
        - **分析内外诸处**：中识、触、受、想、思、爱各各差别，显示无我——依缘起（此有故彼有的因果法则）道理引出第一正见清净
        - **诸处灭则诸受随之灭**（如灯灭则明灭、树倒则影灭），离增上慢（未得谓得的自我高估），如实知涅槃最胜寂静——第二正见清净
        - **以智慧刀永断一切烦恼**，超越当来众苦——第三正见清净
        - **于一切苦乐舍法不起贪嗔痴**（显示见道），善住念住（显示修道），修诸觉分令诸漏永尽、超越现法杂染——第四正见清净
    - **苦住：不守根的人为什么住得苦**
      - **不守根**、心多爱染散乱的比丘受二种苦，病根都在该修的不修
        - **粗重所作苦**：不修身、不修戒与奢摩他（止）→ 身不轻安（身心调畅堪任的状态）、心不轻安
        - **疑惑所作苦**：轻安缺失就触证不了胜三摩地（定），于是于诸法多生疑惑
      - **另一段补说六根**：五寂静相不寂静，招三种苦果——现法中被贬退、讥呵、杀害，当来生老病死众苦，加上等流（同类习气延续）继续不护根的杂染；与此相违则得三苦灭果
    - **观察引发：伏住烦恼之后如何不退不失**
      - **加行伏惑只是暂时压制**，接着要靠观察作意（用试探境检验断与未断的觉察）防止退失与增上慢
        - **伏惑者自问贪欲还在吗**？以净相作意（故意作意可爱境）测试，于断未断得决定
        - **依观察寻求贪欲的生起处所**，了知忆念分别是烦恼最强的安足处；烦恼漂漾心时立即制伏，才保住已得的三摩地并进趣上品功德
        - **不观察会生增上慢而退失**；观察则证决定，心漂漾时能还复整摄，故不退
        - **到猛利审观察而烦恼不生起**，得「我于诸处已能胜伏」的决定胜解，超过学地——如大王自在降魔，证尽无生智（知烦恼已尽不复再生的智慧），梵行圆满
    - **不应供：假福田的两种嘴脸**
      - **两种世俗梵志**（修行人）实非福田而自称福田，不应供养
        - **一类猛利耽着利养恭敬**、诸根贪求躁动，诈现现前离欲之行
        - **一类摄受家产**、与亲属杂居，所行既非自利亦非利他，远离戒与善趣、涅槃妙行，与愚夫无异；与此相违的才名胜义梵志
    - **明与解脱：说法的真正目的与四种修道**
      - **外道说法多为止谤辩胜**、免脱他人问难，第一义上无义无利；佛说法唯为证得明（智慧）与解脱二果，自利利他无不圆满
        - **明分三种名三明**：行于三世无忘失、住最胜义、三种所缘境差别
        - **心解脱与慧解脱都名为解脱**：分别是爱、无明这两个根本杂染的胜对治
      - **为得未得的明与解脱**，四种修道层层引发：修根 → 能正修身；修身所引善行 → 能正修戒；修戒所引念住觉支 → 能修心慧
      - **四修各分三品**（以修根为例，余三同构）
        - **世间修**：靠思择力，虽取可爱不可爱境的不如理相，不起烦恼缠，暂起随即除遣
        - **有学修**：已得圣谛现观（亲见四圣谛），虽因失念生适意不适意，心不为缠缚坚住，速脱杂染
        - **无学修**：心坚固安住，下至失念都没有，不于顺逆境计着其德而趣向
      - **配套两段说明**
        - **适意不适意的差别来源**：可意不可意的境界、有恩有怨、功德过失相应、所爱非所爱的有情；又于恶行随观现法（六处被诽毁）与当来（堕恶趣）过患，故远离而修妙行
        - **位次与次第**：念觉分创始发起在异生（凡夫）地，数修习在有学地，修圆满在无学地；未得断界而希求名依远离，未得无欲界名依离欲，未得灭界名依于灭；整条链是守护诸根 → 惭愧 → 耻恶修妙行 → 无变悔 → 欢喜 → 正定 → 见如实 → 明及解脱圆满（弃舍下劣、回向胜妙名弃舍回向）
    - **善修诸根：弃背境界不等于修根**
      - **接着纠正一种流行错误**：以为只要躲开一切境界就是护诸根
        - **持此见者**：自己于弟子众一分起爱一分生憎，对这么微细的自心杂染不能以慧悟入，反起增上慢；徒众虽独处空闲，心仍缘彼境起寻思杂染，又不为修根勤修正行——都不名善修诸根
      - **佛的标准**：烦恼断故名善修根，不是一味背弃境界
        - **佛善住三种不共念住**：于正行众悦意、于邪行众不悦意，而由此生的贪嗔杂染都无所有——故名无上善修诸根
      - **佛观五品弟子众**，起五转悦不悦意：一向正行毕竟→悦意；一向放逸毕竟→不悦意；正行不毕竟→悦意中生不悦意；邪行不毕竟→不悦意中生悦意；多品杂行→三者皆有——如来虽发五转，终不为爱恚行相染污，因烦恼及习气永离系故
      - **随五转应思惟三种对治**：无常想、慈心、无想定
      - **修根的两种完成相**：无学弟子遇可爱非爱境，由心、慧解脱力以无相令心速弃舍，起厌逆想、见涅槃寂静德，速安住于舍，连一刹那失念的染污心都不起；有学弟子尚有余烦恼熏染相续，被现行烦恼逼迫时方便住厌逆想及过患想，由此修根速得圆满
    - **无我论：论说无我的三件正事**
      - **无我论师该做的三件正事**，每件对着「我执」的一个层面
        - **第一**：于苦集谛所摄诸行显了自相（各各差别、众多性）与共相（生灭相似性），安立无我
        - **第二**：于无我唯有因行中如实显了杂染与清净——三种受缘生的烦恼随眠、见道的我见随眠、修道的我慢随眠及相应无明都未断，便不能作苦边际（杂染面）；相违即清净面
        - **第三**：断除增益我的萨迦耶见（执蕴为我的身见），依实无我正见——凡夫位摄受圣谛现观、得圣慧眼，有学位得尽无生智，无学位见修所断烦恼无余永断
    - **定法：得定住正法的五种殊胜**
      - 同样有世间正见与多闻，心未得定与已得定住正法的人差在哪？列五种正加行果
        - **第一**：心得定故戒清净鲜白（未得定者奢摩他支戒未净）
        - **第二**：得定者于一切受及其所依、所缘、助伴、随转如实知，不为三种无智过患所触
          - **受杂染**：乐受有贪爱缚，苦受有嗔恚缚，不苦不乐受有愚爱缚及随眠缚
          - **世杂染**：现在世贪染缚，过去世顾恋缚，未来世系心缚
          - **现法后法杂染**：生长感后有（来世存有）之业 → 增益后有诸蕴；后有爱生当来自体，资财爱令人追求疲怠、得则染恼、不得自烧、得已复失则愁恼；更由业烦恼起当来生老死众苦
        - **第三**：于上述过患自他都能如实了知
        - **第四**：已入修地，以前所得无我相应正见修习，断界、无欲界与一切菩提分法共圆满
        - **第五**：多闻转成毗钵舍那（观）的助伴，止观平等双转——依断界应遍知者正遍知、应永断者正永断、应作证者正作证、应修习者正修习（色与名当遍知，无明与有爱当永断，明净智与解脱当作证，止与观当修习），依无欲界已知已断已证已修
    - **见苦殿后：二种法见与人天过患**
      - **最后两题**：能「见」的智慧框架，与被称赞的人天实有的苦
      - **二种法见**
        - **有为法见**：于谛依处（名色及人天等有情世间）如实知二谛——世俗谛（假想安立我、有情乃至命者生者，假自称「我眼见色」，假言说名字寿量）与胜义谛（即于彼处有无常、苦、缘生性），各如实了知即名有为法见，成就者言说满足
        - **无为法见**：由二谛善巧增上力，于一切依止息的涅槃深见寂静、心趣入乃至解脱——成就者言说满足
        - **三种人成就法见**：得定心、能如理观察的异生，已见谛迹的有学，诸漏永尽的无学
      - **发誓行梵行却只求人天盛事**，等于称赞人天的二种过患
        - **烦恼所生众苦**：于三世境界住染污的爱乐欣喜 → 所欲有匮乏苦及生老等众苦
        - **无常所生众苦**：顺乐处背离失去起变坏苦，顺苦处现前起厌离苦，一切自体终归灭坏起灭坏苦
      - **如来超过二种过患住一向乐**：一切境相应永尽的无上安隐即有余依般涅槃界（惑尽而身尚存）；得乐的方便是对五种受如实了知
      - **声闻若弃舍此妙乐**、希求下劣人天乐，为智者所毁辱，亦自欺诳
  - **后半卷目录：第二首偈列出的主题**
    - **卷中以第二首偈另起一编**：有第二住、去涅槃远、略说内所证、辩一切智、舍所学与业、空与随业行、恒住、师弟二圆满——以下各节依次展开
    - **有第二住：有爱如何造出来世**
      - **「第二住」**：指安住于为来世再造一个自体，由二因缘成立：有爱故受习其因；此自体灭而第二自体次第生起
        - **有爱分三层现起**：可爱境界将得现前时的染污欣悦名有喜乐；未得已得而未受用期间由喜乐力住染欣悦名有欢喜；正受用时多生贪爱名有染着——合名有爱
        - **另一套时间分法**：对未来的希求与已得的领纳是喜乐，对过去的忆念是欢喜，正受用时生贪爱是染着
      - **第二自体如何生起**：喜乐等为集聚之因，于当来世以生老为根的众苦生起——与此相违即无第二住
    - **去涅槃远与鄙碎士夫：什么把人往轮回里拖**
      - **烦恼与涅槃二法互相违**：安住杂染法便随顺后有而转，随顺后有即名去涅槃远
      - **六种鄙碎士夫行相**：性多忿恚、所作不思、乐逼恼他、受苦便发不实粗恶语、发真实而引无义的粗恶语、展转发起无量恶言不知少足
      - **对治二法令出家人速证沙门义利**（未信者生信、已信者增长）：忍辱（于他怨终不返报）与柔和（心无愤性不恼他）
    - **内所证：两种涅槃界与涅槃何以唯内证**
      - **如来依二种处所说涅槃界之教**：有余依涅槃界教（烦恼已断名成就断，不住彼果后有众苦——惑尽而身尚存）；无余依涅槃界教（寿尽灭没后一切余依都无所有，不住此身、余身与中有（两世之间的过渡身），证得一切众苦边际）
      - **涅槃是内证法**：不靠信乃至见、审察、忍可等外在途径安立，而是现法中各别如实了知内外杂染的有与无
      - **附记三种念力强因**：年少壮、前生串习、现法数习
    - **一切智：佛知什么**
      - **三因缘显示诸佛无上菩提**：觉了一切境、觉了有及非有如实事、觉了染净二品一切法——他人在此三处请问世尊
      - **诸有为法同时俱转令心迷乱**、于相邪取分别，故佛分别开示令决定悟入——为知真实相、于自无欺诳、于他坦然无畏正记别
    - **舍所学与心株覆事：堕落的人困在哪里**
      - **出家者弃舍所学**，便安立于顾恋境界；毁犯戒者，又令未出家者弃背趣入之心
      - **最极爱味心株覆事**：远离惭愧、一味贪爱、坚执所缘，如心中树桩，使上品善业不得调柔堪能；又行诸恶行而隐匿于心，成「覆」——合名于境最极爱味心株覆事
    - **业的传递：顺观与逆观两条链**
      - **顺次**：不护根 → 乐闻不正法 → 生无明触所生的染污作意 → 不知当来诸处生起的过患 → 起希求 → 造作增长相应业 → 当来世六处生起
      - **逆次倒推**：六处以业为因 ← 业以爱为因 ← 爱以无明为因 ← 无明以不如理作意为因 ← 不正作意以无明触为因
      - **业与受果有时间差**：先所造业是现法受六处之因；现法造业是次生受（或更后受）六处之缘——爱与业的关系亦然
    - **随业而行、不言随爱：爱与业的分工**
      - **后有生起需二因缘**：后有业与后有爱；但经中说有情「随业而行」不说随爱——三爱是欲爱、色爱、无色爱
        - **欲爱纵有异熟**（果报），若不起恶不善业，终不能感恶趣异熟；因贪嗔痴于境现行而造不善业才堕恶趣——非但由贪嗔痴缠定堕，爱在业感果时只是助伴
        - **希求可爱境而修善业得生善趣**：异熟果以业为引生因，不是染污性的爱
        - **色无色爱虽非不善而是染污**，皆无异熟果；由闻法观欲界粗鄙、证明触、调伏贪嗔痴，造修所成善有漏业方生彼界——爱仍只是助伴
      - **随行的机制**：于能顺喜的境不如理执相 → 贪欲 → 寻思求觅 → 广行福非福行；顺忧境生嗔恚，顺舍境生愚痴，同理
    - **空：从世俗空到七种胜义空**
      - **世俗谛空**：世间假名说有「受者」「作者」，有时空现可得有时不空——这是世俗谛空，非胜义空
      - **胜义谛空**：恒时一切诸行唯有因果，都无受者与作者——展开为七种
        - **后际空**：未来诸行若已实有则不应生、无常不可得——诸行生时无所从来，本无今有
        - **前际空**：过去行聚若常住则不应说灭——诸行正灭时都无所往积集而住，散灭不待余因
        - **中际空**：刹那生灭中唯有诸行暂时可得，无余行亦无别物——亦即常空、我空
        - **受者空与作者空**：果性诸行空无受者，因性业行空无作者
        - **总结**：唯有诸行前生灭后生生，无舍前生者取后生者；「此有故彼有，此生故彼生」的作用只是依世俗谛假立
    - **恒住：阿罗汉为何住得安稳**
      - **阿罗汉诸漏永尽**，于一切境随顺而行，恒时连失念生烦恼都不可能，故恒住无杂染住名恒住——随行之中喜忧欣戚全无
      - **极难行故、无罪故名最胜**；成就者极难得故名第一真实福田，应当奉请
    - **师弟二圆满：圣教靠什么撑起**
      - **第一轮**：大师德圆满二相——依利他行为令悟入「诸所有受皆是苦」，说受的所依与因缘、能杂染的随行、能对治与所对治、一切种究竟出离；依自利行宣说不共三种念住无杂染住
        - **弟子德圆满二相**：了知法教而未到闻之彼岸者，要以法随法行（按教法实修）证得出离，不以随顺言说为究竟；又不以下劣生喜足，要往趣贤敏丈夫所趣之地
      - **第二轮**：大师德圆满三相——最初施设远离二边的中道正行；以正方便令未生信者入圣教、毁犯者离诸毁犯；对已入者以四法摄正摄受
        - **四法摄**：于隐密难言处用如法闲静的方式教授；于违犯以如法苦切语言现前呵摈；于耽着寻思者教令于内勤修寂静（渐次乃至第四静虑方能究竟寂静）；令时时听闻正法、远离相似正法
        - **弟子德圆满二相**：最初忍受大师的空无我见——不增益我执，亦不毁坏世俗道理；忍受已能正修行法随法行——有苦有害者如实知而速断灭，无苦无害者如实知而速作证
      - **收尾**：如是大师及弟子众所摄受的诸佛圣教，一向无染清净，是诸聪慧者的归趣
