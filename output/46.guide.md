# 瑜伽师地论卷第四十六 导读

## 一、内容总览
卷四十六接续「菩提分品」之尾，开启「菩萨功德品第十八」。前半由四种「法嗢拖南」（无常、苦、无我、涅槃寂静）入，以三世（过现未）、四相（生住老灭）、二无我等推演菩萨对诸行诸法的如实观；并以王子戏车、病者换药二喻，点明未证菩萨与声闻于涅槃仅有「相似胜解」，须资粮成熟方生如实慧解。后半广明菩萨功德：希奇法、不希奇法、平等心、饶益、报恩、欣赞、不虚加行等「五法」一组组的功德聚，及加行、退堕胜进、相似真实功德、调伏有情；复以施设建立（法谛理乘）、四寻思、五无量、七大性、十种菩萨、菩萨名号收束，终以「相似菩萨」与「真实菩萨」之辨作结。

## 二、结构层次
全卷以「法嗢拖南 → 菩萨功德聚 → 名相建立」三段推进：

- **法嗢拖南（总标四门）**：先标四法嗢拖南（无常、苦、无我、涅槃寂静）→ 次依「言说自性／离言自性」二门解无常 → 推及三世分段、一刹那四相（生住老灭）、有分无分 → 以理推求「生等实物不可得」，破斥「生别有体」「灭别有性」→ 结成三苦、二无我、涅槃寂静 → 二喻（王子假车、病者换药）显未证者于涅槃唯有相似胜解，闻佛赞说后追生羞愧，依后如实胜解。
- **菩萨功德聚（嗢拖南颂 + 五法一组）**：以两首嗢拖南颂总列功德名 → 次以「五法」为基本单元广说：希奇法、不希奇法（而名希奇）、平等心、饶益事、报恩、欣赞、不虚加行 → 加行五、退堕五、胜进五、相似功德五、真实功德五、调伏有情十处，层层枚举。
- **名相建立（收束全体）**：施设建立四（法谛理乘）→ 谛立一至十 → 乘立声闻／独觉／大乘各七行相 → 四寻思、四如实遍知 → 五无量（有情／世界／法／所调伏／调伏方便）→ 说法五大果 → 大乘七大性 → 八法摄大乘 → 十种菩萨阶位 → 菩萨假名号 → 真实／相似菩萨之辨，由广大归于切实。

## 三、关键结论
- 四法嗢拖南摄尽佛法宗要：诸行无常、皆苦、无我、涅槃寂静，菩萨依此入如实观。
- 生住老灭四相不离诸行别有自体，离言法性不可作实物推求，否则堕「生生」「灭灭」无穷过。
- 菩萨之胜在于「不希奇而名希奇」——以利他苦为己乐、誓受生死，与二乘不共。
- 大乘以七大性为体，由法大性至圆证大性因果相生，经三无数大劫方证菩提。
- 真实菩萨不在自自称名，而在如实施修菩萨学；自称菩萨而不正修者只是相似菩萨。

## 四、易混辨析
- **有为之相「有分／无分」**：有分显「生住异」（诸行本身作用），无分显「灭」（归无）；佛依此立三相（生、灭、住异），非别有实物。
- **相似功德 vs 真实功德**：相似者外现威仪、习外道论、说像似正法；真实者具胜悲心、本性威仪、开示正法遮灭像似。
- **胜解行地 vs 净胜意乐地 vs 决定地**：胜解行地尚以胜解思择力修行；净胜意乐地已入初地证清净增上意乐；决定地堕决定中无复退转。此三位即五种加行之所依。
- **有情界无量 vs 所调伏界无量**：有情界通摄住种性、不住种性一切有情；所调伏界唯约堪能受化之种性位差别而说。

## 五、阅读提示
带着两组问题读：一是「菩萨的希奇处究竟在哪？」（注意「不希奇而名希奇」的反语结构）；二是「大乘之所以为『大』靠什么立？」（盯住七大性与十种菩萨阶位的因果线索）。
