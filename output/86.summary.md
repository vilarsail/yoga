- **全篇总括**：本卷属《瑜伽师地论》摄事分「行择摄」第二部分，围绕一个总问题：如何如实观察一切迁流不住的「诸行」（因缘所生的存在）并从中超越。两首纲要偈分出上下两半：上半卷从修无常想讲到慧眼清净、九种智、四种我见，直到无余涅槃为何令人惊恐及其对治；下半卷讲速疾通慧的三种力、生死爱河的流转结构，最后以断我见的验收相、资粮清单、师门规范与邪行对治收束，点出唯佛法能观无我而不怖涅槃。
  - **上半卷之一·观察装备：看破诸行靠什么**
    - **开篇嗢拖南**（纲要偈）是上半卷的目录：想（无常想）、愚相（愚夫之相）、眼（慧眼）、胜利（十种胜利）、九智、无痴、胜进、我见差别、三相行、法总（法嗢拖南）；本块先讲观察诸行的基本功。
    - **无常五相：换五个角度观察「坏」**
      - **修无常想**：有五种行相，像从五个角度确认同一件事：诸行必坏
      - 刹那刹那在坏 → 无常性；住寿有上限 → 无恒性；大劫之后终不存 → 非久住性；可能遭遇非时横死 → 不可保性；即使住着也不得安乐 → 变坏法性；能否思惟这五相，正是下文愚夫与智者的界线
    - **愚夫之相：在假指标上比输赢**
      - **愚夫**（凡夫）对五无常性不能思惟，却在「胜劣」这类非真实的比较标准上称量自他、以己为胜——此为第一愚夫之相，谓等、谓劣同例
      - **与此相违**：即是三种智者之相
    - **慧眼清净：远尘、离垢与十种胜利**
      - **圣者慧眼清净由二相成立**：远尘（见道所断烦恼的现行，即缠，已离系）＋离垢（烦恼随眠，即潜伏的种子，已离系）；现观（亲证四谛）时的关键一击，是遍知能取所取平等，令粗重我慢当下断灭
      - **得法眼**（见四谛的智慧之眼）同时获十种胜利：见法、得法（随获一种沙门果位）、知法（自知永尽那落迦（地狱）等三恶道、已证预流初果）、遍坚法（四证净，于佛法僧戒的净信）、自所证无惑、他所证无疑、说圣谛教不待外缘、不看他面（他论不能动转）、记别解脱无所畏、由正世俗与第一义二门随入圣教
    - **九种智：遍知超越的阶梯**
      - **九智清单**：流转智、还灭智、杂染因缘智、清净因缘智、清净智、苦智、集智、灭智、道智
      - **流转与还灭共用一个公式**：喜集、触集、名色集三种因缘聚集 → 色受识等诸行生起；三因缘灭 → 诸行还灭
      - **杂染清净因缘智与清净智**：对应爱味（贪恋其乐）、过患（看清其害）、出离三重观察；苦集灭道四智即四圣谛智
      - **修习门槛**：凡夫位先修前五智，圣者速证后四谛智；前五智有缺不能遍知诸行，谛智有缺不能以对治断烦恼、超一切行——两段缺一不可
    - **三处无愚痴住：三世各有各的观法**
      - 对过去行如实知无常性，对现在行如实知灭法性，对未来行如实知生灭法性 → 三世不愚痴，不染污心安乐住（堕明数，有智慧一类）；反面即愚痴住，堕无明数
  - **上半卷之二·烦恼与我见：贪喜怎么分、慢怎么生**
    - 讲完观察装备，本块转认烦恼：先给出贪嗔痴的别名清单与喜贪的六组分界，再讲四胜进的取证路线，最后解剖我见与我慢的生起机制。
    - **烦恼词典与喜贪之辨**
      - **贪嗔痴各有一串异名**：贪叫喜、顾、欣、欲、昵、乐、藏、护、着、希、耽、爱、染、渴等；嗔叫恚、憎、忿、损、不忍、违戾、暴恶等；痴叫无智、无见、非现观、惛昧、愚痴、无明、黑闇等
      - **喜与贪的六组分界**：受上生欣乐＝喜／境上起染着＝贪；将得＝喜／已得＝贪；临将受用＝喜／正受用＝贪；能得的方便＝喜／境本身＝贪；后有名喜／现境名贪；他人荣利名喜／自己荣利名贪
    - **四胜进：从预流到阿罗汉的进取**
      - **公式**：未得为得（先证预流初果）→ 未会为会（契会上学果，一来、不还）→ 未证为证（证阿罗汉，于诸惑断能作证）；证阿罗汉后无可进取，只为此生安乐住而修，即第四胜进
      - **依自义的三种胜进想**：厌背想（于诸行思惟如病、如痈、如箭、恼害，对应四大失调之苦、宿业之苦、怨敌之害、亲财匮乏中自邪计之苦）、过患想（思惟无常与苦）、实义想（思惟空性与无我性）
      - **修习顺序**：先修过患想与实义想，之后方能安住厌背想（原文先说果后说因）
    - **四种我见：我慢从哪来**
      - **分类**：有分别我见（外道邪分别所起）、俱生我见（生来即有，下至禽兽也起）、缘自依止我见（缘自身起）、缘他依止我见（缘他身起）
      - **两个比喻**：分别我见如清净圆镜上依质像生影像——缘自依止我见更生缘他依止我见，再互比胜等劣而生我慢；俱生我见如明眼人对清水自观眼耳
      - **萨迦耶见**（执五蕴为我我所的身见）唯依佛的善说法与律方能永断，余邪教不能 → 报恩有二：于大师及同梵行者（同修道友）处如实自显，或依所闻句义勤修正行；后者只是随分报恩，因师长所望尚未满足
  - **上半卷之三·寂灭与惊恐：涅槃为什么吓人，怎么治**
    - 断我见之后直接面对「无我、寂灭」：本块先安立无余涅槃与四句法纲要，再解剖闻「无我」者心退还的机制，最后给出解了心与调柔心的对治。
    - **无余涅槃与四法嗢拖南：寂灭不是「我消失」**
      - **无余依涅槃界**（烦恼与身心诸行全部灭尽的最终涅槃）由三相安立：先业宿愿所感的今生诸行永灭、诸行生已任运灭坏（本非究竟可住）、一切烦恼永断后不更生
      - **由三相说名寂灭**：但不是「永无一切相」——若连寂灭相也无，就无从说名为寂灭
      - **三解脱门**（空、无愿、无相三种入解脱的门径）建立四句法纲要：一切行无常、一切行苦依无愿门，一切法无我依空门，涅槃寂静依无相门
    - **惊恐的机制：听见「无我」心会退还**
      - **求寂静的增上行欲分二种**：胜解俱行欲（由四句纲要于诸行生起求离之欲）与意乐俱行欲；后者虽独处空闲思惟寂静，仍会因四相心退还——见不到利益不趣入、不信、于所缘不喜不安住、起不乐胜解
      - **更深一层**：依「无我胜解」之欲，于涅槃反生惊恐，二缘是此欲未串习到究竟、作意时忘失正念
      - **机制链**：欲未串习 → 数数思惟「我我尔时当何所在」（我将来在哪里）→ 作念唯有诸行、当来不有 → 随逐身见起变异随转之识 → 惊恐，于寂灭心退还
    - **对治二法：解了心与调柔心**
      - **二法多有所作**：一是在有智慧的道友处如实自显（坦白自己）；二是因善法欲发起解了心与调柔心
      - **解了心**：闻法由三增上生欢喜——见可赞仰的佛与善说法者（补特伽罗增上，即人增上）、法能令人出离烦恼业苦并信解深义（法增上）、自有力能随说觉悟（自增上）
      - **调柔心即三见**：依彼而转（未得现观时，依胜解俱行的极善串习正见而转）、由彼遍知（依随顺现观的正见，于三事——所取的五取蕴、能取的四取、执取方式的四识住——遍知我执萨迦耶见及其随眠）、应所引发（由此永断三事执着，于圣谛智不待外缘）
      - **三见转起的差别**：我执随眠俱全 → 不能入处中行（远离断常二边的中道）；我执离系犹被随眠缚 → 已入处中行、堪能出离；我执随眠俱离 → 先趣入、后得出离
  - **下半卷之一·速疾通慧：三力、善巧与五级台阶**
    - **第二首纲要偈**（速通、自体、智境界、流转、喜足、行、顺流、违粮、师所作）开启下半卷；本块先答「怎样最快证得真实究竟解脱」。
    - **通慧三力与智见之辨**
      - **三法得速疾通慧**：智力（堪能无间永尽诸漏的有学智见）→ 不放逸力（依所得之道防护心、遮止恶不善法）→ 数习力（常作常转地修，不起「今日能否尽漏」的邪思，故无厌倦、无怯畏、不舍加行）
      - **智见之辨**：同一慧在不同处名智或见，原文列约十组二分——照过去未来名智／照现在境名见；所取为缘名智／能取为缘名见；闻思所成名智／修所成名见；断烦恼名见／证解脱名智；缘自相名智／缘共相名见；世俗假立名（我、有情、军林等）名智／取自相共相名见；寻求名智／伺察名见；缘无分别影像名智／缘有分别影像名见
    - **四善巧事与清净道、五种渐次**
      - **四善巧事**：观察事＝四念住（对治常乐我净四颠倒）、舍取事＝四正断（断不善法、修善法）、出受事＝四神足（依四静虑次第超出忧根乃至乐根）、方便事＝根、力、觉支、道支（断见修所断烦恼的正方便）
      - **能依的有学无漏法尚未清净**：还被无明穀卵（无明之壳）缠裹；清净道有四：习近正法正审静虑、亲事善友、以持戒护根少欲等熏练其心、独处空闲以止观（奢摩他、毗钵舍那）胜安乐为翼从
      - **五种渐次**：先集资粮 → 依此修止观 → 具谛现观与涅槃胜解 → 不以少证为足、于可厌法深生厌患 → 证最后金刚喻定（如金刚摧断一切惑的禅定）相应学心
    - **自体无常：五因缘与泥团之喻**
      - **一切自体**（生命体）皆无常的五因缘：寿量有限、因所生、彼因造作、广大兴盛终归磨灭（大梵、帝释、转轮王也不例外）、由佛现见现证而无倒宣说
      - **泥团之喻**：欲验者执持泥团，随时可持可弃；反观必死之身，连延长一刹那都不能遂愿，何况久住
      - **受欲者三种圆满**（资产、自体、广大有情供养）及其三因：布施、持戒调伏诸根、欲界慈心修习之果（以慈为先导，损害寂静）
    - **七种智行与十五相觉了：五蕴五喻**
      - **七种如实通达智行**：已得智、未得智、无颠倒智、知是处非有、知是处不空、苦不净智、速灭坏智
      - **以十五种相觉了诸行**：归结为五蕴五喻：色如聚沫（水界所生、似我显现、随欲造作）、受如浮泡（三和合生）、想如阳焰（能显能烧能令迷乱）、行如芭蕉柱（萨迦耶见为根本、多品自体、刹那无住）、识如幻事（有取之识依四识住发起种种自体）——广说如《摄异门分》
  - **下半卷之二·生死爱河：两种世间与顺流漂溺**
    - 通慧讲完，本块解剖流转的另一半：愚夫为何在爱河里漂而不息、外道为何止步于知足，以及逆流而上的聪慧者长什么样。
    - **两种世间：有情生死与器界生死**
      - **二种世间摄一切行**：有情世间（种类生死）与器世间（器生死，物质环境）——同为「生死」，两界的运行规律却不同
      - **五不同分**：因（器界共因所生、有情不共）、时（器界前后际断、有情相续无断）、治（器界被火水风坏、有情不然）、断（器界之因无永断、有情可永断）、续（器界断而复续、有情断已无续）
    - **流转五相与五缚：愚夫漂而不息的结构**
      - **流转五相**：以无明为爱因 → 以善恶趣业为爱果（往善趣者爱结所系自然乐往，往恶趣者爱锁所系强逼令去）→ 爱自性为三爱（后有爱、喜贪俱行爱、彼彼喜乐爱），摄为有爱与境爱二种 → 因果展转 → 依止前际无穷无尽
      - **结系之别**：喜贪俱行爱＝爱结系（于彼事驰走）；后有爱与彼彼喜乐爱＝爱锁系（于彼事流转）
      - **五相所缚**：被系于处（善趣如柱、恶趣如撅——系桩）、被无明而缚、能缚正是自己（同类于苦无厌）、依后有诸蕴而缚、领受生等众苦
    - **四喜足与爱所行路：知足的陷阱**
      - **四喜足**（多分是外道的止步处）：以人身、欲界天身、生梵世、到边际有顶为满足，愚夫于彼如次若趋若住若坐若卧
      - **五种爱所行路**：后有、未来所求境界、将得现前境界、已得境界、现前受用境界；另有意业希求、身语二业、获得、于所得转习四条路；其果相有心差别（品类与贪嗔痴杂染）与身差别（种种身、一种身）二种，心杂染能为身差别之因
    - **顺流漂溺与逆流行者**
      - **顺流漂溺五相**：于此漂溺（于善恶趣两岸往来）、由此漂溺（爱河——游诸境界趣下分、微细随行难觉了、于境难回转、乃至有顶诸行随逐、不寂静乱身心）、依此漂溺（依色等五蕴攀缘而漂）、如此漂溺（于流转不如实知、计我我所）、漂溺时相（虽宝爱其身欲使长久，自性灭故不能令住）
      - **与此相违**：即逆流行者；聪慧者十相：俱生慧、闻思修三慧、善思所思善说所说善作所作、自依己性不以命依附于他、所求无不安乐、以法不以非法、正防守资产不令散失、观过患而受用、医药观察思择而后服行、善避非时死缘
  - **下半卷之三·断我见、资粮与师门：从验收相到全卷收束**
    - 看清流转之后，本块给出断我见的验收标准与想之修法，再列违顺资粮与师门言教规范，最后以邪行对治收束，回扣「涅槃惊恐」。
    - **断萨迦耶见的三个差别相与三种胜利**
      - **相一**：未断者忘念之行多分现行，已断者相反
      - **相二**：未断者于可爱事多生喜乐、于不可爱境多生忧苦，境界现前时连不放逸者也难守正念，萨迦耶见缠绕其心令心不能解了，已断者相反
      - **相三**：未断者不能于自身诸行现前安立离有情想（如看待草木一般看待自己），已断者相反
      - **断后三种胜利**：永断能感后有的一切烦恼、不久速能积集彼对治道、自义利已成而依道勤修现法乐住，得极安乐
    - **无常苦想的四种差别修法**
      - **果差别**：此想能遣欲贪、色贪、无色贪三种本烦恼及伴随之掉举、慢、无明（即下分结与上分结）
      - **自性差别**：闻慧名亲近、思慧名修习、修慧名多修习；以作意分：了相作意名亲近、其余作意名修习、加行究竟作意名多修习
      - **品类差别**：速能永拔一切随眠、弃舍下地善法摄受上地善法、于不净想等诸想中最高广、皆随顺趣向临入涅槃、永断无明大闇；无学之想由一切无漏学想增上而得
      - **方便差别**：独处空闲无颠倒数数作意观无常之性 → 由无常想住无我想 → 见道住无漏无我想 → 修道以有学想永害我慢，有余依、无余依二涅槃皆得
    - **资粮清单与住时行时言教**
      - **五种违资粮法**：忆念往昔欢娱承奉而生愁叹、于所受法多忘念不能显了、饮食过少过多令身沉重羸劣不乐梵行、喜眠为上品睡眠所缠、亲近猥杂远离正法思惟
      - **五种随顺彼法**（更深一层的病根）：于二离欲（对现行烦恼与随眠种子的离欲）一种也未成就、不护根门、食不知量、初夜后夜不勤修警觉、不观察善法究竟——与此相违即顺资粮法
      - **住时三种正道言教**：以世间作意观察诸行无常、诸法无我、涅槃寂静而得无惑无疑；住时不正寻思三事（资命众具、他损害相、他毁骂等非爱现行）；以教授为先、依他音如理作意生正见断邪见
      - **行时二种言教**：闻处非处（是理非理之辨）不生忿怒、于粗弊资具得失及戒等灾害心不热恼为第一；于所得利养恭敬心不悒然（不郁闷）为第二
    - **师五种所作与佛陀的日常**
      - **师于声闻五种所作**：正折伏、正摄受、正诃责、正说杂染、正说清净；诤事覆相记别（不公开点名处理）有二因缘——防扰乱增广、与律相应；驱摈（开除出僧团）有七因缘（一切种皆行邪行、多分邪行、由上座轨范师亲教师的方便、不堪共住、已被摈、避现前过、防未来过）
      - **如来入聚落乞食的十因缘**：显杜多（头陀苦行）功德、引一部分人入乞食、以同事行摄受、为未来众生作大照明、引粗弊胜解的外道、现妙色寂静威仪令谤者惊叹归向、令处中者以少功树多福、令坏信放逸者深生耻愧（懈怠者同此）、令盲聋癫狂心乱者灾害静息、令天龙八部随从宾卫不为恼害
      - **如来入寂静天住**（安住禅定）的八因缘：引乐杂住者入远离、同事摄远离者、自受现法乐住、与大族诸天集会、以佛眼观察十方现神变饶益、令声闻渴仰、显大声闻善悟略说、劝舍戏论文词之着
      - **大师摄受声闻五相**：以法、以财、与依止、初摄受、摈摄受（连驱逐也是摄受）；释梵天等往诣如来有七因缘（供养、闻法、决疑、翼从、愍他饶益、爱重圣教、知佛起世俗心欲令赴会）
    - **新学、恶作与邪行六相**
      - **初新者性五相**（按出家进程分）：晚出家、幼出家、少出家、劳策出家（作务沙弥）、受具出家；生起恶作（懊悔）的三增上：违越所学、誓受法律、弃舍居家
      - **如来说法前现四相**：从极下座升于高座俨然而坐、安住随顺说法威仪、謦欬（清嗓）示将说法、面目顾视如龙象王
      - **犯戒声闻应于三处生惭羞往大师所**：深知己犯、师事失仪、以方便调顺威仪而往；呵责三反：汝期鄙劣活命、意乐不清净、以活命意乐行非法行
      - **六相遍摄一切邪行**：现行过失（贪染嗔憎而无羞耻）、意乐过失（贪嗔意乐最下劣）、加行过失（不精进或缓慢）、智慧过失（闻思忘念住痴、修定不寂）、寻思过失（多思惟居家恶觉）、依止过失（宿世不修集因——小信、小戒、小念、小慧）
      - **入圣教而行邪行的四因**：微劣不净意乐、伺求圣教瑕隙为正法贼、专为衣食活命、怖畏王贼债主；由此于二事稽留（耽搁）——失坏在家自义与出家自义；其因缘即于三事不正寻思及随取相好的不正想
    - **两种对治与全卷收尾：唯内法不怖涅槃**
      - **二种对治**：以无颠倒数数二行于四念住善住其心（断不正寻思）、修习无相心三摩地（断不正想）
      - **成办靠猛利乐欲**：其生起有二缘：此对治有大果（能证无相心定、住断界与无欲界二甘露门，接近有余依与无余依二涅槃）＋不共一切外道（无相定唯内法有）
      - **收尾对照**：外道由我见故，于涅槃心不欣乐、唯增惊怖其心退还 ↔ 住内法者了知唯是苦灭、唯见寂静之德，有学唯祈内灭不更向外求教诫，无学唯欣内灭，先业所生诸行任运归灭而般涅槃
