# 瑜伽师地论卷第二十一 导读

## 一、内容总览
本卷为「声闻地第十三」之始，含「初瑜伽处种姓地第一」与「初瑜伽处趣入地第二」二地。先以嗢拖南总标声闻地三相——种姓、趣入、出离想地；次广立种姓地（自性、安立、诸相、补特伽罗）；复广立趣入地（自性、安立、诸相、补特伽罗），由「能否证涅槃」的种姓有无立宗，逐层展开声闻行人的根机差别与进趣阶位，是声闻地全篇的奠基。

## 二、结构层次
全卷按「总标 → 种姓地 → 趣入地」三大段推进：
- **总标（P1-P2）**：嗢拖南举声闻地略有三——种姓、趣入、出离想地。
- **种姓地（P3-P61）**：嗢拖南列四门（自性/安立/诸相/数取趣）→ 种姓自性（种子法、六处所摄、法尔所得，别名种子界性）→ 种姓安立（细粗、堕一相续、四因缘不般涅槃、胜劣二缘、劣缘十一种、胜缘二种、种姓真实修集）→ 无涅槃法补特伽罗六种无种姓相 → 安住种姓补特伽罗诸差别（软中利根、贪嗔痴行、远近、未熟已熟、未净已净）→ 佛出世度彼。
- **趣入地（P62-P96）**：嗢拖南列四门 → 趣入自性（初得正信至调柔诸见，展转胜进至最后有身）→ 趣入安立（有种姓/有趣入/将成熟/已成熟四句、六位补特伽罗、极速三生极经七有）→ 已趣入者八种相 → 已趣入补特伽罗差别。
以「总标 → 自性 → 安立 → 诸相 → 补特伽罗」为统一骨架，二地同构。

## 三、关键结论
1. 声闻地略有三：种姓地、趣入地、出离想地；种姓谓住种姓补特伽罗有种子法，遇胜缘堪能证涅槃。
2. 种姓以「附在所依、六处所摄、从无始世法尔所得」为体，别名种子、界、性；堕一相续，非于六处有别异相。
3. 虽有般涅槃法而不般涅槃有四因缘：生无暇、放逸过、邪解行、有障过。
4. 涅槃法缘有二：胜缘（正法增上他音及内如理作意）、劣缘（自圆满至依三摩地十一种）；劣缘修集从自圆满始、依三摩地为最后。
5. 无涅槃法补特伽罗有六种无种姓相（阿赖耶爱遍随缚、生死不见过患涅槃不见功德、上品无惭无愧、闻法不发心、假相出家、善业皆求诸有）。
6. 趣入补特伽罗六位：堪能、下品善根、中品善根、上品善根、究竟方便、已到究竟；最极速疾般涅槃者要经三生，极经七有。

## 四、易混辨析
- **种姓 vs 趣入**：种姓约「有涅槃法种子」、趣入约「已获正信等加行」；有种姓未必已趣入，已趣入必有种姓。
- **将成熟 vs 已成熟**：将成熟未得最后有身、从趣入后展转胜进；已成熟即得最后有身能般涅槃或趣正性离生。
- **劣缘 vs 胜缘**：劣缘十一种是资粮（自圆满至依三摩地），胜缘谓正法他音及如理作意，正能入谛现观。
- **软根 vs 中根 vs 利根**：约诸根运转迟速与堪能势力辨，非约善根有无。
- **时远 vs 加行远**：时远约经多百千生方遇胜缘，加行远约未发胜加行；二种总名远。

## 五、阅读提示
本卷是声闻地「根机论」总纲，可带「种姓有无 → 障缘差别 → 资粮修集 → 趣入阶位」四线索读；六位补特伽罗与八种趣入相最宜对照列表，把握声闻行人由种姓到究竟的完整进路。
