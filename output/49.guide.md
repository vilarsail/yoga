# 瑜伽师地论卷第四十九 导读

## 一、内容总览
本卷含三品，属《本地分·菩萨地》第三持究竟瑜伽处：**地品**依前十三住建立「七地」框架，并说明十种净修地法与菩萨超过恶趣之因；**行品**开列四菩萨行（波罗蜜多、菩提分法、神通、成熟有情），释十波罗蜜多之所以唯立六种；**建立品之一**开始列举如来百四十不共佛法，广明三十二相八十随好之业因、四一切种清净及十力名义。

## 二、结构层次
全卷以「地→行→建立（果）」一线贯穿，由菩萨阶位推至佛果功德：

- **地品（立位）**：依十三住建立七地（前六唯菩萨，第七杂立菩萨如来）→ 问答「胜解行地入净胜意乐地云何超过恶趣」（世间静虑+悲愿代苦→断粗重→得转依）→ 十种净修地法（所治↔能治安立 → 略义二种清净：前三意乐、余七加行 → 次第修证：信→悲→慈→舍→无倦→知论→知世→惭愧→坚力持性→供养如来）。
- **行品（立行）**：四菩萨行总摄一切善行 → 十波罗蜜多别释（后四摄于前六；慧智分二：胜义无分别 vs 世俗有分别）→ 波罗蜜多唯六之建立（三因缘：对治、生起、异熟果；三学：戒心慧普摄一切学道）→ 四所应作事收束。
- **建立品之一（立果）**：百四十不共佛法总列 → 三十二相八十随好广释（先列相好名目 → 逐相明感业 → 归纳为四种善修事业：决定/委悉/恒常/无罪 → 福聚展转倍增感相好乃至法螺相）→ 四一切种清净（所依/所缘/心/智）→ 十力别释（处非处智力居首，自业智力最详，静虑解脱等持等至智力、宿住随念、死生、漏尽各明其相）。

## 三、关键结论
1. 七地中前六唯菩萨地，第七到究竟地杂立菩萨与如来，显示如来位为菩萨行之极果。
2. 菩萨入净胜意乐地时，依世间清净静虑及悲愿力，能代有情受恶趣苦，断粗重得转依，毕竟不堕恶趣。
3. 十种净修地法通治一切地所治法，前三种显意乐清净，余七种显加行清净，有严格次第（信为首，供养如来为终）。
4. 波罗蜜多唯有六种，由对治、生起、异熟果三因缘次第建立，三学（戒心慧）普摄一切菩萨学道，过此更无余法。
5. 如来三十二相以净戒为根本因，由四种善修事业感得；十力中处非处智力最居其首，「处」即如理因，「非处」即不如理因。

## 四、易混辨析
- **慧波罗蜜多 vs 智波罗蜜多**：慧取胜义、无分别转；智取世俗、有分别转。一门分二，对望而立。
- **三十二大丈夫相 vs 八十随好**：相是粗显大相（足下千辐轮、无见顶相等），好是随顺相、令端严的细妙相（手足指节殊妙等）；相以净戒为因，好由福聚展转倍增所感。
- **七地 vs 十三住**：十三住是能行人，七地是所依地；前六住配前六地，第七最上成满菩萨住+如来住合为到究竟地。
- **决定地 vs 决定行地**：决定地即无加行无功用无相住，堕第三决定；决定行地即无碍解住，于决定地上更修四无碍解等胜行。

## 五、阅读提示
读时把握「地—行—果」三段一线：地品定阶位，行品明所修，建立品显果德。相好业因部分留意「四种善修事业」的归纳作用；十力部分可对照前文威力品与菩提品，以「处非处」为纲统摄余九力。
