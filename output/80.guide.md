# 瑜伽师地论卷第八十 导读

## 一、内容总览

本卷为《瑜伽师地论》卷第八十，是「摄决择分」的收官之卷，含「菩萨地决择之九」与「有余依、无余依二地决择」两大块。前半承接前卷，进一步决择菩萨正行所学、四种声闻与菩萨之别、世间出世间智、三学、善不善学沙门、世俗胜义律仪、如来调伏与密意语言等菩萨地余义；后半以问答体决择二涅槃界的离系、寿行、转依、差别及回向菩提声闻等义，并以「方隅所学教导」作整部摄决择分的总结。

## 二、结构层次

全文以「菩萨地余义 → 二涅槃地决择」两大段贯穿，前段散论，后段问答：

- **菩萨正行所学（总起）**：以「云何菩萨于正行中安立所学」开题 → 立**十三中道行**为正修纲领 → 逐一条贯（补特伽罗空性 → 无我性 → 法空性 → 法无我性 → 增益损减二边 → 法现观 → 回向大菩提 → 不缠绕心 → 胜解差别 → 因性 → 到边际空性 → 空性威德），形成「空—无我—二边—现观—究竟」层层推进。
- **声闻与菩萨差别（对比）**：先列四种声闻（变化、增上慢、回向菩提、一向趣寂）↔ 再以十三相、二王子喻显菩萨胜于声闻，归结「诸声闻依菩萨生，非诸菩萨依彼声闻」。
- **利他三智三学（应用）**：世间智止息粗/中品杂染 → 出世间智断微细随眠 → 三学加行（戒、心、慧）→ 善学/不善学沙门 ↔ 世俗/胜义律仪 → 诸戏论法皆悉寂静即无漏尸罗。
- **如来教导与密意（收束菩萨地）**：如来调伏方便（自体同分、胜解同分）→ 密意语言以无二相智悟入 → 论/果/果胜利三种圆满 → 菩萨藏胜解胜利映蔽世间富贵因。
- **二涅槃地决择（问答收尾）**：嗢拖南总标六门 → 以「问—答」展开：现在转时离系、寿行、转依与六处异不异、二涅槃差别、无余界常乐自在、回向菩提声闻增寿发大菩提 → 末以「不定种性」与「如来秘密不可思议」收束，全论摄决择分以「方隅所学教导」作结。

## 三、关键结论

1. 菩萨正行以贯穿十三中道行为纲，从补特伽罗空性到空性威德层层深入，以「业烦恼断对治」为究竟。
2. 声闻有四种，与菩萨有十三差别；菩萨虽未到究竟，威德智慧已映蔽一切声闻独觉。
3. 转依与六处「异不异性俱不可说」，以真如清净所显故；无余依涅槃界中转依当言是有、是常、是乐（胜义乐）。
4. 无余依界中无有差别可立，阿罗汉与如来同离一切障，但阿罗汉阙本弘愿、种性尔故，不能作诸佛事。
5. 回向菩提声闻是「不定种性」，唯住有余依界能发大菩提；如来秘密不可思议，胜解行地至十地展转清净。

## 四、易混辨析

- **四种声闻**：变化声闻（佛菩萨化现度他）vs 增上慢声闻（执邪法无我智为净）vs 回向菩提声闻（劣慈种姓、蒙佛觉悟后发大菩提，加行迟钝）vs 一向趣寂声闻（毕竟不能趣大菩提）。
- **增益边 vs 损减边**：增益边即于遍计所执言说自性执为实有（差别增益八相、自性增益）；损减边即于邪法无我性起胜解、执一切法相都无所有——一是「妄加」，一是「妄减」。
- **世俗律仪 vs 胜义律仪**：世俗律仪有四位（虽具六支尸罗而萨迦耶见缠等过失未除、世间清净律仪、未损法无我怖畏、邪法无我胜解及增上慢），仍有戏论法可得；胜义律仪即出世间烦恼不相应、能对治三界之尸罗，诸戏论法皆悉寂静，即无漏尸罗。
- **有余依涅槃 vs 无余依涅槃**：有余依堕众数、犹有众苦、转依与六处相应；无余依不堕众数、永离众苦、转依永不与六处相应。

## 五、阅读提示

建议先抓住「十三中道行」与「四种声闻」两块骨架；读二涅槃界问答时，把「转依与六处异不异」作为枢纽贯穿始终；末段「回向菩提声闻」要注意「不定种性」与「增寿行」两关，方能理解声闻回心向大的可能条件。
