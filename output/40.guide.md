# 瑜伽师地论卷第四十 导读

## 一、内容总览

本卷为《瑜伽师地论·本地分菩萨地》戒品之首（戒品第十之一），是瑜伽行派菩萨戒的根本所依。全卷以九相戒为框架，先标总名，次释自性戒与一切戒（即三聚净戒），复明受戒羯磨与十方佛菩萨作证之仪则，终出四他胜处法及舍戒条件——奠定了菩萨戒「以菩提心为体、可重受、不共声闻」的根本特质。

## 二、结构层次

本卷以「颂偈总标 → 别释二戒 → 受戒法 → 他胜处法 → 舍戒」一线推进：

- **总标九相（P1-P3）**：嗢拖南颂出九相戒名 → 长行复述一过，立全卷框架。
- **别释自性戒（P4-P8）**：四功德（从他正受、善净意乐、犯已还净、深敬专念）→ 辨「二法为因、二法所引」的能所关系 → 由惭愧防护尸罗 → 离诸恶作 → 结显自性戒具妙善、无量、饶益、大果四义。过渡句「云何菩萨一切戒」转入下文。
- **别释一切戒（P9-P52）**：先二分（在家/出家）→ 开三聚（律仪、摄善法、饶益有情）→ 复以「云何菩萨住律仪戒」等层层展开三戒之行相：
  - **住律仪戒**：舍转轮王出家 → 不味未来现在妙欲 → 勤修等持 → 防护不正言论寻思 → 不惧难行学处 → 堪忍加害 → 五支不放逸 → 十支成就。
  - **住摄善法戒**：不忍受五过（顾恋身财、犯戒根本烦恼、恚害怨恨、懈怠懒惰、等至味着）↔ 五处如实了知（善果、善因、倒与无倒、摄善法障）。
  - **住饶益有情戒**：十一相一一成就一切种（助伴、说理、报恩、济怖、解忧、施资具、与依止、随心转、显实德、调伏、现神通）。
- **受戒法（P53-P61）**：访求同法菩萨 → 礼请启白 → 供养十方佛菩萨 → 对佛前三说羯磨 → 十方佛菩萨法尔作证 → 受后专谛思惟、听闻素怛缆藏摩怛履迦。↔ 反显不堪受者（无信、悭贪、毁戒、忿恨、懒惰、散乱、愚痴谤法）。
- **他胜处法与舍戒（P68-P77）**：列四重戒（自赞毁他、悭财悭法、嗔不受谏、谤法建像似正法）→ 缠犯轻重判舍不舍（软中品不舍、上品即舍）→ 与声闻对比（菩萨舍后可重受、声闻不可）→ 结明转身不舍、忘失重受「非新受亦不新得」。

## 三、关键结论

1. 菩萨戒以九相统摄，而其实质在三聚净戒——律仪（止恶）、摄善法（修善）、饶益有情（利他），三聚圆融即菩萨戒不共声闻之体。
2. 自性戒四功德中，「从他正受」「善净意乐」是因法，「犯已还净」「深敬专念」是所引；由惭愧防护尸罗、离诸恶作，成妙善净戒。
3. 菩萨律仪戒虽依七众别解脱律仪，然以菩提心为根本——舍转轮王位、不味天上妙欲、不顾现在利养，与声闻律仪体性迥别。
4. 受菩萨戒须从有智有力的同法菩萨受，三说羯磨，十方佛菩萨法尔作证；谤菩萨藏者不应率尔宣说，恐其不信反生诽谤聚罪。
5. 四他胜处法是菩萨重戒；软中品缠犯不舍戒、上品缠犯即舍，舍后现法可更重受——此与声闻犯他胜法即永弃不可更受，根本不同。

## 四、易混辨析

- **律仪戒 vs 摄善法戒 vs 饶益有情戒**：律仪戒重在防禁恶行（止恶），以七众别解脱律仪为体；摄善法戒重在积集一切善法（修善），由闻思修乃至回向菩提；饶益有情戒重在利他，以十一相成熟有情。三聚一体，非次第别修。
- **他胜处法（菩萨）vs 他胜法（声闻）**：菩萨四他胜处法为自赞毁他、悭财悭法、嗔不受谏、谤法建像似正法，体即损他谤法；声闻四他胜为杀盗淫妄，体即损自根本。声闻犯即永弃不可更受，菩萨软中品缠犯可悔、上品缠犯舍后可重受。
- **舍戒二缘 vs 不舍戒**：舍戒由二缘——弃舍无上菩提大愿、现行上品缠犯他胜处法；不舍戒——转身十方在在生处，不舍菩提大愿、不现行上品缠犯。忘失本念值善友觉悟重受者，「非新受亦不新得」，以戒体未曾失故。
- **坚固菩萨 vs 相似菩萨**：坚固菩萨堪受净戒——以慧观察自所意乐、堪能思择、非唯他劝非为胜他；相似菩萨——犯四他胜处法之一、不能增长菩提资粮、意乐不清净，名相似而非真。

## 五、阅读提示

建议先记九相与三聚净戒的对应（自性戒明戒体，一切戒开三聚广明戒相，难行以下六相是三聚的殊胜相，详在后文），再随文辨析「住」三戒的行相细节，最后聚焦受戒羯磨与他胜处法的舍戒差别——这是本卷菩萨戒与声闻戒的根本分野，也是菩萨戒「可重受、不舍戒体」特质的所依。
