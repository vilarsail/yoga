- **全篇总括**：本卷是〈思所成地〉第四节，体裁是论议：逐首讲偈颂，每段固定三拍——偈颂点题、长行解释、末尾「略义」收束。二十多颂都在说一件事——心：起步要会说话、修五德、勤多闻；对照凡圣看清染净差异；诊断众生普遍的束缚；给出调心的路线与工具；最后解剖欲望的机制，以一首总颂收尾。
  - **入门三门：动手修行之前，说话、做人、学习各要什么底子**
    - **开篇三颂**：都指向起步阶段的基本功，在家出家一体适用：先管住嘴（善语），再立住身（信惭戒施法五德），最后靠多闻升级认知
    - **善语颂：什么才算「善的说法」**
      - **善语三标准全部成立才叫善说**：悦意（让人听了欢喜）、无染（自己的戒行无缺口）、唯善（能把人从坏处境引到好处境，带来利益与安乐）
      - **按「爱语、谛语、法语」组合出高下**：只有爱语是花言称赞假德；只有谛语是怀着嗔心用粗恶话讲真过错；最高是法语——不乱赞也不乱骂，只善巧说正法把人引向善处
    - **五德颂：去善处要带的五件行李（信、惭、戒、施、法）**
      - **公式**：对佛法生正信 → 耻于居家放逸（惭）→ 受持净戒、少欲知足 → 利养不私藏，与同行共享（施）→ 受持研寻正法并传授他人（法）
      - **收益三档**：最低被善人称赞；福德（戒与财施）、智慧（法施）两种资粮圆满则生于清净天中，未圆满也保证身坏后生善趣天上；论文另给简版讲法——信恶戒堕恶趣、悭贪得贫穷报，由羞耻而改过行施，同样现世被赞、来世生天
    - **多闻颂：能知法、能远恶、能舍无义、能得涅槃**
      - **两级课程**：初级「施论、戒论、生天之论」让人认清恶行是苦因 → 得乐舍苦；高级「四圣谛教法」让人认清生死是苦、涅槃是寂静
      - **高级课的兑现看根机**：根熟资粮满者一闻即入现观（直接亲证四谛）乃至漏尽（烦恼断尽）；未熟者也不白学，仍能依戒起定、依定发慧，渐次证涅槃
  - **凡圣对照：什么染不上圣者，什么缠住了凡夫**
    - **讲完起步功课，镜头转向「心被什么决定」**：先画圣者不受染的三个样板，再看凡夫认错佛、心王被染、心城失守的连环病相
    - **虚空·帝幢·清凉池三喻：三种修行人各长什么样**
      - **一个比喻对应一种心的自由度**：阿罗汉（烦恼断尽的圣者）如虚空——顺逆世间法（利养、衰损乃至苦乐）都染不上；向阿罗汉果的有学（已见真理、还需修学的圣者）如帝幢——修无相心三摩地（心不住任何相状的定）时，傲慢、戏论、求生之愿带起的贪爱都摇不动他；不还果（不再回欲界受生的圣者）如清凉池中的泳者——贪着滋味的爱味定与生死热淤泥都不再欣乐
      - **论文再换角度归类**：阿罗汉吃饭、说话、行走都住「无相」中，但仍被残余身命之苦随逐；又可按慧解脱（凭慧断惑）、身证（有学一类）、俱解脱（定慧俱成）三类分判
    - **以色量我颂：靠长相和声音找不到佛**
      - **颂文**：按「内了知与否 × 外能见与否」排成四格：内外俱知者「非音声所引」；只内知、只外见、内外皆无三种，都被人言牵着走
      - **病例与变体**：带欲贪的凡夫见佛三十二相便断定「这是佛」，后来亲近恶人、听不正法，反毁谤佛法僧——根子是不如实知如来法身（佛的真实体性）；得定的天眼看佛、欲界业报的肉眼见佛，结局同样随他言转；完全看不见的人则终生被声音牵引
      - **贤圣的正解**：得圣慧眼，于内亲证法身；见色身、佛塔、画像也知道那不是第一义的觉者——所以不随他论，于三宝决定信受
      - **略义**：以世俗表象见如来不保险，以胜义（法身）见如来才决定
    - **第六增上王颂：最难渡的是第六条瀑流**
      - **「第六增上王」就是心意识**：五根对应的五条瀑流已渡，第六条意的瀑流（对禅定滋味的爱染）还在——这就是「染时」
      - **「染自取」**：长夜把染污攥为己有，贪本身是染，贪招来的后世苦也叫染；解法只有一道闸门——修意对治作意（对治心染的作意功夫）把染挡下 → 现在心无染、后世苦也无染，不修这功夫即长夜受苦的愚夫
    - **骨城颂：这座心城被四个坏管家把持**
      - **城=心意识**：骨头当砖、筋当绳、肉当泥灰——身体只是围住心的骨架工事
      - **四个恶法任持此城，按身份两两分组**：在家受欲者被贪、嗔把持；在错误教法中出家者被我慢与覆（隐藏己过）把持
      - **后果**：贪嗔者连善法都不信受；慢者不肯亲近佛与弟子；覆者哪怕佛亲自上门也不肯发露己过——四种杂染让在家出家的心城都进不去善法
  - **束缚与出离：谁真正不自由，终点设在哪里**
    - **看完个案，这五颂升级为全景**：先给两个「收放自如」的样板（收摄寻思入深定、佛示现舍寿），再连发三份诊断——普遍的不自在、追求的空转、被魔驱役的实况
    - **龟藏支颂：收摄寻思，如龟缩壳**
      - **功夫次第**：依初静虑先舍欲、恚、害三种恶寻思，再舍初静虑里「好的」寻思，安住无寻无伺定（没有粗细心理活动的定，往上直到有顶——三有的最高处）
      - **纪律与收获**：住定时对定境不生爱味；出定后调顺柔和、不恼同行、无人争讼——由此入现观、得漏尽，凭自己善净的智见分清法与非法，不颠倒毁谤
      - **略义点题**：这一颂给出断除四种扰乱的道——染污与不染污的寻思、对胜定的爱味、互相争讼、对正道的诽谤
    - **等不等而生颂：连佛的涅槃都在示范「舍」**
      - 佛成道时的色身与做菩萨时正相等（三十二相八十随好依旧），名身（心与心所的精神一面）却因殊胜无漏（离烦恼的清净品质）而不等；他又依定自在以定力主动舍掉剩余寿命与三有之行，不满寿量而入涅槃——如鸡破卵，同种渐长、破壳而出
    - **无淤泥等欲颂：四种失控的对照表（陷淤泥、被鬼魅附、入罗网、堕急流）**
      - **世间现见的四种失控正好对应四种真实的失控**：欲——沉溺臭秽诸欲之泥，不能自在修善；嗔——出家后忿怒粗言，刺伤同行智者；痴——在错误教法中出家，钻进恶魔的邪见罗网；爱——已到上界离欲之地，爱结未断，仍顺流堕回下界
      - **略义**：这是各界各类愚夫的缠缚清单；论文另配四味药——清净出家、远离恚害、敬事父母、乐行惠施
    - **虚空无鸟迹颂：三种人生追求，两种注定落空**
      - **三种求**：欲求（求妙欲）、有求（求胜妙之身）、梵行求（求沙门解脱的修行）；前两种靠布施持戒换天上妙欲妙身——如鸟翔空无处落脚，在无常的欲与身中安住不了
      - **梵行求也分岔**：依错误教法的外道没有真沙门；依正确教法却动机不纯（邪梵行求）也没有；只有正梵行求才有沙门——三门追求都算戏论（无实义的言说思辨），如来弃舍一切希求故无戏论
    - **住戏论皆无颂：阿罗汉为何连天人都不认识**
      - 阿罗汉离爱解脱、随意游行，愚夫遇见却不识，反在两处轻毁：弃自财乞食是傻、不求生天只求断灭也是傻——其实连他们事奉的天神都看不懂这位圣者
      - **愚夫被魔王驱役的四相由重到轻**：被四识住（识安住的四种处所）驱使在五趣往来；由增益或损减的恶见造恶堕恶趣；被欲爱高墙困在欲界；生到色无色界又被无明深堑围困在生死牢狱——略义：愚夫把不该羞的当羞、该羞的不羞；不该怕的怕、该怕的不怕
  - **修行路线：从解除四轭到「诸恶莫作」，一步一步怎么走**
    - **诊断完毕，连排四颂给出可执行的路线**：逐层定境解除四轭 → 净信者的四种正行 → 「诸恶莫作」总纲 → 调伏那颗轻躁的心
    - **四轭颂：一层定拆一道轭**
      - **阶梯公式**：依初静虑除欲界恶寻思 → 依第二静虑离初静虑的分别 → 依第三静虑超脱「喜」的碍着 → 依第四静虑超脱「乐」的碍着 → 依无色定超脱一切色想；拆下的是染污寻思、不染污寻思、喜乐系缚、一切色想四轭——拆净后不再往生下地，而凡夫哪怕定生到有顶仍会掉回下界，这就是有学与凡夫的差距
    - **惠施令福增颂：净信者的四种正行**
      - **路线**：居家时离悭垢、受持七种依福业事（布施类的福德事）→ 感财富；出家后修忍护戒、心无恶言、慈心遍满一方 → 灭怨害、生善趣；依戒起定、依定发慧 → 入现观永舍恶趣业，渐除诸结，先证有余依涅槃（带着残余身命的解脱），后证无余依涅槃（连身命也寂灭）
      - **略义归并为四行**：感财富行、感善趣行、离恶趣苦的清净修行、离一切苦的清净修行
    - **诸恶莫作颂：全部圣教的总纲**
      - **三步走**：诸恶断尽（一切因缘、一切处所的恶行都不做）→ 众善奉行（善住戒律，依戒起定、依定发慧，如实知见）→ 自调伏其心（如实知 → 厌患 → 离染 → 解脱）
      - **略义强调**：三学（戒、定、慧）及其果利，是佛陀圣教不与其他教法共有的标识
    - **难调伏颂：心难调，调了就安乐**
      - **病历**：心长夜贪爱热闹，硬按在修行里也会迅速回弹——贪嗔痴与掉举（心躁动不静）反复生起；硬按在寂静里，仍贪恋五欲、驰趣沉没
      - **药方与果**：圣弟子不放纵这颗生苦的心，反复思择、成办远离，恒修心一境性（定）；由正定如实知 → 厌患 → 离染 → 解脱——现法安乐住，当来众苦永尽
  - **调心核心：用什么工具、什么人算调成、心本身长什么样**
    - **路线讲完，聚焦操作层面**：止、举、舍的调心旋钮，真苾刍的验收清单，最后直接解剖心本身的四个侧面
    - **于心相善知颂：止、举、舍三个旋钮与四种功德**
      - **前提**：已见真理的有学善知止举舍相——何时把心沉静（止）、何时把心提起（举）、何时平等放舍（舍）
      - **由此得四功德**：止（奢摩他）得身心安乐；由净定心起观（毗钵舍那）审思法理；以止观为底恒修菩提分法（趋向觉悟的修行项目）无懈无惮；终得正念正知、心善解脱，受用解脱喜乐
    - **无工巧活颂：真苾刍的验收标准是五加五**
      - **成就五支（该有的都有）**：不搞邪命自活、不攀权贵名声；减省物欲、衣仅蔽身食才充腹；敬慕沙门与学处，命难也不破戒；修方便入现观或速遣恶寻；于一切结缚随眠（烦恼及其潜伏种子）心得解脱
      - **永断五支（不该做的永远不会做）**：不舍学处退转、不积财执为己有、不受用欲境、不为财命妄语、不犯梵行，也不持自作他作无因生等苦乐邪见
    - **心远行颂：给心做一次全面体检**
      - **四相逐一解释**：远行——过去无量世换过无数身体，没有作者却在生死里流转，起点不可知；独行——现在的心一个刹那只生一个，没有同伴；无身——心不像五根那样定性延续，刹那间种种品类生灭，染污的实体并不成立；寐于窟——未来的心带着随眠住在四识住里，预备来生往来
      - 能以总慧如实知过现未三世心，修厌、离、灭、心解脱，超越萨迦耶见（执身为我的见）到彼岸者，才叫婆罗门
      - **略义的三时判**：过去心长夜染污而无作者；现在心刹那自性清净；未来心随放逸与否而染污或清净
    - **谁能覆世间颂：一问一答的护心课**
      - **阿氏多所问的四问四答**：无明覆世间、放逸令不显、戏论涂染、苦为大怖畏；念能止诸漏、慧能堰塞诸流
      - **再追问到底**：念慧与名色何时灭尽？——诸识永灭时；如何让识灭？——对内外一切受都不生欣乐；什么样的人能行？——不耽着诸欲、心无浊染、于法巧念的比丘
      - **三种人各从一扇门漏苦**：恶说法者从无明门、在家从戏论门、善说法者从放逸门；对治分两级——以念逆流遮止是伏对治，以无漏慧彻底堰塞是断对治，合称防护
      - **结局分两档**：阿罗汉已显了，无须再作不放逸功夫，只等寿尽识灭、名色随灭；有学应显了，还须常时、周密地修不放逸——不耽诸欲故下分结（系于下界的烦恼结）不能染，心无浊故上分结（系于上界的烦恼结）不能染；略义：在家与恶说法出家者决定杂染，善说法出家者放逸堕染污品、不放逸堕清净品
  - **欲望解剖与收尾：欲钩怎么起作用，梵行怎么算圆满**
    - **最后回到最切身的对象**：先逐层拆解欲望的机制，再以贤善梵行的五相收束；卷末以一首总颂把整组论议的主题串成「论议十四种」，为全卷收束定卷
    - **义品诸欲颂：爱味、过患、出离三分账**
      - **三种自性**：爱味——希求、获得、受用诸欲时生的喜乐；过患——退失时爱箭入心如中毒箭，大忧苦甚至丧命；出离——远离爱味如避毒蛇之首，调伏断灭对色乃至触的贪爱
      - **欲望分两层**：事欲是对象（求谷靠田、求财靠金银；经商用宝珠环钏、受用有女色僮仆陪伴），烦恼欲是对对象的贪着——依耽着识起种种妄分别贪
      - **危害与出离对照**：烦恼欲使心沉没下劣，事欲变坏时愁悲缠心如破船进水，招来未来生老病死之苦；出离则断除染污识如砍多罗树顶不再生长，事欲变坏时清净识不住忧苦，如莲叶水滴不沾
    - **贤善颂：清净梵行的五相验收**
      - **前三相是对三世的正确姿态**：对过去无恋、不追恋不舍；对未来不希求人天果报；对现在五取蕴正观——遍观三世无常 → 苦 → 无我，不执为我与我所
      - **后两相是成果**：依初观智，福德智慧资粮增长，君王也劫夺不走；依第二观智，涅槃功德增长，烦恼也动摇不了——按此哪怕只修一日一夜，也是贤善中的第一贤善，超过其余一切梵行
