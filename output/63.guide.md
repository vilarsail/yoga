# 瑜伽师地论卷第六十三 导读

## 一、内容总览

本卷属《瑜伽师地论》「摄决择分」，承接前卷对三摩呬多地的决择，并依次决择「非三摩呬多地」「有心地」「无心地」三地。主旨是对四类与「心—定」相关的地类作深入决择：先讲定的障碍与支分建立（三摩呬多地续），次讲未到定之种种相状与对治（非三摩呬多地），再揭明心识的所依能依与染净差别（有心地），最后论心不生的七种因缘（无心地）。一线贯之即「定之成坏 → 识之染净 → 心之生不生」。

## 二、结构层次

全卷四地决择，前后以「如是已说……决择我今当说」互相钩连，呈层层递进：

- **三摩呬多地之二（P1–P65）**——定的障碍、支分与退相，内分三线：
  - 障碍 → 先列定相违法、三种远离，次明心清净行苾刍的五种厚重过失（忿、慢、欲贪、萨迦耶见、不能堪忍），并指其分障初定、谛现观、入根本定三阶（P3–P12）；
  - 支分建立 → 由嗢拖南（数、所对治、支分广建立、远离、苦散动、上支分差别）总摄，再逐问答：何故唯四静虑、各治何障、各几支、何故立五支四支、初二等静虑差别、四种修定为四补特伽罗所建立、六种离欲、静虑名住/三摩地/奢摩他/心一境性之由（P13–P52）；
  - 退相 → 十种从离欲退之因缘，配四种补特伽罗（烦恼善法上下品）的退入迟速，明出定闻声之机制（P53–P65）。
- **非三摩呬多地（P66–P84）** → 立「自性、阙轻安、未发趣、散乱、太聚、未得、未圆满、杂染、不自在、不清净、出定、退」十二种不定地，再一一配以对治方便（取不净相、勤修作意、护念正知、思惟净妙、观过失、无间修、谛善巧、不放逸、修远离等）。
- **有心地（P85–P108）** → 五相建立诸心差别：世俗 → 胜义（阿赖耶识为所依、转识为能依，心意识名义与八识俱转）→ 俱有（与三受相应）→ 染净（末那恒与四任运烦恼俱，世间道不能伏，唯出世间道能伏，有学无学差别）。
- **无心地（P109–P119）** → 以「心不生因有七」立纲：缘阙、作意阙、未得、相违、断、灭、已生，反此七因缘则心可生。

## 三、关键结论

1. 定之障碍有粗细层次：忿、慢、欲贪障初定，萨迦耶见障谛现观，不能堪忍障入根本定——同一「心清净行」中分三阶对治。
2. 四静虑唯立四支或五支，是为对治缺减、逼恼、流散三类杂染住，亦如受欲者求财、受用、自在三事之相似建立。
3. 末那恒与萨迦耶见、我慢、我爱、不共无明四种任运烦恼相应，世间离欲不能损伏，唯出世间道现前方伏，至无学位方永不现行。
4. 阿赖耶识与转识如水浪与暴流、影像与明镜，是所依能依关系；八识可于一时俱转。
5. 心不生不出七因（缘阙、作意阙、未得、相违、断、灭、已生），反此心即得生——是从反面显心之缘起。

## 四、易混辨析

- **三摩呬多地 vs 非三摩呬多地**：前者是已得平等安心之地（定地），论定之支分与障碍；后者是未发趣、散乱、未得、杂染、退等十二相之不定地，反向论未到定之相状与对治。
- **有心地 vs 无心地**：有心地从「心差别而转」立五相（世俗、胜义、所依能依、俱有、染净），无心地则从「心不生」立七因；一正明显起之相，一反显不生之因。
- **世俗道理 vs 胜义道理**：世俗依名相假立（如前意地已说），胜义就所依能依实相立——阿赖耶识为所依、转识为能依，以水浪、明镜为喻。
- **自性离欲 vs 对治离欲**：前者是对自性不净、苦受、寻伺等境事之厌背（随境而起之厌离），后者是由厌坏、断、持、远分四种对治断烦恼而起之离欲。

## 五、阅读提示

带着两个问题读：①四静虑的「支分」为何如此建立？它在回答什么问题？②末那的四烦恼为何「世间治道不能损伏」？这与「心不生七因」中的「断」有何呼应？
