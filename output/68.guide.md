# 瑜伽师地论卷第六十八 导读

## 一、内容总览

本卷属《瑜伽师地论·摄决择分》中对「声闻地」的决择（之二），紧接前卷对四谛中苦、集二谛的讨论，进一步决择灭谛与道谛的体相、差别与修证，并广明毗奈耶（戒律）的种种建立。全卷以「四谛决择」与「毗奈耶决择」两大块构成：前半由灭谛、道谛入手，展开正见的十一种差别、修道对治、现观与断证；后半以偈颂统摄毗奈耶七处，广释犯相、出罪、尸罗功德过失、十时不放逸、摄受清净等，是一部贯通「慧学」与「戒学」的决择要典。

## 二、结构层次

全卷以「灭谛 → 道谛 → 正见差别 → 现观断证 → 毗奈耶建立」为主线，由理入事、由慧至戒：

- **灭谛决择（P1-P6）**：先以问答界定「诸行寂灭」与「灭谛」的宽狭关系（灭谛必寂灭，寂灭未必灭谛）→ 次明灭谛以「烦恼灭」「依灭」立有余、无余二种 → 再以「四过失」（增益、自相邪分别、相杂乱、损减）遮遣对灭谛的四种邪执。
- **道谛决择（P7-P12）**：先释唯以「正见为先八圣支道」为道谛的理由——三学摄八支 → 次将八支配三蕴：正语业命属戒蕴（受用法、受用财二因）、正见思惟精进属慧蕴（通达真义、为他宣说、法随法行三业）、正念正定属定蕴（自性与四所依）。
- **正见差别与修道对治（P13-P25）**：先列十一正见——苦谛下八见（如病如痈如箭如障、无常苦空无我）+ 集/灭/道各一（结见、离系见、能离结见）→ 次辨先说「如病等」的次第依于已得道者 → 次配三三昧（空、无愿、无相）→ 次明修道中出世道总治三界烦恼、多修无相行 → 末以「苦谛应遍知、集谛应永断」收束四谛行相之别。
- **现观与断证（P26-P28）**：立智现观、断现观二种 → 五种发正精进因缘 → 二种断作证（伏断、永断）与二种离系。
- **谄曲过患（P29-P35）**：由「勿行谄诳」一诫引入 → 列十二过患 → 欲界谄有八行、七事，逐一释相。此段转入「学处违犯之相」的检视。
- **粗语声闻（P36-P41）**：九种粗语之相 → 配二种举罪补特伽罗。
- **毗奈耶总纲（P42-P59）**：以嗢拖南颂「摄制立尸罗、无逸障学观、依摄受受用、甚深说喻事」总括 → 略七处（教敕、开听、制止、犯处、有犯、无犯、出罪）→ 广释十八犯处、五犯聚、九种犯、四无犯、五相出罪 → 次列十种制立学处清净、十种尸罗过失、十种尸罗功德。
- **十时不放逸（P59-P77）**：于毗奈耶勤学苾刍，依犯、定、生、乞食、所作、受用利养、求多闻、思正法、远离、通达究竟十时修不放逸，逐一广释行相。
- **出家障与持律观察（P78-P87）**：四种障能障出家 → 五处应学 → 六种差别所犯成重（制立、事、穿穴、烦恼、智、时）→ 持律者以五相观察所犯。
- **依止修加行与摄受清净（P88-P109）**：依止七处于六处中修加行 → 五种摄受（属己、承受、委寄、舍施、为他）各以二因缘明净不净 → 五因缘所受用事不清净收束全卷。

## 三、关键结论

1. 灭谛是「证所显、非生所显」，无生无灭故常；说灭谛须离增益、损减等四过失。
2. 八圣支道统摄于戒、定、慧三蕴，正见为前导，三学圆满即道谛。
3. 十一正见中，苦谛下八见为「缘苦谛正见」，集、灭、道各配一见；空行即空行见、无相行即离系见、余为无愿行。
4. 修道中出世道总缘四谛、总治三界烦恼，以无相行最能引发现法乐住。
5. 毗奈耶略七处摄尽别解脱，犯、无犯、出罪各有其相；持律须以五相观察所犯，方断其罪。

## 四、易混辨析

- **灭谛 vs 诸行寂灭**：灭谛必是诸行寂灭，而诸行寂灭未必是灭谛——由无常灭、非择灭所得寂灭非灭谛，唯烦恼灭、依灭所显方为灭谛。
- **增益过失 vs 损减过失**：于诸行尽灭言「有异」是增益（添执实体），言「非有异非无异」是损减（拨无差别）；「无异」是自相邪分别，「亦有异亦无异」是相杂乱。
- **性罪 vs 遮罪**：性罪是自性不善（如杀生等），违善之遮罪是佛制方犯；性罪应一向不犯，遮罪则观方时人有制立依处。
- **伏断作证 vs 永断作证**：伏断仅伏种子现行，永断则断种子令不重生；离系亦分「烦恼品别离系」与「烦恼事相属离系」二种。
- **有余依灭谛 vs 无余依灭谛**：烦恼灭故得有余依（身心犹在），依灭故得无余依（身心已尽）。

## 五、阅读提示

读本卷可带着两个问题：① 佛说四谛，为何唯苦谛称「应遍知」、唯集谛称「应永断」？② 毗奈耶建立繁复，七处如何统摄一切别解脱？顺着「灭谛→道谛→正见→现观→戒律」的次第，可看见由慧入戒、由理入事的一条贯通脉络。
