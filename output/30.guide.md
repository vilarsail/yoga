# 瑜伽师地论卷第三十 导读

## 一、内容总览
本卷为「声闻地第三瑜伽处之一」，由前瑜伽处之补特伽罗品类所缘等转入正修行次第，先明往庆问寻求安立五处，次广辨心一境性（九心住、四作意、四毗钵舍那、六事差别所缘），最后详述不净观与慈愍观的六事差别所缘毗钵舍那。九心住与六事差别所缘是本卷核心，为声闻地奢摩他毗钵舍那修法的根本教授。

## 二、结构层次
全卷按「往庆问寻求 → 五处安立 → 心一境性 → 不净慈愍六事差别」推进：
- **往庆问寻求（P1-P17）**：先四处安住正念往诣师所 → 师赞励庆慰 → 四种审问处法（归三宝/净尸罗正直见/闻四圣谛/信涅槃寂灭）→ 于愿种姓根行四处以审问/言论/所作/知他心差别智寻求。
- **五处安立（P18-P29）**：①护养定资粮 ②远离处（处所圆满五种、威仪圆满结跏趺坐、身远离心远离）。
- **心一境性（P30-P46）**：数数随念同分所缘流注无罪适悦相应 → 九种心住（内住/等住/安住/近住/调顺/寂静/最极寂静/专注一趣/等持）→ 六力成办 → 四作意配位（力励/有间缺/无间缺/无功用）。
- **四毗钵舍那（P47-P57）**：正思择/最极思择/周遍寻思/周遍伺察 → 三门（唯随相行/随寻思行/随伺察行）→ 六事差别所缘（义/事/相/品/时/理）→ 三觉建立（语义觉/事边际觉/如实觉）。
- **不净观六事差别（P58-P74）**：寻思义 → 寻思事（内及外）→ 寻思自相（内地水二界、外三种变坏）→ 寻思共相 → 寻思品（黑品白品）→ 寻思时 → 寻思理。
- **慈愍观六事差别（P75-P85）**：寻思义（与乐）→ 寻思事（亲怨中三品）→ 寻思自相 → 寻思共相（怨亲无决定发起平等性心）→ 寻思品 → 寻思时 → 寻思理。
以「往师 → 安立五处 → 止观体 → 二观六事差别」为统一骨架。

## 三、关键结论
1. 初修业者先应四处安住正念往诣师所，师以四种审问处法审问、于愿种姓根行四处四因缘寻求，然后于五处安立。
2. 九种心住：内住、等住、安住、近住、调顺、寂静、最极寂静、专注一趣、等持；由六力成办——听闻思惟力（内住等住）、忆念力（安住近住）、正知力（调顺寂静）、精进力（最极寂静专注一趣）、串习力（等持）。
3. 四作意配九心住：力励配内住等住、有间缺配安住乃至最极寂静、无间缺配专注一趣、无功用配等持。
4. 四毗钵舍那：正思择尽所有性、最极思择如所有性、周遍寻思取相状、周遍伺察审谛推求；三门六事差别摄一切毗钵舍那。
5. 六事差别所缘：义、事、相（自相共相）、品（黑白）、时（三世）、理（观待/作用/证成/法尔四道理）；依三觉建立。
7. 慈愍观寻思共相：怨亲无决定真实、无始流转互为亲故，于一切有情发起平等性心相似利益意乐。

## 四、易混辨析
- **九心住 vs 四作意**：九心住约心安住相差别，四作意约修习运转差别；力励配初二、有间缺配中五、无间缺配第八、无功用配第九等持。
- **奢摩他品 vs 毗钵舍那品**：奢摩他品约九心住寂静其心，毗钵舍那品约四种慧行观察简择；同以四作意修习。
- **正思择 vs 最极思择**：正思择尽所有性（自相差别），最极思择如所有性（共相真实）。
- **周遍寻思 vs 周遍伺察**：寻思议俱行取相状，伺察审谛推求复审观察，约粗细辨。
- **三门 vs 六事差别所缘**：三门约能观行相粗细，六事约所观境义差别，六事各起三种伺察。

## 五、阅读提示
本卷是声闻地奢摩他毗钵舍那修法根本教授，可带「往师五处安立 → 九心住六力四作意 → 四毗钵舍那三门六事 → 不净慈愍六事差别」四线索读；九心住与四作意配位表、六事差别所缘框架最宜对照把握。
