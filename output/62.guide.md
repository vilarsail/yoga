# 瑜伽师地论卷第六十二 导读

## 一、内容总览
本卷为《瑜伽师地论·摄决择分》中三摩呬多地（等引地）决择的第一部分。三摩呬多地，即「等引」，是十七地中专论禅定的部分。本卷围绕「修定者如何得定、如何不退、如何发通、如何解脱」一线展开：先列举障碍心一境性的多随烦恼及其三类人三处所起，次论十遍处、八解脱、爱味等至、近分定四道六作意等定学要义，再依次释《随身念经》《摩诃俱瑟祉罗经》《法因缘经》三经，最后以眠缠对治与三大性大三摩地收束。本卷是理解唯识定学的关键篇章。

## 二、结构层次
全文按「立障 → 对治 → 显德 → 释经」四段递进，由障到治、由通到别：
- **总起障相**：先以「云何」问答逐条列举障定之多随烦恼（谄、诳、矫、诈、无惭无愧、不信、懈怠乃至唯悕活命等） → 归纳于俱违犯/增上戒/增上心/增上慧四类违犯 → 推及三类补特伽罗依放逸、耽欲、邪行三处起随烦恼。从「列名」到「归类」再到「约人约处」，是「由相到性、由总到别」的展开。
- **定学通义**：以「复次」分段，连续展开定学诸命题——十遍处五事 → 八解脱所显 → 上下地法起与三种断灭 → 三退 → 近分定四道六作意 → 二通互碍 → 四种修静虑者 → 无想/灭尽等至漏无漏辨。各段并列，但内部由「所修」到「所证」到「所除障」层层推进。
- **释经别明**：以三经为骨架层层深入：
  - 《随身念经》：四随烦恼 → 五作意对治 → 三学所依 → 多果清净，作意与所治一一对应，是「对治→证果」的完整链条。
  - 《摩诃俱瑟祉罗经》：慧解脱 ↔ 心解脱 → 世间正见 → 出世正见 → 六寂静，二解脱因果差别以「所对/无所对」为枢纽。
  - 《法因缘经》：八相请问 → 八圣支道三蕴对治 → 五取蕴观察诸受 → 三受皆苦的相对义，归宗于四谛。
- **收束**：眠缠五种对治 → 增上心学离染污寻思 → 六顺出离界 → 三大性大三摩地通达真如，自浅至深收束全卷。

## 三、关键结论
1. 心一境性之失，根本在于多随烦恼，可统摄于戒、心、慧三学违犯之下。
2. 三类补特伽罗依放逸、耽欲、邪行三处起随烦恼，显示烦恼之源不在身分而在所依。
3. 修十遍处乃至识无边处，能引发神通与诸解脱，然识无边处以上不立遍处胜处，由其无量无边不可胜解。
4. 灭尽等至是无漏、非学非无学摄，唯除已入远地菩萨能起出世法而不舍烦恼。
5. 随身念依三学，以多作意对治四随烦恼，证四果、五果、九果清净，是定慧一体的实践纲领。

## 四、易混辨析
- **慧解脱 vs 心解脱**：慧解脱以世间慧为始，由如实了知善恶行及因缘，出世间慧为果；心解脱以心染净所依为始，由心离杂染、诸根清净为果。前者重慧，后者重定。
- **无想等至 vs 灭尽等至**：无想等至唯一有漏，是异生所修；灭尽等至是无漏，唯圣者所行，非学非无学摄，唯远地菩萨能起。
- **方便道/无间道/解脱道/胜进道**：方便道是加功用行之位；无间道是正断烦恼之位，无有间隔；解脱道是已断烦恼证解脱之位；胜进道是更进趣胜境之位。四道次第配近分定六作意。
- **爱味等至之染污 vs 不染污**：于等至起「我当证、我当爱味」者是染污爱；专求离欲欣乐上地寂静者是不染污。

## 五、阅读提示
带着「为何不能得定」的疑问读前半（多随烦恼及三处所起），带着「定中差别与解脱因果」的疑问读后半（等至诸义与三经释）。两线汇于「对治」二字。
