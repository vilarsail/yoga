# 瑜伽师地论卷第七十 导读

## 一、内容总览
本卷为《瑜伽师地论·摄决择分》中「声闻地之四」，继前数卷之后继续决择声闻行者的行持事义。全卷由数十段「复次」组成，呈枚举式结构，依次决择：智光明功德、尸罗律仪与根律仪、于食知量与觉悟瑜伽等行持、神足与定学退因、补特伽罗差别、邬波索迦德与法施财施、僧团驱摈与众生主四支等。主旨在于系统厘清声闻行人从初业到为众之师的种种法相、对治与功德差别。

## 二、结构层次
全卷以「复次」分段，并无单一线索，但可按「戒学—行持—定学—补特伽罗与僧事—众生主四支」五大板块串联：

- **戒学与根律仪（P1–P21）**：智光明十五德胜外光明（赞戒慧功德之总起）→ 三种调善/寂静/寂止/梵志/婆罗门（戒行人品类）→ 尸罗坏四因与戒具足 → 尸罗清净具足三因缘（意乐、命、行）→ 密护根门中妄念四相与不如理作意四相 → 尸罗律仪圆满五因 → 二种对治与四种根律仪。由「戒之体」层层推到「根门防护之用」。
- **行持事义（P22–P33）**：于食知量圆满五因 → 旧受/苦受等义 → 精进圆满（殷重加行 + 无间加行）→ 五处知量正知而住。承接戒学，落到日常四威仪的节度。
- **定学与神足（P34–P43）**：神足断行四支（修习、证胜进、护随烦恼通达、引发能净）→ 定四增上缘（听闻、教授、宿习、多闻）→ 七种法证三摩地（内/外定退及对治）→ 于身观集灭法住。由「加行」转入「定体」与「观慧」。
- **补特伽罗与僧事（P44–P60）**：五种补特伽罗施设 → 邬波索迦三德 → 闻法/行法/究竟证法与外道法对比 → 诸欲得舍次第 → 驱摈犯戒三因 → 心趣远离/出离/涅槃 → 闻法三过与五相为闻修器 → 大师五功德。聚于「能修之人」与「所依之师」。
- **善说链与对治修（P61–P94）**：以无我见为唯一出离道为枢纽 → 四欢喜 → 善说→出离→三菩提→不可坏→窣堵波→可依→如来（一连串「由二因缘」递推）→ 四种能障断法与慧眼盲垢翳 → 法念住十一种杂染 → 出世间道以世间道为助伴 → 如来天眼四相 → 七渐次 → 四念住对治九所治 → 出家在家过失 → 愚夫四相 → 生死大海五相似 → 法施胜财施 → 五心自在 → 烦恼魅甚于鬼魅 → 计我五过 → 爱恚杂染与五种对治。多组并列枚举，归宗于「无我见与对治」。
- **众生主四支（P95–P121）**：四种补特伽罗出家五功德 → 三苦九相 → 苾刍为众主成就四支（解脱随烦恼、不离正智、任持已生善法、任持未生善法），最后广解「解脱五种随烦恼」与「闻思修三智」，收束全卷。

## 三、关键结论
1. 智光明以慧为性，能害内翳、能作一切有情义利，十五德皆胜外光明，为持戒修观之功德总赞。
2. 尸罗坏有四因（毁犯无余罪、不悔除有余罪、不忆念所犯、犯不犯执倒），清净具足则由意乐、命、行三清净而立。
3. 密护根门须先了知妄念四相（阙、劣、失、乱）与不如理作意四相（烦恼生因、与杂染相应、毁坏羞耻、起错乱犯），方能于执取相随好处修防护。
4. 定学退失分内退（懈怠、惛沉睡眠）与外退（掉举、五妙欲散乱），对治依持在光明想；出世间道仍须以世间道隐盖、远分制伏为助伴。
5. 唯无我见能得出离：未曾得故、现能对治烦恼故、现于解脱无怖畏故。
6. 苾刍为众主须成就四支：解脱五种随烦恼、不离正智（八圣支道配闻思修三智）、任持已生善法、任持未生善法。

## 四、易混辨析
- **内定退 vs 外定退**：内定退因懈怠、相为惛沉睡眠，是向内沉没之失；外定退因掉举、相为于五妙欲散乱，是向外流逸之失。对治分别为善取相观察与观身不净，二对治共同依持为光明想。
- **殷重加行 vs 无间加行**：殷重加行约「坐/行」威仪对治五盖（第一二四盖宜坐等），重其修相之厚重；无间加行约「昼夜时分」相续不断，重其刹那无间。二者合为精进圆满。
- **见迹 vs 见趣**：见迹行者欣乐断烦恼障/定障、契圣道迹；见趣行者依外道妄见（我非有等）趣向，到究竟见趣者即非想非非想处，到究竟见迹者即六触处无余永断。
- **财施 vs 法施**：财施起他身恶行烦恼、有罪安乐、有尽；法施起善行、对治烦恼、无罪安乐、无尽，故法施为胜。

## 五、阅读提示
本卷「复次」极多且多为并列枚举，建议按上述五大板块分块阅读，重点关注「戒学—定学—众生主」三段递进；遇「四种」「五种」等枚举时，先抓「所对治」与「能对治」的对应关系，比死记条数更易上手。
