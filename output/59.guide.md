# 瑜伽师地论卷第五十九 导读

## 一、内容总览
本卷为《瑜伽师地论》卷五十九，属「摄决择分」中「有寻有伺等三地」决择的第二部分。全卷以两大主题贯串：前半（P1-P50）决择「烦恼杂染」，从烦恼三相出发，层层展开随眠十八种、粗重十八种、与五受根相应关系、三聚性类、能断差别、缘境现行、结生相续等义；后半（P51-P93）转入「业杂染决择」，以「事、想、欲乐、烦恼、方便究竟」五相建立十不善业道自相，并广辨各业道圆满与不圆满的差别相状。

## 二、结构层次
全文以「烦恼杂染 → 业杂染」为总框架，由内因推至外业，层层递进：

- **烦恼总相开列**（P1-P2）：先明「十烦恼皆能发业」且唯猛利、分别起者发恶趣业 → 立自相、共相、差别相三相，差别相又分「门差别」（结、缚、随眠、缠等）与「转差别」（随眠转、所缘转、现行转等七种）二门。
- **随眠与粗重深辨**（P3-P9）：随眠十八种以成对方式列出（自境/他境、被损/不被损、随增/不随增、可害/不可害等） → 转入粗重体性之辩（与诸行「异」）→ 列粗重十八种（自性异熟/烦恼/业三粗重为基，遍及盖、寻思、愁恼、饮食、眠梦等） → 略述六种转差别相之所指。
- **迷行与受根相应**（P10-P20）：先明七种迷行（萨迦耶见等三于所知境起邪了、无明不了、疑了不了、见取等执邪了） → 逐一决择各烦恼与乐喜忧苦舍五根的相应：先约「任运/不任运」总标，再分辩贪、恚、萨迦耶见、边执见、见取、戒禁取、邪见、慢、疑各与何根相应，最后以「先粗后细」收束。
  ↔ 与前文「迷行转」相接，构成「烦恼如何迷境 → 烦恼如何与受相应」的递进。
- **三聚性类与能断次第**（P21-P37）：三界系三聚判善/无记、多/少性等对比 → 以嗢拖南收束 → 设八问（能断、已断、从何断、顿渐、次第、几种、断相、胜利） → 七种能断差别（资粮、四种瑜伽、相续成熟、了知烦恼、止观、了知所缘） → 见断顿断/修断渐断 → 断已之相（不染着、少欲喜足等）与胜利（超越忧苦、现法乐住等）。
- **缘境、现行、结生**（P38-P50）：缘境十五种（具分/一分、有事/无事、内/外、自境/他境/无境等） → 现行二十种（二十补特伽罗 × 二十现行 × 二十缘，三重配列） → 结生相续（一切烦恼皆结生，七或九种差别） → 嗢拖南「业相事乐等」总结烦恼杂染。
- **业杂染决择**（P51-P93）：由「五相」（事、想、欲乐、烦恼、方便究竟）建立十不善业道自相 → 逐一广辨杀生至邪见十业道的事、想、欲乐、烦恼、方便究竟 → 别立贪欲、嗔恚、邪见各五相（圆满相须五支具足） → 广说各业道具体相状（杀生方式、不与取诸相、欲邪行非支非时非处等） → 末后抉择邪见为诸邪见中最为殊胜者，以断善根、顺恶业故偏说。

## 三、关键结论
1. 十烦恼皆能发业，唯「猛利现行」与「分别起」者能发往恶趣业，失念、任运起者不发。
2. 烦恼粗重与诸行「异」——阿罗汉永断粗重而诸行相续未绝，证粗重别有体性。
3. 见道所断烦恼顿断（现观智与坏缘谛作意相应，三心顿断），修道所断渐断（数数修道）。
4. 断烦恼从「相应」与「所缘」两面说：对治道生，烦恼不起得无生法，相应断已不复缘境。
5. 一切烦恼皆能结生相续——受生时贪爱、恚、疑、我我所见等一时现行。
6. 十不善业道圆满必具五支：事、想、欲乐、烦恼、方便究竟，阙一即非圆满业道。

## 四、易混辨析
- **缠 vs 随眠 vs 粗重**：缠是烦恼现行缠缚心王；随眠是烦恼种子随逐不舍；粗重是烦恼品令身心刚强沉重、无堪任者。本卷以「觉悟随眠」（与缠俱转）与「不觉悟随眠」（离缠恒逐）对辨，又明「离系断即随眠断」，区别现行伏断与种子永断。
- **见所断 vs 修所断**：见道所断烦恼顿断——现观智谛现观与坏缘谛作意相应，三心顿断迷四谛见惑；修道所断烦恼渐断——数数修道方能断除。
- **有事烦恼 vs 无事烦恼**：见与慢缘本无之「我」分别而转，故名无事；贪恚有所缘实事，名有事；无明疑通二种。
- **圆满业道 vs 非圆满业道**：须五支（事、想、欲乐、烦恼、方便究竟）全具方名圆满；如染污心起欲乐而业不现行、或现行而不究竟，皆非圆满业道所摄。

## 五、阅读提示
带着「烦恼如何由内因发为外业」的主线读：前半重在烦恼体相、受根相应与断法次第，后半重在烦恼发动为业的五相建立与十业道差别。两段交接处以「如是已说烦恼杂染决择。业杂染决择。我今当说」明示转折。
