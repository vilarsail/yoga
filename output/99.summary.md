- **全篇总括**：本卷进入「调伏事摩怛理迦」——把戒律（毗柰耶）的原理系统化：先讲佛为何制戒（十种胜利、五种罪聚与还净），再给出一套完整的「犯与不犯」判定学（性罪遮罪、四种犯因、三品轻重），然后是修行人的五件随身装备（安住、居处、所依、受用、羯磨）、五种学法障碍（重点解剖「像似正法」二十多种伪装），最后以僧团和合的五寂静法与四种灭诤程序收尾。全卷相当于一部「戒律的操作系统说明书」。
  - **制戒的总理由：十种胜利与僧团三级目标**
    - **佛在律中制立学处**：是看到十种胜利（如摄释分所说），核心链条：摄受僧伽 → 令僧精恳 → 令僧安乐
      - **摄受僧伽**：接纳四大姓等正信出家之人
      - **令僧精恳**：为出家者讲有因缘、有出离、有所依、有勇猛、有神变的甚深法教
      - **令僧安乐的五相**：顺道具不匮乏、摈除异法者、善除遣恶作（悔恨）、降伏烦恼缠、永灭随眠（潜伏烦恼种子）
      - **五种安乐各有作用**：未净信者生信 / 调摄鄙恶者 / 惭愧者得安住 / 防护现法诸漏 / 永灭当来诸漏
    - **安乐之后还有第三级**：令未得入者容易进入，令梵行久住——「摄受 → 安乐 → 易入」是第二差别
  - **罪的分类学：五种罪聚与十五种过失**
    - **五种罪聚摄一切罪**：他胜罪聚（最重的根本罪）、众余罪聚、损坠罪聚、别悔罪聚、恶作罪聚（最轻的悔恨罪）
      - **还净的边界**：除他胜外的罪聚都可一律还净；他胜只有特定两种人可还净，所以不立在一向还净聚中
      - **初修业者的例外**：犯了四他胜但无猛利烦恼缠（意乐不粗暴、明知障沙门则宁死不犯），可以出罪、沙门果仍有堪能；若事重＋猛利无惭愧缠两者皆重，则成不可出、不般涅槃
    - **十五种犯罪过失遍于一切罪聚**：事重、猛利缠、匮乏不喜足、他所讥嫌、令不信者更不信、多财宝多事业、染着、恼他、发起疾病、障往善趣、障沙门，以及五个「应…而不…」的颠倒项（避护、为依、恭敬、覆藏、习近各一对）
      - **每类过失配具体戒相示例**：如非时教授苾刍尼、执触女手、无根毁他、持羊毛过三由旬、破坏和合僧、向未受具戒者说过人法、受用不净衣等
  - **犯与不犯的判定学：五法摄律 + 四种犯因 + 三品轻重**
    - **五法摄毗柰耶**：性罪（本性不善，不制也堕恶趣障沙门）、遮罪（佛因形相不如法等而遮止）、制（遮止项）、开（许可项）、行（实际行持）
      - **行分三种**：有犯（邪行）↔ 无犯与还净（正行）
    - **犯罪的四种因缘**：无知（没听懂学处，以为没犯）、放逸（懂了但失念）、烦恼盛（贪嗔痴猛利、身不由己）、轻慢（信解下劣、对沙门涅槃无顾恋、无敬无耻）
      - 无知与放逸所犯是不染污（可原谅的过失），烦恼盛与轻慢所犯是染污（性质严重）
    - **轻重五把尺子**：由自性（他胜重、恶作轻）、由毁犯（轻慢最重）、由意乐（烦恼品级）、由事故（同样的嗔心，杀畜生是损坠、杀人犯他胜、杀父母加无间罪）、由积集（犯而不悔的数量累积）
    - **「应作」的五种**：村邑所应作（乞食衣事、三宝事、令未信生信）、道场所应作、善品所应作（资粮事如十三种资粮、清净事如修作意）——不做或反向加行即成犯
    - **无犯的五因缘**：密护根门饮食知量勤修胜行正知而住、于戒起上品精勤与惭愧、少财少事少业、住喜足专修善品、初业者痴狂心乱病恼所逼（第五种是免责的客观原因）
  - **还净的操作：五种恶作对五种除遣**
    - **犯后先如实生起五种恶作**：（自我恳责、天呵责、大师与智者呵责、恶名流布、当堕恶趣），以五支不放逸行为依止
    - **五种相除遣恶作**：佛所说法定有出离故罪可还净、能犯的无知放逸等已断而正智已生、当来无犯的意乐已生、已向同梵行者发露悔灭、佛虽呵责恶作为盖为障但坚执不除才不对——忏悔干净本身就是善哉
  - **修行人的五件随身装备（五毗柰耶所随行法）**
    - **安住**：五种想住 → 入聚落如入牢狱、在道场自住沙门想（审谛观察二十二处）、饮食时作疗病想、对色声作盲聋喑哑想、寝息时作旷野惊怖鹿想——如此虽受用王级供养也不落欲乐边
    - **居处**：五类 → 苾刍居处、苾刍尼居处、外道居处、杂染居处（羯磨不全设）、无杂染居处（羯磨具足）
      - **选择规则**：爱乐所学者在杂染居处应舍弃利养恭敬离开（除危难、路途、度人三种例外）；苾刍尼与外道居处不应住（同三种例外）；无杂染处可尽寿住但常怀羁旅之想、常恐被智者讥嫌
    - **所依**：五种 → 村田、居处、补特伽罗（依止师与教授教诫者）、资具（衣服饮食医药）、威仪（四威仪得安乐住）
    - **受用**：五种不净 ↔ 五种清净 → 不净是受用塔物（非重病）、僧物（非授非堕钵）、他人物、非委信物、秽污物；清净受用者能善酬报信施
    - **羯磨（僧团议事程序）**：四种 → 单白、白二、白四、三语羯磨
      - **所依二事**：有情数事（出家、受具、出罪、举罪、摈斥、安居等）与无情数事（受持衣钵、护衣、结界等）
      - **按众数分级**：二众（对首三说别悔）、四众（粗罪发露）、十众（受具足）、二十众（出苾刍众余罪、苾刍尼受具）、四十众（出苾刍尼众余罪）、合众（增长羯磨等）
  - **五种违逆学法：障碍、像似正法、恶友、烦恼炽盛、宿资薄弱**
    - **障碍五重**：增上戒障（奴婢等障出家法）、增上心障（十一障，从数与众会到处分居处）、增上慧障（不敬法与法师、轻贱自己、悭法谤法）、往善趣障（恶欲邪见忿恨）、利养寿命所作事障（招讥嫌、不行施福、不避恶象灾疫、障衣钵事业）
    - **像似正法：披着佛法外衣的错误**（本卷最详尽的部分，两种——似教正法与似行正法）
      - **伪造层面**：在经中安置伪经、律中安置伪律
      - **见地层面**：以增益见（虚事实有）或损减见（实事拨无）讲无常等义；把佛说补特伽罗经典的密意讲成「实有我」；把假有法讲成实有；把离戏论涅槃分别说成实有或实无
      - **极端化的修行**：因佛赞密护根门就说「宁可不视色、不用意思法」；因佛赞简静就立「默然戒」一言不发；因佛赞节量衣食就断食露体；因佛赞离諠杂就弃舍卧具、什么都不修
      - **义理误读**：执「心将导世间」为唯一识流转生死；说障道之欲习近不为障；说阿罗汉死后无所觉了；以「诸蕴无我谁来造业受证」质疑无我与业果；唯信解作意是止是观、能得究竟
      - **行为伪装**：非处恶作不思惟、乐僧事而轻观行、毁戒集资供三宝、专以听闻为究竟、趋炎附势多利养的僧团、弃深经学世间文章咒术、折伏犯戒者时起不饶益恶心、构集矫诈威仪、以文章咒术多求利养、以非法积财作有罪福
    - **恶友**：劝人放逸、劝人恶行、劝人满足于下劣功德者；愚戆烦恼炽盛 → 昧劣种类长时猛利烦恼；宿世资粮薄弱 → 宿世不修信等善根，今生虽极精恳也无力现法证涅槃
    - **反面换成正面**：五种随顺学法 → 对治上述五种违逆
  - **防护戒蕴的五法：正出家、善请问、审观察、修对治、任持信**
    - 正出家（不因负债逃债，唯求涅槃爱乐所学）→ 善请问（往持经律论者处请决未了）→ 审观察（一日三时自省尸罗，无犯欢喜、有犯速悔）→ 修对治（时时常修贪等烦恼对治，不只听戒言就满足）→ 任持信（深信有犯感不爱果、无犯感爱果）
      - **五法与四犯因一一对治**：由正请问不犯无知故、由审观察不犯放逸故、由修对治不犯烦恼盛故、由任持信不犯轻慢故
  - **僧团和合的五寂静法与四种灭诤**
    - **五寂静法**：柔和易可共住（六种可爱乐法）、断（人天四轮）、断支（五断支）、敬事、灭诤（七灭诤法）
      - **共住的三类障碍**：现行憎恶、共有财物不平受用、戒见不同——六可爱乐法正是对这三类白品因缘而立
      - **配套概念**：慈善友（现在前身等业令他得利益安乐）、如法利养、堕钵中/钵所摄、平等受用（不偏精妙、显露共食、不给隐秘闭门食）
      - **可乐性二相**：体彼有德而尊重（未生令生）↔ 荷彼有恩而慰意（生已增广）；由财法二摄而善和合，和合则心无扰恼、名一趣性
      - **人天四轮以四处圆满为依**：处所圆满（五种妙好处所）、教导圆满（正士善友）、正行圆满（自发正愿五相：敬顺取教授、行无违逆、如实自显、于粗细供养生喜足、无间殷重乐断乐修）、资粮圆满
      - **宿所作福的五相果胜利**：内外可爱果报（长寿端严、生富贵家）、非人不能障碍、于善法趣入无怠、作恶能猛利悔愧令恶微劣、事业展转昌盛少功多成——四轮是天上人间止观的车轮，缺一不转
    - **敬事的七种次第**：先敬大师 → 敬其所说法 → 敬戒学处 → 敬定慧教诫 → 时修财法供养 → 修三摩地 → 通达谛理永尽诸漏无有放逸；敬事三相 → 体德起尊重、身语意三行恭敬、设幢旛盖等供养
    - **灭诤实务**：四种诤事对应四种除灭 → 他举诤事（以实举罪，四目相对，既正解了不再重举，得除灭）↔ 愿出所犯；互疑诤事（犯罪者忘失自犯，被举后求「忆念毗柰耶」清净）↔ 施与清净；自举诤事（癫狂不成犯，求知「不痴毗柰耶」）与互疑真犯（僧中寻求事之自性、待得实已如法断）↔ 许求实性；互举诤事（两众憍慢互不发露，各推有智众首互往发露）↔ 各各发露——诤事与除灭各四种，一一配对
