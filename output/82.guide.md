# 瑜伽师地论卷第八十二 导读

## 一、内容总览
本卷为「摄释分」下半，承接上卷，系统阐述「如何听法、如何赞佛、如何说法、如何释经」四大主题。前段论听法者应以何等因缘恭敬闻法（一因至十因），及说法者当先以略广二途赞佛功德；中段总束为「五分说法」；后大半以「住学胜利」一经为范例，逐层展示文、义、等起、门差别、释难、次第等释经方法论，末以「六相解释一切契经」收束全篇。本卷可视为一部完整的「释经学教程」。

## 二、结构层次
全文以「听法 → 赞佛 → 说法五分 → 释经示范」一线递进，由外而内、由事入理：

- **听者（P1–P21）**：以「一因 → 十因」枚举展开，说明恭敬听法之必要 → 每一因皆指向现前利益与究竟涅槃，从「能证利益安乐」逐层扩展到「引一切世出世间静虑解脱等持等至」。
- **赞佛略广（P22–P51）**：说法前先赞佛 → 先「略赞」（五相：妙色、静寂、胜智、正行、威德；又六种）→ 后「广赞」（从「无边名称」至「到彼岸者」，以一系列德号铺陈佛德），略广相待而互补。
- **五分说法（P52–P60）**：总束前文 → 说法师应「寻求文义 → 转五种释 → 安立自身 → 起品类言说 → 安处听者 → 赞大师功德」，五分如五分音乐，能令自他喜乐。
- **释经示范（P61–P143）**：以「住学胜利」经文为标本，逐层解剖释经方法：
  - **文义（P61–P72）**：先释「文」（名句字身等六文）→ 再释「义」（地义、相义、作意义、依处义、胜利义、过患义、所治义、略广义），由文入义。
  - **等起（P73–P80）**：说明佛说此经的动机与所化对象 → 指出四种苾刍体及对治不同过失。
  - **义之差别（P81–P90）**：分「总义 → 别义 → 训释名言 → 义门差别（自性、界、时、位、补特伽罗）」，由总到别、由义到门。
  - **门差别（P91–P103）**：逐一剖析「苾刍、住、慧、解脱、念」五法之自性、训词、门差别 → 五法对应戒、慧、解脱、念之修学骨架。
  - **释难（P104–P127）**：以问答体解惑 → 三学次第何以此经先戒后慧不说心、何以但说住学胜利等，层层辨析。
  - **次第（P128–P130）**：分「圆满次第 → 能成次第 → 解释次第」，说明修学与解说之先后。
  - **收束（P131–P143）**：补释大师、声闻等名义 → 末以「六相解释一切契经」总结全篇方法论。

## 三、关键结论
1. 恭敬听法是引生世间与出世间一切功德的根本方便，从现法利益到究竟涅槃皆由听闻正法而得。
2. 说法者须先赞佛德、次善安立自身、复以八种言词为众宣说，五分具足方能自他两利。
3. 释经须从「文」与「义」双入手，义又分地、相、作意、依处、胜利、过患、所治、略广等多门，层层深入。
4. 「住学胜利」一经以戒、慧、解脱、念四句收摄三学——戒为基、慧为上首、解脱为果、念为增上，四法相资。
5. 一切契经皆可依六相解释——遍知事、舍离恶行、受学善行、如病等行智遍知、彼果、自他领受彼果。

## 四、易混辨析
- **略赞 vs 广赞**：略赞以五相（妙色、静寂、胜智、正行、威德）或六种扼要概括佛德；广赞则以一系列德号（无边名称、能施光明、成就明眼……到彼岸者）详尽铺陈，一简一繁。
- **自相 vs 共相**：自相指一法不共他法的自体（如「慧自体」）；共相指该法与其所依、助伴、所缘等共同显现的相状（如慧之所依助伴所缘）。
- **圆满次第 vs 能成次第 vs 解释次第**：圆满次第是修学由戒生定、由定生慧的前后渐满；能成次第是以前法成办后法的因果相生（住学胜利→成慧上首→成解脱坚固，由念增上）；解释次第是解说经典时由大师、声闻等名义依次阐释的逻辑顺序。
- **见所断 vs 修所断**：见所断是见道位所断的分别起烦恼，断已入预流果；修所断是修道位所断的俱生起烦恼，须数数修习方能断尽。

## 五、阅读提示
阅读时可先抓住「听法—赞佛—说法—释经」四大段落，再以「住学胜利」一经为线索，看论主如何从文、义、等起、门差别、释难、次第六个维度层层解剖一经，体会唯识释经的方法论框架。
