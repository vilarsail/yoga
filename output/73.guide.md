# 瑜伽师地论卷第七十三 导读

## 一、内容总览

本卷为《瑜伽师地论》卷第七十三，「摄决择分中菩萨地之二」，承上一卷继续决择菩萨地所依事。全卷分两大段：先以嗢拖南颂开列五事（相、名、分别、真如、正智）决择的主题，广辩五事与四谛、相名、所取能取、三无自性性等的关系，并以四句分别层层展开；次转入三自性（遍计所执、依他起、圆成实）的决择，详述遍计所执自性的种类、执着相状及愚夫如名执有自性的因缘。两段以「真实义分」为纽带，前者为「事决择」，后者为「自性决择」，相互贯通。

## 二、结构层次

本卷以两首嗢拖南颂为枢纽，分两大块推进：

- **第一段（P1-P74）五事决择**：
  - 颂开列主题 → 「思择自性取、萨迦有世间、真寻思实智、密意与次第」
  - 总说五事摄谛与相名关系（P3-P10）：判五事几谛所摄 → 以四句分别辩论「相与名」「相相与相」「分别与相名」「思惟真如与观真如」「思惟相与观相」
  - 诸法自性不可言说（P11-P20）：立「如幻事相」喻 → 破「言说安立自性」诸计（破名言依相立、破相如名立、破二和合生、破名言显自性） → 结成「随言自性皆无所有」 → 由八分别生三事展转相续
  - 所取能取与三种取所行义（P21-P31）：判五事能所 → 立「有言有相、无言有相、无言无相」三种取 → 辩无相取之成立（不构获、不增益、不灭无、自内证）
  - 苦等智与无相智（P32-P33）：立有相为无相因 → 无相智为苦等智因假立果名
  - 修观除遣相与涅槃（P35-P38）：缘境修三摩地 → 除遣五境相 → 无上转依无为涅槃（水、金、虚空三喻） → 无相转五位
  - 三乘建立与三种粗重（P39-P49）：随三根立三乘 → 二乘以大乘为本 → 最后乘经三无数大劫 → 断皮肉心三粗重 → 三乘因缘（变化、誓愿、法性）
  - 失坏正法（P50-P52）：声闻计「断灭」为涅槃 ↔ 菩萨执「本无」为已证
  - 五事与诸法相摄（P53-P55）：判萨迦耶、四种真实、四种寻思、四种如实遍智
  - 三种无自性性与密意（P55-P70）：依五事说三种无自性性 → 依何密意说无生无灭、等于虚空、如幻、无常苦空等
  - 五事次第建立（P71-P74）：相→名→分别→真如→正智，由杂染次第圆满转入清净次第

- **第二段（P75-P113）三自性决择**：
  - 过渡（P75）：由真实义分事决择转入三自性修观
  - 颂开列（P76）：总举、别分别、缘差别、依止、微细执着、如名等执性
  - 三自性定义与所缘（P77-P80）：遍计所执=随言说假立 → 依他起=众缘所生 → 圆成实=真如
  - 遍计所执自性种类（P81-P92）：五种遍计自性（义、名、杂染、清净、非杂染清净） → 复五种（依名遍计义等）
  - 遍计所执自性执（P93-P96）：加行执五种 + 名施设执二种
  - 微细执着（P97）：五种颠倒执
  - 愚夫如名执自性的五因缘（P98-P104）：问答→寻思→寻求→语于名转→各别义转
  - 名言所缚的理与教（P105-P113）：由理（离名言喜乐不得、展转相依、修对治时安心无相） → 由教（引世尊颂） → 异生喻

## 三、关键结论

1. 五事（相名分别真如正智）摄尽一切法，然诸法自性不可言说，唯有名相可得，喻如幻事。
2. 随言自性于一切种皆无所有，凡计「名言依相立」「相如名立」「二和合生」「名言显自性」皆不应理。
3. 三种无自性性（相、生、胜义）依所化势力安立，真如不由无自性性说无自性。
4. 遍计所执自性依假名言建立，依他起从众缘生，圆成实即真如，三者相待而立。
5. 愚夫于相为名言所缚，由理、教二门可证；修对治时安心无相界即得解脱。

## 四、易混辨析

- 思惟真如 vs 观真如：思惟是分别所摄如理作意，但见真如相不见实真如；观是通达时胜义非思惟其相。
- 言说随觉 vs 言说随眠：随觉是名言显了现行，对应「有言有相」「无言有相」取；随眠是名言习气潜在，离随眠即「无言无相」无相取。
- 三种无自性性：相无自性性指世俗言说自性本空；生无自性性指缘生非自然有；胜义无自性性指真实义相所远离。
- 遍计所执自性 vs 依他起自性：前者依假名言建立自性，毕竟无体；后者从众缘所生，如幻有体。

## 五、阅读提示

带着「世尊依何密意说一切法无生无灭」的问题读，看五事与三自性如何贯通密意之教；注意本卷几乎每辩论都用四句分别展开，是把握结构的关键。
