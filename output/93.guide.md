# 瑜伽师地论卷第九十三 导读

## 一、内容总览
本卷为《瑜伽师地论·摄事分》中「契经事缘起食谛界择摄第三之一」，承接前文「处择摄」，正式进入缘起、食、谛、界四门的择摄。全卷围绕十二支缘起展开，以「三相建立缘起差别」为骨架，串联起菩萨观谛、九相苦树、三处所摄教、五相正勤、增上慢、缘起甚深四相、世俗胜义二谛、大空与中道等一系列法义，是贯通有情流转与还灭、世间与出世间的关键篇章，也是后世唯识宗解释缘起性空、补特伽罗无我与法无我的重要依据。

## 二、结构层次
全卷由两首嗢拖南总摄，按「缘起建立 → 流转与还灭 → 甚深义 → 二谛收束」一线推进：

- **总标（P1-P4）**：以总、别两首嗢拖南列示全卷纲领——立等二谛、触为缘、有灭食等、如理等，覆盖缘起差别、苦聚谛观、微智、上慢、甚深等十目。
- **三相建立缘起差别（P5-P18）**：从「前际中际得生 → 中际后际得生 → 中际生已趣清净」三层展开。先说流转门（无明缘行乃至生缘老死），次说还灭门（无明灭故行灭，乃至证现法涅槃、有余依与无余依般涅槃界），形成流转—还灭一对相待结构。
- **九相苦树喻（P19-P23）**：以「小苦树」「大苦树」为喻，对比非聪慧者以贪爱水溉灌后有、与多闻圣弟子损减其业不令增长的白品差别，承接前文流转之因。
- **菩萨观察四谛（P24-P34）**：追述世尊昔日菩萨位于菩提座，依缘起门逆次观察苦集灭道，历观三圣谛后寻求道谛，证无上正等菩提，开四圣谛令生等觉。这是「缘起 → 四谛 → 现观」的过渡。
- **三处所摄教与聪慧弟子（P35-P42）**：佛所教法摄为三——缘生法无作用、利他行、自利行；并辨别外道虽离欲至有顶仍未解脱、与圣弟子悟入最极微细识无常性的差别。
- **三际思量与五相正勤（P43-P50）**：苾刍依苦依处、苦因缘、苦因缘依处三相，于过去、现在、未来三际正思量；复由五相正勤方便观察缘起，证涅槃如陶师置瓮于清凉岸。
- **增上慢与缘起甚深四相（P51-P72）**：先辨有学、无学二种增上慢相；再说缘起四相甚深——微细因果、无我、离系有情而有系缚、有系有情而离系缚，逐层破斥外道我见，显明唯因果相续无实作者。
- **二谛与大空收束（P73-P95）**：以「异世俗胜义、法尔、此作等、大空与分别、自作」收束，明世俗胜义二谛道理，建立补特伽罗无我与法无我名为大空，远离自作他作等四边，安立中道行，归结到「觉了中道、勤修正行能尽众苦」。

## 三、关键结论
1. 缘起差别由「前际中际」「中际后际」「中际趣清净」三相建立，流转与还灭同依一支缘起而立。
2. 识与名色展转相依如束芦，缘生法非自作、非他作、非无因生，第一义中都无作用，唯世俗假施设。
3. 圣弟子由明触所生受，观四谛入现观，断无明与爱，证慧解脱与心解脱，乃至有余依、无余依二涅槃界。
4. 缘起本性最极甚深，由微细因果、无我、离系有情而有系缚、有系有情而离系缚四相显发，唯慧眼所见。
5. 一切无我总名为空，即补特伽罗无我与法无我，略摄为一名为大空；远离增益损减二边，名中道行。

## 四、易混辨析
- **前际中际得生 vs 中际后际得生 vs 中际趣清净**：前者指由宿世无明业感现在果；中者指现法再造业感当来果；后者指于现法中闻法如理作意，断无明爱趣证涅槃——前二为流转门，后一为还灭门。
- **明触 vs 无明触 vs 非明非无明触**：明触生起与闻思修正智相应之受，是圣慧所依；无明触生起与痴相应之受，为爱取所依；非明非无明触则以内外色为缘，是有对触所摄。
- **补特伽罗无我 vs 法无我**：补特伽罗无我指离缘生行外别有实我不可得；法无我指即缘生诸行其性非实我、是无常故。二种合说即大空。
- **有学增上慢 vs 无学增上慢**：有学增上慢者自谓已断三结、拔毒箭，实由微细我慢间无间转；无学增上慢者自谓已寂静涅槃，实有未断微细现行慢，且必先于有学起慢。

## 五、阅读提示
读本卷可带着两个问题：其一，为何缘起既「非自作非他作」又「不离因生」？其二，「甚深」之「深」究竟深在何处？把握「束芦相依」「苦树溉灌」「陶师置瓮」三大譬喻，可助理解抽象法义。
