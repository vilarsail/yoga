# 瑜伽师地论卷第六十五 导读

## 一、内容总览

本章为《瑜伽师地论》卷六十五，属「摄决择分」中「思所成慧地」之首篇，承接前文「闻所成慧地」决择而转入思所成慧地之决择。全章主旨在于以「思议」为门，从「有非有」「实有假有」入手，破斥「我」之实有，建立「无我唯有蕴」的杂染清净道理；继而以「五相差别」为统一框架，系统安立有色无色、有见无见、有对无对、有漏无漏、有诤无诤、有染无染、世间出世间、有为无为乃至所缘诸法等一系列法相差别，最后归于「名」之观察与瑜伽四种所缘，收束于修行实践。

## 二、结构层次（★重点）

全章以「思议总标 → 有无建立 → 破我显无我 → 五相分法 → 名相收束」一线贯穿：

- **思议总标**：先开四种思议（事、有非有、因果、乘） → 再约二种（恶思、善思） → 点明思所成慧所缘境域，并广引黑白银白等对待，定下善恶二品之框架。
- **有无建立**：由「有非有思议」展开 → 立「实有」「假有」二相（不待所余施设自相为实，待依所余为假） → 我及有情命者数取趣等是假有，色等诸蕴是实有；饮食车乘瓶衣等依色香味触假立，虚空无为、灭尽等至亦假施设。
- **破我显无我**（全章重心）：以「不可得、不可见」立宗 → 破外道四计（即蕴、异蕴住蕴中、住离蕴法中、一切不相应无蕴） → 显「我非实有，唯有诸蕴」 → 由此一切杂染（无明触→受→爱→业→后有苦）与清净（他音内正作意→明→断爱→业灭→苦灭）道理皆得成就。
- **应用与展开**：有情九种安立 ↔ 破离系外道「树等有命」之邪执（以增长因、相似不相似三问破之）；复辨饮食车乘等假有依色香味触实有而立，辨一聚非一聚之依止差别。
- **五相差别统摄诸法**（并列铺陈，前后呼应）：有色无色 → 有见无见、有对无对 → 无见无对 → 有漏无漏 → 有诤无诤 → 有染无染 → 耽嗜出离 → 世间出世间 → 有为无为（旁决涅槃异不异之戏论） → 所缘诸法。每对皆以「事、因缘、自相、共相、业」等五相建立，结构整饬，可对照阅读。
- **名相收束 → 瑜伽所缘**：引「名映于一切」之颂 → 显补特伽罗无我（了四无色蕴）与法无我（了遍计所执自性及世俗言名） → 归结瑜伽作意四种所缘（遍满、净行、善巧、净烦恼），收束于修行实践。

## 三、关键结论

1. 「我」非实有：依实有假有之相，我及有情等但依色等诸蕴假立，于内外中间离蕴皆不可得不可见；外道所执四计皆不应理。
2. 无我唯有蕴故，一切杂染与清净道理皆得成就——杂染依无明触起爱发业感苦，清净依他音内正作意发断爱业灭，皆不待实我。
3. 假有诸法（饮食车乘瓶衣庄严具等）皆依实有色香味触等想事而施设，非别实物；色等遍一切假有想中无差别转。
4. 诸法差别皆可由「五相」统一建立，显示唯识法相分析之严密，举一反三。
5. 涅槃由有为灭之所显，与有为法其相异故，不可说异不异，戏论俱遣；唯是内所证寂灭无戏论相。

## 四、易混辨析

- **实有 vs 假有**：实有不待所余、不依所余施设自相（如色等诸蕴、四大种）；假有待于所余、依于所余施设自相（如我、有情、饮食车乘、虚空无为）。
- **有漏 vs 无漏**：有漏由事、随眠、相应、所缘、生起五相建立，核心是烦恼种子（随眠）未断；无漏由离缠、随眠断、断灭、见道对治、修道对治五相建立。
- **有诤 vs 有染**：二者皆依五取蕴事、因缘、自性、助伴、等起五相建立，差别在因缘——有诤重在「爱味染着耽嗜」所引斗讼违诤等五黑品，有染重在「喜乐爱味」所摄贪着。
- **世间 vs 出世**：世间法摄清净色、染污无记心心所、世间善心心所及世间定所行色，堕五种世间；出世法摄见修道对治、想解脱、无学所治解脱等，不堕如是五种世间。

## 五、阅读提示

读本章宜抓「五相」这一统一框架——前半破我、后半分类，皆围绕「相差别建立」展开；遇诸对法（有漏无漏、有诤无诤等）可对照其五相，便能举一反三。又破我四计一段为全章枢纽，宜细辨即蕴、异蕴、住离蕴、无蕴四执之破斥脉络。
