# 瑜伽师地论卷第九十八 导读

## 一、内容总览
本卷为《瑜伽师地论》卷第九十八，属「摄事分中契经事菩提分法择摄第四之二」，承接卷九十七继续择摄契经中菩提分法要义。全卷以九个嗢拖南（颂摄）串联，从外道邪师之失、雪山喻、四种正断与神足、二十二根、思择力与四力、七觉支、八圣道、入出息念，到三学与四种证净，系统铺陈行者从初发心到证果的次第与法相。主旨是以「择摄」方式归纳散见于契经中的菩提分法义，令行者明辨内外、凡圣、因果差别，依法修习。

## 二、结构层次
本卷以九个嗢拖南为骨架，按「破邪→显正→次第→证果」一线贯穿：

- **破邪显正（第一嗢拖南）**：先破外道邪师专求利养恭敬 → 弟子如理抗言重当来 → 雪山喻显三地（无学/有学/异生）中非理作意与魔能行不能行之别 → 劝化安立四义、五种渐次、禁戒净命圆满，立正行根基。
- **加行修习（第二嗢拖南）**：四种正断之「勇」（堪忍众苦不退）→ 四种神足（净意乐/勤务/心喜乐/正智四力持心令定）→ 五解脱处起四种三摩地 → 圣神通之能与不能（不能变根、心、心所、业异熟四事）。
- **根与慧（第三嗢拖南）**：二十二根由六处增上义建立 → 破「内我托六根门行六境」之邪执 → 慧根最胜（思择→精进→正念→一趣→如实知见）→ 外异生品与内异生品之别。
- **力与行（第四嗢拖南）**：思择力 ↔ 修习力 → 三处羞耻（他/自/法）→ 四种力（觉慧/精进/无罪/摄受）→ 阿罗汉八力、有学五力、如来十力之递进 → 质直补特伽罗四相（说正法教/教授教诫/如理通达/得真实证）。
- **七觉支（第五嗢拖南）**：觉支十四差别（自性/所缘/因缘相）→ 觉支之食（正作意/数作意）→ 转轮王七宝喻七觉支 → 三时三分安住 → 二十一想俱行修对治诸障。
- **八圣道与沙门义（第六嗢拖南）**：内外二力（善知识力/正思惟力）→ 八圣道世间与出世间 → 法、毗奈耶、圣、善趣等名义分辨 → 第一义沙门与假名沙门之别。
- **入出息念（第七嗢拖南）**：十六行修 + 五障碍 → 有上十六行修（观命根系属入出息）→ 微细住/不流散/不可伏 → 如来与慧解脱阿罗汉离盖住之极大差别 → 念住教非外道所执。
- **三学圆满（第八嗢拖南）**：增上戒/心/慧三学 → 邪行与正行（下/中/上）→ 净戒/善法/别解脱三圆满 → 律仪诸名义 → 三住（天住/梵住/圣住）为依。
- **四种证净（第九嗢拖南）**：信戒澄清性立四证净 → 三种变异（病/老/死）怖畏中无恶趣畏 → 天路与六随念 → 明镜喻自观染净 → 记别预流/一来/不还果证。

## 三、关键结论
1. 外道邪师专求利养恭敬，弟子重当来者则如理；雪山喻显无学地中非理作意与魔俱不能行，异生地中二俱能行，明凡圣差别。
2. 二十二根摄尽世间所现见义，六根唯领受自所行境，实无「内我」托根门而行，破我执显缘起理。
3. 慧根最为殊胜——由思择力发勤精进，安住正念，令心一趣，如实知见，初后多有所作，能到究竟。
4. 如来与慧解脱阿罗汉解脱无差别，但离盖住极大差别：如来诸盖毕竟断，有学随眠未永断故数数间心。
5. 四种证净以信戒为澄清性，于余生中毕竟无转不退，能滋润福善、引圣道、引断乐，为三学所依止。

## 四、易混辨析
- **有学 vs 无学 vs 异生**：异生是未见谛凡夫；有学是初果至不还果圣者，修道未清净；无学是阿罗汉，诸漏永尽。雪山喻三地、清净鲜白等处分明此三差别。
- **思择力 vs 修习力**：思择力是于诸恶行深见过、正思择息恶修善，能往善趣与现法涅槃；修习力以念住为依止修菩提分法，依思择力而起，二者是依止关系。
- **世间八圣道 vs 出世间八圣道**：世间者为三漏四取所随缚，不能尽苦，但能往善趣；出世间者与彼相违，能尽众苦。
- **第一义沙门 vs 假名沙门**：第一义沙门依八支圣道安立沙门义，毕竟无失坏；假名沙门虽出家受沙门性，无实义，即不如是。

## 五、阅读提示
读本卷可带着两个问题：一是「破邪显正」的判教线索如何在每一嗢拖南中反复出现（外道 vs 内法、邪师 vs 善知识、邪行 vs 正行）；二是修行次第（戒→定→慧→解脱→证净）如何在根、力、觉支、念住、证净诸法相中一以贯之。
