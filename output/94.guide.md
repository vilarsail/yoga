# 瑜伽师地论卷第九十四 导读

## 一、内容总览
本卷为《瑜伽师地论·摄事分》「契经事缘起食谛界择摄」之第二部分，承前卷继续择摄契经中缘起、食、谛等要义。全卷以三首嗢拖南串起三大板块：先论触缘受的记别与见圆满，次明三学正行、法住涅槃二智、六种圆备及四圆满等修证方便，最后广辨四食安立、食与爱业的关系及食中喜贪的过患与功德。三大板块由「正见缘起」到「修证方便」再到「食事观察」，层层收束于「唯法引法」的缘起深义。

## 二、结构层次
全卷以三首嗢拖南为纲，依「缘起见→修证方便→食义观察」三层递进：

- **嗢拖南一（触缘见圆满）**：先立三种无倒记别（开自宗→伏他宗→有执无执杂染清净）破无因恶因论 → 次明见圆满，于五种因如实了知自性、因缘、灭、道 → 次辨阿罗汉六种记别所解 → 由三学邪行正行判能否超越疾病衰老夭没 → 出法住智、涅槃智 → 明六种圆备发起精进 → 明四种圆满名善来善出家 → 辨二种犹豫法及三种苦恼补特伽罗。此段以「破邪显正→立见→记别→修行→证智」为线。
- **嗢拖南二（有灭若沙门）**：由有学见迹未身触证 → 明真沙门义 → 依明触生受、生慧建立四十四事、七十七智 → 辨流转渐次与二种杂染（业爱、妄见）→ 归结过去今佛皆由缘起思惟证觉。此段以「未证→证因→观相→流转→佛同」为线。
- **七种清净**（承上启下）：戒→心→见→度疑→道非道→行→行断，渐次修集证无造涅槃，缺一不可。
- **嗢拖南三（安立与因缘）**：先安立四食（段、触、思、识）各所长养 → 次明食由爱生、爱由无明触生、追溯至六处 → 次辨食之粗细 → 次观三食生三苦、四食过患 → 末结喜贪未断则魔得所依、已断则如虚空。此段以「食之用→食之因→食之患→断之德」为线。

## 三、关键结论
1. 苦乐皆从缘生，触为受现可得之因，更求余因非为巧妙，由此破无因恶因论。
2. 见圆满须于五种因（恶趣、善趣、识住、杂染、清净）如实了知自性、因缘、灭、道，观至无明为边。
3. 法住智知因果安立，涅槃智于苦集起厌逆、于灭涅槃起寂静想，二智为依方得慧解脱。
4. 四食能令已生有情安住，然本藉爱为缘故有；观段食如子肉、触食如无皮牛、思食如一分火、识食如三百鉾，断喜贪即断后有。
5. 七种清净渐次修集，缺一不可，方证无造究竟涅槃。

## 四、易混辨析
- **法住智 vs 涅槃智**：法住智于缘生行因果分位如理思惟，悟入苦真是苦等如其因果安立之智；涅槃智则于苦集住厌逆想、于灭涅槃起寂静想。前者知「法如是」，后者证「灭如是」。
- **业爱杂染 vs 妄见杂染**：业爱杂染由造作故名「思所作」，妄见杂染由邪计起故名「计所执」；异生具二，有学见迹妄见已断唯余业爱随眠，无学二皆永断。
- **六种记别**：有异门记别（无一疑惑）→无异门记别（我生已尽）→智记别（生缘尽故彼生已尽）→断记别（贪爱因缘皆尽）→总记别（诸受皆苦令彼生尽）→别记别（别记因缘取相），层层细别阿罗汉所解。
- **四食**：段食长养气力、触食生喜乐、思食起专注希望、识食执受诸根大种并寿并暖；前三约长养，识食约住持。

## 五、阅读提示
读本卷可带着「破邪显正」与「缘起唯法」两条线索：前者看佛弟子如何以三种记别对治无因恶因论、以三学正行超越老病死；后者看四食如何由爱生、由无明触生、最终归趣「唯法引法」的缘起深义，理解食即是缘起的具体展现。
