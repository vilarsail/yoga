# 瑜伽师地论卷第四十八 导读

## 一、内容总览
本卷位于《瑜伽师地论·菩萨地》，承接上卷初说极欢喜住，继续展开菩萨十二住中的第二至第十二住，并附「生品」与「摄受品」两品。主旨：以十二住的次第升进为骨干，逐地说明菩萨在戒、心、慧、方便、无相等阶位上的行状果相；末以三无数大劫断障清净收束道位，再以五种受生、六种摄受及十二种艰难事说明菩萨利他方便，构成从初地到法云地、由自利到利他的完整道次第。

## 二、结构层次
本卷以「十二住次第升进 → 三劫断障 → 五种生 → 六种摄受与十二难」四线层层推进：

- **第二至第十二住（主体）**：以「问何行何状何相 → 答先于前住已得十法 → 略说八相 → 广说如十地经配以地名」的固定格式依次展开：
  - 增上戒住（离垢地）→ 增上心住（发光地）→ 觉分相应增上慧住（焰慧地）→ 诸谛相应增上慧住（极难胜地）→ 缘起相应增上慧住（现前地）→ 有加行有功用无相住（远行地）→ 无加行无功用无相住（不动地）→ 无碍解住（善慧地）→ 最上成满菩萨住（法云地）。
  - 每住皆具「善根清净金喻 → 受生 → 威力」三相，且威力随位次递增（十倍→千→百千→俱胝→千俱胝→百千俱胝），呈层层胜进之势。
- **三无数大劫与断障（道位收束）**：以「十二住经三无数大劫」总摄前文，配烦恼、所知二障于极欢喜住、无加行无功用无相住、最上成满菩萨住三住中分断；所知障分皮、肤、肉三品；十三住配十一清净，由种性清净至如来住究竟清净。
- **菩萨五生（外化之一）**：由内证转向外化，举除灾、随类、大势、增上、最后五生，明菩萨受生形式皆为大菩提果之所依止。
- **六种摄受与十二艰难（外化之二）**：举顿普、增上、摄取、长时、短时、最后六种无倒摄受后，列十二种艰难事及对治方便，收结于「善巧方便而正修行，虽遭诸难而无怯弱」。

## 三、关键结论
1. 十二住每一住皆由前住「成上品、极圆满」而入，体现菩萨道「展转修习、成中上品」的渐进逻辑，后后住中支分功德非前前住一切都无，但下品故不堕其数。
2. 烦恼障于三住（极欢喜、无加行无功用无相、最上成满）分断粗重，所知障亦分皮、肤、肉三品渐断，至如来住方究竟清净，二障断位与三大劫位次对应清晰。
3. 第七住「非有烦恼非离烦恼」、第八住证无生法忍，是菩萨道由杂染转纯清净的关键转折；第八住由四寻思引四如实智，邪分别执永断。
4. 菩萨以五生化现世间，以六种摄受成熟有情，纵遇十二种艰难事，亦能以善巧方便自正免脱，无怯弱转。

## 四、易混辨析
- **有加行有功用无相住 vs 无加行无功用无相住**：前者（第七地、远行地）尚须加行功用以修无相，犹名为杂、堕杂染污；后者（第八地、不动地）舍加行功用任运而转，得无生法忍，一向清净。
- **诸谛相应增上慧住 vs 缘起相应增上慧住**：前者（第五地、极难胜地）依四圣谛十行相观察，于诸圣谛决定妙智极难可胜；后者（第六地、现前地）依缘起引三解脱门，无著智现前、般若波罗蜜多住现前。
- **烦恼障 vs 所知障**：烦恼障障涅槃，于菩萨三住中分断粗重；所知障障菩提，分皮、肤、肉三品，至如来住方尽。二者皆有「粗重」品，随位渐断。
- **增上生 vs 最后生**：增上生通十地菩萨受生殊胜处（初地作转轮王王赡部洲，乃至第十地生色究竟天最胜处）；最后生唯指菩提资粮已极圆满、此生现等觉无上正等菩提的最后受生（生婆罗门大国师家或刹帝利大国王家）。

## 五、阅读提示
读时可先抓「十二住固定格式」（问→答→略说八相→广说配十地经地名），再依次对照三劫断障、五生、六摄受与十二难，留意每住「善根清净金喻」由炼金至庄严具、由末尼宝至琉璃宝珠的层层庄严递进意象。
