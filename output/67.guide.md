# 瑜伽师地论卷第六十七 导读

## 一、内容总览

卷第六十七属《瑜伽师地论》「摄决择分」，承前卷思所成慧地决择之后，先收束修所成慧地决择（列十六种修之名相并一一释），继而开启声闻地决择之一（为本卷主体）。全卷主旨有二：一是以「作意—所缘—行相」为纲决择修习差别；二是围绕声闻种性、声闻相貌、染净所依、四圣谛相等展开多番问答决择，破异执、显正义。

## 二、结构层次

全文按「先收束修所成慧地 → 后展开声闻地决择」推进，声闻地又以数番问答层层递进：

- **修所成慧地决择（收束）**：总标十六种修 → 以「云何……」逐一决择。先辨二乘作意差别（声闻 ↔ 大乘：自利 ↔ 自他利，有量 ↔ 无量）→ 次辨境之差别（影像修、事边际修、所作成办修：所缘影像 → 尽所有性/如所有性 → 已证等至）→ 次辨行之差别（得修、习修、除去修、对治修：初得 → 数习 → 除粗 → 对治四门）→ 后辨差别相（少分/遍行/动转/有加行/已成办/非修所成/修所成）。以「于此地中余决择文更不复现」作结。

- **声闻地决择之一（展开）**：以「已说修所成慧地决择，声闻地决择我今当说」为过渡，分四大段：
  - **种性之辩**：先立「毕竟无般涅槃法」之疑 → 以六番诘难—反诘层层破斥（界性、无根、种姓转换、地所喻、转生时节等），显示种性决定之理。
  - **十种声闻相**：列举清净界/已遇缘/杂染界生/清净界生/未法时生/贤善时生/未得眼/已得眼/清净眼/极清净眼十类 → 详释末法时生声闻之恶相（与贤善时生对比）。
  - **月喻经释 + 往他家法**：先释四种净妙之法 → 次明往他家前应断三随烦恼（结亲友家、家悭、染心法施），各以六相说明。
  - **伐他迦经释 + 名映一切 + 四圣谛决择**：先明杂染清净所依（身）、杂染（业感五趣）、清净（二种学、五因显示）→ 次释「名映于一切」之密意（补特伽罗无我、法无我）→ 最后以多番问答决择四圣谛相（无常/苦/空/无我义、八苦配三苦、爱之差别与四句分别）。

## 三、关键结论

1. 修习虽列十六种，要唯以「作意门」与「所缘境」为枢纽：声闻缘有量有分别法、唯观自利；大乘缘无量无分别法、兼观自他利——二乘之别由此而分。
2. 毕竟无般涅槃法补特伽罗实有，种性决定不可转换；以「界性种种差别决定」破斥六番异执，显示无种性之安立不应动摇。
3. 末法时生声闻以「重利养恭敬、违背妙法、具足悭嫉谄诳、内实腐败外现贤善」为特征，身坏命终多堕恶趣；与之相违即贤善时生，生天上乐世界。
4. 染净所依即是此身，愚夫依之造业感苦成杂染，聪慧依真如智、离系烦恼成清净；清净由五因显示（正说者、正行者、正行、心学所治断、慧学所治断）。
5. 「名映于一切」之密意：由遍了知补特伽罗无我与法无我，能断一切境相杂染；执法自性、执我性而转，觉此故觉彼，由觉故还灭。
6. 四圣谛中，无常即苦（五因缘）、苦即无我（五因缘）；八苦中前五显苦苦、中二显坏苦、后一显行苦；爱分三爱（顺后有、喜贪俱行、彼彼喜乐），以四句分别其交涉。

## 四、易混辨析

1. **声闻乘相应作意修 vs 大乘相应作意修**：前者唯观自利益、缘有量有分别法、由安立谛作意门；后者兼观自他利益、缘无量无分别法、由安立非安立谛作意门、大悲增上。
2. **四种对治**（厌患/断/持/远分）：依修道次第递进——世间善道起厌患 → 出世间道缘真如断惑 → 后得道任持已断 → 更修上地道远分不退。又一说：闻思修为厌患，出世道为断，果转依为持，世间修为远分。
3. **顺后有爱 vs 喜贪俱行爱 vs 彼彼喜乐爱**：顺后有爱缘后有境或为后有因；喜贪俱行爱是于已得境界不离久住之爱；彼彼喜乐爱是于未得所求境界和合不离增益之爱。三者有交涉，须以四句分别。
4. **苦苦 vs 坏苦 vs 行苦**：八苦中前五（生、老、病、死、怨憎会）显苦苦性；中二（爱别离、求不得）显坏苦性；后一（五取蕴苦）显行苦性。道谛虽无常而非三苦所摄。

## 五、阅读提示

带着三个问题读：修的十六种差别如何以「作意—所缘」为纲统摄？种性决定之理如何通过六番诘答显明？四圣谛相在「无常—苦—空—无我」的递推中如何成立？抓住这三条线索，全卷脉络自现。
