# 瑜伽师地论卷第八十五 导读

## 一、内容总览
本章为《瑜伽师地论》卷第八十五，即「摄事分中契经事行择摄第一之一」。在《瑜伽师地论》全论五分中，摄事分为第五分，对素呾缆（经）、毗奈耶（律）、摩呾理迦（论）三藏要义作决择摄受。本卷为摄事分开篇，先以二十四契经与四阿笈摩建立素呾缆事的总框架，再以总、别两首嗢拖南为纲领，对契经中「行择摄」的诸要义——邪界调伏、善说法律三不共支、八事观察、诸行四决定、五离系品界、二种渐次、四种邪执、非断非常与四缘、杂染清净、六种死、无我遍智、三种缚、五种杂染、八清净说句、远离四具、三圆满等——作精要决择，是契经摩呾理迦的总持门。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全文以「总标三事 → 素呾缆事展开 → 摩呾理迦决择」一线推进，由建立入决择：

- **总标三事（P1）**：以三处摄事总起，标出素呾缆、毗奈耶、摩呾理迦三分，下文唯决择素呾缆事。
- **素呾缆事建立（P2-P13）**：先以二十四契经略摄一切契经（P2-P4）→ 别释别解脱契经与事契经（P5-P6）→ 事契经中详说四阿笈摩（杂、中、长、增一）之相与名义（P7-P11）→ 以十二分教简判声闻/大乘相应（P12-P13）。是为「经教建立」一节，回应「云何素呾缆事」之问。
- **摩呾理迦决择（P14-P116，全文主体）**：先释本母名义——「譬如无本母字义不明了」，明摩呾理迦为决择如来所说而立（P14）→ 举总嗢拖南（P15）与别嗢拖南（P17）两颂作全章纲领 → 其下依颂次第展开，可分三大段：
  - **第一段·界与解脱道（P18-P62）**：四种邪界有情及如来以四门调伏（界）→ 善说法律三不共支：真实解脱、方便、自内所证 → 二种前行法（见前行、道果前行）→ 八事观察（爱味/过患/出离 + 闻思思择/见道/修道）→ 二种断果与苦灭 → 愚夫二相 → 诸行四决定（无常/苦/空/无我，各由三世相成立）→ 五离系品界及修厌/离欲/灭 → 二种渐次（智渐次：无常→苦→无我；智果渐次：厌→离欲→解脱→遍解脱）→ 四种邪执为智果所断。此段为「行择」之正修次第。
  - **第二段·缘起与杂染清净（P63-P74）**：非断非常（三世无住）→ 四缘建立 → 杂染清净观察（三事、二相）→ 以囹圄系缚喻显三缚、九结、四魔怨。
  - **第三段·略教以下（P75-P116）**：依第二嗢拖南，述略教授三因缘与四自义果 → 六种死（过去/现在/不调伏/调伏/同分/不同分）→ 入士夫数八相 → 无我遍智及断 → 三种缚 → 五我慢现行 → 心善解脱 → 见慢二种五种杂染及因相 → 四有情众（外道/异生/有学/无学）→ 八种清净说句 → 远离四支 → 三圆满。
- **收束（P115-P116）**：以「师圆满」回指世尊为根本、转法眼、所依止，呼应开篇「为欲决择如来所说」，并以二种法师（由教、由证）结叹。

## 三、关键结论
1. 摄事分以素呾缆、毗奈耶、摩呾理迦三事统摄一切佛法，本卷主决择素呾缆事中「行择摄」要义。
2. 契经以二十四相略摄，事契经即四阿笈摩，由「能说、所说、所为说」三相分别杂阿笈摩名义。
3. 善说法律不共外道有三：真实究竟解脱、即彼方便、即彼自内所证，依此简别内外道。
4. 诸行四决定——无常、苦、空、无我——各由过去/未来/现在三世相成立，是声闻见道根本所观。
5. 修行要径为「智渐次（无常→苦→无我）→ 智果渐次（厌→离欲→解脱→遍解脱）」，由见道与修道二力断烦恼，得心善解脱。

## 四、易混辨析
- **断界 / 无欲界 / 灭界**：断界是见道所断诸行断，无欲界是修道所断诸行断，灭界是依灭所显；从粗到细、从因到果递进，合余二为五离系品界。
- **有余依涅槃界 / 无余依涅槃界**：前者犹余今生身心（余依）未灭，后者命终余依灭尽；同属灭界，依余依有无而分。
- **世间解脱 / 有学解脱 / 无学解脱**：世间解脱非真实、有退转；有学解脱真实而非究竟、犹有所作；无学解脱真实且究竟。
- **见邪执 / 慢邪执**：见邪执于诸行执我我所，障谛现观（见道）；慢邪执于诸行起我慢，障修道所断烦恼断。
- **同分死 / 不同分死**：过去不调伏、现在亦不调伏而舍命为同分死（随顺流转）；过去不调伏而现在已调伏为不同分死（随顺还灭）。
