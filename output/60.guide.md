# 瑜伽师地论卷第六十 导读

## 一、内容总览
本卷属《瑜伽师地论》「摄决择分」，承接前二卷对「有寻有伺等三地」的决择，为第三部分（之三）。全卷以「业道决择」与「生杂染决择」两大板块构成：前半系统辨明十不善业道的轻重差别、作与增长、三果异熟、三毒所生、定受不定受及现法受等业果法则；后半由「生杂染」转入十二缘起，特决择「无明」一支之相、自性、业、法、因果，并辨明缘起次第与「俱有依」深义。是贯通业果与缘起两大学义的关键决择文。

## 二、结构层次
全文按「业道 → 生杂染 → 缘起」一线递进，由粗至细：

- **业道决择（P1–P82）**：以十不善业道为纲，层层展开
  - 轻重差别 → 先以杀生为例立「五因缘」（意乐、方便、无治、邪执、事）判重轻 → 余九业道各约「事」说重 → 结以嗢拖南收束。
  - 作与增长 → 立「作而非增长、增长而非作、亦作亦增长、非作非增长」四句，辨业之有无与增广。
  - 三果差别 → 每一业道皆感「异熟、等流、增上」三果，详列器世间增上果之相。
  - 三毒所生 → 十业道各从贪、嗔、痴生，逐一辨其起心差别。
  - 极圆满三因缘 → 「自性过、因缘过、涂染过」，以礠石、日珠为喻明「涂染」唯思转变，无别实法。
  - 定受与现法受 → 四业（异熟定、时分定、二俱定、二俱不定）→ 现法受三因（田广大、思广大、相续清净），缕华、流水、酢滴为喻显受果久近。
  - 业与业道之辨 → 「思是业非业道，杀生乃至绮语亦业亦业道，贪恚邪见业道非业」，收束业道决择。

- **生杂染决择（P83–P97）**：由「业」转入「生」
  - 十一种生 → 依苦乐、清净不清净分类，总摄一切生处。
  - 羯吒斯即贪爱 → 依经释「长夜增羯吒斯恒受血滴」，即集谛苦谛。
  - 五非狂如狂 → 解支节、悭贪、乐生天、乐解脱、伤悼死者，附颂明流转无定、亲怨展转。
  - 斗诤劫四过、八不相数 → 明劫浊衰相。

- **十二支缘起决择（P98–P117）**：聚焦「无明」一支
  - 无明五相 → 相、自性、业、法、因果；自性中列九种无明，法中辨四句痴娆差别，因果中通真如谛理。
  - 十种愚痴有情 → 缺减乃至现见愚痴，遍摄愚痴类。
  - 俱有依与生起因之辨 → 释经中「眼为因色为缘眼识得生」义，明非生起因，依俱有依摄引发因说。
  - 四种缘起次第 → 牵引、生起、受用境界、受用苦，收束全卷。

## 三、关键结论
1. 十不善业道轻重由「意乐、方便、无治、邪执、事」五因缘决定，非仅看行为本身。
2. 每一业道皆感异熟、等流、增上三果；增上果显于器世间种种不可乐相。
3. 十业道各可从贪、嗔、痴生，三毒为方便，究竟能由何毒了别。
4. 业之定受不定受、现法受与否，由「田、思、相续」三广大性及作增长差别决定；阿罗汉已转依故一切不受。
5. 无明有随眠、觉悟、发业等九种差别，能障真实智喜乃至世间吉祥事。

## 四、易混辨析
- **作 vs 增长**：作是造业之行，增长是数习串习令业势增广；有作而不增长（如童稚梦作、他逼令作），有增长而不作（如长时随喜伺害），二者不可混一。
- **异熟果 vs 等流果 vs 增上果**：异熟果是业所招总报（如生那落迦），等流果是同类续流（如人中寿短），增上果是外器世间之相（如饮食少光泽）。
- **业 vs 业道**：思心所是「业」而非「业道」；杀生乃至绮语七支既是业又是业道；贪恚邪见是「业道」而非「业」。
- **俱有依 vs 生起因**：俱有依是同时为依止（如眼根与眼识俱时），引发作用；生起因是亲生种子义。经说「眼为因」依俱有依说，非生起因。

## 五、阅读提示
读此卷可带着两个问题：一、同样是杀生，为何有重有轻？二、佛说「眼为因色为缘眼识生」，此「因」究竟何义？循此二问，可贯通业果与缘起两大主题。
