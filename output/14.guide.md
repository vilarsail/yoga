# 瑜伽师地论卷第十四 导读

## 一、内容总览

本卷为《瑜伽师地论》「本地分·闻所成慧地」第十之二，承卷十三续列「佛教所应知处」——佛弟子当了的法相分类。全卷按「三、四、五、六、七」数目递增，敷善恶业行、生死流转、戒定慧学、补特伽罗差别、烦恼对治等法类，为修所成慧地等立名相基础。

## 二、结构层次

全卷以「已说N种，次说N+1种」过渡，数目递增一线贯穿，段内多「染净相待」：

- **三种（P1-P17）**：恶趣因 → 流转相 → 三明等对治，由染到净。
- **四种（P18-P36）**：四念住 → 四缚、四无量、四预流支 → 四补特伽罗，由观行到果人。
- **五种（P37-P47）**：五欲粗重 → 五下分结、五上分结 → 五圣财 → 五般涅槃差别，由因到果。
- **六种（P48-P57）**：六相明无我 → 六轻懱、六诤根本 → 六通、六随念，由理到行。
- **七种（P58-P65）**：七觉支 → 七补特伽罗、七圣财 → 七识住、七粗重，由行到境。

每数目先列流转杂染，后举还灭对治，以「已说……次说……」衔接推进。

## 三、关键结论

1. 所应知处以「数」分类，从三到七，涵盖业果、流转、戒定慧、补特伽罗等法相。
2. 每类法皆染净相待：先说过患，再说对治，成「流转→还灭」框架。
3. 补特伽罗差别贯穿全卷，依断障深浅从异生到有学无学安立。
4. 闻思修三慧为入道次第，七觉支为修证方便，趣证涅槃。

## 四、易混辨析

- **五下分结 vs 五上分结**：下分结系缚欲界（萨迦耶见等五），上分结系缚色无色界（色贪等五）。
- **四种 vs 七种补特伽罗**：四种依断欲界烦恼分；七种依向道、根利钝、定障烦恼障解脱差别分。
- **四记答**：一向记直答、分别记条件而答、诘问记反诘、置记置而不答。
- **奢摩他 vs 毗钵舍那**：奢摩他译「止」，心一境性；毗钵舍那译「观」，依止起慧观；如车两轮。

## 五、阅读提示

把握「数目递增、染净相待」两条线索，每段先辨明讲流转还是讲还灭，即可理清全卷骨架。
