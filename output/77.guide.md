# 瑜伽师地论卷第七十七 导读

## 一、内容总览
本卷为《瑜伽师地论·摄决择分》中菩萨地之六，紧承前卷决择菩萨地。全章以慈氏菩萨（弥勒）与佛的问答形式展开，材料取自《解深密经·分别瑜伽品》，主题是「依法假安立」修习奢摩他（止）与毗钵舍那（观）。佛从所缘境事、止观体相、依法不依法、缘别缘总、知法知义、除遣诸相、十地所治、见道修道、善知六处、涅槃受灭等层面，系统铺陈大乘止观的完整轨辙，最后以重颂与「瑜伽了义之教」付嘱收束。

## 二、结构层次
全卷以「问答递进」一线贯穿，由所缘→体相→差别→义理→除遣→障治→行位→果德层层展开：

- **总起（P1）**：依法假安立、不舍无上正等觉愿为依为住 → 立全卷宗骨。
- **所缘与体相（P2–P8）**：四种所缘境事分配止/观/俱 → 由闻思起作意思惟、得身心轻安名奢摩他 → 于三摩地所行影像思择名毗钵舍那 → 未得轻安前仅名「随顺胜解相应作意」。
- **唯识要义（P9–P19）**：止观道「非异非不异」→ 影像与心「无异」，以「识所缘唯识所现」立唯识宗义 → 由心相、无间心、心一境性配三种毗钵舍那与多种奢摩他。
- **依法与缘境差别（P20–P34）**：依法/不依法配利根钝根 → 缘别法/缘总法/缘小大无量总法 → 五缘名得缘总法 → 初地通达、三地名得。
- **三三摩地与止举舍相（P35–P39）**：寻伺粗细配三三摩地 → 止相治掉举、举相治沉没、舍相双运转时无功用作意。
- **知法知义（P40–P63）**：知法五相（名句文别总）→ 知义十相（尽所有性、如所有性、七真如等）→ 复以五义、四义、三义普摄 → 闻思修三慧差别、智见差别。
- **除遣诸相与总空性相（P64–P83）**：由真如作意除遣法相义相，乃至真如相亦伏 → 十种相由十种空除遣 → 总空性相即在依他起、圆成实中远离遍计所执相。
- **因果业与障治（P84–P98）**：以清净尸罗、闻思正见为因，善清净心慧为果，解脱相缚粗重缚 → 五系、五盖中辨止障观障俱障 → 五种心散动 → 十地各对治一障。
- **见道修道与善知六处（P99–P115）**：依七真如见道，入菩萨正性离生 → 以楔出楔、如炼金法陶炼其心 → 善知六处（心生住出增减方便）引发广大威德，十六行心生起差别中举阿陀那识等。
- **涅槃受灭与付嘱（P116–P128）**：无余依涅槃中一切受永灭——所依粗重受、彼果境界受各四种 → 重颂 → 命名「瑜伽了义之教」，大会获利。

## 三、关键结论
1. 菩萨修奢摩他毗钵舍那，以「法假安立」与「不舍无上正等觉愿」为依为住，不离大乘愿果。
2. 三摩地所行影像与心无异——「我说识所缘唯识所现」，是本卷唯识要义的纲领。
3. 由四种所缘境事（有分别影像、无分别影像、事边际、所作成办）判摄止、观、俱所缘，是修行阶次的总框架。
4. 知法五相、知义十相（尽所有、如所有、七真如等）普摄一切法义，构成大乘止观的所观境。
5. 依七真如由见道进修十地，以楔出楔、如炼金法陶炼其心，究竟证得无上菩提；十地各对治一特定障，如来地永断二障。
6. 总空性相——于依他起、圆成实中一切品类杂染清净遍计所执相毕竟远离、都无所得，是菩萨于空性相离增上慢的关键。

## 四、易混辨析
- **奢摩他 vs 毗钵舍那**：奢摩他缘无分别影像，由内三摩地心相续作意、引身心轻安而立；毗钵舍那缘有分别影像，于三摩地影像所知义中正思择、最极思择、周遍寻思伺察。未得轻安前二者均唯名「随顺胜解相应作意」。
- **依法 vs 不依法**：依法是依自所受所思法相而得止观，配利根随法行菩萨；不依法是依他教诫教授（如观青瘀、无常、苦、无我、涅槃寂静）而得止观，配钝根随信行菩萨。
- **缘别法 vs 缘总法 vs 缘无量总法**：别法缘各别契经；总法摄一切契经为一团一聚作意思惟，随顺真如；无量总法则缘无量法教、无量法句文字、无量后后慧所照了。
- **止相 vs 举相 vs 舍相**：止相治掉举（缘可厌法及无间心）；举相治沉没（缘可欣法及心相）；舍相于双运转道二随烦恼染污时，无功用作意、心任运转。
- **闻所成慧 vs 思所成慧 vs 修所成慧**：闻慧依文如其说、未善意趣；思慧亦依文、能善意趣，然未现前；修所成慧亦依文亦不依文，所知事同分三摩地所行影像现前，能领受成解脱义。
- **相缚 vs 粗重缚**：相缚是于境相执取系缚；粗重缚是烦恼种子所引粗重系缚。奢摩他毗钵舍那所作之业即解脱此二缚。

## 五、阅读提示
建议带着三个问题读：菩萨既依法假安立，为何影像终归「唯识所现」？七真如与十地所对治障如何对应？「以楔出楔」如何贯穿从见道到如来地的修行？
