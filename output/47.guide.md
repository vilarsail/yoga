# 瑜伽师地论卷第四十七 导读

## 一、内容总览

本卷属《瑜伽师地论·本地分》中「菩萨地」之「第二持随法瑜伽处」，含四个品目：菩萨相品第一、分品第二、增上意乐品第三、住品第四之一。前二品从「相」与「行」两面揭示菩萨的外显样貌与修学要领，第三品转入菩萨内在意乐的层层升进，第四品将菩萨行归纳为十二住位阶次并详释最初三住。全卷由相、行、意、住四维，搭建起菩萨从初发心到将证菩提的完整修证框架。

## 二、结构层次

本卷以「外相 → 行法 → 内意 → 位住」四层递进，由表及里、由因至果：

- **菩萨相品（外相）**：嗢拖南总标菩萨五相（哀愍、爱语、勇猛、舒手惠施、能解甚深义理密意）→ 每相各开「自性、依处、果利、次第、相摄」五转，构成「五相 × 五转」网格化展开 → 末以「五相配六到彼岸」收束，明五相即六度所摄。
- **分品（行法）**：问在家出家菩萨云何速证菩提 → 嗢拖南标四法（善修事业、方便善巧、饶益于他、无倒回向）→ 四法分述，其中「善修事业」以四行相（决定、委悉、恒常、无罪）配六波罗蜜多，「方便善巧」列十种成五事 → 末以「出家菩萨于在家者甚大高胜」作差别收束。
- **增上意乐品（内意）**：先由「七相怜愍」立慈悲之基 → 由怜愍发起「十五种增上意乐」（最上意乐乃至俱生意乐）→ 十五意乐「能作十事」将意乐落实为事业 → 末以「十五意乐普摄世尊一切所说」收束。
- **住品第四之一（位住）**：嗢拖南总标「菩萨十二住 + 如来第十三住」为框架 → 释「种性住」（本具善种）→ 释「胜解行住」（从初发心到未净意乐，详述其行状相，含五怖畏、三忘失等过患）→ 释「极欢喜住」（净胜意乐，断五怖畏、发十大愿、修十净法、现百神变），是全卷着墨最重处。

## 三、关键结论

1. 菩萨真实之相有五，一一皆具「自性、依处、果利、次第、相摄」五转，可操作、可勘验，非泛论菩萨心行。
2. 在家出家二分菩萨虽同修四法，然出家菩萨于在家者「甚大殊异甚大高胜」，解脱亲属、俗务、梵行、证通、律仪五重过患。
3. 菩萨意乐以「七相怜愍」为体、以「十五意乐」为相，最胜者名「俱生意乐」，能令菩萨速证菩提。
4. 菩萨行位总摄为十二住，前十一住是因，第十二「最上成满菩萨住」是菩萨极果，第十三如来住为果上究竟。
5. 胜解行住与极欢喜住是修行关键转折点：前者以「思择力」为主、未离五怖畏、有忘失念；后者入「净胜意乐」、永断五怖畏、发十大愿、得百三摩地与百神变。

## 四、易混辨析

- **种性住 vs 胜解行住**：种性住是本具菩萨善种、性自仁贤，尚未发趣；胜解行住是从初发心起、未得清净意乐，已发趣而未得未净。
- **胜解行住 vs 极欢喜住**：前者胜解「为诸随烦恼染污而转」，有漏有退、未断五怖畏；后者胜解「离随烦恼净胜解转」，永断五怖畏、入正性离生、生如来家。
- **有加行无相住 vs 无加行无相住**：前者仍须「有加行有功用」于真如无分别慧修俱行；后者于前多修习已「任运自然」运转道随行，功行已纯熟。
- **清净意乐 vs 善清净意乐**：清净意乐是从净胜意乐地到决定行地所有意乐；善清净意乐唯指到究竟地之意乐，阶位更高。

## 五、阅读提示

读本卷可带着「菩萨从初发心到成佛，到底要经历哪些可辨识的阶次」这一问题，重点关注胜解行住与极欢喜住之间的转折——这是从凡夫菩萨入圣菩萨的关键节点，五怖畏的断与未断是其分水岭。
