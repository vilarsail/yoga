# 瑜伽师地论卷第九十 导读

## 一、内容总览

本卷为《瑜伽师地论》卷第九十，属「摄事分·契经事处择摄第二之二」，承上卷续明契经要义。全卷以三段嗢拖南（提纲颂）为纲，依次敷演：一、业之种种分类与断尽之道（五种二业、十三种三业、四业）；二、无智与如实智、定障对治、补特伽罗差别、二种着、法无我、八圣道、水海与生死海之譬喻；三、道不同分、师假立句、二世间、世间边际、空住与空性修习。要旨在于：由业的周遍分类导入「如何尽业」，由生死海与水海的对比显出超渡之难，由空住与空性的辨析指示修空的正轨与颠倒。

## 二、结构层次

全卷以三段嗢拖南为轴，各自领起一大片法义，呈「提纲颂 → 逐一展开 → 收束」的循环结构：

- **第一嗢拖南（业品，P1-P31）**：以「五二与十三，四业为最后」总举业类数目 → 先列五种二业（重轻、增进不增进、故思非故思、定受不定受、异熟已未熟）→ 次列十三种三业（善不善无记、顺三受、顺三时、学无学、见修断、曲秽浊净默然）→ 后列四种业（黑黑、白白、黑白黑白、不黑不白）→ 继而依此逐项释义：重业三因缘（意乐、加行、田）→ 故思所造与定受业 → 顺乐受等三业、顺现法受等三时业 → 故思不善业的除断（现法断、生断、后断）与四无量对治 → 曲秽浊净默然五业 → 黑黑等四业以那落迦、魔宫、六触处之果报处所收束。

- **第二嗢拖南（智定障着等，P32-P86）**：以「无智智与定，殊胜障学等，着无我圣道，二海不同分」为纲 → 先明无智（邪见、我见、无明三种杂染）→ 次明二种如实智（如理作意所发、三摩地所发）及分位转变、无常苦想 → 内法者与外道定心之别及六触处五种寂静妙行 → 如来胜安立智超苦乐 → 勤修定者二门二时二地诸欲障碍与五种对治 → 二种补特伽罗（已得意、未得意）与不放逸、六处寂灭增上慢 → 二种着及过患 → 法无我与八圣支道五相 → 以水海与生死海三种不同分（自性、沦没、超渡）收束。

- **第三嗢拖南（道师空性等，P87-P132）**：以「道师不同分，王国二世间，有为遮身行，坚执三空性」为纲 → 道二种不同分（自性、行相）→ 五种师假立句与憍慢三过患、离慢三胜利 → 王国譬喻与有情器世间 → 有为无为空 → 世间边际 → 二种空住（尊胜、引彼）→ 正见圆满与世间道、出世道修空 → 应所证空（外空、内空）与应所修空（无我见、无常见）→ 以杂住过患、利养恭敬之患收束，归宗于修梵行之必要。

## 三、关键结论

1. 业的分类可从多维度展开（重轻、故思与否、定受与否、善恶无记、顺三受三时、学无学、见修断、曲秽浊净默然、黑白等），同一业可归入多类；最终指向「不黑不白无异熟业」——出世间无漏业能尽诸业。
2. 重业由三因缘成重：意乐（猛利缠）、加行（无间殷重长时积集、劝他赞叹）、田（有恩有情、住正行及正行果者）；与彼相违名为轻。
3. 故思所造不善业可由现法断、生断、后断三种方式除断；修四无量定能尽恶业因缘，以其对治有量境界之恶业心、发起无量饶益意乐故。
4. 内法者虽未得定，由信闻无我胜解便能于六触处断知离欲证解脱，胜于外道虽得非想非非想定而未能断六触处——以智胜故。
5. 生死海与水海有三种不同分：自性（一切行为自性、无边无量）、沦没（诸天亦没，由身语意贪嗔痴及生等苦）、超渡（异生于五可爱境及内六处未能超渡，有学遍知六处方能毕竟超渡）。
6. 空性正修：非谓诸法自性毕竟皆空（那是颠倒趣入），而是于自相上一类有一类非有、一分远离一分不离地如实观照；应所证空（外空、内空）与应所修空（无我见、无常见）相互依止。

## 四、易混辨析

1. **曲业 vs 秽业 vs 浊业 vs 净业 vs 默然业**：曲业是邪见所起（外道邪见增上力）；秽业是猛利贪嗔所起；浊业是猛利痴（上品钝根忘失念）所起；净业是能往善趣妙行；默然业是能往涅槃妙行。前三染污，后二清净，对读可见由邪见→贪嗔→痴→善趣→涅槃的递进。

2. **黑黑异熟业 vs 白白异熟业 vs 黑白黑白异熟业 vs 不黑不白无异熟业**：黑黑感那落迦（各别处所纯苦）；白白感天趣（各别处所纯乐，如魔宫梵世等）；黑白黑白感余处苦乐杂受；不黑不白是出世间无漏业，不再招异熟、能尽诸业。

3. **尊胜空住 vs 引彼空住**：尊胜空住是阿罗汉观无我住，法尔尊胜、于诸住中最胜，是果；引彼空住是初修者了知烦恼有无、修断行、证三摩地、观察无我，是引导趣向尊胜空住的方便，是因。

4. **应所证空 vs 应所修空**：应所证空是证得果，分外空（超过五种色想、离欲贪）与内空（断增上慢）；应所修空是修行方便，分无我见与无常见。后者依止前者，无常见又依止无我见，层层相因。

5. **时爱心解脱 vs 不动心解脱**：时爱心解脱是钝根阿罗汉所得，于世间定是退法，时时退失时时现前，于现法乐喜欲证住；不动心解脱是利根阿罗汉所得，不退法，以无漏道力解脱，一切种都无退失。

## 五、阅读提示

读此卷可带着两个问题：(1) 业的种种分类最终指向什么？——指向「如何尽业」，即出世间无漏业能尽诸业，修四无量、修空性是关键对治道。(2)「空」的正义为何？——非谓诸法自性毕竟皆空（那是颠倒趣入），而是于自相上一类有一类非有、一分远离一分不离地如实观照，世间道与出世道各有其修法。
