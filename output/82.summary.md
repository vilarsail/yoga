- **全篇总括**：本卷是《摄释分》的下半篇，主题是「怎么讲经、怎么解经」：前半从听众一头入手——说法师先用一到十的理由把听众安置到恭敬闻法的状态，再学开场赞佛的略与广，然后串起一场完整开示的五道工序；后半选一句十二字经文「住学胜利」作解剖标本，示范拆文、释义、探发起、辨差别、答疑难、立次第的整套解经方法，最后收束为解释一切经典的六相公式。
  - **安置听者：为什么值得恭敬地听法**
    - **卷首接续前卷**：「说法者」的话题，转到听者一头：法师开讲前第一件事不是讲内容，而是「安处」——把听众安置到恭敬、无倒听闻的状态；论中给出从一到十的层层理由
      - **一、二因打底**：恭敬听法现前就能兑现利益与安乐（收益当场到账，不是远期支票）；且法本身「善建立」（离过失、有大义），说与听双方的辛劳才有殊胜果报，否则「徒废己业」、两皆无果
      - **三、四因看果报**：恭敬听法能舍恶趣、得善趣、速引涅槃之因；细看是一条四步链——听懂契经等法 → 舍不善、受诸善 → 离恶因所招后苦 → 速证涅槃
      - **五因列出两个「五」**：一是佛法的五个面向（有因缘、有出离、有依趣、有勇猛、有神变，详见《摄异门分》）；二是五种发心恰对应闻思修三种智慧的清净方便——闻所未闻、闻已研究属闻慧，除断疑网、弃背诸见属思慧，以慧通达甚深句义属修慧
      - **六到八因换角度证明法值得听**：能报佛恩、观自利、离热恼……；由此修集七种正法（知法、知义、乃至知人的尊卑差别）；法又易得（连旃荼罗即最低种姓者也可听）、易修（行住坐卧皆可修）、能引增上生与决定胜二果、初中后皆善、感现乐与后乐
    - **九因把听法说成一场「越狱」**：恭敬听法能解脱九种世间逼迫——生死牢狱、贪等坚缚、七财之贫、闻法之俭、无明之暗、四暴流（欲有见无明四种烦恼激流）、烦恼之病、贪爱之网、生死旷野稠林；其中生死牢狱最重，故放在第一条
    - **十因**：是从现世生活到三乘证果的十步路线
      - **前三条是现世受用**：得思择力（如法求财、见过患而受用）、善知出离（失财遭病不悲恼）、于诸欲深见过患而清净出家、证诸静虑
      - **中间是证悟的台阶**：速顺证解甚深缘起（佛说圣弟子专耳听法能断五法、修七法、速疾圆满）→ 「所有集法皆成灭法」（凡缘起之法终归熄灭）→ 远尘离垢、生正法眼 → 引摄预流果乃至阿罗汉果资粮
      - **后三条指向高远处**：引摄独觉资粮、无上菩提资粮、一切世间出世间静虑解脱等持等至
  - **赞佛：开讲前如何致敬法源**
    - **安置好听众之后**：说法师将欲开阐先当赞佛；赞分略、广两种
      - **略赞五相**：从五个维度评一位导师：妙色（三十二大丈夫相、八十随好）、静寂（密护根门、永拔烦恼习气）、胜智（于三世法及非世法无碍无著）、正行（自利利他正行圆满）、威德（神通游戏）
      - **另有六种略赞**：功德圆满、离垢染、无浊秽、无与等、唯利有情为业、于此业有堪能（广分别见《摄决择分》）
    - **广赞佛是一长串名号的连排**：每个名号都带一条理由
      - **前段立德**：能施光明、除无智暗、具三眼、见胜义谛、戒圆满——故是两足中尊、调御中最胜、沙门众中最殊美、世间难得珍宝
      - **「人中」比喻系列逐个给出理由**：人中师子（离怖畏）、人中牛王（御大众）、人中龙王（无误失）、人中良马（心善调）、人中莲华（不为世间八法即利衰毁誉称讥苦乐所染）
      - **中段立果**：白法圆满、一切智、苦乐不扰其心；善调、寂静、安隐（已入决定地）、般涅槃（已证菩提）、拔毒箭（拔爱箭）——还能调未调者、寂未静者（令凡夫证预流一来果、令初二果进证不还与阿罗汉）；另有两个技术词：离垢（断烦恼障）与无垢（断所知障、兼拔习气），胜观（日夜六反观察世间）
      - **收尾在大悲**：经三大阿僧祇劫长时积集方证，缘一切有情、以一切种苦为境界，于损恼变异利养得无转、于有情平等转
  - **五分说法：一场完整开示的五道工序**
    - **讲完安置听者与赞佛两大环节**：本节回头串起整场说法的完整流程
      - 先当寻求经文的文与义 → 次以五种释转相解释 → 再把自己安立于前说的法师十种圆满（善法义等）→ 然后处五大众、以八种可喜乐言词为众说法 → 安处他住恭敬无倒听闻 → 又应先赞大师功德
    - **五分具足的说法者**：如五分音乐能令自他生大喜乐；善修学已更有五种胜利
      - **五种胜利**：解佛语不难、善圆满说诸法相、令自他相续生广大欢喜、引善出离且天人名誉遍满、生起无量功德
  - **例经「住学胜利」：一句经文怎么拆**
    - **方法主体由此展开**：经以文义为体，所以先拆文、再拆义——本节选一句十二字的「汝等苾刍。应当安住修学胜利」作标本
      - **拆「文」**：十二字、四名、一句，摄名、句、字身；言说是学处之相则摄行相；本为苾刍请问而说则摄机请；如来言音则摄于语——一句之内六种文具足（其余诸句同理）
    - **拆「义」**：八个角度逐一提问
      - **地义**：学胜利=资粮地；慧为上首=加行地；解脱坚固、念为增上=见地、修地、究竟地
      - **相义与作意义**：学胜利显戒自相、并显作意建立的处所；慧为上首——慧自体是自相（所依、助伴、所缘是共相）、配了相与胜解作意；解脱坚固——永离烦恼粗重、配远离摄乐方便究竟方便究竟果作意；念为增上——念自相、配观察作意（由此道理，于「智」等中随应建立）
      - **依处义**：依涅槃而学处所摄清净行，随应起教导乃至庆喜——于过去现在已证、正证故庆喜（起示现），于未来起教导及赞励
      - 胜利义=修三学速得圆满；过患义=出家者不应行异行、不应储余财；所治义=犯戒、无智、烦恼、忘念（三学等行即能治）；略义=略举其宗，展开即广义，此外无过无增
  - **法与等起：这部经是什么、佛为什么说它**
    - **文义拆完**：还要交代经的「身份」与「发起缘由」
      - **法**：十二分教中此经属契经所摄，又是记别（因说了义故）
      - **等起（发起缘由）**：佛为自显遍行智力（遍知一切境的佛智力）而发起此经；也为令精勤修清净行者、及重财利者信解，依住学胜利等精进修习速圆三学
    - **等起的核心是「对症下药」**：每句经文都是开给特定人群的药
      - 学胜利为远离种姓形相的挂名苾刍、及诈现轨则威仪的苾刍；慧为上首为远离贪着虚誉称赞的苾刍；解脱坚固念为增上劝修真实正行的苾刍——四种苾刍体由此显出
      - **四句各治一病**：乐追求世间文章咒术、于戒慢缓者 → 说学胜利；守戒而舍多闻者 → 说慧为上首；唯于闻思生喜足者 → 说解脱坚固；于戒慧解脱起增上慢者 → 说念为增上
      - **药理**：贪乐声誉者慧不增长；离此过者方能于真实正行、正解脱中堪任劝导（对下劣喜足者则劝令渐渐增进）
  - **别义与义门差别：一个词的多副面孔**
    - **进入词义细部前先立骨架**：总义上此经宣说正行及正行果，三学是「学」的边际，「如是住」显四种瑜伽所摄的正方便；别义则训释「学」字——清净身语正命现行是学自性，由此正行令尸罗（戒）、忍辱等修显发故名学，为静寂清凉进习除灭亦名学
    - **「学胜利」的义门差别**：同一名目在五个维度各有一副面孔
      - **自性差别**：所显示的是七品尸罗（或者超过一百五十学处）
      - **界差别与时差别**：欲界是别解脱律仪（逐条受持的戒律仪轨），色无色界是静虑律仪，无漏律仪不系于任何界；而此学过去已学、未来当学、现在正学，于三世平等无异
      - **位差别**：未成熟是下位、正成熟是中位、已成熟是上位；勉励修行为苦位、喜乐修行为乐位、非苦非乐位；又皆是善位；闻位、思位、修位；未证增上心慧唯是增上戒位，证得则兼二位
      - **补特伽罗差别**：唯说出家声闻（非独觉——彼别自觉悟；非菩萨——彼以解脱为坚固），钝根利根、贪行等分行薄尘行皆摄，唯人非天
      - **慧为上首、解脱坚固、念为增上三句**：各随其应有如上五种差别
    - **「胜利」的词源**：功德增进圆满之名的差别——此法能饶益、应称赞，随生有情定应随逐，称赞所随，故名胜利
    - **门差别之下**：经文五个关键词各用「自性、训词、门差别」三件套训释
      - **苾刍（比丘）**：舍离家法、趣非家之名，自性是具足别解脱律仪众同分，怖畏恶趣自防守、摄无损故名苾刍；住：俯就于时精勤修习之名，离所说学无有别法，以种种威仪摄受时分故名住
      - **慧**：智、见、明、现观等之异名，自性是简择法相的心所有法，简择性、治无智故名慧；念：不忘失、心明记忆之异名，自性是心所有法，追忆诸法、明了记忆故名念
      - **解脱**：永断、离系、清净灭尽、离欲等之异名，自性是粗重永害、烦恼永断，能脱贪等系缚故名解脱（又为种种牟尼体性）；门差别：待时解脱与不动解脱、见所断与修所断、欲色无色三界所系
  - **释难：问答环节钉死疑难**
    - **训释之后是释难**：用问答把四句经文各钉死一义
      - 住学胜利=于增上戒学见胜功德而住；慧为上首=诸根中慧根第一；解脱坚固=见修所断烦恼永断；念为增上=于少下劣不生喜足（「增语」即别名代称）
    - **疑问一**：他经三学次第另说，为何此中戒后说慧不说心？
      - **答**：闻等所成慧摄受无悔等，由此渐次得三摩地——增上心学就藏在这条链里；引五根为证：五根中慧根最能摄受，由慧根力乃至能修定根——慧是引定、引烦恼断之因，故心慧俱时而说（另问「不说增上心学修习圆满」，道理同前）
    - **疑问二**：为何但说住学胜利，不说住慧胜利、住解脱胜利？
      - **于下劣中劝取胜利**：也就令所化有情于胜妙中摄受胜利；且摄受于僧等十种胜利分明易了易入
      - **为何说住慧上首不说住解脱上首**：解脱另有「不共差别」——慧于无常法上无上，解脱以常故最为坚固
    - **「住学胜利」的正定义与十种胜利的内部结构**
      - **定义**：在所施设学处中观十种胜利，常守尸罗、坚守尸罗、常作、常转；总句「摄受于僧」之下：令僧精恳=离受用欲乐边，令僧安乐=离受用自苦边——先不落苦乐二边
      - 未净信令净信、未入正法令入正法；已净信令增长、已入正法令成熟；难调伏令调伏、犯戒者善驱摈、惭愧者安乐住、净持戒者令无悔
      - **二漏之防**：防现法漏=随顺摧伏烦恼缠；防后法漏=止息邪愿修梵行、随顺永断随眠（潜伏的烦恼种子）
      - **十种胜利略摄为三**：令僧无染污住、令僧得安乐住、令佛圣教长时随转——前二由敬养、自苦行、资财乏少、展转相触、心追变、烦恼缠、邪愿七种随护显示，末句显圣教相续不断
    - **四道工序的精确定义**：常守尸罗=不弃舍学处；坚守尸罗=不毁犯学处；常作=于学处无穿穴；常转=穿穴已复还净（受学学处=具随学诸学处）
    - **修行人再以正念自查三问**：尸罗蕴圆满不、于诸法有正慧善通达不、于解脱善证不——依正念持学胜利、发上首慧、证坚固解脱（此解脱无退故名坚固，是出世间圣智果；正念三来源：因说法、依教授、观察应作不应作）
    - **最后一组「依何立句」**：依何戒？苾刍戒（最胜故）；依何慧？具依闻思修三慧；依何解脱？出世间不动解脱；依何念？应作不应作观察随念（就胜为言）
  - **次第：三种排列各答一个问题**
    - **疑难清完**：卷末从三个角度重排全经的推进逻辑
      - **圆满次第答「怎么走完」**：先安住苾刍尸罗 → 次听受正法 → 次如理思惟；持戒无忧悔 → 无悔等渐次生定 → 正思惟令增上心学速得成满——前前后后渐圆满
      - **能成次第答「靠什么成立」**：由住学胜利能成慧为上首，由慧为上首能成解脱坚固，而这一切又由念为增上能成（如是住修三学速得圆满，亦名能成次第）
      - **解释次第答「为何这样讲」**：先释「大师」（能教诫应作不应作事、能化导令苦寂灭、为摧邪外道出现世间）与「声闻」（从他闻法声、亦令他闻）——唯为声闻说住学胜利等，因声闻众是佛随顺修学的真实之子
  - **散句落实与「利益安乐」之辨**
    - **广分别中剩余的名相**：逐一落实
      - 此中法=宣说名句文身，学处=所宣说的五毁犯聚（五类犯戒罪聚）；五种悲智名号各配定义：具怜愍（长夜恒住慈等无量）、具大悲（拔济多苦）、乐义利（与众生多乐）、求利益（与妙善法）、恒悲愍（拔除诸恶不善法）
      - 「为令多人梵行久住」依刹帝利等族姓说、「转增广」依有情种类后后增广、「为诸天人」依有势力者说——显大悲普覆一切而非唯一分；「正善开示」即如其所有性、尽其所有性而说；正法即十二分教，当听受研寻、任持读诵、处静思惟
    - **「利益」与「安乐」是两把不同的尺子**：佛随不同场合分别使用
      - 能令汝利益=依增上戒说；能令汝安乐=不依止弊苦艰难不自在行；利益安乐=离欲者的增上心行与增上慧行（行善名利益、能饶益名安乐）
      - **另一组对照**：赞杜多（头陀苦行）功德处=利益；听受百味饮食百千衣服处=安乐；制立三学处=利益安乐兼摄——佛以彼彼慧善观察，为利益、为安乐、为利益安乐，分别依增上戒、心、慧三学而说
    - **两个「善」各有二因缘**：善观察（长夜串习遍了知、无倒正觉悟）、善证得（到究竟、不还无退）
    - **「我所应说如是已说」是总结句**：略所标举与广分别至此收束
  - **六相：解释一切契经的万能公式**
    - **卷末把全卷方法压缩成六相**：任何一部经典都可按它解释
      - 一遍知事（事即蕴、界、处、缘起、念住、正断等）；二舍离恶行及诸烦恼随烦恼；三受学善行；四以如病等行智遍知通达；五彼果（厌患、离欲、解脱、遍解脱）；六自及他领受彼果（我生已尽）
    - **由此六相及如前所建立诸相**：应善解释一切经典——「如是等类名摄释分」
