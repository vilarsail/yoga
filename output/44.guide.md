# 瑜伽师地论卷第四十四 导读

## 一、内容总览
本卷承接前文菩萨地初持瑜伽处，涵盖两品：第十六「供养亲近无量品」之末（供养三宝、亲近善友、修四无量），以及第十七「菩提分品」之开篇（惭愧、坚力持性、心无厌倦、善知诸论、善知世间等菩提分法）。全卷以两首嗢拖南总摄："供三宝　亲善友　修无量　最为后"与"惭愧坚力持　无厌论世智　正依无碍解　资粮菩提分　止观性巧便　陀罗尼正愿　三摩地有三　法嗢拖南四"，是菩萨从积集资粮、依师闻法，到起悲度生、深入世间的一组核心行门。

## 二、结构层次
本卷以两品嗢拖南为纲，先以"供养—亲近—无量"三事收束前品，再转入"菩提分法"展开后品：

- **供养三宝（P1-P19）**：先列十种供养名目 → 逐一举相解释（设利罗/制多/现前不现前/自作教他/财敬/广大/无染/正行）→ 比较福果胜劣（唯现前·唯不现前·俱供；唯自作·唯教他·自他俱）→ 摄归"正行供养"为最第一 → 结云"如供养佛，如是供养若法若僧"，由佛推广至法僧，并辅以六种增上意乐。

- **亲近善友（P20-P37）**：以连续问答展开 → 善友八支（自相圆满）→ 五相不虚（所作利益）→ 五相作信依处（外相威仪）→ 五相为善友事（化他：谏举·令忆·教授·教诫·说法）→ 四相亲近（弟子之行）→ 听法五想 → 于师五处不作异意，层层落到"如何听闻正法"。

- **修四无量（P38-P73）**：先明三种缘（有情缘/法缘/无缘）↔ 配慈悲喜舍四门 → 指出共不共（初共外道·次共二乘·无缘唯菩萨）→ 别就"悲"广明一百一十苦为所缘 → 十九苦摄大悲 → 大悲四缘 → 结归"菩萨菩提悲所建立"，附四无量功德胜利。

- **菩提分法（P74-P110）**：以长嗢拖南总列十五门 → 依次释惭愧（自性+四依处）→ 坚力持性（自性+五依处）→ 心无厌倦（五因缘）→ 善知诸论（五明处·名句文身）→ 善知世间（有情世间五浊·器世间成坏·八相观义）→ 菩萨于世间待人接物之仪则，由"知"落到"行"。

## 三、关键结论
1. 十种供养中，"正行供养"（少时修慈悲喜舍、于涅槃修胜利想、于三宝波罗蜜多随念、于离言法性起无分别心）最第一最上最胜，胜过财敬供养百千邬波尼杀昙倍。
2. 善友须具八支（戒、闻、证、哀愍、无畏、堪忍、无倦、善词），弟子当以四相亲近、五想听法、五处不作异意，于说法师未尝见过。
3. 四无量有有情缘、法缘、无缘三重：初共外道，次共二乘，唯无缘无量不共一切声闻独觉及诸外道。
4. 菩萨观一百一十苦修悲，由四缘（甚深微细、长时积习、猛利作意、极清净）故名大悲；如来答"菩萨菩提谁所建立"——"悲所建立"。
5. 善知世间须如实知有情世间五浊增减、器世间成坏、世间集灭与爱味过患出离，及世俗假名与胜义，方能于世间正知正转。

## 四、易混辨析
- **三种无量**：有情缘无量缘有情起与乐拔苦想，共外道；法缘无量正观唯法假说有情，共二乘不共外道；无缘无量于诸法远离分别，唯菩萨不共一切。
- **惭 vs 愧**：惭是于罪现行"内生羞耻"（自省），愧是"于他敬畏外生羞耻"（畏他）；二者自性虽异，依处同有四种（应作不作、不应作作、覆恶、恶作随逐）。
- **设利罗供养 vs 制多供养**：设利罗供养是亲供如来色身（遗体/舍利），制多供养是于为如来所造之塔、龛、台等处设供，一缘身、一缘塔。
- **五浊**：寿浊（命短不过百年）、有情浊（不识尊长、不修福戒）、烦恼浊（非法贪、斗诤妄语）、见浊（推求像似正法）、劫浊（饥馑疫病刀兵中劫）；前四约有情，第五约时节。

## 五、阅读提示
读本卷可带着"菩萨如何积集资粮、如何依师闻法、如何起悲度生"三条主线，对照两首嗢拖南的目录功能，把纷繁的名相归位其下，避免迷失在十相、八支、五想、百一十苦的枚举中。
