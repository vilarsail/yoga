# 瑜伽师地论卷第三十三 导读

## 一、内容总览
本卷为「声闻地第四瑜伽处之一」，由有作意转入世间道与出世道二趣，广辨世间离欲道——七作意（了相/胜解/远离/摄乐/观察/加行究竟/加行究竟果）配初静虑至非想非非想处八地，详释初静虑离欲恶不善法有寻有伺离生喜乐，次明四静虑、四无色定、二无心定、五神通及诸天生差别。七作意与八定次第是本卷核心，为声闻地世间道修法的根本。

## 二、结构层次
全卷按「二趣 → 七作意 → 四静虑 → 四无色 → 二无心定 → 五神通 → 诸天生」推进：
- **二趣（P3-P6）**：世间道（外道/羸劣止行/善根未熟/菩萨当来证）与出世道；世间道观下地粗上地静。
- **七作意（P7-P28）**：了相（觉了欲界粗相初静虑静相，六事寻思）→ 胜解（超过闻思唯用修行起胜解）→ 远离（最初生起断烦恼道断上品烦恼）→ 摄乐（断中品烦恼爱乐断远离）→ 观察（审察未断随眠离增上慢）→ 加行究竟（断下品烦恼伏断方便）→ 加行究竟果（证入根本初静虑定离生喜乐遍身分）；余六作意摄入随顺/对治/顺清净/顺观察四作意。
- **四静虑配位（P29-P43）**：初静虑离欲恶不善法有寻有伺离生喜乐五支具足；二静虑内等净心一趣定生喜乐；三静虑离喜安住舍正念正知有身受乐；四静虑舍念清净不苦不乐心住无动。
- **四无色（P44-P48）**：空无边处（超色想有对想种种想入无边空）→ 识无边处（超空无边处入无边识）→ 无所有处（超识入都无余境）→ 非想非非想处（超无所有，非有想非无想，唯微细想缘无相境）。
- **二无心定（P50-P52）**：无想定（异生弃背想作意，已离遍净贪未离广果贪）→ 灭尽定（圣者止息想受作意，已离无所有处贪）。
- **五神通（P53-P62）**：依静虑发神境/宿住/天耳/死生智/心差别五通，修十二想（轻举/柔软/空界/身心符顺/胜解/先所受行次第随念/集会音声/光明色相/烦恼所作色变异/解脱/胜处/遍处）。
- **诸天生（P63-P66）**：四静虑下中上品生梵众至色究竟，五净居唯不还者无漏间杂熏修有漏。
以「七作意 → 八地次第 → 定果神通生差别」为统一骨架。

## 三、关键结论
1. 七作意配离欲：了相（觉了粗静）、胜解（起胜解修行）、远离（断上品）、摄乐（断中品）、观察（离慢审察）、加行究竟（断下品）、加行究竟果（证根本定）；前二名随顺厌坏对治，次二名对治断对治。
2. 初静虑五支：寻伺喜乐心一境性；离生喜乐遍诸身分无有间隙。
3. 二静虑离寻伺内等净心一趣定生喜乐；三静虑离喜住舍正念正知有身受乐；四静虑舍念清净不苦不乐心住无动，断寻伺喜乐出入息三灾患。
4. 四无色：空无边处超色想、识无边处超空、无所有处超识、非想非非想处超无所有唯微细想。
5. 二无心定：无想定异生弃背想作意、灭尽定圣者止息想受作意；灭尽定已离无所有处贪。
6. 五神通依静虑修十二想引发，圣神通堪任有用、非圣如幻不堪受用。
7. 五净居天唯不还者以无漏第四静虑间杂熏修有漏第四静虑所生。

## 四、易混辨析
- **了相作意 vs 胜解作意**：了相约闻思间杂觉了粗静相、六事寻思；胜解超过闻思唯用修行于所缘起胜解。
- **远离作意 vs 加行究竟作意**：远离最初生起断烦恼道断上品烦恼、加行究竟断下品烦恼心得离系。
- **观察作意 vs 摄乐作意**：摄乐断中品爱乐断远离、观察审察未断随眠可爱净相是否起习近心以离增上慢。
- **无想定 vs 灭尽定**：无想定异生弃背想作意已离遍净贪未离广果贪、灭尽定圣者止息想受作意已离无所有处贪。
- **初静虑寻伺 vs 二静虑内等净**：初静虑未见过失有寻伺对治欲界善寻伺、二静虑寻伺寂静内等净心一趣。
- **圣神通 vs 非圣神通**：圣神通随所变事化事胜解皆能如实成办堪任有用、非圣如幻化唯可观见不堪受用。

## 五、阅读提示
本卷是世间道修法根本，可带「七作意配离欲 → 四静虑四支 → 四无色八地 → 二无心定 → 五神通十二想 → 诸天生」六线索读；七作意与烦恼品对治表、四静虑支差别表最宜对照把握。
