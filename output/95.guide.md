# 瑜伽师地论卷第九十五 导读

## 一、内容总览
本章为《瑜伽师地论》卷九十五，属『摄事分中契经事缘起食谛界择摄第三之三』，紧接前卷继续抉择契经中『谛』（四圣谛）的事义。全卷以『谛智』为轴心：从如理与不如理作意的分判，到集谛所摄百八爱行的差别相，再到转法轮的相状、谛现观的修习方便与障碍、未现观的过患，最后归结于圣谛智的殊胜义利与人身难得。是一部关于『如何依四圣谛修证现观、断除诸漏』的修学指南。

## 二、结构层次
全文以『谛智』为轴心，按『所断→能修→差别→转法轮与现观→过患与义利』五段递进：

- **所断门（如理不如理分判）**：先立不如理作意（依恶说法起邪胜解 → 三世我见 → 六种见处 → 萨迦耶见为根本的见稠林、见旷野、见结等）→ 反显如理作意 → 由如理作意入圣谛现观、断见所断漏 → 为断修所断漏，修四种因缘（善护身、善守根、善住念、修出世道）。构成『流转→还灭』一对。
- **能修门（循身念与止观）**：四圣谛摄一切善法 → 修循身念（缘色身、名身）生起观品（无常苦无我）与止品（忍慈、尸罗清净、得三摩地）→ 始修业地究竟成满 → 进趣已作办地（观造色如草木泥、通达缘起、趣入四圣谛）→ 一切有漏无漏善法皆入四谛摄。
- **集谛差别门（百八爱行）**：由四因缘（内外、所依、自性、时分）抉择集谛所摄百八爱行 → 五种我慢为依发起有爱、无有爱 → 三十六种爱行 × 三世 = 一百八种 → 复以流润、着境、痈根、纤缴等十一喻显示爱之自性。
- **转法轮与谛现观门**：五相善转法轮 → 三周正转十二相智（智、明、觉）→ 四种瑜伽为入现观方便 → 谛智六种作业 → 谛现观如肴膳、如大石楼 → 四种障碍（不信、上慢、待时、放逸）→ 闻思修三慧任持。
- **过患与义利门（收束）**：未现观四种过患（黑黑异熟业等喻）→ 四圣谛智如四阶蹬 → 三种爱枪不能转动三类有情 → 诸苦多分已断 → 人身难得、见谛难得、资粮难得 → 以『善识恩养、惠施作福』等世间正行收结。

## 三、关键结论
1. 如实知四圣谛是与不如理的根本分水岭：不如理作意以萨迦耶见为根，滋生六种见处；如理作意则入谛现观，渐断见修所断诸漏。
2. 一切世出世间善法皆入四圣谛摄——能知智亦是所知境，无一法在谛外。
3. 集谛所摄百八爱行，以五种我慢为依，由内外、所依、自性、时分四因缘差别建立，津润、流溢、纤缴等十一喻显其相。
4. 转法轮以三周十二相为方便，从菩萨现观到阿若憍陈最初悟解，展转随转至梵世，故名为『轮』。
5. 谛现观有四种障碍——不信、上慢、待时、放逸，须由闻思修三慧任持对治；既证之后，如大石楼不为异论所动。

## 四、易混辨析
- **如理 vs 不如理**：如理者，听闻正法、为寂静调伏涅槃而起胜解；不如理者，闻不正法、不为寂静而起邪胜解，于不如理生颠倒想。
- **见稠林 / 见旷野 / 见结**：同以萨迦耶见为自性，由障碍妙慧名『稠林』，损善法名『旷野』，能结构后有苦名『见结』。
- **始修业地 vs 已作办地**：前者依循身念修观品（无常苦无我）与止品（忍慈得定），究竟第四静虑；后者进观造色如草木泥、通达缘起，趣入四圣谛智，起厌患解脱。
- **有爱 vs 无有爱**：有爱依五种我慢发起，有软中上三品，愿『我当有』；无有爱由审思择方起，无三品差别。

## 五、阅读提示
读本章可带着两个问题：（1）『谛智』如何从『听闻』一步步推进到『现观』？（2）『百八爱行』的四因缘差别如何一一对应？把握『如理—修习—现观—义利』的主线，对照各喻（疾病、大石楼、肴膳、四阶蹬、爱枪），便不难贯通全卷。
