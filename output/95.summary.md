- **全篇总括**：本卷是四圣谛的实战手册：先判定思惟的方向（如理还是不如理），清点「我」被安放的六种位置与一百零八种爱行这条造苦生产线；再看佛陀怎么开讲四谛（转法轮五相）、修行者怎么入门（断漏四抓手、循身念两地、四种瑜伽）；接着列出入现观的四大障碍及其对治；最后结算这笔账——三种异熟业决定投生去向、证果后还剩多少苦，以及这一切为什么难得。
  - **岔路口与见处：思惟方向决定断不断烦恼**
    - 这一大块回答：同样在听法思惟，为什么有的能断烦恼、有的越修越苦——先立判定标准，再清点跑偏的具体内容，最后给正面功课
    - **如理与不如理**：判定标准不在知识对错，而在方向——是否导向寂静（心平）、调伏（习性驯服）、涅槃（苦的止息）；结论：于谛智不如实知 → 不能尽漏（断不尽烦恼），如实知 → 能尽诸漏
      - **跑偏者画像**：不乐亲近正法与善士、不受学别解脱戒与密护根门（守护感官门户）、于圣谛无闻思修，反而闻不正法起「邪胜解」（把错的坚定认成对的、把不如理当如理）——参照系坏了，越努力越偏
      - **非理作意的双向拧巴**：该思的无颠倒法（契经应颂等）不能解了也不思，不该思的颠倒法不能解了却偏要故思
      - **病根**：依三世言论的增上缘，于过去未来现在计我或有或无——一切不如理作意都绕着「我」转
    - **六种见处**：「我」能被安放的全部位置，都以萨迦耶见（执五蕴身心为「我」的见）为根本
      - **前五处**：在三世诸行（身心相续）里找「我」，按所取（被认知的对象）与能取（能认知的心）分出五相：缘所取成常见（我实是常）或断见（我无）；缘能取则「以我观察我」「以我观察无我」，甚至以「无我」随观昔曾有我——连无我也被安立成我
      - **第六处**：在身心之外安立实我，并虚构这个我做事——能作、能起、能生、能说、能受、领受，乃至「能舍此蕴、能续余蕴」；支撑它的论证是：若无有我，这些事谁来成办？
      - **这类见的别名串**：障真实微妙慧名见稠林、损善法名见旷野、劳役他人名见厌背、诘责他论而自动摇名见动摇、能结构后有之苦名见结；结局：潜伏的漏被养到现前，下品养出中品、中品养出上品，生起当来老病死苦——由不实知而造作苦谛集谛杂染
    - **断漏四抓手**：正面功课——听正法起正胜解，随观三世诸行无我我所；见道断见所断诸漏之后，修道位还须精勤修习四种因缘
      - 善护身（远离恶象等险难，为尽漏扫清障碍）、善守根（于可爱境界远离非理净相、思惟不净相）、善住念（安住四处：受用衣物经思择、能除遣恶寻思、能忍受精勤疲苦与粗恶言等、依不放逸无杂而住）、如先所得出世间道以妙慧多修习——四因缘具足，修所断诸漏皆得解脱，乃至证得最极究竟
  - **循身念两地：观与止怎么一步步长出来**
    - 这一大块回答修道功夫的具体样子：修循身念（以身为所缘的正念），从始修业地（起步段）走到已作办地（成办段），每段都长出观品（慧）与止品（定）
    - **先立总纲**：诸法略分能知智与所知境，而能知智也是所知境——所以一切与智俱行的善法无不归四圣谛摄；「四谛唯是境界、另有我在修善」之说被当场驳斥
    - **循身念的公式**：始修业地缘内外大种色、或缘触受想行识；已作办地缘所造色、缘作意与所生诸蕴——或缘色身或缘名身，各个实例全照此套
    - **观品善法**：于内外大种色及余诸蕴起正决择慧
      - **三类想**：于外大种观劫尽修无常想；于内大种观身唯食、渐渐不净修不净想；观身从爱生长、后有老死修无常想与苦想
      - **分野与落地**：愚夫于此身执我我所，圣弟子如实知无常苦而不执（苦无我想）；遇手足杖块等非爱触时，于受等诸行正观无常、离爱离恚、唯观有界（唯有界想）——即远离愚痴
    - **止品善法**：以观为依，于内正安住心
      - **生长链**：依锯喻教授于怨家修忍辱 → 无倒修慈 → 戒得清净 → 无忧悔 → 欢喜 → 得三摩地乃至第四静虑
      - **清理与岔路**：此时三摩地仍被行相拘执、未能无功用双运——再修四支不放逸行，第四静虑才清净鲜白；若为静定爱味漂转、不观涅槃寂静，则对佛法僧深生厌耻（依三宝竟无所得、是恶得非善得），内心调柔故才生厌耻便能安住平等妙舍；始修业地成满的标志：妙慧净治第四静虑 + 于萨迦耶心增上舍
    - **已作办地**：于所修不生喜足，观造色身如草木泥，以如实慧通达缘起、趣入四圣谛智；依上修道起厌患 → 离欲 → 解脱 → 解脱智见
      - **到此大师教中所应作事皆已作讫**：不同于异生以世间道解脱、作已仍会退失重作，此是毕竟作
  - **集谛解剖：一百零八种爱行**
    - 转入集谛，回答「爱到底有多少种面貌」——由内外、所依、自性、时分四种差别，把爱展开成一百零八种爱行
    - **内外差别**：以内外六处为依起诸爱行；所依差别：爱依止五种我慢——未衰老时「是我如昔」、好色大力安乐辩时「我今美妙」、反之「我非美妙」、衰老损败时「我今变异」
    - **自性差别**：五慢为依发起有爱与无有爱——有爱分软中上三品（软品「愿我当有」、中品「愿我得有」、上品「愿我定有」猛利追求），无有爱须审细思择才能生起、不立三品；计数：内六处为依说十八种爱行、外六处亦然，合三十六种，再乘过去未来现在三世——共一百零八种
    - **爱的一串别名**：因（集谛摄）、流润（顺生死流漂转）、着境、痈根（引生五取蕴痈病之苦）、流溢（难制伏）、纤缴（微细现行被魔所缚）、条干（上至有顶）、枯竭（令无饱足）
    - **三界分层**：欲界爱名冥闇、色界爱名昏昧、无色界爱名翳瞙
      - **三人喻**：盲瞽全无所见 ↔ 闭目少分似见 ↔ 翳瞙覆眼见而不睹真色——病一层比一层轻，但都在迷
  - **转法轮五相：佛陀怎么开讲**
    - **视角切换**：前面讲弟子怎么修，这里讲老师怎么教——善转法轮有五道工序
    - **五相**：一为得所缘境界（菩萨时所缘即四圣谛）→ 二得方便 → 三证得自所应得 → 四得已树他相续、令信解自证 → 五令他于他所证亦生信解
    - **方便** = 三周正转十二相智
      - **第一转**：菩萨入现观时如实了知是苦圣谛乃至道圣谛——现量圣智能断见道所断烦恼，说名生圣慧眼；依三世差别名智、明、觉
      - **第二转**：有学妙慧通达「犹有所作」——未知苦应遍知、未断集应永断、未证灭应作证、未修道应修习
      - **第三转**：无学已得尽智与无生智（苦已遍知、不再受生的两种智慧）——「所应作我皆已作」；前二转是有学慧眼，第三转是无学慧眼
    - **自证** = 无上正等菩提；树他相续 = 阿若憍陈如闻正法最初悟解四谛、答「我已解法」，与诸比丘皆证阿罗汉
    - **令他信他所证**：憍陈如起世间心说我已解法 → 如来印知 → 地神举声传告、展转乃至梵世
      - **「轮」的得名**：法义展转随转如轮；正见等法所成性故名法轮；为梵行增语所转故名梵轮
  - **入现观之路：凭什么入门、走到哪算哪**
    - **回答从凡夫到无学怎么分程**：先立四种入门瑜伽，再以医病喻定位四谛，然后划出位次
    - **四种瑜伽（一条因果链）**：净信增上 → 发生厚欲 → 精进炽然（有势、有勤、有勇、坚猛、不舍其轭）→ 有善方便（念 + 正知 = 不放逸：于染法防守心、常修诸善法）
    - **医病喻给四谛定位**：苦谛如疾病、集谛如起病因、灭谛如病得除愈、道谛如病愈后令不再生——病者与良医都只需这几味法药，故更无第五圣谛
    - **背谛智不成现观者有十相过患**：胜义不认其为沙门、于后有众苦与恶趣皆未解脱、堪能弃舍正所学处、不堪证出世间圣道果涅槃、唯能寻访世间福田、不堪超更多苦不还与现法解脱等——与此相违即十相功德
    - **得依处与得方便**：于善说法毗奈耶净信出家名得依处，所趣向者三种——声闻菩提、独觉菩提、如来无上菩提；得方便即三周正转，随其次第智见现观（直观亲证四谛的智慧现前）
      - **位次两种划分**
      - **按进程**：智位（入现观时如实了知是苦圣谛等）→ 见位（此后于诸谛复有所作：遍知、永断、作证、修习）→ 现观位（无学地：我已遍知、永断、作证、修习）
      - **按体性**：无学尽无生智所摄极解脱智名智位；此智所引正见名见位；从预流果（初果）至究竟的一切学慧名现观位
  - **谛智的作业与功德：这智慧工作时什么样**
    - 回答「证得谛智后它能做什么、威力多大」
    - **作业及相举要**：是能永灭众苦的前行（如日将出先现明相——正尽苦者断初见谛所断众苦，作苦边者断至阿罗汉）；又能对治大无明闇（如日光破世间大闇）
    - **广大用果**：已证谛智永断三结（见道所断的三种束缚）者，纵因失念暂为欲贪嗔恚所染，依不放逸入初静虑、由触谛智即得不还果（不再还生欲界）；渐次虽入非想非非想定，因已证不退法而与外凡迥别
    - **谛智所见的一对总图**：过去已生、现在正生、未来当生，总名集法；由无常灭——已灭、向灭、当灭，总名灭法
    - **稳固如大石楼**：八方猛风不能倾动、一切异论不能移转；悟解不假他缘、不视他面、不观他口——不再等外道说什么才决定信什么
    - **结构与体受**：四圣谛智渐次集成、缺一不可，名谛现观——如肴膳，圣弟子的无上慧命皆依此活；得一智而阙余三如睒弥叶，四智具足则如娑罗枝叶一切圆满；谛智与喜乐俱、觉真义、令身心极轻安
    - **代价换算**：阙谛智者堕那落迦（地狱）受烧燃、治罚二苦，无量生猛利大苦；反之，为得谛智纵使一身灭坏尚应踊跃忍受——毁百身也值得，何况只此一身
  - **现观四障碍：多数人为什么入不了**
    - 讲完功德接着回答「既然难得，为何多数人入不了」——四障碍：不信、上慢、待时、放逸，佛一一亲自开示对治
    - **不信三种**：于谛现观不生信解、于僧善行不生信解、于佛菩提不生信解
      - **破前二**：佛自引现量所证——「我于四圣谛得现观故证觉菩提」「我昔与汝长世流转，由未正思惟；今由正见通达尽生死流转，自今无后有、唯余最后身」
      - **破第三**（若是一切智，何以有的问题记、有的不记）：佛所觉法如大地草木叶，为他说者如掌中叶少不足言；不记别是因能引无义利，非不知
    - **上慢（未证谓证）**：佛先立两难作比——远以箭射箭而筈筈无遗、析一毛为百分置其毛端而不落，已极希有；通达圣谛更难于彼：以能取作意还即通达能取作意，能缘所缘平等平等、无漏智生，最细最难
    - **待时（把修行推待后时）**：得无坠人身已极难（引盲龟为喻），哪有时机可等
    - **放逸略说三种**：邪思惟、邪寻思、邪戏论
      - **邪思惟** = 于不应思处强思惟：我于过去世有耶无耶、未来我是谁从何来往何去、世间常无常有边无边、命与身一异、此作此受、静虑境界、诸佛境界、如来灭后有无
      - **不应思惟的二因**：一非思惟所缘境；二其事无所有——强思求之，唯有令心转增迷乱；邪寻思即欲等寻思，邪戏论六种（颠倒、唐捐、诤竞、于他分别胜劣、分别工巧养命、耽染世间财食）
    - **对治总纲**：世尊亲为堪受化者教诲、令速断放逸；弟子以三行相任持圣谛——闻慧任持其文、思慧任持其义、修慧任持其证
      - **思慧释「圣谛」得名**：法性（真实义本身是谛）+ 胜解（于真实义起谛胜解），愚夫唯依法性、圣者二种具足，故偏名圣谛；修慧证得内证现量谛智并得证净，谛智与证净更互相依——一处有一必有第二，疑惑由此远离
  - **反面结算：四过患与三种异熟业**
    - 回答不成现观者会落在哪、业力如何决定投生
    - **四种过患**：爱乐下分恶趣之行、造业增长 → 颠坠恶趣坑；爱乐欲界人天烧煮之行 → 生彼大热恼常所烧然；爱乐色无色界无明昏闇之行 → 堕于生闇；退失受用境界涅槃之道 → 中间堕入常见、断见、现法涅槃见三种妄见黑暗，坠堕三界
      - **三种异熟业（掷杖为喻）**
      - **黑黑异熟业**：纯黑之业，掷杖根堕——感那落迦、傍生、鬼趣
      - **黑白黑白异熟业**：杂业，掷杖不定——或堕恶趣不清净处、或生善趣少清净处
      - **白白异熟业**：生色无色界，然寿尽业尽仍退堕五趣——如五辐轮旋转不住
    - **上升教的高下**：教世间道虽能升至有顶，非第一义、非毕竟升；如来圣谛相应言教是第一义、毕竟升——世俗智至有顶只名世间聪慧，由谛智方是第一义聪慧
  - **四谛智阶梯与大义利：解脱这笔账**
    - 收尾先给四谛智一个建筑结构，再算清证果后还剩多少苦
    - **四谛智四喻**：初（苦谛）智譬如本足、第二（集谛）智譬如墙壁、第三（灭谛）智如下层级、第四（道谛）智如上宝台——又即四阶蹬上升大智慧殿、四桄梯蹬上解脱寂灭
    - **三爱三枪**：三种爱如三支枪，魔罗执之挠搅生死大海、令受生有情随而回转；但三种有情不被回转——劲锐（预流）、处中（余有学）、逆流道行圆满者
    - **苦的余断之喻**（多分已断、少分犹在）：慢所成苦如砾石对大雪山；无色爱苦如大池沼仅沾二三滴、色界爱苦如大陂湖、欲界爱苦如大海；业惑所生苦以金山、苏迷卢、大地及泥团为喻
    - **大义利结算**：有学最极唯余七生人天之苦，恶趣苦已越度；无学唯现法所依之苦在，余一切苦皆已越度——故圣谛如实现观有大义利
  - **后难得：一连串「难得」清单**
    - 卷末回答「这么好的东西为什么稀罕」——从身到慧到资粮层层说难得
    - **难得的阶梯**：住是身入谛现观，此身最为难得 → 圣明眼见谛的有学转甚难得 → 闻思修所成妙慧难得（于善说法中解了能审分别 → 胜了能生胜解 → 决了于法入证）
    - **现观资粮难得**：孝养父母等善业道、有暇圆满（生恶趣已难可解脱、生善趣已速疾乖离，故甚难得）、世间初正见乃至解脱智的十种正法
      - **资粮如何落地**
      - **善识恩养**：了知父母皆应孝养而勤修孝养；乐己利者了知沙门婆罗门是福田而勤修供养
      - **善御家长**：知亲属以我为室为归、我乐彼乐我苦彼苦——时以饮食衣服医药摄受、为彼义利勇励施造；不求报答、禀性忠平、不淫佚费财、不于非处发怒，于耆长尊重处正善随转——一切以正法不以非法
      - **两重怖罪**：于此世罪（或杀缚罚退、或被讥毁）正思择已终不现行；于他世罪（感恶趣苦与匮乏苦）亦然
      - **施福斋戒**：时时间受学施福业事（看病、躬自执当事佛法僧）、受斋学戒乃至尽寿；十业道由闻思慧正多修习
    - **卷末归于正见**：见谛故正见无差别生起（于三世已生、今生、当生）；世间正见应随防护、有学正见并其断果应随触证、无学正见并其离系果应随作证——如正见，乃至解脱智亦尔
