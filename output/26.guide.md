# 瑜伽师地论卷第二十六 导读

## 一、内容总览
本卷为「声闻地第二瑜伽处之一」，先以嗢柁南总列十六义门，再广辨「补特伽罗品类差别」与「建立补特伽罗」，并开启「所缘」一门，详述遍满所缘、净行所缘中之不净与慈愍所缘。是声闻地由根机论转入行法论的开端，补特伽罗建立与所缘境事构成本卷主体。

## 二、结构层次
全卷按「嗢柁南总列 → 补特伽罗品类 → 建立补特伽罗 → 所缘境事 → 不净慈愍」推进：
- **总列（P1-P2）**：嗢柁南举补特伽罗、建立所缘教、学随顺学法、坏瑜伽作意、瑜伽师作修、果门数取趣、因魔事无果十六门。
- **补特伽罗品类（P3-P31）**：总标二十八种 → 逐广辨（钝根/利根、贪嗔痴慢寻思增上、得平等/薄尘性、行向/住果、随信行/随法行、信胜解/见至、身证、极七返有/家家/一间、中般/生般/无行/有行般涅槃、上流、时解脱/不动法、慧解脱/俱分解脱）。
- **建立补特伽罗（P32-P52）**：总标十一差别道理 → 逐广辨（根/众/行/愿/行迹/道果/加行/定/生/退不退/障差别建立）。
- **所缘境事（P53-P78）**：总举四种所缘 → 遍满所缘四相（有分别影像/无分别影像/事边际性/所作成办）→ 颉隶伐多问佛四义安住其心（相称/相似/无倒/不舍静虑），以二伽他释。
- **不净所缘（P79-P95）**：六种不净（朽秽/苦恼/下劣/观待/烦恼/速坏）→ 朽秽分依内依外 → 治五贪 → 四种憺怕路。
- **慈愍所缘（P96-P101）**：亲怨中三品 → 慈俱心无怨无敌无损害 → 广大无量胜解遍满 → 慈悲喜别。
以「总标品类 → 逐广辨 → 建立道理 → 所缘四事 → 净行别明」为统一骨架。

## 三、关键结论
1. 补特伽罗品类二十八种：约根机（钝利/贪嗔痴慢寻思增上/得平等/薄尘性）、约果位（行向/住果/随信行/随法行/信胜解/见至/身证/极七返有/家家/一间/中般/生般/无行/有行般涅槃/上流/时解脱/不动法/慧解脱/俱分解脱）差别建立。
2. 建立补特伽罗由十一差别道理：根、众、行、愿、行迹、道果、加行、定、生、退不退、障差别；愿可移转而种姓不可移转。
3. 四行迹：苦迟通（钝根无定）、苦速通（利根无定）、乐迟通（钝根有定）、乐速通（利根有定）。
4. 四种所缘境事：遍满、净行、善巧、净惑；遍满所缘四相摄毗钵舍那品（有分别影像）、奢摩他品（无分别影像）、一切事真实事（事边际性）、因果相属事（所作成办）。
5. 六种不净治五贪：依内朽秽治内身欲欲贪、依外朽秽治外身淫贪（青瘀治显色、变赤治形色、骨锁治妙触、散坏治承事）、苦恼下劣治境贪、观待治色贪、烦恼速坏治萨迦耶贪。
6. 慈愍所缘：于亲怨中三品平等利益意乐，欲界乐名广、初二静虑乐名大、第三静虑乐名无量；慈与乐、悲拔苦、喜庆乐。

## 四、易混辨析
- **钝根 vs 利根**：约所知事诸根运转迟速、堪能势力辨；又有本来种姓与已/未善修习二相。
- **随信行 vs 随法行**：随信行从他求请教授教诫、唯随他信修行；随法行自有功能势力随法修行、不从他求。见道时分别名信胜解、见至。
- **慧解脱 vs 俱分解脱**：慧解脱已尽诸漏而未身证八解脱；俱分解脱已尽诸漏复于八解脱身作证具足安住，烦恼障与解脱障俱解脱。
- **有分别影像 vs 无分别影像**：前者毗钵舍那行观察简择，后者奢摩他行寂静其心九相住内。
- **尽所有性 vs 如所有性**：尽所有性约色等五蕴外更无余色等；如所有性约所缘真实真如四道理性。二种合名事边际性。

## 五、阅读提示
本卷是声闻地行法论开端，可带「二十八品类 → 十一建立 → 四所缘 → 六不净治五贪 → 慈愍三品」五线索读；四行迹与根/定关系表、六不净与五贪对治表最宜对照把握。
