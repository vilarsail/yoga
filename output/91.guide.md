# 瑜伽师地论卷第九十一 导读

## 一、内容总览
本卷属《瑜伽师地论·摄事分》「契经事处择摄第二之三」，紧接前卷续讲「处」类契经要义。全卷以四组嗢拖南为纲领，统摄离欲、杂染、根门律仪、精进解脱、菩萨胜道等主题，由声闻行者的离染断惑，渐次推进至菩萨六处圆满超胜声闻，最后以「寻求我论」收摄于空性正见，一线贯穿。

## 二、结构层次（★重点）
全卷由四组嗢拖南串联，整体呈「杂染过患 → 对治方便 → 位次差别 → 菩萨殊胜 → 空性收束」的递进骨架：

- **离欲与杂染（P1-P15）**：嗢拖南「离欲未离欲…」总起 → 三种缠与随眠使取识染净，染则不任证涅槃 → 四如理问者、六识身因缘、二杂染自性（欲贪）行路（内外处） → 保命忽然夭丧之警策 → 魔所著「着安足处」 → 外境、内受二杂染 → 十五相爱见杂染收束。
- **因同分与解脱位次（P16-P46）**：总别嗢拖南「因同分思缚解脱相触遍胜解护根门教爱相为后」 → 因同分识随入无我 → 六处灭离戏论俱四种行相 → 缚与解脱 → 善守根相、草木相似、如来明力 → 破四种苦乐邪论（自作他作俱作无因） → 四相平等精进 → 阿罗汉六处胜解、三学、五种补特伽罗 → 密护根门三类补特伽罗 → 新学苾刍淫贪三对治。
- **律仪与退缘（P47-P77）**：嗢拖南「唯缘寻思愿…」 → 六触处唯为作缘 → 寻思躁扰九相安住 → 后有愿微细缚（三十三天囹圄喻） ↔ 律仪非律仪、软中上世间有学无学律仪 → 不护根门造众苦 ↔ 律仪三因缘摄持虫兽六根 → 妙慧资粮三过患、圣谛现观 → 七因缘退舍所学 ↔ 白品不退。
- **着处邪行至菩萨胜道（P78-P104）**：四着处 ↔ 四种邪行 → 于义不善与圣教广义、边际根成熟住 → 不护根门顺流者 ↔ 非顺流者 → 八相摄菩萨正行道（哀愍→内勇悍→谛察法忍→出离→观谛行→广大正见→无漏觉分→进修无上修道） → 六处修满证六种自在圆满，超胜声闻为无有上。
- **寻求我论收束（P105-P110）**：四种寻求我论（自性、转、因、窟宅） → 破萨迦耶见 → 施设十二处六识为我 → 诸行如幻如阳焰、本无今有有已散灭 → 约世俗谛诸行尚空何况胜义 → 闻思修三慧次第生欢喜、等喜、遍喜。

## 三、关键结论
1. 杂染以欲贪为自性、内外处为行路，缠为现行、随眠为根本，离此即堪证究竟涅槃。
2. 六处灭究竟寂静中，有无、异不异等戏论俱四种行相不应思惟，唯应依他增长觉慧审谛观察。
3. 苦乐唯是根境识三事和合所生，唯触遍行为因，自作、他作、俱作、无因四邪论皆虚妄计度。
4. 阿罗汉六处胜解最极圆满，有学仍因忘念与未断烦恼而减劣；五位补特伽罗由三学次第所摄。
5. 菩萨由八相正行道、六处修满证六种自在圆满，超胜声闻乘为无有上。

## 四、易混辨析
- **律仪 vs 非律仪**：律仪于可爱境诸杂染心不忍不执，暂起寻还弃舍；非律仪则放纵「心牛」入境界田，损坏善根苗稼，缠与随眠犹尚和合。
- **软中上世间律仪 vs 有学无学律仪**：软、中世间律仪由思择力摄，唯能暂伏过患；上品世间律仪由修习力摄，观受无常乃至有顶；有学律仪永断见道所断，无学律仪更断修道所断，最极圆满无过无胜。
- **有学六处胜解 vs 阿罗汉六处胜解**：有学似幼童等持念慧羸劣，遇胜境时忘念现前仍有所作；阿罗汉贪嗔痴永断，得尽智无生智，六种恒住所摄，第一义最极圆满。
- **顺流者 vs 非顺流者**：不护根门、为境界爱所蔽伏、行恶不善失路沿流名顺流；与此相违白品名非顺流。

## 五、阅读提示
读时可带着两个问题：一是「杂染如何由缠到随眠、由外境到内受层层建立」，二是「从凡夫到阿罗汉到菩萨，根门律仪的位次如何递进」。把握「着安足处」与「六处胜解」两条线索，即可贯通全卷。
