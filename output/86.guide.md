# 瑜伽师地论卷第八十六 导读

## 一、内容总览
本卷为《瑜伽师地论·摄事分》「契经事行择摄第一」之第二部分，承接前卷对「行」（诸有为法）的抉择。全卷由两首嗢拖南（总颂）统领：前半围绕无常想、慧眼清净、九智、我见差别、无余依涅槃、三解脱门等「行择」要义展开；后半转入速疾通慧、自体无常、流转喜足、顺流逆流、资粮正道、师所作事等修道次第与僧事议题。是连接义理抉择与修行实践的枢纽章。

## 二、结构层次
全卷以两首嗢拖南为骨架，分两大块，每块先颂后广，由解入行：

- **第一颂（想行……三后广）→ 行的体相与抉择**：
  - 五无常想（无常/无恒/非久住/不可保/变坏法）→ 三愚夫相 ↔ 三智者相（缘起观察 → 凡圣对照）。
  - 慧眼清净（远尘离垢）→ 十种胜利（断缠断随眠 → 得果证净无畏，因果并举）。
  - 九智能遍知超越诸行 → 三处无愚痴住 → 三烦恼异名（贪/嗔/痴各列多名）→ 喜贪差别（辨析名相细微处）。
  - 四胜进想 → 四种我见（分别/俱生/缘自/缘他）→ 三相无余依涅槃 → 三解脱门建立四法嗢拖南 → 二种增上行欲（胜解俱行/意乐俱行）。
  - 由涅槃惊恐、身见随逐 → 对治二法 → 三见差别（依彼而转/由彼遍知/应所引发），收束于见道修道的次第。

- **第二颂（速通……师所作等品后广）→ 修道次第与僧事**：
  - 速疾通慧三力（智力/不放逸力/数习力）→ 智见差别多门辨析 → 四善巧事（念住/正断/神足/根力觉道）→ 清净道四差别 → 五渐次。
  - 自体诸行五因无常 → 十五相觉了诸行（聚沫/浮泡/阳焰/芭蕉/幻事五喻）。
  - 二种生死（种类/器）五种不同分 → 愚夫五相流转 → 爱结/爱锁系缚 → 四喜足 → 五爱所行路 → 游爱行路果相。
  - 顺流漂溺五相 ↔ 逆流聪慧十相（对比）→ 萨迦耶见断三差别 → 无常苦想四差别（果/自性/品类/方便）。
  - 违资粮五法 ↔ 顺资粮五法 → 住时/行时正道言教 → 师所作事五事 → 驱摈七缘/入聚落十缘/入天住八缘/摄受五相 → 邪行六相及其对治（无相心三摩地）。

## 三、关键结论
1. 诸行无常可由五性（无常、无恒、非久住、不可保、变坏法）层层观察，凡夫不明此五性即落三愚夫相，智者反是。
2. 远尘离垢得法眼即获十种胜利，由见道时断缠（远尘）与断随眠（离垢）两重离系而成，一约现行一约种子。
3. 九智中前五（流转、还灭、杂染因缘、清净因缘、清净）是异生位所修，后四谛智属圣者证得，二者相须方能遍知超越诸行。
4. 三解脱门（空、无愿、无相）建立四法嗢拖南（一切行无常、一切行苦、一切法无我、涅槃寂静），是全卷义理之纲。
5. 萨迦耶见永断有三相差别（念、境界、想），是判定有学无学的关键；断此见后方能逆生死流、入涅槃道，得三种胜利。

## 四、易混辨析
- **远尘 vs 离垢**：远尘约「缠」离系，指见道时粗我慢断灭、见所断诸烦恼缠得离系；离垢约「随眠」离系，指一切见道所断烦恼随眠断。一约现行，一约种子。
- **诸行流转智 vs 诸行还灭智**：前者观喜集、触集、名色集三因缘集故诸行集，是顺观缘起；后者观三因灭故三行灭，是逆观还灭。一顺一逆。
- **胜解俱行欲 vs 意乐俱行欲**：前者由四法嗢拖南于诸行中生乐欲，缘有为法起；后者缘涅槃寂静独处思惟，向无为起。前者易退转，后者以无我胜解为依。
- **种类生死 vs 器生死**：种类生死是有情自体生死，不共因生、相续无断、断已无续；器生死是外器世间，共因所生、火水风坏、断而复续。五种不同分（因/时/治/断/续）。

## 五、阅读提示
带着「凡夫如何转为圣者」的主线读：先以无常想与慧眼立其基，再以九智与三见明其渐，最后以顺流与逆流、违资粮与顺资粮决其行。两颂之间是「解→行」的递进，前颂抉择理，后颂落实于修道与僧事。
