- **全篇总括**：本卷是《瑜伽师地论》「摄决择分」中有寻有伺等三地的第二篇，分两大块。前半抉择「烦恼杂染」：从烦恼怎样才算造业问起，依次梳理烦恼的相貌与潜伏形态、烦恼与苦乐感受的对应、断烦恼的条件与次第、断后的相貌与利益、烦恼攀缘的对象与发作方式，最后落到「投胎时一切烦恼都在场」。后半抉择「业杂染」：先定出「圆满恶业」的构成要件，再按统一公式逐条展开十种不善业道。全卷以问答加列数推进，体系性极强。
  - **板块一：烦恼杂染决择——把「烦恼」从长相讲到断除**
    - **本板块沿五站推进**：先看烦恼的长相（自相、共相、潜伏态），再看它绑定哪种苦乐、属于哪一界，接着讲怎么断、断后什么样，最后看它缘什么对象、怎样发作、怎样参与投胎
    - **烦恼的相貌：什么是烦恼、潜伏态有多少种**
      - **发业门槛：烦恼怎样才够得上造业**
        - **第一问「贪等十烦恼几能发业」**，答：一切都能发，但有两道门槛——唯有「猛利现行」（强烈发作）才造得出堕恶趣的业，失念中的发作不算；且须「分别起」（经思虑挑起）而非「任运起」（习惯性自然生）
      - **三相：给烦恼画像的三个角度**
        - **画像公式「自相＋共相＋差别相」**：自相是各各本性（贪自是贪、嗔自是嗔）；共相是共同的「不寂静相」——一切烦恼都让心不安静
        - **差别相分两路**：「门差别」是同一烦恼的不同称呼（结、缚、随眠、缠等，本地分已说）；「转差别」是烦恼运转变化的七类状态——随眠转、所缘转、现行转、品差别转、力无力转、因果转、迷行转，本卷重点展开
      - **随眠十八转：潜伏烦恼的十八种形态**
        - **「随眠」**（潜伏未现的烦恼习气）列十八种转相，多数成对，按四组对照理解
        - **按地界**：随逐自境↔随逐他境（生上地却被下地烦恼追）、被损（世间离欲者压伏了下地烦恼）↔不被损（自地烦恼压不住）、随增（遇境增长）↔不随增
        - **按身份与性格**：具分（凡夫全具）↔不具分（有学圣人已缺一角）、可害（有涅槃种性者终可断尽）↔不可害、增上（贪行等人烦恼偏重）↔平等↔下劣（薄尘行）、觉悟（与现行烦恼一起转）↔不觉悟（无现行仍暗中跟随）
        - **按苦果轻重**：能生多苦（欲界）↔能生少苦（色、无色界）↔不能生苦（已得自在的菩萨）
      - **随眠与粗重：习气是身心上可摘除的一层**
        - 问：既然「粗重体性名随眠」，它与身心相续是同是异？答：异——阿罗汉永断了烦恼粗重，身心相续仍在运转，可见粗重是身心中可分离的一层
        - **粗重也列十八种**，几乎覆盖一切身心涩劣状态：自性异熟、自性烦恼、自性业，烦恼障、业障、异熟障，再加盖、不正寻思、愁恼、怖畏、劬劳、饮食、眠梦、淫欲、界不平等、时分变异、终没、遍行
      - **迷行转：十种烦恼各自「迷」向何处**
        - **其余转相多指回前文**，此处展开因果转与迷行转：烦恼、业、生的整条链都以烦恼为因果，且只有欲界一分不善烦恼才招异熟果
        - **迷行转**：按对四圣谛的迷法给十烦恼分工：萨迦耶见（执有实我）、边执见、邪见对所知境起错误了别；无明是纯粹的「不了」；疑半明半不明；见取、戒禁取及贪嗔等以错误见解为对象，同属执取错误了别
        - **再分两路**：迷苦集谛＝迷「因缘所依处」，迷灭道谛＝因怖畏而迷；任运而起、修道所断的，是任运现行的迷执
      - **有事与无事：诸见与慢的对象是虚构的**——五蕴中实无有我，诸见与慢靠分别而转，属「无事」；贪与恚对象真实，属「有事」；无明与疑两边都通
    - **受报与三界：哪种烦恼绑定哪种苦乐，哪一界最重**
      - **受根对应：先立总规则再逐个对号**
        - **换角度问十烦恼**：各与乐、喜、忧、苦、舍哪种受根相应；总规则：任运而起的烦恼于三受皆现行——遍一切识身的与一切受根相应，不遍一切识身的与意地一切受根相应
        - **贪三受都可能伴随**：求乐受不得、求离苦受不得→忧苦相应；如愿→喜乐相应；于不苦不乐受耽着→舍相应；恚通常忧苦相应（被苦逼、思维可憎事发恨），也可喜乐相应——盼怨家「没苦不济、得乐还失」，愿望成真便生喜乐
        - **萨迦耶见与边执见随所依的受走**：于乐俱行蕴执我执常→喜根，于苦俱行蕴→忧根，于舍俱行蕴→舍根；断见所摄的边执见一切相反；见取、戒禁取随所取之见相应；邪见分人——先作善行者起邪见生忧（怕善行白费），先作恶行者生喜（以为作恶无报）
        - **慢分高举慢**（称量、解了、利养三种高举，喜根相应）与卑下慢（忧根相应）；疑看场合：在利养称誉善趣等好事上犹豫→忧根，在无利养讥毁恶趣等坏事上犹豫→喜根；无明则与五根全相应
      - **三界比较：欲界烦恼处处占「重」的一边**
        - **烦恼按所系缚的界分三聚**：欲界系、色界系、无色界系；只有欲界一分是不善，上二界全无记，不善才招异熟果（苦报）
        - **一串对照品目中欲界烦恼**：全取重的一边：多性、猛利长时染恼、发起外门杂染（向外攀缘）、发起恶行、能生多苦、大有罪、迟离欲、三摩地相违等——上二界取轻的一边；节末以偈颂收束
    - **断烦恼：八个问题一套答案**
      - **八问总起与「算断」的判据**
        - **讲完长相与来源转向实修**，连问八件：怎样能断、到什么程度算断、从何说断、顿断渐断、次第如何、断有几种、断后何相、有何利益
        - **「怎样才算断」给出多条平行判据**，条条落在同一门槛「对治已生，当言已断一切烦恼」：资粮积集、经方便地见地修地到究竟地；修四种瑜伽；相续成熟、得随顺教、内正作意、对治道生；了知烦恼的事、自性、过患而不坚着；止观双修；了知所缘而得转依
        - **止观一条偈云**：「相缚缚众生，亦由粗重缚，善双修止观，方乃俱解脱」——人被相缚（表象捆绑）与粗重缚（习气捆绑）双重束缚，止观双修才一起解开
      - **从何说断、顿还是渐**
        - **从「相应」与「所缘」两面说断**：对治道一生，烦恼不再生起、心不再与之相应、不再缘境，故名为断
        - **见道所断的烦恼顿断**：凭现观智谛现观（直接照见四谛的智慧），三心顿断一切迷苦谛等的见断烦恼；修道所断的渐断——须数数修道
      - **次第：由外而内像闯关**
        - **在家者**：先断不善业与恶见→再断出家障（欲、恚、害三种寻思）→再断得定障（眷属、国土、不死三种寻思）→再断得作意障（乐远离者的身粗重）
        - **之后依次**：见断烦恼→修断烦恼→属苦忧乐喜舍的诸定障品烦恼→（更上一类人）所知障品诸障——由粗到细层层推进
      - **种类、相貌与利益**
        - **断分两大类**：缠断（现行断）与随眠断（潜伏断），「离系断」即随眠断——压伏不算真断，拔掉潜伏习气才是
        - **断后之相**：可爱法无论现前与否、观察再猛利也不染着，可嗔不嗔、可痴不痴；六根触境不喜不忧、住于舍、正念正知；成就真实少欲、喜足、远离、精进、正念、寂定、聪慧，天性爱好无戏论
        - **断后之利**：超越忧苦、喜乐、色想乃至生等一切苦，证安隐、清凉、第一现法乐住，心自在转、所证不退、自义利圆满，或进而修利他行、令天人安乐
    - **对象与发作：缘境十五种，现行二十乘二十乘二十**
      - **缘境十五种：烦恼攀缘什么**
        - **烦恼各有「所缘」（攀缘对象）**，十五种按几组对照理解：具分缘（身见等把五蕴全体执为我）↔一分缘（贪嗔慢只缘一部分）；有事缘↔无事缘；内缘（缘自身六处）↔外缘（缘妙五欲）；现见缘（缘现在）↔不现见缘（缘过去未来）
        - **自类缘**（贪续贪，缘同类烦恼）↔他类缘（缘异类烦恼或烦恼所依事）；有缘（缘后有、盼来世）↔无有缘（缘断灭）
        - **自境缘是各缘本界行相**；他境缘是上地缘下地——生上地者见下地有情似有「常恒乐净」功德，自谓为胜而生慢等；无境缘是缘根本不存在之物——分别假计的灭道、广大佛法
      - **现行公式：二十种人依二十种缘起二十种现行**
        - **「谁、为什么、怎么发作」**：三条线各列二十格：二十种补特伽罗（人）、二十种缘、二十种现行烦恼
        - **二十种人按维度分组**：在家↔出家、住恶说法↔住善说法、增上烦恼行↔等分行↔薄尘行、世间离欲↔未离欲、见圣迹↔未见圣迹、执着↔不执着、观察↔睡眠↔觉悟、幼少↔根成熟、般涅槃法↔不般涅槃法
        - **二十种现行多成对**：随所欲↔不随所欲、无所了知↔有所了知（不知不觉起与明知故犯）、粗↔等↔微、内门（定中）↔外门（散心）、失念↔猛利、分别起↔任运起、可救疗↔不可救疗等；二十种缘是燃料——三受、欲、寻思、触、随眠、宿习属内因，亲近恶友、闻不正法、不正作意、不信、懈怠、失念、散乱、恶慧、放逸属外缘，再加烦恼、未离欲、异生性（凡夫本性）缘
    - **结生相续：投胎时一切烦恼都在场**
      - **全界结生：为何说一切烦恼都参与受生**
        - 问：投生时是全部烦恼都结生还是只有一部分？答：全部——未离欲者才能受生，其烦恼粗重随缚自身，本身就是换一个身体受生的因
        - **受生一刻的心理现场**：于自体贪爱现行、于男女起爱恚、疑心现起（「此男此女今为与我共行事不」）、我我所见及我慢等全都现行
      - **七种结生：什么样的人怎样入胎**
        - **结生分七种或开为九种**：缠及随眠结生（现行加潜伏）——凡夫；唯随眠结生（只剩潜伏）——见圣迹者
        - **入胎清醒度递进**：正知入胎——转轮王；正知入住——独觉；一切位不失正念——菩萨
        - **按能引分**：业所引发——除菩萨外一切人，引无义利；智所引发——菩萨，能引义利；节末偈「业相事乐等，不善等及断，所缘与现行，续生最为后」为整个烦恼杂染决择开出内容清单
  - **板块二：业杂染决择——一条恶业怎样才算「成立」**
    - **本板块回答「业」的问题**：先立业的分类框架，再定「圆满业道」的构成要件，然后按统一公式把十种不善业道逐条过一遍，最后展开各自的认定细则
    - **总纲：业的框架与圆满业道的要件**
      - **五相建立：业的分类框架**——业由五相建立：根本业道所摄的身语意业，加方便（准备动作）与后起（事后延续）所摄诸业；十不善业道就是「根本业道」所摄的不善身语意业
      - **自相要件：染污心＋欲乐＋现行究竟**
        - **圆满业道公式**：染污心（被贪嗔痴蒙蔽）＋起彼欲乐（起造作意愿）＋即于是处业现行而得究竟（就在目标上做且做完），支分圆满才算
        - **四个反例各缺一环**：有染污心无欲乐；心与欲乐俱有却认错对象；业未现行就完成；现行了却未究竟——都不圆满；掌握公式即可类推判定一切不善业道
    - **十业道逐一：一套公式过十遍**
      - **广建五相：把每条业道拆成五个零件**——完整自性差别由五相建立：事（对象）、想（认知判断）、欲乐（动机）、烦恼（背后三毒）、方便究竟（动作与完成时点）；事或有情数或非有情数，想有认对认错等四种，欲乐依倒想或无倒想而生，烦恼是三毒的任意组合，方便究竟在当时或后来完成
      - **杀生：写得最细的一条**
        - **事是有情众生**，于彼起「众生想」（不颠倒想），由此生「我当害生」的欲乐，烦恼是三毒或具不具
        - **完成时点分两种**：害后无间命终，当时成就究竟业道；过后才死，则于其命终时成就
      - **其余九条：各自的「完成点」在哪**
        - **不与取**：事是他人物，移离本处即究竟；欲邪行——事是不应行处（非支、非时、非处、非量等），两两交会即究竟
        - **妄语**：事是见闻觉知的有无颠倒，听众与对论者「领解」（谎言被接收）才究竟；离间语——被离间方领解才究竟；粗恶语——呵骂对方即究竟；绮语——「才发言」就算
        - **意三业道在心上完成**：贪欲——于他财心里决定「属己」；嗔恚——「损害等期心决定」（打定主意要害）；邪见——「诽谤决定」（认定并坚执诽谤）
    - **品级与圆满：业的轻重怎样判**
      - **杀生三品：罪的三个因缘**——杀生分有罪增长、有罪不增长、无有罪三品；生罪因缘有三：烦恼所起、能生于苦、希望满足——三缘全备是第一品，缺「希望满足」是第二品，只余「生苦」是第三品
      - **意三业道：五心齐备才算圆满**
        - **贪、嗔、邪见三条意业道各设五相**，要求五心齐备、缺一即非圆满
        - **贪欲五心**：耽着心（恋自财）→贪婪心（乐积财）→饕餮心（对他财生爱味）→谋略心（盘算「何当属我」）→覆蔽心（不觉羞耻、不知过患出离）
        - **嗔恚五心**：增恶心→不堪耐心→怨恨心（反复忆念不饶益事）→谋略心（盘算捶挞杀害）→覆蔽心；邪见五心：愚痴心→暴酷心（乐作诸恶）→越流行心（不如理推求）→失坏心（谤无施与爱养祠祀等妙行）→覆蔽心
    - **展开细则：十业道的认定清单**
      - **身三业：手段与动机全面收录**
        - **杀生**：手、块、杖、刀、缚录、断食、咒药、厌祷等手段皆算，为财利、除怨、自谓为法、戏乐皆算，自作教他都得杀罪
        - **不与取**：明劫、窃盗、攻墙、解结、伏道窃夺、拒债不还、寄物不还、诳谄矫诈取、怖畏方便取、现威德取……自取教他、自为为他皆罪
        - **欲邪行细目**：非支（产门之外皆算）、非时（经期、孕满、哺乳、受斋戒、病不宜时）、非处（尊重集会处、灵庙、大众前、坚鞕不平地）、非量（过量，量「极至于五」）、非理（不依世礼）；自行或媒合他人皆摄
      - **口四业：从内容到场合全算**
        - **妄语**：因自、因他、怖畏、财利而说，不见说见或见说不说，书面、默然示意、动肢体表态、作证、自说令他说——皆妄语罪
        - **离间语**：以实事或假合方便为乖离而说，依亲近、施与、知友、给侍等途径，自言令他言——皆离间语罪；粗恶语：当面辛楚之言，或不当面、对大众、幽僻处，随实过或不随实过，依种族、依止、作业禁戒过失——皆粗恶语罪
        - **绮语范围最宽**：歌舞歌词、佛法外无义书论受持赞美讽颂开示、斗讼诤竞语、王论臣论贼论国土论、乃至不思不择的无义言，另列七事——斗讼诤竞语、恶咒术语、苦所逼语、戏笑游乐语、处众杂语、颠狂语、邪命语
      - **贪欲：连「求清净名」也是贪**
        - **从谋财起**：想同家主统领仆使、想把他的父母妻子奴婢乃至七摄受事、十资身事都归己
        - **再到求名求供养**：想让人知道自己少欲知足、漏尽多闻，想让国王乃至商主、比丘比丘尼、优婆塞优婆夷恭敬供养；最后求利养与胜生：求衣服饮食卧具医药、求生天上妙五欲、求生鲁达罗、毗瑟笯世界乃至他化自在天——这一系列「起欲」皆贪欲业道所摄
      - **嗔恚：报复、支配与咒愿都是嗔**——「彼于我作无义，我于彼当作无义」「彼已作正作当作，我亦当作」的报复心、九恼害事，想缚害驱摈鞭挞怨家、散其财产夺其眷属的支配心，愿他丧失资财眷属善法、身坏生恶趣的咒愿心——皆嗔恚根本业道
      - **邪见与一问一答：为何业道中独说「诽谤见」**
        - **「决定无施」**（认定没有布施果报）乃至谤因、谤用、谤果、坏真善事——皆邪见根本业道
        - 问：一切倒见皆名邪见，为何业道中只说这条诽谤见？答：它为害最大——依止它能断善根、最顺恶业，怀此见者于恶法随意而行；其余见并非不是邪见，只是这条偏说于恶业道
