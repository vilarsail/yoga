# 瑜伽师地论卷第四十一 导读

## 一、内容总览
本卷为《瑜伽师地论·菩萨地》「戒品」第二部分。承接卷四十所立四他胜处重戒，本卷系统列举菩萨戒中诸「恶作」轻罪，逐条判明染违犯、非染违犯与无违犯三类，并辨明菩萨与声闻于遮罪的共学、不共学，开示菩萨为利他可「性罪少分现行」之特例，最后明还净出罪之法及勤学所成三种圆满。全卷以「判罪框架→逐条列举→总括通缘→综集还净→三种圆满」一线贯穿，是菩萨戒学处的核心义理所在。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
本卷由总纲分判到逐条列举再到综集收束，按「总—分—总」推进：

- **总判犯不犯相（P1）** → 立全卷判罪框架：于违犯、无违犯、是染非染、软中上品「应当了知」，定下后文每条戒的判释模板。
- **逐条列举诸恶作戒（P2-P67）** → 每条以「若诸菩萨安住菩萨净戒律仪」起，先述违犯因缘（染/非染），后述无违犯例外，构成若干组：
  - P2-P12：供养三宝、不贪利养、恭敬同法、受请、受施、施法、不弃暴恶犯戒有情——菩萨对三宝、师长、有情的「应作不作」类。
  - P13-P19：声闻遮罪共学↔不共学——先立共学（将护他故令生净信），后立不共学（声闻自利可「少事少业」，菩萨利他须广求百千衣钵财宝），↔对比自利与利他两翼。
  - P20-P28：性罪少分现行——以善权方便为利他故，杀、夺位、不与取、非梵行、妄语、离间、粗恶、绮语七支可少分现行而无所违犯生多功德，此为菩萨戒最特出处。
  - P29-P67：邪命、掉动、不乐涅槃、不雪谤、报骂打弄、不谢不受谢、怀忿、贪供事睡眠谈世事、不请教授、贪欲盖味静虑、毁声闻/弃菩萨藏/学外论/毁菩萨藏/不信深法、自赞毁他、不往听法、轻毁法师、不为助伴、不供事病、不为宣说、不知恩、不开解愁恼、不给施、不摄徒众、不随心转、不显扬功德、不诃责治罚、不现神通——一系列「消极不为」的违犯。
- **总括一切无违犯（P68）** → 三种通缘（心狂乱、重苦逼切、未受净戒）贯一切处，收束前文诸条无违犯。
- **综集结说与还净出罪（P69-P76）** → 说明诸戒散在素怛缆中、今于菩萨藏摩怛理迦综集 → 一切违犯皆恶作摄 → 上中下品缠犯对应三种对境发露（三人/一人/自誓） → 无对境时可对佛像前自誓受戒、自誓防护。
- **三种圆满安乐而住（P77-P81）** → 加行圆满（无缺犯、身语意清净现行）→ 意乐圆满（为法出家、求大菩提、不求活命）→ 宿因圆满（昔修福善今无匮乏复能惠施），与此相违则三种衰损危苦，收束全章。

## 三、关键结论
1. 菩萨戒每条恶作必判染/非染违犯与无违犯三类，判罪核心在动机——嫌恨恚恼憍慢为染，懒惰忘念无记为非染，狂乱重苦未受戒为无违犯。
2. 菩萨与声闻于遮罪有共学（将护他故）有不共学——声闻自利可少事少业，菩萨利他须广求财物，「少事少业」于菩萨反成染违犯。
3. 性罪少分现行是菩萨戒独特开许：为利他故，于杀盗淫妄等七支可依善权方便少分现行，前提是纯以怜愍心、利益安乐意乐而作，则无所违犯且生多功德。
4. 菩萨于涅槃应倍于声闻忻乐、于烦恼应倍于声闻厌离，破「菩萨不应忻乐涅槃」之邪见。
5. 违犯皆摄于恶作，依上中下品缠分别对三人、一人发露，或无对境时对佛像自誓防护还净。
6. 勤学毗奈耶成就加行、意乐、宿因三种圆满安乐；反之三种衰损危苦。

## 四、易混辨析
- **染违犯 vs 非染违犯**：染违犯由烦恼（嫌恨、恚恼、憍慢、嫉妒、贪着）发起，罪垢重，须如法对三人对境发露；非染违犯仅由懒惰、懈怠、忘念、无记之心发起，罪较轻，可对一补特伽罗发露。
- **遮罪 vs 性罪**：遮罪是佛为避讥嫌、将护他心而制（如不受金银等），非本性恶；性罪是本性即恶（杀盗淫妄等）。声闻于遮罪一律不犯；菩萨于遮罪有共学不共学，于性罪有利他时可少分现行而不犯。
- **共学 vs 不共学**：共学指将护他有情令生净信的遮罪，菩萨与声闻等学；不共学指「少事少业少悕望住」类遮罪，声闻应学、菩萨不应学（菩萨须为利他广求百千衣钵）。
- **他胜处法 vs 恶作**：他胜处法是重戒（四波罗夷），犯则失戒；恶作是轻戒（本卷所列），犯而可悔。但若以上品烦恼（上品缠）违犯他胜处法即失戒，须更受戒。

## 五、阅读提示
读此卷可带着三问：菩萨戒为何有如此多「开遮持犯」细判？声闻与菩萨戒的差别根本何在？「性罪少分现行」的开许条件究竟为何——杀人反生功德？抓住「动机」与「利他」两钥，全卷判罪脉络自明。
