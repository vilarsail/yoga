# 瑜伽师地论卷第二十五 导读

## 一、内容总览
本卷为「初瑜伽处出离地第三之四」，续广辨二道资粮，明「善友性」「闻思正法」「无障」「惠舍」「沙门庄严」五资粮。善友性约八因缘及八支广辨；闻思正法约十二分教与四道理思惟；无障约内外二障及加行/远离/寂静三障；惠舍约能施所施用何施何相施云何施何故施；沙门庄严约十六种功德庄严。是声闻地资粮分的外缘、教法、离障、施福、庄严五门总结。

## 二、结构层次
全卷按「善友性 → 闻思正法 → 无障 → 惠舍 → 沙门庄严」五段推进：
- **善友性（P1-P23）**：八因缘（禁戒/多闻/有所证/哀愍/无厌倦/堪忍/无怖畏/语具圆满）→ 八支作用（谏举/忆念/教授/教诫/善说正法）→ 略义四因缘（心善稠密哀愍/如实知利益安乐/有势力方便善巧/翘勤无堕）。
- **闻思正法（P24-P42）**：正法谓十二分教 → 闻正法谓受持三藏 → 思正法远离六种不应思处，以算数行相、称量行相二种思惟，称量复依观待/作用/证成/法尔四道理。
- **无障（P43-P56）**：依内障（不修福、贪嗔痴、多病、乐事业语言睡眠諠众杂住掉乱）→ 依外障（依不善士、恶处諠杂猛利恶触怖畏）→ 略义三障（加行障/远离障/寂静障），寂静障分奢摩他障与毗钵舍那障。
- **惠舍（P57-P69）**：施性无罪为庄严心 → 六问（谁能施/谁所施/用何施/何相施/云何施/何故施），所施分有苦有恩亲爱尊胜四，施物分有情数无情数财谷处三。
- **沙门庄严（P70-P98）**：嗢拖南列十六种 → 逐广辨，杜多功德十二或十三种，为断饮食贪（美食/多食）、衣服贪（多衣/软触/上妙）、敷具贪（諠杂/屋宇/倚卧/敷具）。
以「广辨 → 略义」或「总举 → 逐释」为统一骨架。

## 三、关键结论
1. 善友性八因缘：安住禁戒、具足多闻、能有所证、性多哀愍、心无厌倦、善能堪忍、无有怖畏、语具圆满；略义四因缘摄一切种。
2. 十二分教三藏所摄：素怛缆藏（契经乃至方广希法）、毗奈耶藏（因缘）、阿毗达磨藏（论议）。
3. 思正法远离六种不应思，应依算数行相、称量行相思惟；称量依观待/作用/证成/法尔四道理。
4. 三障：加行障（病乏等令无堪能）、远离障（乐事业睡眠諠杂等难舍阿练若）、寂静障（奢摩他障谓放逸住非处、毗钵舍那障谓乐自恃举掉乱）。
5. 惠舍六问：谁能施、谁所施、用何施、何相施、云何施、何故施；施性无罪为庄严心为资瑜伽为得上义。
6. 沙门庄严十六种，杜多功德十二或十三种，对治饮食/衣服/敷具三贪。

## 四、易混辨析
- **善友八因缘 vs 八支作用**：八因缘约善友自体德相，八支作用约化他功能，八支依八因缘起。
- **闻正法 vs 思正法**：闻正法约受持三藏文义，思正法约独处空闲以算数称量二行相观察诸法自相共相。
- **依内障 vs 依外障**：依内障约自根身心业烦恼，依外障约依不善士恶处諠杂恶触怖畏。
- **奢摩他障 vs 毗钵舍那障**：奢摩他障谓多放逸及住非处，毗钵舍那障谓乐自恃举及掉乱。
- **杜多功德十二 vs 十三**：约乞食无差别唯十二，约乞食分随得/次第二种则十三。

## 五、阅读提示
本卷是出离地资粮分的外缘与庄严总结，可带「善友八支 → 十二分教四道理 → 三障 → 施六问 → 庄严十六」五线索读；杜多功德对治三贪的对应表最宜对照把握。
