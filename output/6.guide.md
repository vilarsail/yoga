# 瑜伽师地论卷第六 导读

## 一、内容总览
本卷入「不如理作意施设建立」，列举并破斥十六种外道异论——皆由不正思惟而起，违缘起正理。本卷详破前五种：因中有果论、从缘显了论、去来实有论、计我论、计常论；余十一种仅于嗢拖南点名，待后卷展开。

## 二、结构层次
全文以「总标十六异论 → 逐一破斥」为骨架，破斥循「立论 → 立因 → 诘难 → 结不应理」四段式：
- **总标（P1-P3）**：嗢拖南七句摄十六异论 → 长行列名立纲。
- **分破五论（P4-P56）**：
  - **因中有果论（P4-P7）**：雨众计因中先有果 → 因果相异不异四句 → 五种了知相破。
  - **从缘显了论（P8-P12）**：法本已有从缘显而非生 → 诘障缘有无 → 附破声相论。
  - **去来实有论（P13-P23）**：三世实有如现在 → 破三世相一异 → 立三世各十二相。
  - **计我论（P24-P45）**：计实我萨埵 → 多重审问萨埵觉即异所见事 → 结第一义假我及四因假立。
  - **计常论（P46-P56）**：计我及世间常住 → 分破前际、后际、极微常 → 结常住相正理。

## 三、关键结论
1. 因中本无果，果由因待缘生；因果相异不异皆不立「因中先有果」。
2. 诸法非本有从缘显；由远、障、极微细、根损坏等，虽复有而不可取相。
3. 过去未来非实有，佛说三世依因相、自相、果相密意假说，各具十二相。
4. 无实我，「我」唯于诸行假施设；第一义我无常变坏。
5. 我及世间非常住；极微非常，常性不立。

## 四、易混辨析
- **因中有果论 vs 从缘显了论**：前者计因中先有果体（谈生），后者计法性本有由缘显了（谈显），同出不正思惟。
- **第一义我 vs 外道所计我**：前者于诸法假立、无常变坏，后者谛实常住能作能受，一假一实。
- **三世实有 vs 密意说有**：外道执过去未来体实如现在；论主说有过去业等依习气密意假说，非谓体实。

## 五、阅读提示
每破一异论必立一正理，破邪为显正，把握「破→立」往复即得全卷脉络。
