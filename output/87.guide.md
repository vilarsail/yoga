# 瑜伽师地论卷第八十七 导读

## 一、内容总览
本卷属《瑜伽师地论·摄事分》「契经事行择摄第一」之三，紧接前二卷，继续择摄契经要义。全卷以四个嗢拖南（颂偈总摄）为骨架，分三大板块展开：第一嗢拖南摄「行因、阿罗汉胜利、二智、愚夫位、见差别、圣教」直至识流转与有余涅槃；第二嗢拖南摄「断支、如实显了、所缘事、无等教、四有情众、道四行相、究竟五相」；第三嗢拖南摄「黑白二品总摄、涅槃甚深、荷担内缚、如来与阿罗汉同异、无我胜解与离增上慢、内外师别、诸行非定苦乐」。核心落在「如何由见清净趣入究竟涅槃」与「如来圣教不共外道」的判摄。

## 二、结构层次
本卷按四个嗢拖南串联，每颂皆以「列名 → 释相 → 收束」推进：

- **第一嗢拖南（因·胜利·二智·愚夫·见·圣教）** P3-P79：
  - 行因 → 立「共因/不共因」二门（喜润自体障厌离 vs 顺触等别待余因）；
  - 阿罗汉胜利 → 四胜利 + 三渐次（厌离 → 离欲 → 心解脱 → 无相住 → 内般涅槃）；
  - 见趣 → 萨迦耶见为根本，分前际/后际/前后际俱行，广开六十二见，归为六因缘建立，结为三种衰损；
  - 二智 → 法住智（知自相共相过患）+ 涅槃智（永断诸行），由二门（因他教授/自力多闻）令见清净；
  - 愚夫五位与四种妄计我论 → 我见杂染四相（因缘/自性/果/等流），明位三位与无明位二种；
  - 圣教 → 善说法律（二果大利）↔ 恶说（唐捐），四识住、四取、四身系，识流转与三解脱门，归于有余涅槃三断名（寂静/清凉/宴默）。

- **第二嗢拖南（断支·实显了·行缘·无等教·四有情·道四·究竟五）** P82-P100：
  - 五支摄受断 → 身远离、心远离、奢摩他品、毗钵舍那品、常委；
  - 如实显了 → 十二行相 + 四种所缘事（内法异生/在家异生/外道/有学）四类清净杂染对比；
  - 如来教无与等三因缘（不共/无倒/自觉）→ 四有情众 → 见道修道四行相；
  - 究竟五相 → 以「入宫城五相」为譬，详明从断五下分结到安住圣住（行三相 + 住五相）。

- **第三嗢拖南（二品总略·胜解断流转·善不善清净·师等别）** P101-P150：
  - 三处总摄黑白品（所遍知法/遍知/成遍知）→ 如来灭后不可记，涅槃甚深广大无量；
  - 内外荷担苦差别 ↔ 内缚外缚差别 → 魔罥与离欲位关系；
  - 如来与慧解脱阿罗汉同分异分（解脱等 / 现等觉·能说·正行）；
  - 二种无我胜解（闻思/修证）、二种断（烦恼断/事断）、三种密苦、三有性；
  - 离增上慢无我见 → 不善清净（顺决择位粗我慢）↔ 善清净（八相遍知、法印）；
  - 内外法师弟子五种高下差别 → 诸行非定苦染/非定乐净（依生处/受/世）。

## 三、关键结论
1. 一切恶见以萨迦耶见为根本，依前际/后际/前后际展开六十二见，皆由无智而生；如来于三种衰损如实了知而出离。
2. 见清净依「法住智 + 涅槃智」二智，由因他教授或自力多闻二门而得；现观边智三位（顺生无漏/无漏/无漏后相续）次第导入见清净乃至善清净。
3. 阿罗汉有四胜利（行时恒住、住时无相、往因任运归灭、后有不生），由五支摄受断而得究竟，以「入涅槃宫城五相」为究竟位之相。
4. 如来与慧解脱阿罗汉解脱等同，而由「自然等觉、能说法、行正行」三相声闻不共；善说法律得二果大利（离三苦、断诸结），恶说唐捐。
5. 涅槃甚深广大无量，如来灭后若有若无等皆不可记；无我见须离增上慢方名善清净。

## 四、易混辨析
- **法住智 vs 涅槃智**：法住智了知诸行自相差别与共相过患（缘起因果之智）；涅槃智于一切有苦诸行起无余永断之想，是趣入灭之智。前者为后者先导。
- **世俗定 vs 内法定**：世俗定即世间静虑，于谛未了达、心未善解脱；内法定证入诸谛、心已善解脱。外道依世俗定起见趣，内法依内法定得清净。
- **共因 vs 不共因**：共因谓喜，于彼彼生处滋润自体、障于厌离；不共因谓顺苦乐等触望受等心法（十种）、色等望六识（六种），刹那别待余因方生。
- **不善清净 vs 善清净无我见**：前者依世间智观无常忍制伏我见，但顺决择分位仍有粗我慢微细现行，为欲/萨迦耶爱漂溺；后者由八相遍知三世过患，证无我真智、得法印。
- **内荷担/内缚 vs 外荷担/外缚**：外缚为色一分（木铁索）他缚、死后即无；内缚为诸行自缚、难知、死后随逐循环，乃至有顶未脱魔罥。

## 五、阅读提示
带着「为什么圣教不共外道」「从凡夫到阿罗汉的清净之路如何次第」两问读，注意嗢拖南颂与长行的对应；六十二见与三种衰损部分可对照表解，勿陷名相。
