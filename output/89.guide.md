# 瑜伽师地论卷第八十九 导读

## 一、内容总览

本卷为《瑜伽师地论》卷第八十九，属「摄事分中契经事处择摄第二之一」，承接前卷「行择摄」之后转入「处择摄」。「处」即内六处、外六处等所依所缘之事。全章以总别二嗢拖南列目，依次广说安立、差别、愚不愚、教授、解脱、烦恼业六大主题：由受之五相安立开为八种差别，引出愚与不愚的分野；次明佛及弟子的三种教授、解脱妙慧与心清净行苾刍所修五法；继而广列烦恼杂染一系列名相（漏、结、缚、随眠、随烦恼、暴流、轭、取、系、盖、株杌、垢、烧害、箭等）；最后辨业杂染之正邪二论、领受业异熟论之杂染与不杂染、正邪二行业染净对比，并以三类补特伽罗的断证差别收束全章。

## 二、结构层次

本章以「总嗢拖南列目 → 别嗢拖南开章 → 六门次第展开」一线贯穿：

- **总别嗢拖南（P1-P4）**：以二颂总标「安立、差别、愚不愚、教授、解脱、烦恼业」六门，作为全章展开的纲领。
- **安立与差别（P5-P11）**：先以五相（自性、所依、所缘、助伴、随转）安立诸受 → 再开为八种差别（内处、外处、六识身乃至六爱身），由三和合、受因缘、触果、分别受、业烦恼二杂染义层层建立 → 最后以「少分一切」与「一切一切」收束「一切」一词的施设范围。
- **愚与不愚（P12-P17）**：愚与不愚各以三相分别（自性、因缘/碍、果/障），构成一组对比 ↔ 愚者由缠随眠忘失、于受安立不了、感愁等苦；不愚者善觉自相共相、断烦恼证涅槃，并指出四魔为碍、烦恼缠为障。
- **教授与解脱（P18-P20）**：佛及圣弟子以三种教授（引导、安处所缘、得自义）即三种神变 → 求解脱妙慧由闻思与有学二种相续慧 → 略立有学、无学二种解脱。
- **心清净行苾刍五法（P21-P37）**：正教授（三种正友）→ 奢摩他支（尸罗无悔欢喜心定）→ 毗钵舍那支（三种言教：圣正、厌离、令心离盖趣爱）→ 无间殷重加行（五种精进）→ 出世间慧（入谛现观、除遣随烦恼、证金刚喻定）。五法之间为依次相生、前前为后后依止的递进关系。
- **烦恼品广说（P38-P77）**：以「解脱 → 三漏 → 九结 → 三缚 → 七随眠 → 随烦恼（忿恨覆等数十种）→ 四暴流 → 四轭 → 四取 → 四系五盖 → 株杌垢烧害箭所有」一连串名相枚举，由根本烦恼到随烦恼、由结缚到盖垢，构成一份完整的烦恼杂染词汇表，逐一安立自相。
- **业杂染与正邪二论（P78-P147）**：先立恶行与业杂染 → 次辨邪论（决定受恶趣）与正论（作亦增长方定受、追悔对治可转）之别 ↔ → 次明十种业对治 → 再辨现法防护身语意业的善巧与不善巧 → 施设领受业异熟论的五相杂染（恶因、无因、三过）与五相不杂染 → 邪业清净与邪行有二过患（内证稽留、他所讥毁）↔ 正业染净与正行有二胜利（内证无滞、他所称赞），构成一对正邪对比的收束。
- **三类补特伽罗（P148-P156）**：未入圣教异生、已入圣教有学、已入圣教异生三类，各以三相分别其在正见邪见上的生断差别，作为全章断证旨归的落脚点。

## 三、关键结论

1. 受之安立以五相为自性，开为八种差别，归根于六识身触受想思爱之流转，业烦恼二杂染是建立第七第八差别的依据。
2. 愚与不愚的分野在于能否觉了受安立中的自相共相；不愚者能断烦恼、证谛、入涅槃。
3. 心清净行苾刍由正教授、奢摩他支、毗钵舍那支、无间殷重加行、出世间慧五法次第修习，能证有学无学圆满解脱。
4. 业杂染非决定不可转：若于业追悔修习对治，虽顺恶趣受可转成顺现法受，不障解脱；故邪论谓「一切决定受恶趣」是谤梵行涅槃。
5. 邪业清净（修自苦行令宿业变吐）不合理，业之自性、时分、品类决定，苦行不能令顺苦受业成顺乐受；正行唯在依圣道永断对治。

## 四、易混辨析

- **邪论 vs 正论**：邪论谓故思造不善业一切决定当受恶趣，否定梵行能证涅槃；正论谓作亦增长者定受恶趣，作而不增长或追悔对治者可转，不谤涅槃。
- **邪业清净 vs 正业染净**：邪业清净依宿因论修自苦行欲令宿业变吐；正业染净谓不造新业、故业寻复变吐、由对治力永断无余。
- **有学解脱 vs 无学解脱**：有学者金刚喻三摩地俱，无学者在金刚喻定以上；有学久远相续慧成就无学解脱，如理闻思久远相续慧成就有学解脱。
- **缠 vs 随眠**：缠是烦恼现行，随眠是烦恼品类粗重随附依身、为生起缠的种子；八种随烦恼于四时数数现行立为八缠。
- **欲漏 vs 有漏 vs 无明漏**：欲界系烦恼（除无明）名欲漏，色无色界系烦恼（除无明）名有漏，三界所有无智总摄为一立无明漏。

## 五、阅读提示

读本章可带着两个问题：（1）受的安立如何由五相开为八种差别，又如何引出愚与不愚的分野？（2）正邪二论、正邪二行如何在业决定与业可转之间建立中道？抓住「安立差别」与「业染净正邪」两条主线，全章纲目自明。
