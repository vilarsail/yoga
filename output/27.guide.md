# 瑜伽师地论卷第二十七 导读

## 一、内容总览
本卷为「声闻地第二瑜伽处之二」，续广辨净行所缘之余三（缘性缘起、界差别、阿那波那念），次明善巧所缘（蕴界处缘起处非处五善巧）与净惑所缘（世间道粗静相、出世道四圣谛），最后略说教授。阿那波那念五种修习为本卷最详尽处，善巧所缘摄自相共相二善巧，净惑所缘分世出世二道。

## 二、结构层次
全卷按「净行余三 → 善巧所缘 → 净惑所缘 → 教授」四大段推进：
- **缘性缘起所缘（P1）**：于三世唯行唯法唯事唯因唯果堕四道理，无作者受者，治痴行。
- **界差别所缘（P2-P15）**：六界差别（地水火风空识）→ 内外二分 → 离一合想治慢行。
- **阿那波那念所缘（P16-P67）**：入息出息中间二息 → 二因缘二所依二行二地四异名二过患 → 五种修习：①算数修习（以一为一/以二为一/顺/逆/胜进，过算数地）②悟入诸蕴修习（息及所依身悟色蕴，念相应领纳等悟受想行识蕴）③悟入缘起修习（息依身心、身心依命根、命根依先行、先行依无明）④悟入圣谛修习（无常苦无我悟苦谛，贪爱为缘悟集灭道谛，得现观）⑤十六胜行（念入出息若长短乃至灭随观）。
- **善巧所缘（P69-P88）**：五善巧——蕴善巧、界善巧、处善巧、缘起善巧、处非处善巧；略为自相善巧（蕴）与共相善巧（余四）。
- **净惑所缘（P89-P116）**：世间道观下地粗性上地静性（体粗性/数粗性）暂断非究竟；出世道四圣谛——苦谛（八苦乃至五取蕴苦）、集谛（爱及后有爱等）、灭谛（爱无余断）、道谛（八支圣道）；建立苦苦坏苦行苦三性。
- **教授（P118-P123）**：四教授（无倒/渐次/教/证）→ 三神变教授（神境/记说/教诫）。
以「所缘四事 → 教授」为骨架，所缘中净行/善巧/净惑皆「总举 → 逐广辨 → 略义」。

## 三、关键结论
1. 缘性缘起所缘：于三世唯行唯法唯事唯因唯果堕四道理，唯有诸法能引诸法无有作者及以受者，治痴行。
2. 界差别所缘：六界各分内外，内界亲附执受、外界非亲附非执受；于身中离一合想得不净想，治慢行。
3. 阿那波那念五种修习：算数、悟入诸蕴、悟入缘起、悟入圣谛、十六胜行；十六胜行为有学见迹已断见所断为断修所断复修。
4. 五善巧略为二：自相善巧（蕴善巧显自相）、共相善巧（界处缘起处非处显共相）。
5. 净惑所缘二道：世间道观粗静相暂断、出世道观四圣谛究竟断；四谛黑品果因（苦集）、白品果因（灭道）。
6. 三苦性：苦苦（苦受及所依处）、坏苦（乐受及所依处无常变坏及烦恼缠缚变坏）、行苦（不苦不乐受俱行诸蕴无常粗重随逐）。

## 四、易混辨析
- **悟入缘起 vs 悟入圣谛**：悟入缘起约息依身心、身心依命根、命根依先行、先行依无明之顺逆观；悟入圣谛约无常苦无我悟苦谛、贪爱为缘悟集谛、爱尽悟灭谛、能断悟道谛，得谛现观。
- **世间道净惑 vs 出世道净惑**：世间道观下地粗上地静唯伏烦恼暂断非究竟；出世道观四圣谛永断见修所断一切烦恼究竟解脱。
- **自相善巧 vs 共相善巧**：蕴善巧显自相（五蕴种种差别性非一众多性），余四善巧显共相（无常苦无我）。
- **苦苦 vs 坏苦 vs 行苦**：苦苦约苦受及所依处，坏苦约乐受及所依处无常变坏及烦恼缠，行苦约不苦不乐受俱行诸蕴无常粗重随逐遍行五取蕴。
- **处善巧 vs 处非处善巧**：处善巧约十二处三缘流转，处非处善巧约善不善法因果非不平等道理，是缘起善巧差别。

## 五、阅读提示
本卷是声闻地所缘境事的主体，可带「净行五所缘对治五行 → 善巧五门自共相 → 净惑世出世二道四谛三苦 → 教授四门三神变」四线索读；阿那波那念十六胜行与三苦性建立最宜对照把握。
