# 瑜伽师地论卷第五十八 导读

## 一、内容总览

本卷属《瑜伽师地论》「摄决择分」中「有寻有伺等三地」决择之首卷，承接前文五识身相应地、意地决择，转入寻伺三地义理。全卷以「烦恼杂染」为主干，先以焰摩法王、大海水碱等杂问引入，随即依五种相——自性、自性差别、染净、迷断、对治——系统建立烦恼的体性、分类、染净机制、与四谛的迷执关系及解脱对治之道，末以杂问与嗢拖南颂收束。

## 二、结构层次

全文以「杂问引入 → 五相建立 → 杂问收束」为纵线：

- **杂问引入（P1-P9）**：焰摩法王由饶益众生得名（令地狱众生忆念自业、自知因果、不造新业而脱苦）→ 大海水碱由众生福与非福增上所致，两则问答为正文暖场。
- **五相总标 → 自性（P10-P11）**：总标五相 → 自性仅分见性、非见性二种，开门见山。
- **自性差别（P12-P46）**：十烦恼逐一展开 →
  - 见性五（萨迦耶见→边执见→邪见→见取→戒禁取）与非见性五（贪→恚→慢→无明→疑），各出体性、分类、与三界系属；
  - 十烦恼互缘互不相应之理（P43）；
  - 由「取一切事」引出**随烦恼**（P34-P46），以四相建立，明其与根本烦恼的品类等流关系（P44-P46：寻伺以慧思为性，粗慧名寻、细慧名伺）。
- **染净差别（P47-P53）**：缠（现行）与随眠（种子，亦名粗重）之分 → 具缚者于三世何系 → 伏断之道：断随眠非断缠 → 「断三世」的辩证——非断去来今，然说断三世。
- **迷断差别（P54-P71）**：十五种迷断（三界×五谛）→ 迷苦十、迷集八、迷灭八、迷道八，逐谛列明 → 修道所断（欲界嗔恚+三界贪慢无明），下道断上品 → 五种所缘（P71）。
- **对治差别（P72-P79）**：四阶对治（资粮→加行→见道→修道）→ 见道智行相、一心与九心建立 → 熟痈喻（利刀剖→周回搦→腻团帛帖）说明见道断、修道断分工 → 二种粗重：漏粗重（阿罗汉断）与有漏粗重即烦恼习（唯如来究竟断）。
- **杂问与嗢拖南（P80-P99）**：五相总结 → 士夫欲、八种虚妄分别、何故唯说贪嗔痴为不善根等问答 → 五盖等譬喻（龟、母驼、凝血、屠机上肉、浪耆、岐路、轮围）→ 中嗢拖南颂收束。

## 三、关键结论

1. 烦恼杂染依五种相建立——自性、自性差别、染净、迷断、对治，构成从体性到解脱的完整框架。
2. 根本烦恼有十：五见为见性，贪恚慢无明疑为非见性；随烦恼皆为此十的品类等流。
3. 染净之机在缠与随眠：缠是现行，随眠是种子；断烦恼关键是断随眠，缠先已舍。
4. 迷断依四谛三界建立十五种：见道所断者迷四谛各有定数，修道所断者为欲界嗔恚及三界贪慢无明。
5. 对治有四阶，见道顿断见惑、修道渐断修惑；粗重有二种，漏粗重阿罗汉能断，有漏粗重（烦恼习）唯如来究竟断。

## 四、易混辨析

- **缠 vs 随眠 vs 粗重**：缠是烦恼现行现起（觉位），随眠是烦恼种子未断未害（不觉位），亦名粗重；粗重又分「漏粗重」（修道所断烦恼断时永离，阿罗汉能断）与「有漏粗重」即烦恼习（唯如来究竟断）。
- **俱生 vs 分别起**：俱生烦恼一切愚夫异生乃至禽兽皆有，不待计度；分别起烦恼由外道等计度而起。俱生萨迦耶见唯无记性，分别起者在欲界唯不善。
- **见道所断 vs 修道所断**：见道所断者迷四谛之烦恼，见道时顿断；修道所断者为欲界嗔恚及三界贪慢无明，任运而转、长时坚固，须渐断。能断道分下中上三品，下品道断上品惑。
- **见性烦恼 vs 非见性烦恼**：五见以慧为体、推度分别为性，彼此互不相应；贪恚慢疑更相违故亦不相应——贪令心卑下，慢令心高举，故贪慢相违。

## 五、阅读提示

读此卷宜抓住「五相」总纲，随原文「云何自性→云何自性差别→云何染净→云何迷断→云何对治」的问答节奏推进，将十烦恼、随烦恼、缠随眠、四谛迷执、四阶对治逐一归入五相之下，脉络自明。
