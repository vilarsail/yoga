# 瑜伽师地论卷第五十四 导读

## 一、内容总览
本卷为《瑜伽师地论》卷五十四，属「摄决择分」中「五识身相应地意地」之四，承接前卷对意地的决择，由「识蕴」入手，经蕴的差别、次第、相摄，逐步收束到「色蕴」的精细分别。全卷以「识蕴差别 → 诸蕴次第 → 蕴善巧摄 → 色蕴广辨」为脉络，是从心识总相到色法别相的层层展开，也是唯识色法理论最集中的篇章之一。

## 二、结构层次
全文按「总辨识蕴 → 总辨诸蕴 → 别辨色蕴」三段推进，由总到别、由心到色：

- **识蕴差别（总辨心识）**：先标五门——安住、杂染、所依、住、异相 → 「住」门最详，依经说四识住，展开依取、因缘、边际、寂止四重，最后归到「心性本净，唯识不立识住」 → 「异相」门约界、约种、约补特伽罗三品层层枚举心相差别。
- **诸蕴次第（总辨五蕴）**：从「色受想行识为何如此排序」出发，举出生起、对治、流转、住、安立五种次第道理，并补「我众具事」义 → 回答的是五蕴教说的施设逻辑。
- **蕴善巧摄（相摄道理）**：先说六种蕴界处根相摄 → 再扩为十种摄（界、相、种类、分位、不相离、时、方、全、少分、胜义） → 收束于「三法摄一切法」（色蕴、法界、意处）。
- **色蕴广辨（别辨色法，本卷主体）**：以一颂「嗢拖南」标十门——物、极微、生起、安立、流、业、刹那、独所行、余相杂、最后 → 逐门展开：
  - 物：眼等根几物所摄，色等境、声界、触处造色假实；
  - 极微：三种微细性、五相建立、五眼所行、无生无灭、五种胜利；
  - 生起：色物五生（依止、种子、势引、摄受、损减）、大种造色三缘、中有色聚；
  - 安立：空界、形色假有、法处所摄色、有见有对等；
  - 流：等流、异熟生、长养三流，四食长养；
  - 业：四大种各五业、造色五业；
  - 刹那：任运灭义，遮破火等灭因、灭相灭因等计；
  - 独所行：大种造色异相、根性所行性、境界现前、六种所行、能生作意；
  - 余相杂：欲界身发起色界大种，如水处沙。

## 三、关键结论
1. 识蕴虽有杂染，心性本自清净；唯识不立识住，以无独缘识性而起染爱故。
2. 五蕴次第非随意排列，而是依生起、对治、流转、住、安立等五种道理施设。
3. 色法以大种为所依、造色为能依，大种于造色能作生起、依止、建立、任持、增长五业。
4. 极微由觉慧分析至极边际而立，非实体有，故无生无灭；聚色全分而生、中间尽灭犹如水滴。
5. 一切色蕴皆是刹那灭性，任运坏灭，非由火等外因所灭。

## 四、易混辨析
- **四识住 vs 识住寂止**：四识住是识随色受想行而住之相（流转义）；寂止是依对治断贪爱随眠后识不复安住（还灭义）。一流转、一还灭。
- **有覆无记 vs 无覆无记**：有覆无记指有烦恼覆障但不属善恶心；无覆无记指无烦恼覆障的非善恶心，分异熟生、威仪路、工巧处、变化心四种。
- **等流流 vs 异熟生流 vs 长养流**：等流流是同类因果相续（含异熟等流、长养等流、变异等流、本性等流）；异熟生流是业所引果相续；长养流是由食、睡眠、梵行等令色增益。色根唯由异熟、长养二流流转，无别等流。
- **大种 vs 造色**：大种是地水火风四大（所依、能造）；造色是眼等根、色等境（能依、所造）。造色望大种定有异相——异根所行、可运转与不可运转、可变异与不可变异。

## 五、阅读提示
读本卷可带着两个问题：一是「识蕴」如何从差别相收归于「心性本净」？二是「色蕴」一颂十门如何把纷繁色法收为一张表？抓住「嗢拖南」颂，便能理清色蕴广辨的全局。
