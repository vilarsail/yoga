# 瑜伽师地论卷第二十六 词语注释

① 贪增上补特伽罗　先余生中于贪烦恼已修已习已多修习，今生于所爱事有猛利贪有长时贪。

② 得平等补特伽罗　先余生中于贪嗔痴慢寻思不修不习，而于彼法未见过患，于境无猛利长时缠然得现行。

③ 薄尘性补特伽罗　先余生中于贪等不修不习已多见过患已善推求，于上品境起微劣贪，中下品境贪全不起。

④ 行向补特伽罗　行四向者：预流果向、一来果向、不还果向、阿罗汉果向。

⑤ 住果补特伽罗　住四果者：预流果、一来果、不还果、阿罗汉果。

⑥ 随信行补特伽罗　从他求请教授教诫修证果行，唯由随他补特伽罗信而修行。

⑦ 随法行补特伽罗　如所闻所受所思所量所观察法自有功能势力随法修行，不从他求。

⑧ 信胜解补特伽罗　即随信行补特伽罗因他教授教诫于沙门果得触证时。

⑨ 见至补特伽罗　即随法行补特伽罗于沙门果得触证时。

⑩ 身证补特伽罗　于八解脱顺逆入出身作证多安住，而未能得诸漏永尽。

⑪ 极七返有补特伽罗　已永断萨迦耶见戒禁取疑三结得预流果，极七返有天人往来证苦边际。

⑫ 家家补特伽罗　分天人家家与人家家，从家至家若往若来证苦边际，俱是预流。

⑬ 一间补特伽罗　即一来补特伽罗行不还果向已，永断欲界上中品烦恼唯余下品，唯更受一欲界天有即般涅槃。

⑭ 中般涅槃补特伽罗　从此没已中有续生便般涅槃，分三种如小札火、铁抟星流、热铁椎星流。

⑮ 生般涅槃补特伽罗　才生彼已便般涅槃。

⑯ 无行般涅槃补特伽罗　生彼已不起加行不作功用，不由劳倦道现在前而般涅槃。

⑰ 有行般涅槃补特伽罗　生已发起加行作大功用，由极劳倦道现在前而般涅槃。

⑱ 上流补特伽罗　不还补特伽罗从此上生初静虑展转上生诸所生处，乃至色究竟天或非想非非想处。

⑲ 时解脱补特伽罗　钝根种姓于现法乐住容有退失，或思自害或守解脱励力勤修不放逸行。

⑳ 不动法补特伽罗　与时解脱相违，利根种姓于现法乐住定无退失。

㉑ 慧解脱补特伽罗　已能证得诸漏永尽，于八解脱未能身证具足安住，已解脱烦恼障未解脱定障。

㉒ 俱分解脱补特伽罗　已能证得诸漏永尽，于八解脱身已作证具足安住，烦恼障分及解脱障分心俱解脱。

㉓ 十一差别道理　建立补特伽罗之十一门：根/众/行/愿/行迹/道果/加行/定/生/退不退/障差别。

㉔ 四行迹　苦迟通、苦速通、乐迟通、乐速通，约钝利根与得不得根本静虑辨。

㉕ 苦迟通　钝根性未得根本静虑所有行迹。

㉖ 乐速通　利根性已得根本静虑所有行迹。

㉗ 四种所缘境事　遍满所缘境事、净行所缘境事、善巧所缘境事、净惑所缘境事。

㉘ 遍满所缘境事　谓有分别影像、无分别影像、事边际性、所作成办，遍行一切所缘境中。

㉙ 有分别影像　于所知事同分影像由三摩呬多地毗钵舍那行观察简择极简择遍寻思遍伺察。

㉚ 无分别影像　于所缘影像以奢摩他行寂静其心，九种行相令心安住谓内住等住乃至等持。

㉛ 事边际性　所缘尽所有性如所有性总说为一；尽所有性谓五蕴外更无余色等，如所有性谓真实真如四道理性。

㉜ 所作成办　修习奢摩他毗钵舍那圆满故便得转依，超过影像于所知事有无分别现量智见生。

㉝ 所知事同分影像　由三摩呬多地胜解领受相似作意领受，所知事相似显现，亦名光影、三摩地相等。

㉞ 相称缘安住其心　贪行应于不净、嗔行应于慈愍、痴行应于缘性缘起、慢行应于界差别、寻思行应于阿那波那念安住其心。

㉟ 六种不净　朽秽不净、苦恼不净、下劣不净、观待不净、烦恼不净、速坏不净。

㊱ 朽秽不净　分依内（发毛爪齿乃至屎尿）与依外（青瘀脓烂变坏膖胀食啖变赤散坏骨锁等）。

㊲ 五贪　于内身欲欲欲贪、于外身淫欲淫贪、境欲境贪、色欲色贪、萨迦耶欲萨迦耶贪。

㊳ 四种憺怕路　世尊依外朽秽不净差别皆依四种憺怕路而正建立，见彼彼尸死经一日乃至七年各起青瘀等胜解。

㊴ 慈愍所缘　于亲品怨品中品平等安住利益意乐，能引下中上品快乐定地胜解，所缘能缘总略为一。

㊵ 慈俱心　显示于亲怨中三品所缘利益意乐，无怨无敌无损害，广大无量胜解遍满具足住。
