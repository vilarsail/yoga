- **全篇总括**：本卷是《摄事分》的开篇，回答「三藏怎么整理、经怎么读」：先给经藏立24种分类，讲清四阿含的来历与「摩呾理迦」（本母，论纲）的意义；随后对契经内容作纲要决择，沿修行全程推进——破四种邪见的分诊、解脱的三重标准、诸行四决定、五涅槃段位、智与智果的渐次、四缘机制与染净观察工具，最后算清六种死、三种缚与见慢杂染这笔账，以远离、精进、三圆满收官。
  - **开篇框架：摄事分如何整理佛说**
    - **衔接**：上卷「摄异门」之后，本卷转入「摄事」：把佛说归入三大库房——素呾缆（经）、毗奈耶（律）、摩呾理迦（论），本卷只展开经藏
    - **经藏**：用24种分类概括一切契经，大致几组：教乘内容（别解脱、事契经、声闻相应↔大乘相应即方广分）、义理（未显了义令显了↔已显了义更明净、不了义↔了义）、染净（显示黑品↔显示白品）、文义配比（义与文句的略广深浅配对）、功能（除遣疑惑、远离当来与现前过失、令正法久住等）
    - **两个重点分目**：别解脱契经依五犯聚及出犯聚说150条学处，令自爱者精勤修学；事契经即四阿笈摩（四阿含），由师弟展转传来得名
      - **杂阿含是「相应教」**：按主题归类——佛与弟子所说、蕴界处、缘起食谛、道品、八众相应；一切相应归为三相：能说（佛或弟子）、所说（蕴处缘起与道品）、所为说（比丘天魔等听众）
      - **其余三阿含**：只是对同一套相应教的再剪辑：处中说→中阿含，广长说→长阿含，按一二三渐增编数→增一阿含
    - **为什么需要本母**：本母所不摄的经，其义隐昧不明——如无字根则字义不了；以下即以论纲决择契经，卷首偈颂先立总目录（界、略教、想、行、速通、因、断支、二品、智、事、诤、无厌少欲住）
  - **界与四种法教：佛如何对症下药**
    - **病根**：四种所化有情，由先世听闻不正法、不如理作意，把邪解脱见熏习成「界」（深入个性的成见倾向）——常见、断见、现法涅槃见、萨迦耶见（执我我所）
    - **诊断**：佛以种种胜解智力、界智力探知其先胜解与后界，再对症转法教；同时兼顾智未成熟者令成熟、已成熟者令解脱烦恼
    - **四种法教一一对应**：（一种邪见配一剂药）
      - 常见→说因灭故行灭，从「行尽门」见无常 → 断见→说因集故行集，从「行起门」见无常 → 现法涅槃见→从诸行苦门转法教 → 萨迦耶见→离诸行执我者用「诸行空门」，即诸行执我者用「无我门」
  - **善说的标准：三不共支与解脱段位**
    - **接着立「善说法律」的检验标准**：三种不共外道之处：宣说真实究竟解脱（终点）、宣说方便（路线）、宣说自内所证（自己能验证的账）
    - **解脱三档**：世间解脱（有退转，非真实）↔ 有学解脱（真实而未究竟，犹有所作）↔ 无学解脱（具足二种）；见道果由毕竟故名真实，而非究竟
    - **方便是一条观察链**：依如所有性、尽所有性修无常想 → 依无常修苦想 → 依苦修空无我想 → 入谛现观得正见；得正见后住厌逆想——住不生喜、行不染着、于所求境界处中，喜贪缠速灭、心清净住，再多修习永拔粗重随眠，即「心善解脱」
    - **自内所证（内慧触证的几笔账）**：有学自知已尽恶趣诸行、已尽七生二生一生之余后有、已住不退转道；无学自知应学已作毕、无余一生在（况二况七）、能为他如实记别
    - **两种前行法**：见前行法（由闻思修如理作意，入正性离生，得出世正见）→ 道果前行法（得正见后起正思惟等，为断余烦恼）
  - **八事观察：证得解脱前的功课清单**
    - **衔接**：为证得「所未得解脱」，应观察八事——爱味、过患、出离三事＋闻、思、思择力、见道、修道五种观察
    - 观爱味通达其自相，观过患了知三受分位的过患共相，结论：爱味甚少、过患甚多；且烦恼「不现行」只名断，随眠究竟超越、心解脱方名永离欲
    - **观察力逐级推进**：闻所成慧随圣教知无常→苦→空无我，再以思惟微细作意如实了知，由思择力烦恼虽起不实着、能舍离；由思择力入正性离生，由修道力渐离诸欲乃至究竟离欲
  - **断果苦灭与愚夫二相：修行的收成与反面教材**
    - **衔接**：接着验收修行收成（断果、苦灭），再从反面画愚夫像
    - **二种烦恼断果**：见所断果（自知永尽恶趣、证预流无退堕法）↔ 修所断果（最后身暂时支持，第二有永不复转）
    - **苦灭多组二分**：现在因↔过去因、心苦↔身苦、坏苦苦苦苦↔行苦、非爱业果↔可爱业果；已见谛的圣弟子因未永尽诸结，犹有未来生老死怖，故发猛利乐欲、正念不放逸勤修观行
    - **愚夫二相**：所应求的（涅槃、诸行永灭）不知乐求 ↔ 非所应求的（老病死、非爱合会、爱别离、所欲匮乏、愁忧热恼）反生欣乐——于诸行深起乐着、积集诸业，致生老病死众苦不得解脱
  - **四决定：给诸行盖四枚印章**
    - **衔接**：愚夫错在把诸行当可欣可乐，本段正面立论——诸行有四种决定属性：无常、苦、空、无我
    - **论证套路**：统一「过去未来尚且决定如此，何况现在」：无常三相（先无而有、先有而无、起尽相应）、苦（已度苦／未至苦／现前苦）、空（未有故空／已灭故空／虽在而远离谛义胜义故空）、无我（非我相未现前／已越度／正现前）
    - **每相再以二相重申**：无常（已灭坏、应灭坏法）、苦（生等苦法、三苦性）、空（我我所毕竟空；断烦恼心中烦恼空）、无我（种种外性、众缘生不自在）
    - **复以败坏、变易、别离等十相**：总束四决定（声闻地已广分别）
  - **五离系品界与二种渐次：修行段位与进阶顺序**
    - **衔接**：诸行性质定了，接着立修行成果的段位表与进阶次第
    - **五离系品界（依出世道作意修）**：一线排开：断界（见道所断）→ 无欲界（修道所断）→ 有余依涅槃界（唯余依身）→ 灭界／无余依涅槃界（依身亦灭）
    - **五界别名三套**：诸行止（一切行永寂静）、空（我我所我慢执着及随眠远离）、无所得（一切相远离）；又随次第名爱尽、无欲、灭（涅槃）；与修习对应名修厌、修离欲、修灭
    - **二种渐次**：智渐次（智怎么生）：先无常智（思择生灭）→ 依之生苦智（生老忧苦热恼）→ 依之生无我智（缘起流转不得自在），即「无常故苦、苦故无我」
    - **智果渐次（果怎么熟）**：厌（对治现前，烦恼不现行）→ 离欲（不假思惟对治而贪不现行——伏断）→ 解脱（永拔随眠）；遍解脱＝生等苦杂染亦普解脱；又可分位说：厌位断界成满，下地离欲立离欲位，非想非非想处离欲立解脱位
    - **进路上的四种邪执**：见邪执（执我我所，障谛现观）、慢邪执（我慢，障修所断烦恼断）、自内邪执（独处空闲不正分别执实我）、他教邪执（由他教而起）——一切邪执永断即名智果
  - **非断非常与四缘：诸行流转的机制**
    - **衔接**：证智果之后回头解答疑难——诸行刹那不住，为何不是断灭、不是恒常
    - **非断非常**：诸行之因是无住之行（因无常，生已住因不可得）故「非常」；现在因灭能生未来诸行故「非断」
    - **四缘（诸行展转流转的四类动力）**：因缘（诸行种子）、等无间缘（前六识及其相应法灭，让位给后六识等无间生）、所缘缘（五识缘五种别境，第六意识缘一切法）、增上缘（根身与作意等助缘；先业望爱非爱果、资粮望道、道望涅槃亦摄其中）——四缘略归二种：因唯是因缘，余三只是「缘」
  - **三事二相与牢狱喻：观察染净的仪器**
    - **衔接**：机制之外还须观察自身染净——由三种事、二种相
    - **三事**：观爱味（知杂染因缘）→ 观过患（知清净因缘）→ 观出离（知清净本身）；按如所有性（三事体性）与尽所有性（穷尽其所有）观察，且遍及过去未来现在、内外、粗细、劣胜、远近
    - **三事的分量对比**：爱味极为狭小 ↔ 过患极为广大 ↔ 出离寂静无上、毕竟安隐
    - **证三事实有的三种有情众**：于诸欲染着众、远离众、离系众；相应三种世间愚痴（魔梵以欲与净的自在、沙门婆罗门以勤修其因、诸天人随业果受生）
    - **能断能证者**：有二种道离四倒心（入见地者与修道久住者），得四相心解脱果：贪嗔缚解脱、欲贪灭断出离、九结离系、生等诸苦解脱——前三相因处烦恼解脱，后一相果处诸苦解脱
    - **牢狱喻总括处境**：种种缚＝贪嗔痴缚；看守＝不正寻思与未拔随眠（不正寻思令人动弹不得；随眠未拔，纵以世间道逃至有顶天仍被抓回）；狱中妙欲＝九结（令人乐着不想逃）；怨家＝四魔以生等苦加害——四缚尽脱，方名从一切缚得解脱
  - **请略教授与六种死：生死这笔账**
    - **衔接**：偈颂「略教教果」起转入新主题——什么样的人向佛求「略教授」，由此算起生死账
    - **三种人求略教授**：厌多闻者（以为略闻得义、修行才实在）、怖畏繁难者（怕入门工程大）、多闻心乱者（所学太多怕作意散乱，不知依何法速证通慧速得出离）；正教授的四种自义果：形相、事业、意乐、处舍取具足 → 无上得、现法得、自然得、内证得
    - **六种死**：死的关键不在呼吸停止，而在带不带走随眠：按时间分过去死、现在死（诸行没乃至命根灭）；按调伏分不调伏死（随眠相续、命终结生相续、未来自体复起）↔ 调伏死（无有随眠，未来自体不复生起）；按同异分同分死 ↔ 不同分死（过去不调、现在已调而命终）
    - **六种死收摄为二相**：诸行流转过患相（不调不伏，取未来众苦与烦恼缚）↔ 诸行还灭胜利相（已调已伏，不取众苦、解脱诸缚）
    - **附注**：由名、种类、族姓、饮食、苦乐领受、长寿、久住、寿量边际八种相，安立世俗言说的「士夫」——只是假名安立
  - **无我遍智与三种缚：解脱难在哪、怎么破**
    - **衔接**：死得好不好，差别在遍智与缚——本段拆解二者
    - **无我遍智与断**：内、外、内外三种遍智（了知诸行无我、无我所、互不系属），断亦如是；路径是先由法住智得决定 → 数习遍智 → 舍相应随眠得毕竟断；佛对未得遍智者令得，对已得未断者令数习永断、复加劝导
    - **三种缚**：（令心难解脱，唯善说法律能解）：余结所系的诸有漏事（缚相「种种」）、爱结所染的诸有漏事（缚相「坚牢可爱乐」）、能生后有的诸行（缚相「微细」）
    - **后有缚的五相我慢**：所依（萨迦耶见）、所缘（计我当有／当非有，「有」又分有色无色、有想无想等五种，合为六种所缘）、助伴（动乱心）、自性（恃举为其自相、戏论为其共相）、因果（能感生为因，业行与爱相随）
    - **心善解脱三相**：于诸行遍了知（以四行知如所有性、十一行知尽所有性）、烦恼断得作证、烦恼断已于一切处离爱而住
  - **见慢杂染与清净说句：一张对照清单**
    - **衔接**：本段把染与净各列成清单，便于对号入座
    - **见杂染与慢杂染各有五种**：计我、计我所、我慢、执着（缠的现行）、随眠（种子随缚相续）——有学者应知应断，无学者已知已断
    - **五种因相**：以有识身及外事等为因，又分所缘因相与因缘因相——计我、我慢以有识身为所缘因相，执着以闻不正法、不如理作意及随眠为因缘因相，随眠以烦恼缠数数串习为因缘因相
    - **四种有情众对照**：外道（一切杂染具有）→ 佛法异生（正为断彼而未能断）→ 有学（已断一分，不自称已见——未得尽无生智）→ 无学（一切已断，自称如实见）
    - **八种清净说句**：超过见慢二句、除相（断因相）、寂静（断执着）、善解脱（断随眠）；有学二句（已割贪爱、转三结——贪爱不现行）；无学二句（止慢现观、已作苦边——贪爱随眠永拔）
  - **远离、精进、三圆满：卷末的实践叮嘱**
    - **衔接**：卷末回到日常行持——环境、动力、师承三件套
    - **四支具足远离**：无第二而住、处边际卧具、身远离、心远离——远离居家境界所生的寻思贪嗔，依不放逸防守其心
    - **五相发勤精进速证通慧**：被甲（有势力）、加行（有精进）、无怯劣（勇捍）、寒热蚊虻不能动（坚猛）、下劣无喜足（不舍善轭）；并以奢摩他、毗钵舍那分别对治惛沉睡眠与掉举恶作，令正止观不失坏
    - **三圆满**：行圆满（听闻正法、为他演说、自正修行、法随法行）→ 果圆满（心善解脱、证现法涅槃）→ 师圆满（一切梵行以世尊为根本、由佛转法眼而师弟展转传来、有疑唯依世尊能决）
    - **说法师二种**：由教（从他闻正法而宣说）、由证（依学道无学道的证得而宣说）
