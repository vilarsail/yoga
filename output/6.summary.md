- **全篇总括**：本卷讨论「不如理作意」——人为什么会一套一套地想错。论主先开出十六种外道异论的总目录，再逐一解剖前五种：因中有果论、从缘显了论、去来实有论、计我论、计常论。五种共用同一解剖流程：先摆出主张与依据（师承的「教」加自创的「理」），再用连环两难层层驳斥，判为「不应道理」，并立出正确说法。
  - **十六异论：想错有哪些固定套路？**
    - **卷首点题后**：先用一首偈颂、再用一段列举，把十六种异论的名字全部报出，作为本部分的总目录
      - **十六种大致分几类**：因果观三论（因中有果、从缘显了、去来实有）、有我与恒常二论、宿命与神创二论（宿作因、自在等为作者）、害为正法论、有边无边论、不死矫乱论（被问到「不死」问题时故意乱答）、无因见、断见、空见三论，以及妄计最胜、清净、吉祥三论
      - **本卷只逐个解剖前五种**：其余十一种留给下一卷
    - **五种异论共用一套解剖公式**：立论内容 → 问「为什么会有这种主张」→ 两类依据（「教」是先师传下的教典，「理」是论敌自己的一套推理）→ 论主发起连环两难 → 判定「不应道理」；驳斥的通法是逼对方选边，每个问题都设计成非此即彼，而每个选项各有内在矛盾，进退皆输
  - **因中有果论：果是不是早就藏在因里？**
    - **第一种异论回答**：「果是新生出来的，还是本来就有」。雨众外道主张：恒常如此，果在因中本自存在——好比认为芽早就整个藏在种子里
      - **四条理由**：世人共许此因只生此果、求果者只取此因、只在此因上加工、果只从此因生；若不承认，就得说「一切法能生一切果」——求一个果须取一切因，显然荒唐
    - **论主问**：因相与果相，是异还是不异？
      - **不异** → 因果没有差别，「因中有果」这句话本身就失去意义
      - **异** → 果在因中是未生还是已生？未生而说有，自相矛盾；已生则不必再从因生，同样矛盾
    - **论主正面立标准**：要认得「甲中先有乙」，须凭五相——处所可指认（如水在瓮中）、所依可指认（如眼识在眼中）、自相直接可得、自作业可得、因或缘一变果跟着变；「因中恒有果」一条也占不上
  - **从缘显了论：果不是生出来的，只是被显出来的？**
    - **第二种异论是因中有果论的翻版**：回答「条件在生成中扮演什么角色」。主张：诸法「性本是有」，众缘只令它显了、并非生它；持此论者中还有声相论师——声音常住无生无灭，说出来才显现
      - **理由**：果若先无而后生，说不通；人费力加工，岂不正是为了把本有的果「显了」出来？
    - **论主连环发问，两路夹击**：
      - **障碍两问**：障缘为何只遮果、不同样遮因（因与果同为存在，如黑暗既遮盆中水也遮盆）？又说障的是「有性」还是「果性」——障「有性」则因也被遮；障「果性」则一法亦因亦果（芽既是种子的果又是茎的因），到底显还是不显？
      - **「本法」与「显现」是一是异**？不异 → 法应恒常显现、显了之后何须再显；异 → 显现自身无因，或「因不显而果显」自相颠倒
    - **论主补一个关键区分**：东西存在不等于当下可取——太远、被障、极微细、心散乱、根损坏、缺相应智慧，都取不到相；但这救不了显了论，它的毛病出在「先有后显」的逻辑本身
  - **去来实有论：过去未来是像现在一样实有吗？**
    - **第三种异论回答**：「过去未来是否真实存在」。主张：过去未来的法体相成就、如现在一样实有非假；持论者中还有佛门内部的人（把佛经读成了字面实有）
      - **经据**：经文字面说「一切有」即十二处（六根六境便是一切），佛又说过有过去业、过去色未来色
      - **推理**：法若未来没有便未受自相、过去没有便失自相，自相一失诸法皆不成就
    - **论主先拆三世框架本身**：
      - **三世之相是一是异**？一 → 不必另立三世；异 → 「实有」立不住。堕三世的法是常是无常？常 → 不该流转三世；无常 → 不该恒是实有
      - **未来法怎样进入现在**？七个选项逐项碰壁：「来至今」则有方所、与现在无别、应是常；「未来死后生今」则未来未生谈不上死；「住未来为缘生今」则未来应是常、且成「本无今有」；本无业今有业、相由不圆满到圆满、相由异到异、未来先有现在分——各项同理皆有过失；现在退入过去也照此有一套
    - **论主再回应**「能想起过去，过去就实有」的反难：
      - **人对「没有」照样能起认知**：取「无我」「兔角」「石女儿」的认知明明存在，可见「有认识」推不出「对象实有」
      - **佛说「有」多是密意**（话里有言外之意）：有相法持有相、无相法持无相，都名为法、名为有——修行人须知有亦知无，否则无法无间断地观所知法；说有过去业，实指习气（业行过后在诸行相续中留下的势力）能感爱不爱果，假说为有；说三世色识，则依因相、自相、果相三种行相密意而说
    - **论主正面给出**：三世各自的十二种相，证明三世法相根本不同：
      - **未来**：因所显、体未生、待众缘、可生与不可生、未生染净、应求不应求等
      - **现在**：果所显、体已生、众缘会合、一刹那、不复生、现染净、可喜不可喜等
      - **过去**：已度因缘果、体已坏、已灭种类、不复生、染净静息、应顾恋不应顾恋等
  - **计我论：身心之中真有一个「我」吗？**
    - **第四种异论篇幅最长**：回答「我是不是实有」。主张：有我、有情、命者、生者、数取趣（轮回中一再受生的主体），谛实常住
      - **两条理由**：不假思索就自然冒出「有情」之感；先有「我要做什么」的念头，才有行动
      - **论敌的论证**：见色形、苦乐、名字、造作、识缘境这五类事，若无我，只该各起色受想行识之觉；可事实上五事都直接生起「萨埵（有情）之觉」，可见我觉独立于五蕴之觉
    - **论主的总破法**：把我觉放到每个可能的位置逐一检验，让每个选项都露出矛盾
      - **检验一**（我觉经不起认识论检查）：我觉若即于所见就算不上「颠倒觉」，若离于所见则我该有形量、有胜劣贵贱；现量（直接感知）里只有五蕴没有我，比量（推理）也推不出——婴儿不会推理，照样有我觉
      - **检验二**（造作归因连环问）：做事以觉为因还是以我为因？作因是常无常？能作的我有没有动作？作是有因无因？依自依他？——每个答案都碰壁
      - **检验三**（我与五蕴四种位置全落空）：即蕴则我与蕴无差别、谈不上常住；在蕴中则常我受苦乐损益便成变异、不受损益则善不善无处安立且应不经修行自然解脱；在蕴外则我成无为法；不属蕴则我应永无染污、与身心不相干
      - **检验四**（「见者」之我与种种比喻）：见等作用是我造的业还是我用的工具？比作种子则我无常；比作陶师、神通者则我该是假立；比作地、虚空，它们尚有持载、容受的明显业用而我拿不出；比作镰、火同样对不上号
      - **检验五**（染净流转不须我）：诸行自身便有疾疫灾横及其止息（染净义成），也有有因、可生、可灭、相续生起、有变异五种流转相——身、芽、河、灯、车都是无我而流转的现成例子；说我是受者作者解脱者同样两难：我若被苦乐思业烦恼改变，诸行本身已是受者作者；若不被改变，便说不上受与作
      - **检验六**（我见自身的价值）：我见若善，愚人不经修习就率尔起我见、令众生怖畏解脱、增长诸恶，善在何处？若不善，则非正非不颠倒，所计实我更无着落；反观无我见，是智者所说、令不怖解脱、能如实对治诸恶——分明是善。世间对火说「烧者」、对假名士夫说「德友」「佛授」，都是假立，何须于我独实
    - **结论**：从起觉、有作、假施设、杂染清净、流转止息、假立受者作者解脱者等多方面看，计实有我处处不成
    - **论主正面立论**：第一义的「我」只是诸法上的假名，非实有体；不必说它与诸法是一是异；其相无常、非恒、不可安保、变坏、生老病死、唯是诸法、唯是苦恼。佛在经中说假我有四个用意：令世间言说方便、随顺世间习惯、断除「定无我」的怖畏、为宣说自他功德过失令人生决定信解
  - **计常论：我和世间是永恒不变的吗？**
    - **第五种异论与我论同根**：回答「常是不是实相」。主张：我及世间实常住，不是被造的、不是被变化的，不可损害、积聚而住（如伊师迦那样坚固难坏）；细分为计前际一切常、一分常，计后际有相、无相、非想非非想，以及极微常住
      - **常见的来源多与禅定经验有关**：依静虑忆念前世（宿住随念）而不善知缘起，只见记忆不见生灭 → 计过去常；依天眼见诸识从此世到彼世相续不断 → 常见；见梵王随意成立世间、见四大种与诸识的变异 → 计一分常等；于想受只见现象差别、不见自相差别 → 计我世常住
      - **极微常论的来由**：不知缘起，认为粗物由极微集起、坏散即离散，把粗物不断分析到极微便到尽头——粗物无常，极微是常
    - **论主判定**：计前际后际常，属于我执论的差别相——我论既已攻破，常论随之而破
      - **直接检验**：宿住随念取的是诸蕴还是我？取蕴则由它立「我世常住」不成道理；取我则所忆不出「我曾名某姓某」等种种差别相，与常住自相矛盾
      - **再检验**：一境界起眼识时其余诸识是灭是转？灭则把灭坏之识计为常，转则一境界应令一切时一切识起；想受不断变异，我若随之变异则非常、无变异则一想之后不该有种种想、纯乐之后不该有苦——还连带牵出我是色非色、有边无边等种种异计，其实只是同一执著换了说法
    - **极微常论单独受审，连环数问**：
      - **不经观察就断定极微常** → 违背正理；自认观察过 → 又与诸量相违
      - **因「细」而常** → 极微离散损减只会愈弱，谈何常住；因「相异于粗物」而常 → 极微与地水火风不同类，怎能生出同类之果
      - **粗物与极微异不异**？不异则粗物也应常、因果无别；异则粗物从离散生还是聚集生、体量不过极微还是过量？——各有矛盾
      - **极微造粗物像种子还是像陶师**？像种子则极微应无常，像陶师则极微应有思虑——合适的比喻根本找不到；外物的生起由有情还是不由有情，也各有难
    - **收尾与全卷一致**：论主立出真正的常住之相——一切时、一切种、自然、由他都无变异，且无生相；拿这把尺衡量，极微与我都不够格，前五种异论至此全部判为「不应道理」
