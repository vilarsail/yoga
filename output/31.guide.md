# 瑜伽师地论卷第三十一 导读

## 一、内容总览
本卷为「声闻地第三瑜伽处之二」，承前卷正修方便，广辨净行所缘中缘起、界差别、阿那波那念三观的六事差别毗钵舍那，次明九白品加行与九黑品加行、净障四因缘（遍知自性/因缘/过患/修习对治）、四种作意（调练/滋润/生轻安/净智见），是声闻地奢摩他毗钵舍那修习的进阶教授。

## 二、结构层次
全卷按「三观六事 → 九白品加行 → 净障 → 修作意」推进：
- **缘起观六事（P1-P10）**：寻思义（无作者受者）→ 事（十二支内外）→ 自相（无明等前际后际无知）→ 共相（本无今有有已散灭无常苦空无我）→ 品（颠倒黑品无颠倒白品）→ 时（三世无正常性）→ 理（观待/作用/证成/法尔）。
- **界差别观六事（P11-P19）**：义（种姓种子因性）→ 事（六界内外）→ 自相（地坚水湿火暖风动识了别空无碍）→ 共相（皆无常无我）→ 品（一合相不了知起慢黑品）→ 时（三世六界为缘入胎）→ 理（如草木和合名舍，六界和合名身）。
- **阿那波那念观六事（P20-P28）**：义（系心了达无忘明记）→ 事（内外可得）→ 自相（长短遍身）→ 共相（系属命根及有识身皆无常）→ 品（不住正念黑品）→ 时（三世互系属）→ 理（都无持息者假想施设）。
- **九白品加行（P30-P47）**：相应/串习/无倒/不缓/应时/解了/无厌足/不舍轭/正加行 → 应时加行详明止观举舍四相及所缘因缘相 → 正加行明数起胜解数正除遣（五种除遣：内摄其心/不念/于余/对治/无相界），如画师喻。
- **净障（P49-P55）**：四因缘——遍知自性（怯弱/盖覆/寻思/自举四障）、遍知因缘（非理作意多分串习）、遍知过患（未证不证已证退失）、修习对治（随念/精进平等/恭敬听闻/不净等所缘/如理思择）。
- **修作意（P62-P70）**：四种作意——调练心（于可厌法令心厌离）、滋润心（于可欣法令心欣乐）、生轻安（厌欣交替安住内寂静生身心轻安）、净智见（依内静心修增上慧）；可厌处四（自他衰损/兴盛坏灭）、可欣处三（三宝/学处尸罗清净/自所证差别）。
以「六事差别 → 加行 → 净障 → 作意」为统一骨架。

## 三、关键结论
1. 三观六事差别：缘起观治痴、界差别观治慢、阿那波那念观治寻思，各寻思义事相品时理六事。
2. 九白品加行能令心速疾得定，九黑品反之；正加行核心为数起胜解数正除遣，如画师数作数除形相转明。
3. 五种除遣：内摄其心、不念作意、于余作意、对治作意、无相界作意；正意唯取内摄其心不念作意。
4. 净障四因缘：遍知自性/因缘/过患/修习对治；四障为怯弱/盖覆/寻思/自举。
5. 四种作意：调练心（厌离）、滋润心（欣乐）、生轻安（厌欣交替）、净智见（依静心修慧）。
6. 奢摩他与毗钵舍那展转相依：观串习清净故增长身心轻安，轻安增长故心一境性增长，二法展转相属，得转依方究竟。

## 四、易混辨析
- **止时 vs 观时 vs 举时 vs 舍时**：掉举时修止、沉没时修观、沉下时修举、掉举已解脱时修舍。
- **正加行五种除遣**：内摄其心（九相心住毗钵舍那上首）、不念（背一切相）、于余（缘余定地）、对治（不净治净等）、无相界（于无相界作意）。
- **胜解作意 vs 真实作意**：胜解约数数起相除遣、画师喻；真实约趣入实际境量。
- **调练心作意 vs 滋润心作意**：调练于可厌法令心厌离、滋润于可欣法令心欣乐，二心背黑向白易脱而转。

## 五、阅读提示
本卷是奢摩他毗钵舍那修习进阶，可带「三观六事 → 九加行应时四相 → 净障四因缘 → 四作意」四线索读；应时加行的止观举舍四时、正加行画师喻最宜对照把握。
