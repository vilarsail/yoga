# 瑜伽师地论卷第二十二 导读

## 一、内容总览
本卷为「初瑜伽处出离地第三之一」，承种姓、趣入二地之后开演出离地。先以嗢拖南总标出离地三相——世间离欲、出世间离欲、二道资粮；世间出世二离欲各约粗相静相、四圣谛立，二道资粮为本卷主体，先总举十四资粮，次专广辨第一资粮「戒律仪」，是声闻地戒学根本。

## 二、结构层次
全卷按「总标三相 → 略明二离欲 → 二道资粮总举 → 广辨戒律仪」推进：
- **总标（P1-P3）**：嗢拖南举世间离欲、出世间离欲、二道资粮。
- **世间离欲（P4-P5）**：于下地观粗相、上地观静相，渐次离欲乃至非想非非想处。
- **出世离欲（P6）**：亲近善士、于圣法聪慧调顺，如实知四圣谛，遍三界见修所断法中自得解脱。
- **二道资粮总举（P7-P11）**：嗢拖南列十四资粮——自他圆满善法欲、戒根律仪食知量、觉寤正知住善友、闻思无障舍庄严。
- **广辨戒律仪（P12-P99）**：嗢拖南列六门（辨三亏满十六异门三诤胜功德十种）→ 戒律仪三相思择（无失坏/自性/自性功德）→ 六种异门（受持/出离/修习戒性）→ 十亏损因缘与十圆满因缘 → 亏损中二因缘名艰难 → 六种尸罗异名（根本/庄严具/涂香/薰香/妙行/律仪，各以伽他释）→ 三观清净因相（观身语意业）→ 十功德胜利。
以「总标 → 广辨第一资粮」为骨架，戒律仪一门占全卷主体。

## 三、关键结论
1. 出离地略有三：由世间道离欲（粗静相观）、由出世道离欲（四谛观）、二道资粮（十四种）。
2. 戒律仪三相：安住具戒显无失坏相、善守护别解律仪显自性相、轨则所行圆满显观他增上自性功德相、于微小罪见大怖畏受学学处显观自增上自性功德相。
3. 尸罗亏损有十因缘：最初恶受、太极沉下、太极浮散、放逸懈怠、发起邪愿、轨则亏损、净命亏损、堕在二边、不能出离、所受失坏；与之相违名十圆满。
4. 尸罗净命亏损摄邪命：矫诈、邪妄语、假现相、苦研逼、利求利五种状相。
5. 戒律仪十功德胜利：从无悔、欢、喜、轻安、乐、心定、如实知见、厌、离染、解脱乃至涅槃为第一，临终善趣为第二，乃至一切所愿皆遂为第十。
6. 尸罗六种异门：根本（建立任持）、庄严具、涂香（除热恼）、薰香（称誉普闻）、妙行（趣妙安隐）、律仪（防护息除远离）。

## 四、易混辨析
- **世间离欲 vs 出世离欲**：前者由世间道观粗静相伏烦恼、未断种子；后者由出世道观四谛断见修所断一切法、超过三界。
- **戒律仪三相 vs 三种戒性**：三相约无失坏/自性/自性功德；三种戒性约受持/出离/修习，开合不同。
- **十亏损 vs 十圆满**：一一相违对立，非别立十圆满因缘。
- **观他增上 vs 观自增上**：轨则所行圆满令他信敬名观他增上，于微小罪见大怖畏自防恶趣名观自增上。
- **根本 vs 庄严具 vs 涂香等六异门**：同一尸罗约义别立——建立任持名根本、服饰妙好名庄严具、除身心热恼名涂香、称誉普闻名薰香、趣妙安隐名妙行、防护息除名律仪。

## 五、阅读提示
本卷是声闻地「戒学」根本，可带「三相 → 十亏损圆满 → 六异门 → 十功德」四线索读；十亏损因缘与净命五种邪命状相最宜对照列表，把握持戒得失的完整判据。
