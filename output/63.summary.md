- **全篇总括**：本卷是决择分四地的连讲：先续三摩呬多地（定地）决择，讲什么过失障定、四禅为何恰好四层、离欲有几义、退定有几条路；再立非三摩呬多地（不定地），把「不定」分成十二种成因并一一给对治；接着用阿赖耶识（摄藏一切法种子的根本识）与转识的框架讲有心地的真实结构；最后以七种「心不生因」收束无心地。四地决择各以「余决择文更不复现」一句作结。
  - **三摩呬多地决择·下篇：定为什么修不成，四禅的账目怎么算**
    - **本部分回答两件事**：一是障定到底障在哪（五种厚重过失），二是把四静虑（四禅）的数、所治、支分、名义、离欲、退失一次清算清楚
    - **五种厚重过失：忿、慢、欲贪、萨迦耶见、不能堪忍——每个过失如何杀死一个定**
      - **开头先交代两份外围清单**：五种定相违法（毁犯禁戒、无无间加行〔不间断用功〕、无殷重加行〔恳切郑重用功〕、有沉没〔心收摄过度而昏昧〕、受他人扰恼）与三种远离（住处、见、闻）——外缘说完，转入真正的内因
      - **每种过失都配一面镜子**：五种厚重三摩地相：得随宜资具便喜足、好乐求诸善法、于身财无所顾恋、观生死过患与涅槃功德、堪忍加行勤苦；五种过失正是障碍这五相而住，故称「厚重」
      - **五条破坏路径遵循同一公式**：起惑 → 引发相应寻思并多随寻伺（念头一波波跟着来）→ 未生的定生不起、已生的还复退失
        - **忿**：乞食不得利养、或得而少劣迟慢不敬 → 愤懑颦戚 → 恚害寻思不断
        - **慢**：被慢制伏 → 对师范福田不能卑屈请问善恶、不勤求善法 → 不解引发三摩地之义
        - **欲贪**：深恋身财 → 于五妙欲多生散乱 → 欲寻思、眷属寻思、国土寻思、族望家势寻思；对治是不净观，略有三相——粪秽相、彼等流相、能依所依差别相
        - **萨迦耶见**（执五蕴为实我的身见）：遇世法便高欣下戚，想弃舍又与身见相违而住，反复烧恼——纵已获得诸三摩地，谛现观（现见四圣谛）的胜三摩地仍生不起
        - **不能堪忍**：已得谛现观胜三摩地，却忍不了蚊虻等苦 → 舍离加行、多生懈怠 → 根本定不生或退失
      - **三道关卡收束**：前三过失障「最初三摩地」，萨迦耶见障「谛现观三摩地」，不堪忍障「入根本三摩地」
      - **附一份人事清单**：师长弃舍近住弟子的八种因缘（怀憎恶心、贪图自身恭敬利养、弟子毁犯、于弟子众偏党饶益损减、于戒与定慧的教授折伏不能堪忍、营众务扰恼不能堪忍）——无烦恼而善住念的阿罗汉不会有这类事
    - **四静虑的完整账目：为什么恰好四层、每层扔什么、每层由什么构成**
      - **一首嗢拖南（纲要偈）**：先立五个待答问题：数、所对治、支分广建立、远离苦散动、上支分差别——以下问答全部按此展开
      - **数**：为何恰好四静虑不增不减——因为要「究竟超苦乐」，从初禅到四禅渐次超越苦乐，到第四层才彻底
      - **所对治**（每层要扔的行李）：
        - **初禅扔五样**：欲贪、欲恚害三种寻思、忧苦、犯戒、散乱
        - **二禅扔五样**：初禅贪、寻伺、苦、掉举、定下劣性；三禅扔四样：二禅贪、喜、踊跃、定下劣性；四禅扔五样：出入息、三禅贪、乐、于乐发悟、定下劣性
        - **规律**：上一层的禅味就是下一层的所治——每升一层，连定中的喜乐也要放下，到四禅连呼吸都停了
      - **支分**（每层的构成）：
        - **初禅五支**：寻、伺、喜、乐、心一境性；二禅四支：内等净、喜、乐、心一境性；三禅五支：念、正知、舍、乐、心一境性；四禅四支：舍清净、念清净、不苦不乐、心一境性
        - **内等净的自性**：就是念、正知、舍
        - **念正知舍**：其实四禅都在，只是显隐不同：初禅由寻伺门引发故不明说；二禅因踊跃等心随烦恼缠缚改显「内等净」之名；三禅心随烦恼已远离才显其自相；四禅显示最极清净（舍清净、念清净）
        - **「离贪」的层级也不同**：初禅离欲贪而非离喜贪，二禅离寻伺贪而非离喜贪，四禅则最极清净
      - **立支的理由给了一串等价公式**：住所依、住饶益、住自性；思惟所缘、受用所缘、于缘不散；饶益所依、增上心所依、增上慧所依
        - **受欲者三事类比**：正求财宝 → 正受用 → 于彼自在随意；修静虑者也有对应三事，支分即依此建立
        - **支分又是对治三杂染住**：（染污住、苦恼住、愚痴住）与三种苦恼行（缺减、身心逼恼、心于外境流散不寂静）
      - **初禅**：既说「离欲」又说「远离恶不善法」，为何重复——原文给了多组解释：为显诸欲的自相与过患（欲发恶行、坠恶处故名恶，违善生故名不善）；为显烦恼杂染断与业杂染断；为显在家人受用门之欲断与出家人寻思门之欲断；为显欲寻思断与恚害寻思断；也为显外道仙人所得之相与其退失后行咒诅之相
    - **几个精细问答：把「不断」与「动」说清**
      - **初禅苦根未断**：因为彼品粗重未远离；若苦根已断，初禅与二禅的住就应无差别
      - **寻伺**：能摄益自地之定、令自地清净，佛为何说它「动」？——是望他地说动，不是望自地
      - **后后禅支更胜的三种因缘**：所治能治、证得胜利、所证得
      - **层间差别三关键词**：初二之别在三摩地圆满，二三之别在饶益圆满，三四之别在清净圆满
    - **四种修三摩地与四类人：同一座定的四种用途**
      - **四种目的**：得现法乐住、得胜智见、得分别慧、证诸漏永尽——依四类人（补特伽罗）建立：苦速通（根钝而行疾）已见谛者、已离欲得无量的凡夫（异生）、乐迟通（根利而行迟）已见谛者、乐速通（根利而行疾）已见谛者
      - **那位已离欲的凡夫**：若再证得死生智通，即名智见清净；乐迟通者虽已见谛但根软名退法，故于欲界受想寻思应常修正念正知
    - **离欲六种与四个名字：先把「厌离」分清，再给定命名**
      - **六种离欲本质各异**：自性离欲（对自性不净不可受用事、苦受、已离初禅染后对寻伺的厌背）、损减离欲（习淫欲法除热恼已的厌倦）、任持离欲（饱食后厌余食）、升进离欲（得胜财贵位后厌下劣）、愚痴离欲（不解涅槃甚深功德反而厌背涅槃——这是错的厌离）
      - **真正修行义的只有对治离欲**：厌坏、断、持、远分四对治，及以世间出世间道断诸烦恼
      - **四个名字一张脸**：名住——系心内所缘、于外不流散；名三摩地（等持）——于所知事影像平等持心；名奢摩他——为寂静一切烦恼而安止；名心一境性——「一境」专指定地所缘，系心于此一境
    - **退定十条路：定得再深也会退**
      - **十种从离欲退，各配实例**：依止不平等（遭重病如马胜之忧「我于此定不能入证」、或性多粗重先不串习）；所缘境界胜（仙人遇美妙母邑而退）；获得敬养（如提婆达多）；遭遇轻毁（仙人愤恚退定现行咒诅）；慢（恃定自举凌他）；增上慢（于胜定证差别中错认）；不作意（不复思惟入定行相）；未串习（安住始业新修）；自地烦恼数起（爱上静虑乃至疑上静虑）；寿尽福尽业尽（从上生处退没下生）
      - **退与入的速度**：由烦恼与善法的强弱四象限决定：烦恼轻+善法重→退慢入快；烦恼轻+善法轻→退慢入慢；烦恼重+善法轻→退快入慢；烦恼重+善法重→一刹那退、一刹那入
      - **出定听声的机制**：从定而起时与定相应的意识仍在转、耳识另起取声——定心本身不取声；不是一取声就出定，而是领受声已、若有悕望后时方出
  - **非三摩呬多地决择：十二种「不定」的病历与处方**
    - **换问反面**：什么情形算「不定地」——不是一刀切，而是按十二种成因分别安立，再一一给对治
    - **前五种成因是性质上的不定**：自性故（五识身）、阙轻安故（欲界心心法）、未发趣故（受欲者）、散乱故（初修者心流五欲）、太聚故（略聚其心便生沉没）
    - **后七种是修证进程上的不定**：未得（散心相应诸法）、未圆满（未证加行究竟作意）、杂染（得果作意而多生爱味）、不自在（染污心故）、不清净（未永害烦恼随眠）、出定（从定起而不退失）、有退（从所得定退）
    - **十二张处方与病因一一对应**：取青瘀脓烂等相以安住心 → 勤修得作意 → 勤修得根本 → 安住正念速疾摄心 → 思惟净妙相并善达沉没 → 猛利护念不忘师教 → 于微劣定不生喜足 → 观杂染过失即除爱味 → 无间修并善巧通达其相 → 猛利修谛善巧 → 不放逸令不退 → 修远离如理作意
  - **有心地决择：从胜义看，心意识到底怎么构成**
    - **换到「心」本身**：心的差别运转略由五相建立——世俗道理（前意地已说，此处不重出）、胜义道理、所依能依、俱有、染净
    - **胜义结构是「二识」**：阿赖耶识是所依，转识（眼识至意识七种）是能依——如水浪依暴流、影像依明镜
    - **诸识**：皆可名心意识，但就最胜分三：阿赖耶识名心（集聚一切法种子，恒缘执受身与不可知器界）；末那（第七识）名意（一切时执我我所及我慢、以思量为性）；其余诸识名识（以了别境界为相）
      - **心、意、识**：于有心位一切时俱有而转；转识若起，或四识俱转乃至八识俱转
      - **一个意识**：能一时分别一境、二境乃至多境，自境他境——所以说意识不可思议
    - **佛说的「出世末那」如何建立**：名假施设、不必如义；对治末那、远离颠倒即是正思量；此末那任持意识令分别转，故说是意识所依
    - **受分深浅两层**：转识或与乐受、或与苦受、或与舍受相应俱转；阿赖耶识相应受则一切时唯不苦不乐、唯是异熟生（果报所生），于识流转中恒相续流至命终不断
      - **其余三受**：是思惟所引发（非俱生、作意引发现前）；俱生受极微细故难可分别——此即胜义道理的俱有差别
    - **染净差别**：阿赖耶识自身无烦恼相应；末那则恒与四种任运烦恼俱起不绝——我我所行萨迦耶见、我慢、我爱、不共无明（末那独有的根本痴暗）
      - **这四烦恼**：与善、不善、无记识俱起而不相违，性唯隐没无记（隐而不显的中性）；其余烦恼由分别起、随众缘力而转
      - **世间治道损伏不了它们**：已离欲者犹现行，随所生处此地烦恼现行不绝——因为它们唯由阿赖耶识种子所引、任运而生，非对治道与境界缘力所能转
      - **有学已见谛者**：圣道现前时不现行、出定又复现行（善通达故、未永断故）；无学则一切种皆不现行
      - **这组烦恼**：唯离非想非非想处欲时一时顿断，非如余惑渐渐而断
  - **无心地决择：心在什么情况下根本不生**
    - **总问总答**：心不生因略有七种——缘阙、作意阙、未得、相违、断、灭、已生；反之，与七因相违（缘不阙、作意不阙、已证得、不相违、未断灭、未灭尽、未已生）则心得生
    - **前两因是条件缺失**：缘阙——内根坏或外境不现前，眼识乃至意识终不生；作意阙——根境俱在，但无能生作意正起，识仍不生
    - **第三因未得**：想证初禅乃至非想非非想处、想证涅槃，若不极作意、不善修习——彼地之心或永解脱心便不生
    - **第四因相违**：乐受心现前则苦受、舍受心不生，贪心现前则嗔心不生——互相抵触的受与烦恼不能共存
    - **五六两因是断与灭**：修八圣道永尽贪嗔痴故染污心不生；生无想天、入无想定灭尽定期间及入无余涅槃后，心由断灭不生
    - **第七因已生**：已生之心刹那必灭——现在时由「已生」故不可再生，灭后亦终不可再生
    - **本卷四地的决择**：至此以同一句「于此地中余决择文更不复现」全部完结
