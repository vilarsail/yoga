# 瑜伽师地论卷第七十六 导读

## 一、内容总览
本卷属《瑜伽师地论》「摄决择分·菩萨地」第五部分，全卷内容引自《解深密经》，借三段菩萨请问、佛回答的体裁，决择大乘唯识三大核心义理：心意识秘密（阿赖耶识缘起）、一切法相（遍计所执、依他起、圆成实三相）、诸法无自性相（三无自性性与三时判教）。是唯识宗建立「八识」「三相」「三无性」「三时教」的经典依据。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
全卷以三段问答一线贯穿，每段皆循「菩萨请问 → 佛以譬喻广答 → 重颂收束」的固定程式，三段之间是「能变识 → 所现相 → 相之性」层层收摄：先说心识如何变现，次说所变现之法的三相，再说此三相皆无自性——由用归体，由相显性。

- **心意识秘密（广慧问）**：立阿陀那识为流转之因 → 三名异实同（阿陀那／阿赖耶／心）→ 六识依之而起 → 暴流、镜影二喻明一识与多识俱转 → 由法住智「善巧」到胜义「不见」为究竟善巧 → 重颂「恐彼分别执为我」。
- **一切法相（德本问）**：总标三相 → 眩翳喻（病眼／净眼）对辨遍计、依他、圆成 → 颇胝迦宝染色喻明依他起上遍计执 → 由三相了知无相、杂染、清净三法 → 由了知而断灭杂染、证得清净 → 重颂「不断杂染坏净相」。
- **诸法无自性相（胜义生问）**：胜义生述疑（佛既说蕴处界谛道品自相，又说一切法无自性，二者如何会通）→ 佛答依三种无自性性密意而说 → 三无性配三相 → 立三无性因缘（有情于依他圆成上增益遍计）→ 三类根机闻法差别（生无性 → 相无性 → 胜义无性次第引导）↔ 谤法者退失善法 → 一乘密意与五种种性 → 三时判教（四谛 → 隐密无性 → 显了无性性）→ 了义经功德校量 → 奉持名「胜义了义之教」→ 闻法获益。

## 三、关键结论
1. 阿陀那识（阿赖耶识、心）为六识身生起之所依，如暴流相续，执受有色根及戏论习气二种执受，是生死流转之根本。
2. 一切法相可归纳为遍计所执（假名安立）、依他起（缘生）、圆成实（真如）三相，三相不离心识而立。
3. 「一切法皆无自性」是依三相立三种无自性性的密意说，非谓诸法全无，闻者不应随言执著。
4. 第三时教以显了相说无自性性，是真了义、无上无容；前二时教是有上未了义，是诸诤论安足处所。
5. 「唯有一乘」是密意说，有情种性有别（趣寂声闻、回向菩提声闻、独觉、如来乘等），非一切有情皆能成佛。

## 四、易混辨析
- **遍计所执相 vs 依他起相 vs 圆成实相**：遍计所执是名言假立的自性，如眩翳所见毛轮，体本非有；依他起是缘生法本身，如眩翳众相现前，如幻而有；圆成实是真如清净所缘，如净眼离翳所见本性，真实不虚。
- **相无自性性 vs 生无自性性 vs 胜义无自性性**：相无性配遍计所执（非自相安立，纯假名）；生无性配依他起（依他缘力，非自然有）；胜义无性通依他起（非清净所缘）与圆成实（法无我性所显）二分。
- **阿陀那识 vs 阿赖耶识 vs 心**：同一第八识的异名，从「执持身」「摄受藏隐同安危」「积集滋长色等」三义立三名，体一义别。
- **一向趣寂声闻 vs 回向菩提声闻**：前者慈悲薄弱、怖畏众苦，一向弃背利生与诸行，终不能证无上菩提；后者已脱烦恼障，蒙佛觉悟可脱所知障，如来异门说为菩萨。

## 五、阅读提示
带着「佛为何对同一群众生说三套看似矛盾的话」这一问题读：留意胜义生提问中「以无量门曾说蕴处界谛道品自相……复说一切诸法皆无自性」的张力，看佛如何用「密意」与「三时判教」化解这一矛盾，最终归宗于第三时显了了义之教。
