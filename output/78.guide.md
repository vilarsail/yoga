# 瑜伽师地论卷第七十八 导读

## 一、内容总览
本章位于《瑜伽师地论·摄决择分》中菩萨地的最后部分（卷七十八），承前卷对菩萨地的决择，进一步以《解深密经》为依，分两大段决择大乘境行果：前半（观自在菩萨请问）系统决择菩萨十地行位与六（及十）波罗蜜多的名义、对治、品类、清净相；后半（曼殊室利菩萨请问）决择如来法身、化身及成所作事，包括三藏言音、四道理、不共陀罗尼等。全卷是菩萨地「行位」与「果德」的总收束，并以两段重颂与「了义之教」结名奉持作终。

## 二、结构层次
全卷以「当知如解深密经中」提领两大段问答，呈「地波罗蜜多（因地）→ 如来成所作事（果地）」的因果递进：

- **第一大段：菩萨地波罗蜜多了义教（观自在菩萨请问）**
  - 总标框架（四种清净 + 十一分普摄诸地）→ 十一分以「彼诸菩萨由是因缘此分圆满。而未能…」的递进句式逐地展开 → 十地得名因缘（极喜乃至法云、佛地）→ 二十二愚痴与十一粗重配地所断 → 八殊胜展转增胜
  - 六度学处（配三学、二资粮）→ 四助伴（方便善巧、愿、力、智与前六为伴）→ 六度因果相生次第 + 每度三品类 → 五相名义（无染等着）+ 相违事、果异熟、间杂染、非方便 + 七种总别清净相 → 五相业用与四种威德、大悲为因
  - 三品波罗蜜多（波罗蜜多／近／大）↔ 三种随眠（害伴／羸劣／微细）配地 → 三大不可数劫断皮肤骨三粗重 → 菩萨烦恼无染污相 → 一乘密意（会通三乘）→ 重颂结名

- **第二大段：如来成所作事了义教（曼殊室利菩萨请问）**
  - 法身相（转依成满）↔ 解脱身（声闻独觉所得，平等而无法身差别功德）→ 化身生起与示现方便善巧（入胎诞生出家成道）
  - 三藏言音（契经／调伏／本母）→ 本母十一相 → 八行观 → 四道理（观待／作用／证成／法尔）→ 证成道理五清净相 + 七不清净相 → 一切智五相
  - 不共陀罗尼义（染净法皆无作用、无补特伽罗，离所为故）→ 如来心生起（无加行而由先方便般若力生心）→ 化身非有心非无心
  - 所行与境界差别（五界差别）→ 成等正觉等三皆无二相 → 法身放光喻（颇胝迦宝）→ 威德住持能令身财圆满或下劣 → 净秽土八易二难 → 重颂结名

## 三、关键结论
1. 菩萨十地以「四种清净」与「十一分」普摄，每一分皆由「已圆满而未能…」的递进结构显其层次，地地展转增胜，至佛地方一切分圆满。
2. 每地各有二愚痴及一粗重为所对治，至佛地方尽二十二愚痴与十一粗重，安立诸地而证阿耨多罗三藐三菩提。
3. 六波罗蜜多配三学、二资粮，方便善巧等四波罗蜜多为前六助伴；波罗蜜多之所以名波罗蜜多，由无染等五相，复有七种总别清净相。
4. 法身与解脱身有别：声闻独觉所得转依名解脱身，唯如来转依成满名法身；法身无生起，化身有生起，化身非有心非无心。
5. 如来言音略有三藏（契经、调伏、本母），本母以十一相决了诸法，摄八行观、四道理，证成道理复分五清净、七不清净。

## 四、易混辨析
- **波罗蜜多 vs 近波罗蜜多 vs 大波罗蜜多**：波罗蜜多在胜解行地，烦恼现行且能制伏菩萨；近波罗蜜多从初地起，烦恼现行但菩萨能制伏非彼所伏；大波罗蜜多从八地起，一切烦恼皆不现行。
- **法身 vs 解脱身 vs 化身**：法身是如来转依成满之相，无量功德所庄严、无生起；解脱身是声闻独觉所得转依，与如来平等但无法身差别功德；化身是法身所起作业，有生起相，非有心非无心。
- **害伴随眠 vs 羸劣随眠 vs 微细随眠**：害伴随眠在前五地（俱生烦恼现行的助伴已永断无余）；羸劣随眠在六七地（微细现行，修所伏而不现行）；微细随眠在八地以上（一切烦恼不复现行，唯有所知障为依止）。
- **契经 vs 调伏 vs 本母**：契经依摄事显示诸法（四事、九事、二十九事）；调伏依声闻菩萨显示别解脱及相应法（七相）；本母以十一相决了分别显示诸法。

## 五、阅读提示
带着「地地如何展转增胜」与「如来果地与菩萨因地如何衔接」两个问题读，留意「彼诸菩萨由是因缘此分圆满。而未能…」这一递进句式与「当知如解深密经中」的提领语，可把握全卷骨架。
