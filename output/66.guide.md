# 瑜伽师地论卷第六十六 导读

## 一、内容总览

本章为《瑜伽师地论》卷第六十六，属「摄决择分·思所成慧地」第二部分，承接卷六十五对思所成慧地的决择。全章以「四圣谛」开篇，依次展开对有情世间因果相续与诸法体性差别的系统决择，涵盖苦相、食、异熟、业果、因果、缘生、内外、名色、执受、大种造色等一系列法相分类，最终以一连串「有/无」「善/不善/无记」「学/无学」「见道断/修道断」等二分、三分法门收束，是思所成慧地对诸法相的总决择。

## 二、结构层次

全章以「四圣谛 → 有情任持 → 异熟业果 → 因果建立 → 诸法差别相」五段递进，由苦至道、由有情至诸法：

- **四圣谛决择（P1-P12）**：先明「行苦」通于三受，以「热痈」喻显三受与三毒相应 → 指出贪嗔痴为三根本烦恼 → 由苦谛入集、灭、道谛，建立四谛粗细次第（先施设生等众苦，后显五取蕴苦）。
- **有情任持（P13-P21）**：先列「四食+命根」五任持法 → 设问「七因缘」与「佛说有情由食而住」之关系 → 以四句分别段食与食之宽狭，明食之多分因缘义。
- **异熟与业（P22-P34）**：分辨「有异熟法、异熟法、异熟生法」三种差别 → 由临终心、结生心明异熟相续 → 依三界明受之异熟差别 → 建立「白白、黑黑、黑白俱」三业。
- **因果建立（P35-P46）**：广明「有因法」由生起因、引发因所立 → 对应明「有果法」之五果（等流、异熟、增上、士用、离系） → 因果对称收束，明二道离系差别。
- **诸法差别相（P47-P108）**：依次决择缘生、内法、名色、执受、大种造色 → 转入一系列二分三门法相分类（有/无、有漏/无漏、有上/无上、应修、三世、三界系、三性、学/无学、见道断/修道断） → 以「甚深难见法」收束，归于诸法自性离言 → 末后总列一切差别相，劝如理思择。

## 三、关键结论

1. 行苦遍于三受，于不苦不乐受中粗重性显了，故说不苦不乐受是行苦；三受分别随增贪、嗔、痴，即三根本烦恼之所依。
2. 佛说「有情由食而住」是依多分、易入、增益、除病、入道五因缘而建立，非遮命根等余任持因。
3. 异熟法唯是无覆无记，从异熟生者通善不善无记，是名异熟生法；黑白业由生类、事、自性差别建立。
4. 五果中，离系果唯出世道所得，世间道但得离系增上果，非究竟离系。
5. 诸法自性绝诸戏论、过语言道，一切法皆甚深难见，由言说为依止方可取可观。

## 四、易混辨析

- **有异熟法 vs 异熟法 vs 异熟生法**：有异熟法指能感异熟果的漏与有漏（善不善有力者）；异熟法指果报心本身（如临终心、结生心、自性住心），唯无覆无记；异熟生法指从异熟果所生之法，通善不善无记。
- **白白异熟业 vs 黑黑异熟业 vs 黑白俱异熟业**：白白业感一向可爱异熟（善业感善果）；黑黑业感一向不可爱（恶业感恶果）；黑白俱业由生类、事、自性差别，二种种子随逐，感杂异熟。
- **等流果 vs 增上果 vs 士用果 vs 离系果**：等流果是同类因所引（如种子生现行）；增上果是缘力所感（如三处现前生胎生）；士用果是功用所成（如正精进生喜乐住）；离系果是断烦恼所显，唯圣道所得。
- **见道所断法 vs 修道所断法 vs 非所断法**：见道所断是分别烦恼（五见、疑、相应无明）及往恶趣业；修道所断是俱生染污及有漏善、无覆无记；非所断是出世圣道及有学无学世间善法（已断故）。

## 五、阅读提示

读本章可带着两个问题：其一，佛说四食、七因缘任持诸行，为何偏说「有情由食而住」？其二，五果中「离系果」与「离系增上果」有何差别？抓住这两条线索，便能贯通前半有情任持与后半因果建立两段。
