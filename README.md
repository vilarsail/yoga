# 瑜伽师地论

本项目是《瑜伽师地论》（弥勒菩萨说·玄奘译）的现代汉语重译本，附有导读与词语注释，目的是方便阅读、便利学习。

## 项目简介

本书为《瑜伽师地论》的重译版本。初版因 AI 技术与工程实践所限，越到后期章节问题越多；V2.0 重译借助更成熟的大语言模型与工程能力进行了全面优化与校对，V3.0 在此基础上进一步完成了全文译文明晰化与学习配套建设。主要更新：

V2.x：

1. 三轮翻译、检查与校对，最大程度保证原文与译文的准确性；
2. 基于语义理解对原文进行智能化段落重划，解决原文段落过长、对照阅读困难的问题；
3. 每卷增设导读，总括内容、梳理逻辑架构；
4. 新增专业术语对照表，对难点、重点术语补充详细译注。

V3.x：

1. 译文明晰化：将残留的文言句式、紧缩复句与省略主语统一改写为顺畅的现代白话，全文语言风格一致，无需对照原文即可一遍读懂；
2. 义理复合术语全卷统一整改：或直接意译、或首次出现时括注白话释义，消除术语未译造成的阅读障碍；
3. 建立「改写→校验→修正」自动化质量闭环，每段改写均经独立校验对照原文逐句审核，不通过则修正或回退；
4. 系统性检测并补译近似未翻译段落与漏译段落；
5. 新增[学习模块](#学习模块交互式教学--思维导图)：每卷一份交互式学习网页与一张可交互思维导图，共 100 卷全部覆盖；
6. 重难点词语注释全面扩充至每卷 111–254 条：在法相术语之外，重点补注非术语的难解文言词（古今异义、生僻字注音、通假、关键虚词句式、律制名物等），并补收旧版漏收的术语、辨析原文讹字；
7. 注释编号统一为「〔1〕〔2〕…」样式且不设数量上限，正文标注与卷末注释表一一对应、双向跳转（epub 打包脚本同步支持），并经序号-位置-字符流脚本校验与跨卷释义一致性审查。

详细说明请阅读[前言](output/0.md)。

## 学习模块（交互式教学 + 思维导图）

`study/` 目录下为每一卷提供了两个纯静态网页（无需安装任何依赖），并有统一目录页 `study/index.html` 汇总全部 100 卷：

- **交互式学习网页**（`N-study.html`）：按「由易到难」的学习路径组织本卷核心义理，通过点击翻转卡片、条件模拟器、流程分步推进、动手归类练习等交互形式拆解抽象义理，适合初学自测与复习巩固；
- **思维导图**（`N-mindmap.html`）：以层级树呈现全卷义理脉络，每个节点附简明白话概述；单击节点折叠/展开分支，支持拖拽平移、滚轮与捏合缩放、一键复位，可先纵览全卷结构、再逐层深入。

本地浏览：

```bash
./serve-study.sh    # 一键启动静态服务（脚本会自动生成目录页）
```

然后访问 http://localhost:8000/study/index.html ，也可直接打开任意一卷的学习网页或思维导图。

## 目录结构

```
.
├── origin/                # 原文（txt，100 卷）
├── docs/                  # 早期版本的译文/原文 markdown（100 卷）
├── output/                # 最终成品（100 卷，每卷 3 个文件）
│   ├── 0.md               # 前言（含 V2.x / V3.x 版本功能说明）
│   ├── N.md               # 第 N 卷原文 + 译文（中英对照式排版）
│   ├── N.guide.md         # 第 N 卷导读
│   └── N.notes.md         # 第 N 卷词语注释
├── study/                 # 交互式学习网页 + 思维导图（每卷各一份，共 100 卷）
├── 交互式教学模块.zip       # 学习模块的离线打包
├── serve-study.sh         # 学习模块一键本地服务脚本
├── .claude/skills/        # 翻译/校对/修复/导读生成的 AI skill 定义与脚本
├── build_epub.py          # epub 打包脚本
├── cover.jpg              # epub 封面
└── 瑜伽师地论(3.0导读注释版).epub / .pdf  # 打包成品
```

每卷包含三类文件：

| 文件 | 内容 |
|---|---|
| `N.guide.md` | 导读，约 1200 字，概述本卷主旨与逻辑架构 |
| `N.md` | 原文与译文，原文段以全角空格缩进、译文段为 `> ` 引用块，原文段中以 〔1〕〔2〕… 标注术语位置 |
| `N.notes.md` | 词语注释，按圈号顺序列出本卷术语的释义 |

## 打包脚本

使用 [build_epub.py](build_epub.py) 将 `output/` 下的文件一键打包为 epub + pdf。需先安装 pandoc（macOS: `brew install pandoc`）与 calibre 的 `ebook-convert`（macOS: `brew install --cask calibre`）。

```bash
python3 build_epub.py                  # 一键生成 epub + pdf：前言 + 100 卷，封面 cover.jpg
python3 build_epub.py 1 50             # 只打包卷 1-50（不含前言）
python3 build_epub.py --no-pdf         # 只生成 epub
python3 build_epub.py -o 自定义.epub    # 自定义输出文件名
python3 build_epub.py -c cover.png     # 自定义封面图片
python3 build_epub.py -c ""            # 不使用封面
```

打包顺序：前言 → 各卷导读 → 原文译文 → 注释，卷间分页。epub 由 pandoc 生成，pdf 由 calibre 从 epub 转换（同名 .pdf）。

## AI 工程链路

本项目借助以下 AI skill 完成翻译与校对，定义于 `.claude/skills/` 下：

| Skill | 作用 |
|---|---|
| `translate-yoga` | 原文 → 现代汉语翻译，三轮流程 |
| `check-yoga` | 译文校对，标出问题段落 |
| `fix-yoga` | 校对问题的人工/智能判定与改写 |
| `read-yoga` | 导读与词语注释生成，带圈号位置校验 |
| `split-origin` | 原文按语义段落拆分 |

各 skill 内的 Python 脚本均使用相对路径，clone 后即可运行。
